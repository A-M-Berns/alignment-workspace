# Glossary

This is the canonical human exposition of vocabulary. The repository's `state/vocabulary.json` is the canonical machine-readable record of preferred labels, aliases, deprecations, and code mappings. Neither duplicates the other's job.

## Relational structure

| term | meaning |
|---|---|
| **answerability** | The relational status in which another participant, with standing, attributes consequences to you under their practice and can raise a challenge you owe an answer to. “Relational answerability” may be used for emphasis; the bare word always has this meaning. |
| **auditability** | The record property that every liability has exactly one computable fate: discharged, mooted by authorized revision, suspended, or open and charging. Past-self and lifetime-finiteness requirements belong here. |
| **audit discontinuity** | Loss of a burden's identity when the vocabulary in which it was stated is retired. The missing transport object is an auditability problem. |
| **efficacy** | The model-relative transition-system property that exercising a normative power reaches its object under every policy of the other party. The concept is named but not fully analyzed; current evidence is limited to fixture-level independence and grant-invariant artifacts. |
| **objection** | Filed grounds assessed by a declared judge footprint. |
| **objection family** | A reporting class of objections. **Open — unregistered:** in the finite footprint grammar, useful families are computed rather than authoritative inputs. |
| **answering** | A recognized response disposition that addresses a due burden, such as acknowledgment, vindication, or a scorekeeper-recognized suspension. |

## Book and accounting

| term | meaning |
|---|---|
| **bounds** | Constraints the book places on its represented credal states or on an accounted quantity. |
| **holdings** | Signed quantities carried by the book and evaluated against its payoff representation. |
| **leverage** | The technical quantity measuring how far a book's forced interval endpoint clears the relevant threshold. It is not a project name. |
| **charge** | An accounted liability produced by a declared rule. |
| **charges run** | The relevant clock conditions hold, so charge accrues. |
| **cap** | A bound on an accumulated accounted quantity. |
| **fencing** | Separation of declared accounts. **Open — unregistered:** finite round evidence reports that fencing alone does not imply bounded downstream influence for a local edit. |
| **mechanism** | A general construction or rule-governed system. |
| **instance** | A concrete model or fixture instantiating a mechanism. |

## Learning

| term | meaning |
|---|---|
| **eventual route coverage** | The learning criterion that every relevant filed occurrence has an authorized assigned route that eventually reaches a consuming terminal action. It is distinct from the broader Open coverage hypothesis that relevant latent reasons become due. |
| **immanent self-correction** | Reduction of represented recurring failures under edits licensed by the practice's public reasons, without positing an external target of normative correctness. |
| **failure pattern → certified lawful edit → remediable pattern → filing → exposed failure → lesson** | The canonical pipeline: identify a repeatable failure; certify an edit independently of its payoff; represent the remediable pattern; file it; expose an occurrence to the theorem; and interpret the response as a lesson only within the proved scope. |

|---|---|---|
| `C_i(j)` | commitments participant `i` attributes to participant `j` | `commitments` |
| `E_i(j)` | entitlements participant `i` attributes to participant `j` | `entitlements` |
| `K_i(j)` | incompatibilities relevant to `i`'s score of `j` | `incompatibilities` |
| `Due` | a publicly due burden | `due` |
| `Answers` | the answering relation/status | `answers` |
| `A` | finite semantic response space | interface object `response-space` |
| `E_g` | prospective selector compiled from `Due` for repair `g` | `selector` |
| `F_g` | compiled surgical transformation for repair `g` | `transformation` |
| `ℓ_t` | bounded prospective performance loss at date `t` | `charge_vector` |
