## Statement
A class of translations weaker than general computation represents objects
moving between variables and keeps implementation claims non-trivial.

## Source
Stated from its content, under the given parent implementation-boundaries: if
translations may be any general (Turing-complete) computation, nearly any
structure implements any other, so a non-trivial implementation relation needs
a weaker class.
