## Statement
The representation extends from belief changes absolutely continuous with the
current state to changes of the sigma-algebra, so that a value change toward a
target outside the convex hull of the prior's support is represented.

updates meeting the conditions for superconditioning, ie, absolute continuity.
I also want to consider the possibility of sigma-algebra changes, which I think
is not so difficult to do, but perhaps we should study the case without
sigma-algebra changes thoroughly first."
