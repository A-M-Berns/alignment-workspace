## Statement
With the expert's own linearity of expectation and asymptotic introspection,
E^A_n(D_n) → 0 and so E^A_n(±D_n) ≳_n 0; Lemma 1 of the Total Trust implies
Value page applied twice at threshold 0 transfers both bounds to the novice,
giving E^H_n(D_n) ≈_n 0, so the gap-bet theorem's conclusion holds for an
inductor expert without provable introspection and without the diagonalization
step.
