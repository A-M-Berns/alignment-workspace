## Statement
The operator's correction carries information about what the agent values, so
on the algebra that contains the correction the agent's utility depends on it
and the correction changes the agent's information rather than its objective.

## Source

projects/deference/corrigibility-note-dump-2026-10-01/corrigibility-discussion-outline.md
(any change of utility function can be represented as a change in belief in an
expanded sigma-algebra);
projects/deference/corrigibility-note-dump-2026-10-01/value-change-as-epistemic-update.md,
section 4.1: for a Gandhi agent the correction carries no such information
(corrections are noise and resisting them is right), for a corrigible agent in
the author's sense it does (the public copy's wording).
