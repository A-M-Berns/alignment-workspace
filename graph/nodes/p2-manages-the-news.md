## Statement
Conditioning on the legitimacy event strictly prefers voiding a set of states
if and only if the penalty is below the set's mass times the gap in expected
value between the complement and the set; it is invariant to thinning the
probability of legitimacy; and its optimum voids every state below the maximum.
