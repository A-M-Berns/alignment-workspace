## Statement
Implementation as a matter of degree, weighting translations by their
description length, keeps enough objectivity to separate genuine
implementations from trivial ones on moving-object examples.

## Source
A question stated here, given computation-implies-triviality: weighting
translations by description length is one way to block the triviality
arguments for implementation (Hilary Putnam, Representation and Reality, 1988,
appendix; David Chalmers, "Does a Rock Implement Every Finite-State
Automaton?", Synthese 108, 1996).
