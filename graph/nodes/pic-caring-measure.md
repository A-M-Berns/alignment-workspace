## Statement
The agent's weight on an unrealized branch is a caring measure: it cares what
happens in that branch and assigns it prior probability to represent that care,
fixed as UDT fixes it.

## Source
The fully updateless reading of updateless decision theory (Wei Dai, "Towards a
New Decision Theory", LessWrong 2009), in which the prior weight on a branch
represents how much the agent cares about what happens there.
