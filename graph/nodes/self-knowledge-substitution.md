## Statement
In the reflective-oracle framework the agent's source code is unknown while
every code's behaviour is known, and this substitutes in part for the bounded
case, where the code is known and its behaviour is not.

"In Cole's framework, source code must remain unknown, but the behavior of any
given code is always known. These two can substitute for each other, to some
extent; not knowing the source code is somewhat like not knowing code's
behavior."
