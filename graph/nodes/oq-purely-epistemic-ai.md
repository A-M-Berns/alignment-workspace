## Statement
An AI trained in this setting has no misaligned agency, so it can be given a
purely epistemic goal.

## Source
projects/deference/note-dump-2026-08-11/notes/li-deference.md, section 0.3,
"**Purely Epistemic AI**": "Or there might be some strong impossibility
results! Perhaps predictions cannot be purely epistemic, for any number of
reasons.";
projects/deference/note-dump-2026-08-11/related-chats/2026-07-05__theory-of-legitimacy__c1ab54d9.md,
turn 17, the maintainer: "perhaps there can be a legitimate thing that is not
agentic, which could cause some bad self-fulfilling prophecies but does not
optimize for bad outcomes, nor good outcomes."

## Notes
Conditioned on the self-fulfilling-prophecy crux: if every harmful
self-fulfilling prophecy is corruption, a legitimate predictor is already
constrained away from them and the purely epistemic goal is easier to state;
the maintainer himself noted that the opposite answer is "good news for the
epistemic-ai direction" because it separates the two questions.
