## Statement
An explicit epistemic state (P, U, V), with V a sub-sigma-algebra for value
uncertainty, carries a notion of optimal policy that yields updateless or
updateful behaviour in a counterfactual mugging according to which more
predictably serves the agent's true values, and is a distinct object from a
bargaining rule.
