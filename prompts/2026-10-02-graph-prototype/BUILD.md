# BUILD.md: implementation specification for the argument map, version 1

*2026-10-02 (v1: §10 lists what changed from v0 on the maintainer's rulings 31–33). This file tells the coder what to build in this tree. Every item carries a register: **Decided (r·n·)**, ruled by the maintainer in ruling n of `research/prioritization/notes/rulings.md` (C1, C2 are its corrections); **Default**, adopted so that something runs and reversible; **Open**, unsettled, with the v0 choice stated. Where this file and the protocol draft (`notes/protocol-draft-v1.md`) differ, §8 lists the deviation and the ruling behind it. Where this file is silent the order of authority is: rulings, protocol draft, `notes/loop-spec-v2.md`, `notes/ranking-design-v3b.md`. This file stays in the lab; `graph/PROTOCOL.md`, `graph/README.md` and `AGENTS-graph-section.md` are what moves upstream.*

**Build rules.** Python 3.12, standard library only (no YAML library exists there: §2.0 fixes the subset the checker parses itself). `fractions.Fraction` for every number that is compared with a threshold or summed into a status or a value; floats only in the ranking's bit estimates, which are advice. The checker refuses and never repairs. Every derived quantity lives in `graph/derived.json`; `graph/tasks.md` and `graph/view.md` are rendered from it and never edited. Tests enumerate at most a few thousand worlds; nothing runs in parallel. **Decided (r5, r28)** that every number is derived; **Default** for the rest.

## 1. Layout and invocation

```
graph/frame.yaml   graph/nodes/<id>.md   graph/events/<handle>.jsonl   graph/policy.yaml
graph/proposals/P-<n>.md   graph/derived.json   graph/versions.json   graph/tasks.md   graph/view.md
graph/PROTOCOL.md   graph/README.md   graph/DESIGN-LOG.md   chats/<session>.jsonl  (empty here)
checkers/__init__.py   checkers/graph.py   tests/test_graph.py   BUILD.md   FIXTURE-NOTES.md
```

`python3 -m checkers.graph --root <tree>` lints, derives, writes the four committed files (`derived.json`, `versions.json`, `tasks.md`, `view.md`), and exits non-zero on any refusal. **Streams:** `REFUSE <rule#> <path>: <reason>`, `WARN` and the final `OK` line go to stderr; a plain run prints nothing on stdout. **Flag-independence:** the committed files are rendered from the plain derivation in the pooled default (no numbers, unscoped) whatever flags are given; `--scope <id>` (§5), `--as <handle>`, `--why` (§6), `--window-dp`, `--frontier K`, `--lambda x` (§5, all off by default) run a second, personal derivation whose task list and view go to stdout, or to `--out <path>` outside `graph/` (rule 11). `--dry-run` writes nothing and prints the (personal, if flags) derivation as JSON on stdout only; `--print` writes nothing and prints the task list and view. `--self-test` runs the null-input cases (empty tree, missing frame, empty ledger, untouched template) and must fail each, then the synthetic cases of §7. `--registry <CLAIMS.md>` (§4 D4); `--today <date>` (tests). **Default** (protocol §1 paths; checker mandate flags; the stream and flag-independence rules follow the first contributor review).

## 2. File formats

**2.0 Flat YAML.** `frame.yaml`, `policy.yaml` and node frontmatter use this subset, which the checker parses itself and refuses anything outside: `key: scalar`; `key: {flow map}` (a `{k: v, k2: v2}` whose values are scalars or `[lo, hi]` pairs); `key: [a, b]` (flow list of scalars or of flow maps); `key:` followed by indented `- scalar` or `- {flow map}` lines; `key:` followed by one level of indented `sub: scalar` or `sub: {flow map}` lines; `#` comments. Scalars: integers, decimals and `a/b` (both parsed to `Fraction`), `true`, `false`, `null`, double-quoted strings (JSON escapes), bare strings. JSONL is parsed with `json.loads(line, parse_float=Fraction)`. **Default.**

**2.1 `graph/frame.yaml`.** The frame is a node of choice: question, outcome classes, roots with roles, settings; no probability, status or value of its own. **Decided (r7)** for its existence and contents; **Decided (r25)** for the class list as provisional and for utilities placed only by humans; **Decided (r27)** that the outside option is the default trajectory; **Decided (r22)** for window/commitment as the horizon mechanism's two settings; **Default** for every field name and value below.

```yaml
question: How does the relationship between humans and AI systems go, and what can we do about it?
classes:                      # utility: number, [lo, hi], or null (= the whole scale [-1, 1] until placed)
  - {id: disutility-max, utility: -1, severity: 1, placed_by: "@maintainer"}
  - {id: high-conflict, utility: -0.5, severity: 2, placed_by: "@maintainer"}
  - {id: no-interesting-life, utility: 0, severity: 3, placed_by: "@maintainer"}
  - {id: earth-gone-aliens-remain, utility: 0.5, severity: 4, placed_by: "@maintainer"}
  - {id: utopia, utility: 1, severity: 5, placed_by: "@maintainer"}
outside_option: default-trajectory         # a valuation node (r32): the default trajectory, committing to no plan
undescribed_failure: undescribed-failure    # a valuation node (r32): where a failure nobody has described lands
valuations: [default-trajectory, undescribed-failure]   # cases nodes read as distributions over the classes
bar: 0.5                             # a conditional below it at J >= 8 concedes the claim above
establishment_level: 8               # headline V at which a leaf counts as established
commit_level: 6                      # the commit line names no plan whose weakest proof-set leaf is below this V
window_minutes: 360                  # minutes the planner schedules exactly
commitment: [{minutes: 12000, mass: 1, forced_by: placeholder}]   # researcher-minutes before the act is forced
audit_share: 0.1
dependence: independent              # the only model v0 computes; the hull is printed beside it
roots:
  - {id: li-deference-collapse, role: shared-claim, preset: worst-case}
  - {id: deference-toward-bounded-agents, role: plan, preset: worst-case}   # a programme: a frame node (r33), no success_class
  - {id: instrumental-convergence, role: risk-story, preset: probabilistic, budget: 0.5}
```

`role` is `plan | risk-story | shared-claim`; a plan root carries `success_class` (**Decided (r28)**: a plan's value is its success probability times that class's utility plus its failure stories' masses times their classes). `preset` is `worst-case | probabilistic | expected-utility`, a status rule only (**Decided (r28)**); `budget` is required by the last two (§4 D6). Every class carries a `utility` and `placed_by`, a human handle; `provisional: true` is permitted and is printed wherever the number feeds. An unplaced outcome is not a class but a *valuation node* (§2.2, r32): `outside_option` and `undescribed_failure` name `cases` nodes listed under `valuations`, whose rows are classes. Nothing in this file is a value of any root. **Decided (r32)** for the valuation nodes; **Decided (r33)** that a programme root is a `frame` node. **Default** for `commit_level`, `window_minutes`, `commitment`, `audit_share`.

**2.2 Node files.** One Markdown file per node, frontmatter in flat YAML, body sections `## Statement` (one or two factual sentences in the claim's own terms), `## Source` (path, with a verbatim quotation where the attribution is a reconstruction), `## Notes`. Fields on every node: `id`, `kind` (`and | or | leaf | cases | choose | frame`), `children` (the only edge; absent on a leaf), `author` (a handle in `policy.yaml`), `size` (`S | M | L`) with `size_reason`, `version` (an integer bumped whenever the Statement's normalized text changes: apostrophes and quotation marks deleted, every other punctuation mark read as a space, whitespace collapsed, case folded; a committed `versions.json` beside `derived.json` keeps the history), optional `source`, `supersedes`, `superseded_by`, `refines`. A node file never contains a level, credence, status, weight, conditional, value or utility. **Decided (r10)** for `cases` and its rows; **Decided (r1, r12)** that no level is typed; **Default** for the field list, `choose` as a kind, the partition leaf, the `observable` field. Other fields by kind: `discharge` on a hypothesis (`definitional | proved-in-model | restates-conclusion | open`); `statement_of_record` and `hypotheses` (child ids) on a record; `negation_of` on a leaf (the pair are mutual attacks needing no admission); `refines: <picture id>` on a sub-picture that split an existing row (the old picture node stays, gets `superseded_by`, and leaves the table); a row's `class` is an outcome class id, a valuation node id, or null (null on the residual row means the frame's `undescribed_failure` node, elsewhere the outside option, C2 and r32); `residual: true` marks the one row whose weight is derived as the remainder. A **`frame`** node (r33) is a programme: `children` are exactly the ids of its `roots`, a list shaped like `frame.yaml`'s (`{id, role, preset, success_class?, budget?}`), with `question` and an optional `outside_option` (a valuation node of the top frame); it is a plan root of exactly one frame and carries no `success_class` there. A **valuation node** (r32) is a `cases` node listed in the frame's `valuations`, every row's `class` a placed class, `provisional: true` permitted (flag and print). A picture leaf's Statement is the scenario in which the claim fails; a `terminal` leaf says an early failure of a named class ends a deployment. **Decided (r10, r18, r20)**; **Default** for the tag values.

`id` is `<handle>-<suffix>` with the ledger's handle (`anson-001`; rule 5), unique across all ledgers (rule 1); `rule` has the form `YYYY-MM-DD.n` (rule 5). `kind` is `map-read | trace | pass | estimate | gestalt | admit | classify | identify | approve | audit | withdraw | external | attribution | retrospective | survey | rule`; `attribution` (human, not the node's author, `verdict: vouched | disputed`, `ref`) is the only event that clears the attribution-unvetted flag (r33); `rule` on a `cases` node may carry `rows` (`{picture: {w: [lo, hi], p: [lo, hi]}}`, no `w` on the residual row), read as the maintainer's J 8 judgments on those rows, admitting them (r32); `vet`, `revive`, `re-examine` and `reconcile` are task kinds only (their outcomes are other events) and are refused as event kinds (rule 2). `target` is `{"node": id}`, `{"row": [cases id, picture id], "field": "w" | "p" | "class"}`, `{"pair": [id, id]}`, `{"proposal": "P-n"}` or `{"event": id}`. `estimate` is `[lo, hi]` (a range), a class id, `"same" | "positive" | "independent"`, or `"accept" | "reject"`; `trace` may carry `"installment": {"done": 2, "of": 3}`; `estimate` and `gestalt` may carry `"reason"` (any non-empty string makes the judgment J 8); a `gestalt` carries `"derived": false`, an `external` carries `"ref"`, an `audit` targets an event and carries `"verdict": "agree" | "disagree"` (all rule 5; audits are tallied per auditor in `derived.audits`, moving nothing). `question` and `answer` are optional in the prototype and checked only when present (00-common); `verbatim`, `gloss`, `minutes`, `attested_by` are recorded, not checked (`verbatim` is checked against the answer turn when present); The full field table with the checked/recorded split is protocol §5. **Decided (r11)** that an estimate may precede reading and is then J 6, unread-weighted; **Default** for the id form.

**2.5 Proposal** (`graph/proposals/P-<n>.md`): a structural change an agent may not apply alone. **Default**; the finer grain is **Open** (protocol §10.9).

```markdown
---
id: P-1
kind: split                     # merge | split | retarget | sharpen | new-root | edge | class | sub-frame
author: "@smithy-verity"
status: proposed                # proposed | approved | applied | withdrawn
targets: [a1-fixed-objective-maximizer]
ops:
  - {op: new-node, file: P-1/pic-T-kk-training-compatible-goal.md}
  - {op: split-row, cases: a1-fixed-objective-maximizer, row: pic-T-not-reward-maximizers, into: [pic-T-kk-training-compatible-goal, pic-T-rest]}
---
## Change
One paragraph saying what the edit does and why, with the source.
## Delta
Filled by the checker on a scratch copy: per affected root, cost to establish, load, status and value before and after.
```

The checker applies `ops` (`new-node`, `add-child`, `remove-child`, `retarget`, `split-row`, `sharpen`) to an in-memory copy and writes `## Delta`. A proposal whose delta could raise any root's value or lower any cost is applied by the agent only after a counted `approve` event; one that only adds structure, cost or width may be applied on filing, and the checker checks `status: applied` against the ledgers either way.

**2.6 Generated files.** `derived.json`: `{checker_version, anchor_rules, generated_hash, nodes, judgments, roots, events: {counted, withdrawn, stale, stale_reasons}, audits, act, units, units_unranked, ranking, world_model: {components: [{roots, variables, worlds, H_S_bits}], cap_per_component}, lines, digest}`; every Fraction as the string `"p/q"`, bits as floats. `tasks.md` and `view.md`: §6. All four committed files are rendered from the plain derivation and are identical whatever flags the run was given. `DESIGN-LOG.md`: dated entries `- YYYY-MM-DD <change | rollback | confusion> <by> — <one line>`; the checker requires the file and warns on a malformed entry. **Decided (r29)** for the log and its purpose; **Default** for the format. `versions.json`: `{generated_hash, nodes: {node id: [{version, normalized, date}]}}`, maintained by the checker and protected by rule 7 like the other three. The digest lists node-status flips, root-status flips (including a flip through a preset budget, named as such), levels moved, events counted since the previous committed derivation and proposals awaiting approval.

## 3. Refusal rules (numbered; each has a test and a null-input self-test case)

1. Ids unique across nodes, proposals and events; every id in `children`, `rows[].picture`, `hypotheses`, `negation_of`, `refines`, `committed`, `supersedes`, `superseded_by`, every event `target`, and every frame's `roots` resolves; `children` is acyclic; the parentless nodes are exactly the top frame's roots and its valuation nodes; a node is a root of at most one frame. **Default.**
2. Kind and fields agree: a leaf has no children and a `leaf_kind`; an `and` has exactly one completeness child; a `cases` has exactly one partition child, every row's picture is a child picture leaf and every picture child is a row, exactly one row is `residual: true`; a `choose` lies only in a plan root's support closure and has `decided_at`; a hypothesis carries `discharge`; a record carries `statement_of_record`; a formal result (`and` with a record child) has exactly one bridge child with `attribution`; a `frame` has `question` and `roots` naming exactly its children, is a plan root of some frame and nothing else. Unknown `kind`, `leaf_kind`, `role`, `preset`, event `kind`, `how`, `via` or class id is refused. **Default.**
3. Factual-form lint: a Statement containing a word from `policy.yaml`'s `evaluative_words` list (seeded: good, bad, safe, dangerous, promising, works, succeeds, should, might, probably), a plan's success predicate, or no sentence at all, is refused. **Default.**
4. A node file containing any of the keys `level`, `V`, `J`, `credence`, `probability`, `status`, `weight`, `w`, `conditional`, `p`, `value`, `utility`, `load`, `cost`, or a row with `w`/`p`, is refused; a changed Statement whose normalized text differs from `versions.json` without a `version` bump, or a bump with unchanged text, is refused. **Decided (r1, r5)** that no level or number is typed; **Default** for the key list.
5. Ledgers: every event has `id`, `by`, `date`, `rule`, `via`, `kind`, `target`, `version`; `by` is a mapped handle and the file is named for it; `id` begins with the ledger's handle and a hyphen; `rule` matches `YYYY-MM-DD.n`; a level-minting event (`map-read`, `trace`, `pass`) has non-empty `checked` and `not_checked`; `withdraw` names an event by the same handle; `rule` and `survey` are by `maintainer`, which `policy.yaml` must name as a human handle; `admit`, `approve`, `classify`, `identify` are by a human handle; an AI handle may write `estimate` and `gestalt` (each with a non-empty `gloss`, its reasoning; r34) and no level-minting event, `external` or `attribution`; a `gestalt` carries `derived: false`; an `external` carries `ref`; an `audit` is by a human, targets an event and carries `verdict`; an `attribution` is by a human other than the node's author and carries `verdict` (`vouched | disputed`) and `ref`; a `rule` with `rows` targets a `cases` node and names its rows; dates within a ledger are non-decreasing. **Decided (r12, r19, r21, r25)**; **Default** for the field list and the id form.
6. When `question` or `answer` is present, both must resolve to turns of one file under `chats/` and `verbatim` must occur in the answer turn (case-folded, whitespace-normalized); otherwise refused. Absent, the event counts (prototype only). **Default (00-common).**
7. `derived.json`, `versions.json`, `tasks.md`, `view.md` carry `generated_hash` over their content; an existing file whose hash is missing or does not match its content was edited by hand and is refused (deleting it lets the checker regenerate it); a `## Delta` section not matching the checker's recomputation is refused. **Decided (r5)**; **Default** for the mechanism.
8. A class lacks a `utility` or a human `placed_by`; `outside_option` or `undescribed_failure` names no valuation node, or a valuation node is not a `cases` node whose rows all name placed classes; `success_class` names no class; a plan root lacks `success_class` or a programme root carries one; a sub-frame's `outside_option` names no valuation node; a `probabilistic`/`expected-utility` root lacks `budget`: refused. **Decided (r25, r27, r28, r32, r33).**
9. A proposal with `status: applied` or `approved` without a counted `approve` event on it; a proposal `op` naming a missing node or row: refused. **Default.**
10. A row with `residual: true` that is the target of a weight event or a ruled weight; non-residual weights whose midpoints sum above 1; a conditional, weight or gestalt range outside [0, 1] or with lo > hi; a class tag naming no class or valuation node: refused. **Default.**
11. `graph/DESIGN-LOG.md` missing; a file under `graph/` outside the layout of §1; a chats file changed after the commit that added it (checked when the tree is a git checkout, else warned); `--out` pointing inside `graph/`: refused. **Decided (r29)** for the log; **Default** otherwise.
12. Flat-YAML violations (§2.0), a frontmatter without closing `---`, a node file missing `## Statement` or `## Source`: refused. **Default.**
13. Component too large: the world model is enumerated per connected component of roots (roots joined by a shared proof-set element, §4 D9); a component above `MAX_WORLDS_PER_COMPONENT` (2^15) worlds is refused with the component's roots and the world count named. **Default** (the cap; the per-component enumeration follows from `dependence: independent`).

## 4. Derivations, in order (each a pure function; `derive(root) -> derived`)

**D1 Parse and lint** (§2, §3). Build the DAG, `support(x)` = nodes reachable from x through `children`, `roots_of(x)` = roots whose support contains x.

**D2 Resolve events.** Each event is `counted`, `withdrawn` (a later `withdraw` by the same handle names it) or `stale` (its `version` is older than the node's current version; it still counts for its level, and the node wears `stale`; or it is an `estimate` on a node that is now a `cases` node, reason `leaf became a table`: it enters no number and is offered under the residual row's conditional as a suggestion, in `derived.nodes[x].stale_leaf_ranges` and in the unranked unit's note). `derived.events.stale_reasons` gives each stale event's reason. For judgments, the latest counted event per (`by`, `target`, `field`) is that signer's current judgment. **Decided (r19)**; **Default** for latest-wins and the stale-table rule.

**D3 Admission.** A row (and so its picture) is *admitted* when the picture's `author` is a human handle, or a counted `admit` with `"accept"` by any human handle targets the row (including the human whose session drafted it); otherwise *proposed*: it enters no status or probability and sets `under attack` on the claim. A row's `class` tag set by `classify` at any J overrides the frontmatter tag. **Decided (r21)** for unilateral filing and no second person; **Default** for one-word acceptance.

**D4 Levels V.** Per node and dimension (`valid`, `ref`), `V_x` is the largest even anchor k such that every anchor from 6 to k has its event counted on this node in dimension x or `both` (no skipping). Anchors: 2 if the node passes §3 (always, in a passing tree; both dimensions); 4, `valid` only, if the node is a record whose `statement_of_record` resolves under `--registry` to class `lean-proved`, `enumeration-verified` or `witness-checked` (without `--registry` records cap at 2 with a warning); 6 a counted `map-read` with at least one `said` item; 8 a counted `trace` with a said item and complete installments (incomplete displays as the range `6–8 (done/of)`); 10 a second human handle's trace, neither the author nor the first tracer; 12 a `pass` by a non-author whose `checked` lists every admitted picture under the node as answered or conceded; 14 an `external` (with `ref`) by a human handle other than the node's author; 16 `retrospective`; 18 `survey` by the maintainer; 20 reserved. A hypothesis with `discharge: restates-conclusion` is held at 0. Headline `V = min(V_valid, V_ref)` with the weaker dimension named. Flags, none changing V: `under attack`, `conceded by <picture or child>`, `stale`, `stale: leaf became a table` (D5), `attribution unvetted` (bridge or `attribution: reconstructed`; cleared only by a counted `attribution` event from a non-author human, r33; a `disputed` verdict sets `attribution disputed (@handle)`), `provisional` (a valuation node marked so), `no belief`, `withdrawn`, `unread-weighted`, `registry unchecked` (a record without `--registry`; replaces the former warning so a clean run prints only `OK`). **Decided (r1, r2, r12)** for spacing, no rounding, reader behind every level above 4; **Decided (r33)** for the attribution-clearing rule; **Default** for the anchor wording, the two dimensions and the flag list.

**D5 Judgments J and beliefs.** A judgment is a row's `w` or `p`, a leaf's range (`estimate` on a node), a root's `gestalt`, a class tag, or a pair answer. Its J: 0 `generated` for an AI handle's `estimate`/`gestalt` (r34; flag `generated` on the belief and `AI number` on the node; a human judgment on the same quantity supersedes every AI one in the pooled number, the AI events staying counted and listed as `superseded_ai`; several AI judgments alone pool at J 0 as mean and hull with no reconcile task; a J 0 conditional concedes nothing); 6 for a counted human `estimate`/`gestalt` with no `reason` whose signer has no counted `map-read` or `trace` on the target node (flag `unread-weighted`); 8 with a said `reason` or such a read; 10 when two human handles' current ranges intersect (midpoint = mean of midpoints, range = their hull); non-intersecting ranges keep the lower J, display their hull, set `disagreement` and raise a `reconcile` task; 12 after a counted `pass` on the node. Belief: `width = max(floor[min(V_node, J)], hi − lo)` with odd levels interpolated and `min(V, J) < 6` giving width 1 (midpoint shown, `unread-weighted`); a gestalt's floor is read at its own J alone (r33); the displayed range is `[mid − width/2, mid + width/2]` clipped to [0, 1]. The residual row's weight is `1 − Σ` other midpoints (width the sum of theirs, clipped). A vetting event changes width and never a midpoint. **Decided (r2, r11, r12, r34)**; **Default** for the floor table and the J anchors. `derived.roots[r].ai_only` lists the proof-set elements (and the root, for an AI gestalt) whose numbers rest on AI judgments only; the view prints "rests on AI numbers" and the task list appends "vet this AI number" to units on such targets (r34: every display marks them).

**D6 Status** `open | established | conceded`, bottom-up, preset-independent at the node level. Leaf: conceded when its `negation_of` partner is established (a leaf with a story against it has become a `cases` node); established when headline `V ≥ establishment_level`; else open. `cases`: conceded when any admitted row's `p` judgment is below `bar` at J ≥ 8 (a J 6 conditional concedes nothing) or its partition leaf is conceded; established when its own `V ≥ establishment_level`, its partition leaf is not conceded and no admitted row is below the bar at any J; else open. `and`: established when every child is, conceded when any is. `or`: established when any child is, conceded when every child is. `choose`: as `or` when `committed: none`, else its committed child's status. `frame`: as `or` over its plan-role children (its shared claims enter through them). A `question` leaf is open and never established. A `cases` node none of whose rows is admitted has no belief and is held at 1/2 (before, it counted as certainly true). Root-level addition by preset: `worst-case` adds nothing; `probabilistic` concedes the root when admitted failure mass `Σ w·(1 − p)` over the rows of `cases` nodes on its proof set, at midpoints, exceeds `budget`; `expected-utility` concedes when the expected loss `Σ w·(1 − p)·(U(success_class or 1) − U(row class, outside option when null))` exceeds `budget`. A conceded node carries a *diagnosis* (the conceding picture or child) and a *revival cost* (`revive` minutes at its size, or the trace cost of a child with `refines` on the conceding picture if one exists). **Decided (r3, r16, r18, r28)** that presets are status rules and worst-case concedes by one reasoned counterexample; **Default** for the bar, J 8, the budget forms and the revival rule.

**D7 Proof set and costs.** `proof_set(root)`: every child at an `and` (completeness leaf included), the cheapest child at an `or`/`choose`, a `cases` node together with its partition leaf (its picture leaves are scenarios, not conjuncts), a shared leaf counted once; enumerate the `or` choices exhaustively (fixtures have few) and take the cheapest total. `cost(leaf)`: 0 when established; `∞` for a question; `revive` when conceded; else map-read plus trace minutes at its size, trace alone from V 6. `cost(root) = Σ cost(proof set)`; `disproof(root) = min over proof-set leaves of attack[size]`. Costs are minutes as Fractions; the rate rows used are recorded for "why". **Default.**

**D8 Load and margin.** `load(x)` = roots whose status depends on x: roots in whose support x lies that are conceded with x forced conceded and not conceded with x forced established (recompute D6 both ways); a root conceded for another reason is not x's load. Under worst-case the *safety margin* of an open root is the least number of currently established proof-set leaves whose concession concedes it, searched exhaustively up to 3 and reported as `>3` beyond; the view prints it only for open `worst-case` roots, and prints a `probabilistic` or `expected-utility` root's failure mass or expected loss against its budget (`budget_loss`). **Default.**

**D9 Probability and value.** Worlds: each proof-set leaf that is not a `cases` node holds with its range midpoint (a leaf with no judgment makes the root's displayed value *undefined*, flag `no belief`; for the ranking's world model only it is held at midpoint 1/2 with width 1 and the view says which leaves are so held); each `cases` node picks a row at the weights' midpoints and holds with that row's `p` midpoint, and when it fails the failure carries the row's class (null → the outside option's class). A root's `Pr` is the mass of worlds where it holds under D6's logic with every leaf's truth substituted. For a plan root, its value is the expected utility: in a world where it holds, `U(success_class)`; where it fails, the utility of the worst class (lowest utility midpoint, then `severity`) among the failing leaves' classes, or the outside option when none is tagged; `U` of a class is its utility midpoint, and `U` of a valuation node is Σ w·p·U(class) / Σ w·p over its admitted rows at midpoints (lo/hi at the conditionals' and utilities' ends; no belief → 0 for the point, [−1, 1] for the interval; r32). A `frame` root is not valued here: its value is its best non-conceded step's option value, the sub-frame's outside option when every step is conceded, undefined while no step has a value (r33). The interval is `[min, max]` of the value at every leaf `p` at its range's lo and at its hi (weights at midpoints), widened by any `provisional` or null utility's interval. A risk story or shared claim shows `Pr` with its interval and its status, and no value: it enters the comparison through the plans whose tables cite it. A root may carry a *gestalt* (`derived: false`), shown beside the derived `Pr` and never entering status. **Enumeration per component:** roots are grouped into connected components, two roots joined when their proof sets share an element; under `dependence: independent` the components are independent, so each is enumerated alone (its variables are the union of its roots' proof sets; a leaf outside them is false), H(S) is the sum of the components' entropies, a unit's bits are computed in its own component, and plans in other components enter the act as constants (their expected value). A component above 2^15 worlds is refused (rule 13). A scoped query enumerates the union of the components whose variables the scope node's truth depends on. `derived.world_model` lists the components with variable and world counts. **Decided (r25, r27, r28, C2)** that the only value is expected utility on the class scale with untagged failure at the default trajectory; **Decided (r16)** for the gestalt; **Default** for the enumeration, the components, the cap and the interval rule; **Open** whether leaf independence is adequate (the comonotone companion is printed).

**D10 Options and the act.** Options: each non-frame plan root of any frame (a programme's steps are options in their own right, since committing to the programme is committing to its best step and max is associative; a sub-frame's own `outside_option`, where named, is a constant option) with a defined value (derived, or the gestalt in its place when the derived value is undefined or the gestalt lies outside the derived interval) **whose root status is not conceded** (a conceded plan leaves the option set until revived; `derived.act.conceded_plans` names them with their diagnoses), refined through its `choose` nodes (a committed child is taken; an uncommitted `choose` takes the child of highest value), plus the outside option valued at the outside class's utility. `V_act = max`, `cand = argmax`. Commit line: `commit now → cand` when `max D ≤ 0` and cand's weakest proof-set leaf has `V ≥ commit_level`; `research first: begin with <top unit>` when some `D > 0`; `no plan vetted enough to commit to; leading candidate <cand>` otherwise, with any conceded plan appended as `(<plan> conceded by <diagnosis>: not a candidate)`; `no non-conceded plan to commit to (…); the outside option stands until a revival (revive T: ranked unit n)` when every plan in scope is conceded (D is then `null` for every unit); `commit line suspended: no plan has a value yet (no belief on …)` when plans exist and none has a value; `commit line suspended: no plan in scope` when there is none. A step is named through its programme, `F → P`. The revival pointer names the ranked `revive` unit (§5). Where the outside class's utility is `null`, the appendix prints it as `unplaced (read as 0; interval the whole scale [-1, 1])` and the view marks every plan's value interval as the whole scale while it is unplaced (C2, r27). **Decided (r14, r15, r27, C1)**: no viability threshold anywhere in the act; **Default** for the gestalt substitution, the `choose` reading, the exclusion of conceded plans and the line texts; **Open**: observability-contingent choices (`observable`, `runtime`) are parsed and ignored in v0.

## 5. Ranking v0 and the scoped query

**Units.** Observation units, ranked: `vet` (a map-read followed by a trace, one unit valued at its end) on any proof-set leaf or `cases` node below the establishment level; `trace` alone from V 6; `map-read` alone (observes the leaf's truth through a channel with `read_error`); `revive` (r33) on the table a conceded root's diagnosis chain ends at, on any conceded table on a proof set, and on a root conceded by its budget alone: minutes = the revival cost (D6), observation = the target's truth, exact, like a vet; `bears_on` lists the conceded roots it would revive; a programme's steps' units appear in the parent's list bearing on the step and the programme; `gestalt` on a root with no gestalt **and no derived probability** (`Pr_defined` false: a proof-set leaf carries no judgment), listed first, before any bits, since without it the root is outside both terms. Judgment and structure units, listed unranked in a second section ordered by the load of their node: `estimate` on rows at J < 8 (the residual row's conditional carries the stale leaf range as a suggestion, D2), `admit` on proposed rows, `classify` on untagged rows and on uncommitted `choose`/`or` under a plan, `gestalt` on a root with a derived probability and no gestalt (note "no gestalt yet"), `reconcile` on disagreements, `re-examine` on tables past five rows, `approve` on proposals with deltas. **Decided (r15)** that research units include internal nodes; **Default** for the list and the gestalt rule; **Open**: chains beyond `vet`, bundles, dependence questions and installments are not in v0.

**Map term.** `S` = the settled truth (holds / fails) of every admitted root in scope, a plan read along its refinement path; `MAP(u) = H(S) − E[H(S | o_u)]` in bits over D9's worlds, where `o_u` is the target's truth (`vet`, `trace`) or its truth flipped with probability `read_error` (`map-read`). Rate: `MAP(u) / ((task_overhead_minutes + rate minutes) / 60)`. **Decided (r4, r6, r9)** that the ranking is across roots, serves mapping, and is improved rather than overridden; **Default** for bits and the rate.

**Decision term.** One-step: `D(u) = E_{o_u}[max over options of value given o_u] − V_act`, exact over the worlds. `--window-dp` runs the exact dynamic programme over the shortlist of at most 6 units within `window_minutes`; `--frontier K` adds the greedy continuation of ranking-design-v3b §3.3; both off by default. **Decided (r14, r22)**; **Default** for one-step as v0.

**Combination.** The list is ordered by map rate. `D(u)` is printed beside every unit and drives the commit line and the regime sentence; it does not reorder the list unless `--lambda x` is given, in which case `score = rate + x · D / (window_minutes / 60)` and the view says so. Regime sentence: no plan root in scope → "no plan in scope; the decision term is suspended; the order is the map's"; every `D = 0` → "no unit can change the act (<reason>: one plan whose failure stories name no class below the outside option | the leading plan leads in every world | …); the order is the map's"; else "the decision term would reorder k units; shown, not applied". **Decided (C1)**: no ad-hoc rescaling; the two terms are reported separately; **Open**: the combination rule.

**Scoped query.** `--scope <id>` sets `S` to the settled truth of that node (a root or an internal node), restricts units to its support closure, and labels the list "scoped: bits about <id> only". **Decided (r8).**

**Audits.** `audit_share` of the session budget (default budget `window_minutes`) is listed first as one line naming a counted event 7–60 days old by another handle, chosen by a draw seeded with the date (fixed for the day; a new event does not re-roll it), or "no auditable event yet"; it is never scored. An `audit` event records the re-performed check's `verdict`; `derived.audits` tallies agree/disagree and self/cross per auditor. **Decided (r24)**; **Default** for the draw and the tally.

## 8. Deviations from `protocol-draft-v1.md`, with the ruling behind each

1. §4 "One value scale": the two-outcome value `2q − 1` and the "value shown" column of the preset table are gone; every value is expected utility on the class scale and presets are status rules only (r28, C2). The ±1 claim-truth reading survives only as the status display.
2. §4 "Two thresholds" and §6 "outside option valued at the lower threshold": `thresholds`, `viable` and the threshold in the act are removed (C1); the outside option is the `default-trajectory` class (r27); untagged failure is valued there, not at `disutility-max` (C2).
3. §4 preset parameterization: the `conditionals: status` parameter (p read as 1/0/open from a picture's failure claim) is not implemented; every preset reads the bar test on judged conditionals at J ≥ 8 (r16); the expected-utility preset's budget is on expected loss (Default).
4. §6 score `bits/hour + λ·D`: λ is off by default and the two terms are reported separately (C1); the frontier and the window DP are flags, off (checker mandate).
5. §6 gestalt as an observation updating a frame base rate, dependence and kind latents, the three-step triage, hysteresis, staleness discount, installments, chains beyond `vet`, bundles: not in v0 (Open; ranking-design-v3b §6 lists what to measure first).
6. §5 binding rules: `question`/`answer` optional and checked only when present (00-common); `via: obsidian` and `voice` accepted as labels, not parsed.
7. §5 agent conduct: `policy.yaml` `users` gains presentation fields (r26) and `graph/DESIGN-LOG.md` is required (r29); the AGENTS section carries the dialogue-and-revision encouragement.
8. §2 `rows[].class` null now means the outside option's class (C2), and rows gain `residual: true`; sub-pictures gain `refines`; `frame.yaml` gains `success_class`, `outside_option`, `commit_level`, loses `thresholds`, `default_class`, `lambda`, `frontier_units`, `plan_base_rate`.

## 9. Checker notes (the coder, 2026-10-02; for the fixture agent and the reviewer)

`checkers/graph.py` implements §1–§6 as written, with these choices where the text is silent (also listed in `derive.__doc__`) and these facts the fixtures depend on:

1. **Ranges on reads count.** A `map-read` or `trace` event carrying `estimate: [lo, hi]` is both the level event and that reader's range judgment on the leaf (J 8, since the signer has read). Every proof-set leaf, including partition and completeness leaves and the residual row's `p`, needs some range, or the root's value is *undefined* (`no belief`) and only a `gestalt` can stand in for it in the option set; the world model then holds the leaf at 1/2 with width 1 and the view says so.
2. **Ledger naming.** `graph/events/<handle>.jsonl` with the handle's `@` dropped (`@anson` → `events/anson.jsonl`); the file must be non-empty; `by` must be a handle in `policy.yaml`.
3. **Row judgments** target `{"row": [cases id, picture id], "field": "w" | "p"}`; the read-check for J 8 looks at the *picture* node; `admit` targets the row with `"estimate": "accept"`; `classify` targets the row with a class id. A proposed row (AI-authored picture, no admit) enters nothing and flags the table `under attack`; a non-residual row with no `w` shares the remaining mass with the residual and is flagged `no belief`.
4. **Pooling.** Two human ranges at J ≥ 8 that intersect pool to J 10 (mean of midpoints, hull); otherwise the lower J, the hull, `disagreement`, and a `reconcile` unit. A counted `pass` on the node lifts the node's judgments to J 12.
5. **Anchor 12** reads a `pass` whose `checked` items name every admitted picture under the node by id. **Anchor 4** needs `--registry`; records cap at 2 with a warning otherwise.
6. **World model.** Enumerated per connected component of roots (§4 D9): a component's variables are its roots' proof-set elements (a `cases` node is one variable with up to 2 × rows outcomes; outcomes of probability zero are dropped, so a point judgment gives one); a leaf outside them is false; refusal 13 above 2^15 worlds per component. On the fixture the two components enumerate 12 and 2560 worlds (the former joint model enumerated their product, 30 720, and a two-row table took it to 122 880); the plain run takes about 0.4 s and 25 MB. An uncommitted `choose` is refined by trying each child and keeping the highest root value; the value interval is taken at all conditionals low and all high (correct when success is worth at least every failure class). The comonotone companion printed under `alternative_calculations` is the minimum hold probability over the proof set. `--window-dp` and `--frontier` run inside the component of the top-rated unit (`derived.ranking_window.component`).
7. **Scope and plans.** `--scope x` restricts S to x's truth, units to x's support, and the option set to plan roots whose support contains x; fixture 2's "no plan in scope" is asserted under `--scope instrumental-convergence`, since all three roots share one frame.
8. **`--window-dp`** runs the exact adaptive schedule over the top six non-`map-read` units (noisy observations are excluded from the DP); **`--frontier K`** adds v3b §3.3's greedy continuation at each commitment mass point and prints `V_idle`. Both report `D_window` beside `D` and reorder nothing.
9. **Generated files.** `derived.json` and `versions.json` have `generated_hash` over their own canonical dump (`json.dumps(obj, indent=1, sort_keys=True)` with the hash field empty); `tasks.md` and `view.md` end in `<!-- generated_hash: … -->`; `versions.json` gains an entry whenever a node is new or its `version` changed; a proposal's empty `## Delta` is filled, a filled one is checked (rule 7). The four are written from the plain derivation (`derive(t)` with defaults) on every non-dry run; flags produce a second derivation for the personal render. `--dry-run` prints the effective derivation as JSON and writes nothing; `--print` prints the render and writes nothing. A `versions.json` without a hash is refused under rule 7; since every normalized text it stores depends on `normalize_statement`, a change to that function means deleting the file once so the checker rebuilds it (the fixture's was rebuilt when punctuation deletion replaced the earlier partial normalization).
10. **Not in v0** (beyond §8): refusals are reported one at a time (first violation, exit 1), not one per line; `observable`, `runtime`, `subframes`, installments as units, bundles and chains beyond `vet`; the `reason` requirement for J 8 is any non-empty string; `anchor_rules` versions are checked for form, not compared across events; the partition leaf's Statement is not compared with the row list. The fifteen-node synthetic graph of §7 is written by `checkers.graph.synthetic_tree`, shared by `--self-test` and `tests/test_graph.py`; it has fourteen events rather than four so that both plans carry defined values.
11. **Size.** The checker is about 2150 lines and the tests about 620, over the mandate's "about 1500 total"; the flat-YAML parser, the proposal machinery and the synthetic-tree builder are the bulk, and each is separable if the size matters.

## 10. Changes in v1 (2026-10-02; rulings 31–33 and the triage acceptances)

1. **Outside option and residual as `cases` nodes (r32).** `frame.yaml` loses the unplaced classes `default-trajectory` and `residual`; `outside_option` and `undescribed_failure` name valuation nodes listed under `valuations`; a valuation node's value is the renormalized weighted mean of its rows' class utilities (D9); a row's `class` may name a valuation node, and the residual row's null class is the undescribed failure (D3). The maintainer's first weights come as `rule` events with `rows` (§2.3), expanded in D2 into J 8 estimates that admit the rows and are superseded by later estimates like any judgment (latest wins per signer, ledger order within a day). The fixture's `graph/events/maintainer.jsonl` holds the two rulings.
2. **Sub-frames (r33).** `kind: frame`; `all_roots(t)` enumerates every frame's roots, a programme's steps before the programme; D6 reads a frame as an `or` over its plan steps; D10 flattens the option set so the steps are options and `cand_label` names a step through its programme; `derived.roots[r].frame` names the frame each root belongs to and `derived.roots[F].subframe` holds `{question, steps, leading_step, roots, outside_option}`; the view prints a `## Sub-frame F: question` section per programme. What the parent reads from the child: the programme's value, its status, and the steps' units; not the child's lines or order. `--scope x` counts a root in scope when it contains x or lies under x, so `--scope F` ranks within the programme.
3. **Revive unit (r33).** §5 Units; `revive_target` follows the diagnosis chain; the commit line's "until a revival" and "not a candidate" point at the unit's rank; the view's conceded-root line says "ranked as revive T".
4. **Gestalt width (r33).** D5: a gestalt's floor at its own J.
5. **Attribution flag (r33).** Event kind `attribution`; rule 5 shape; D4 clearing rule; `attribution disputed (@handle)` flag.
6. **Illustrative handles removed (r33).** No `illustrative` key; the fixture's events are the two rulings; every table is proposed until a human admits a row; a table with no admitted rows has no belief and is held at 1/2 (before, it counted as certainly true, D9); the commit line says "no plan has a value yet" rather than "no plan in scope" when plans exist without values. Every numeric test moved to the synthetic tree (`synthetic_tree(programme=True, prog_p=…)` adds a programme with two plan steps and a shared claim; `concede_steps` in the tests makes both steps conceded tables).
7. **Checker 0.3**; tests: 61 synthetic and refusal tests plus the fixture class (shape and no-belief state of the starting graph, the sub-frame, the valuation nodes, the table case on a scratch copy).
8. **AI numbers (r34).** Rule 5 lets an AI handle write `estimate` and `gestalt` events with a `gloss`; D5 reads them at J 0 `generated`, superseded by any human judgment on the quantity; `derived.roots[r].ai_only`, the node flag `AI number`, the row flag, the unit's `ai_number` and the "vet this AI number" suffix mark them.
