# Proposed registry entries — protected authority and the free token

**Proposed, not registered.** `CLAIMS.md` does not exist in this repository and
filing is a maintainer act under demand-gating. The four entries are in registry
format so the house checkers adjudicate them today:

```sh
python3 -m checkers.run "$PWD/prompts/2026-08-11-phase-ii-authority/CLAIMS-proposed.md"
```

All four are the same finite model — `M(p)` of
`prompts/2026-08-11-deference-channel/REPORT.md` §1.1 — extended by an execution
layer. The point vector is, in order:

```
P(w0) P(w1) P(w2)
X(wi,pj)          (w0,p0)(w0,p1)(w1,p0)(w1,p1)(w2,p0)(w2,p1)
X(wi,bot)         w0 w1 w2
v+(wi,pj)         same order as X
v^+(wi,pj)        same order as X
Ydel(wi)          the quantity DELEGATE actually realises
Ysimf(wi)         the quantity SIM realises with no execution layer
Ysims(wi)         the quantity SIM realises under strict protection
YcSf(wi)          the quantity the token-responsive conduct c_S realises
V_DEL V_SIMf V_SIMs V_cSf
```

`bot` is the null effect: the execution layer's output when the agent's proposal
is not what the actual report authorises. `X(wi,bot)` is a declared modelling
commitment, pinned per entry.

The 91 constraint rows encode, in order: the credence is a probability vector
pinned to the values used as coefficients in the valuation rows; every carrier is
bounded by `B = 1`; the quantity equals the grade on `Pi`; the null quantity is at
its declared value; `v^+` is `t(n)`-measurable in the coarse reading; `v^+` agrees
with `v+` off the critical cell `{w2}`; `J` and `J-hat` are the claimed least
maximisers by strict margins; **each conduct's realised quantity is the quantity of
the effect its interface actually produces**; `YcSf = Ysimf` pointwise — the token
identity; the four valuations; the three gaps; and the two per-state losses at the
critical event.

The realisation rows are the new content. Everything above them re-states the
Phase I model; the interface question is decided by which quantity each conduct
brings about, and that is what those twelve rows pin.

Names are provisional (`AGENTS.md` standard 6); `REPORT.md` §8 lists them.
