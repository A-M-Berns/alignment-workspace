# For humans

The Φ-regret idea now has a valid bridge, within the deliberately frozen first
environment.

The earlier problem was bookkeeping. A merits response on occasion 1 and the
same semantic response on occasion 2 contained different obligation identifiers,
so online learning saw different actions forever. The new interface gives the
learner eight stable choices—two merits directions, default, and five degrees of
decline—and adds the occasion's obligation identifier only after a choice is
decoded. Nothing normatively relevant is merged: a response with an abnormal
ledger effect is rejected from this representation.

The nine repair rules are now data rather than arbitrary Python functions. They
can inspect a small public reason context but cannot carry a captured tariff or
account. The ordinary certificate check still decides each proposed edit. Exact
tests show that applying a rule before decoding gives the same repository
response and charge as decoding first and applying the repository intervention.

This lets Blum and Mansour's online-learning theorem apply with eight actions
and nine repair programs. For each declared horizon it gives a tuned learner
with sublinear expected charge regret, not a particular sampled path and not
moral correctness. The next round may now build and test the learner, including
whether it needs an anytime schedule. If it achieves the theorem's bound, it
cannot keep assigning a positive fraction of its action probability to a
recurring certified failure that saves a fixed amount. A statement about one
sampled path needs another sampling argument.

The result stops at that boundary. It excludes feedback where an edit changes
later arrivals or service, and it says nothing about failures absent from the
nine-rule class or whether the eventual learner remains answerable while
adopting repairs.
