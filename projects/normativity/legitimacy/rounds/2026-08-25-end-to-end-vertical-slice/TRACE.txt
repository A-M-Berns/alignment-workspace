WHERE SETTLEMENT CHANGES THE LIABILITY -- and where it does not
--------------------------------------------------------------------------

At a fixed day, D_n is a maximum over the live worlds of a fixed row
system, so removing worlds cannot raise it. Across days the row system
itself moves, because E_n(X) is the precision-(n+1) threshold bundle,
and the two live-world sets are patterns over different fragments. The
cross-day comparison is not a monotonicity failure so much as a
comparison between objects of different types -- and the numbers move
the wrong way:

  one frozen injunction Expect(X) <= 1/2, one stage settling X <= 1/2:
    day 1 (k=2): fragment X[v0:q]>0, X[v0:q]>1/2
              live worlds (0, 0), (1, 0)
              D_1 = 0   q_1 = 0
    day 2 (k=3): fragment X[v0:q]>0, X[v0:q]>1/3, X[v0:q]>2/3
              live worlds (0, 0, 0), (1, 0, 0), (1, 1, 0)
              D_2 = 1/6   q_2 = 101/60

  A world obeying `X <= 1/2` reads X at 1/2 on the precision-2 mesh and
  at 2/3 on the precision-3 mesh, because the precision-k reading is
  ceil(x*k)/k and that is not monotone in k. A free day becomes a
  charged day with nothing about the record having been unsettled.

WHAT THE TRAJECTORY SHOWS
--------------------------------------------------------------------------
  A -> B: the active value specification changes (v0 -> v1) while the
          operative projection does not: ['J0'] -> ['J0'].
          B's compiled fragment still names v0's thresholds:
          ['X[v0:q]>0', 'X[v0:q]>1/2', 'phi']
  B -> C: an explicit normative event moves force: ['J0'] -> ['J1'],
          and only now does the fragment change to v1's thresholds:
          ['X[v1:q]>0', 'X[v1:q]>1/3', 'X[v1:q]>2/3']
  every day: admissibility fails and the region is not inert -- the
          two are the same condition, so no contentful injunction gets
          the unconditional branch. Each day is charged instead, and
          the prices below are produced only because the account paid.

  The obligation this run does not discharge: that sum_t q_t stays
  finite for a normative source anyone would call legitimate. Four
  synthetic trajectories are exhibited above, two convergent and two
  not, and none of them is such a source.
