# Locality audit

Status: adversarial correction to PR71; unregistered. All new names are provisional.

## 1. `(CFP)` certifies only exterior-fixed variation

PR71's condition

\[
\beta(q,z)=\alpha(q,\rho(z))\star\epsilon(z)\tag{CFP}
\]

is satisfied when \(R=\{*\}\) and \(q\mapsto\alpha(q,*)\) ranges over arbitrary
complete agent policies. It also allows \(\alpha(q,r)\) to ignore \(r\). Independence of
\(\rho(z)\) from \(q\) is a syntactic fact about an input to \(\alpha\); it does not
imply that any behavior of \(\alpha(q,r)\) is invariant.

Thus `(CFP)` proves exactly one held-fixed claim: \(\epsilon(z)\) is the same exterior
response strategy for every \(q\). PR71's stronger sentence “same residual agent” is
false as written.

## 2. Why projections and named equivalences do not repair it

A map \(\operatorname{res}:A\to R\) with

\[
\operatorname{res}(\alpha(q,r))=r\tag{RP}
\]

can be constant, a payload label, or the canonical second projection after putting the
entire agent policy in the first coordinate. It proves recoverability of the chosen
label, not behavioral invariance. A query projection has the same limitation.

An arbitrary equivalence relation \(\equiv_R\) with
\(\alpha(q,r)\equiv_R\alpha(q',r)\) merely moves the relabeling problem into the
relation. Candidate `(RE)` becomes meaningful only when the relation is generated by
observable behavior.

## 3. Minimal behavioral certificate

Supply a protected residual observation

\[
p_R:\Omega_h\to W_R.
\]

A family of residual observables is equivalent to one product-valued \(p_R\). Define the
extensional relation

\[
a\equiv_{p_R}a'
\quad\Longleftrightarrow\quad
\forall e\in E,\ p_R(a\star e)=p_R(a'\star e).
\tag{ERO}
\]

The required locality condition is

\[
\boxed{
\forall r\in R\;\forall q,q'\in Q^{\rm adm},
\quad \alpha(q,r)\equiv_{p_R}\alpha(q',r).}
\tag{BL}
\]

`(BL)` quantifies over every exterior state, not only \(\epsilon(Z)\). This prevents a
patch from looking local on sampled columns while changing residual behavior against an
unseen predictor or opponent strategy. Restricting the quantifier to a declared
\(E^{\rm adm}\subseteq E\) is legitimate only when the contract explicitly has that
exterior scope.

`(BL)` is sufficient and necessary for the exact claim it states: every behavior
observable through \(p_R\) is invariant under query variation against every scoped
exterior. It is not an intrinsic proof that \(p_R\) contains every behavior an informal
reader calls “residual.” No mathematical interface can derive that semantic boundary
from \(A\times E\to\Omega\) alone. A constant \(p_R\) makes `(BL)` vacuous; a contract
which claims substantive residual protection must authenticate a separating family of
residual observables. Nonconstancy or injectivity of residual labels is a useful audit,
not a theorem field: a genuinely trivial residual is allowed.

A residual projection `(RP)` is optional. It is useful when downstream code must recover
a named residual coordinate, but no Coverage or NCSS proof consumes it. The behavioral
certificate, not `(RP)`, carries locality.

## 4. Three levels

1. **Exterior-fixed variation:** `(CFP)`, with \(\epsilon(z)\) independent of \(q\).
2. **Residual-behavior-fixed variation:** `(CFP)+(BL)` relative to authenticated
   \(p_R\).
3. **Inquiry-local variation:** level 2 plus contract semantics identifying
   \(Q^{\rm adm}\) as inquiry policies and certifying target/applicability preservation,
   exposure, and registration capability.

Cartesian Frames provide level 1 and the universal quantification over exterior
responses used by level 2. The Coverage contract supplies level 3. Coverage's access
calculation can be performed at level 1 over complete policies, but calling the result a
*local agent patch* requires level 2. “Inquiry” is semantic and is not derived from CF.

## 5. Existing CF notions

The repository's `agentSetoid` identifies two agent choices only when their complete
world outcomes agree against every exterior. It is too strong here: a useful inquiry
policy must change receipts. Composing outcomes with \(p_R\) gives exactly `(ERO)` and is
the natural target-relative use of that CF construction.

`MultSubagent` can exhibit an agent carrier \(Q\times R\), but the theorem does not
select which factor is residual, prevent a unit residual, or identify inquiry. Nor does a
product carrier ensure the world behavior attributed to \(R\) is independent of \(Q\).
`AddSubagent` concerns restriction and has no held-fixed residual factor. These notions
can realize a chosen locality certificate but cannot replace `(BL)`.

## 6. Corrected exported object

The minimal local object is

\[
\boxed{
\mathcal P=
(C,Q,R,Z,\alpha,\rho,\epsilon,p_R,Q^{\rm adm},q^{\rm act},\mathsf{BL})}
\]

with `(CFP)` defining \(\beta\) and `BL` proving `(BL)`. Target, applicability, receipt,
and registration-capability certificates remain route/contract data; duplicating them in
\(\mathcal P\) has no locality consumer.

What CF contributes is an ambient agent/exterior counterfactual table and extensional
comparison against all exteriors. What remains supplied by the modeler is the agency
boundary, the protected residual observation \(p_R\), the admissible exterior scope, and
the semantic fact that \(Q\) is inquiry-relevant.

The literal English “only the named local degree varies” is true only relative to the
declared decomposition of world observables: `(BL)` says all protected non-query
observables remain fixed. Requiring equality of complete world outcomes would erase the
inquiry effect itself.
