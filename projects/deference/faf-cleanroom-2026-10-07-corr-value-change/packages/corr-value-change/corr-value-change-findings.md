## F1 — `Val(C)` is the situation-weighted policy value, not the evidential value of a policy event (imprecision, §1.3)

§1.3 defines `Val(C) := ∑_j p_j v_j(a^j)` with `p_j = P(C_j ∣ C)`. In the evidential picture the natural alternative is the value of the event "I follow the installed policy", `Pol = ⋁_j (a^j ∧ C_j)`, namely `E[U ∣ Pol] = ∑_j [P(a^j ∧ C_j)/P(Pol)] v_j(a^j)`. The two coincide iff the weights agree; `TwoStep.condExp_policyEvent_eq_ValC` proves they do whenever `P(a^j ∧ C_j) = c · P(C_j)` for a constant `c` (the chosen act's self-model probability does not depend on the outcome — true when acts are independent of everything *and* the self-model gives the chosen acts equal probability, as §5.7 arranges with "given equal probability"). With a self-model that gives `a_1` probability `3/10` and `a_2` probability `7/10`, say, the two differ. The note's definition is the standard sequential-decision evaluation and is the one every later section uses, so nothing downstream is affected; but §5.2's "the Kolmogorov evaluation `E_P[U ∣ a]` *is* the Jeffrey–Bolker value `V(a)`" does not extend to `Val(C)` without the equal-probability convention. Severity: imprecision.

## F2 — Claim 2's strictness clause is false as stated (local error, §2.4)

The note: "with strict inequality iff the acts `a*_i` are not all optimal under `P`." Both directions fail once ties are allowed, and the statement quantifies over *any* maximizers `a*_i`:
- Strict with every installed act `P`-optimal (refutes "strict ⇒ some `a*_i` not `P`-optimal"; `strict_clause_left_fails`): two outcomes `π = (1/2, 1/2)`, acts `b, c` with branch values `S_1(b) = 1, S_2(b) = 0, S_1(c) = 0, S_2(c) = 1`; both acts are `P`-optimal (value `1/2`), `a*_1 = b`, `a*_2 = c`, yet `Val(accept) = 1 > 1/2 = Val(decline)`.
- Equality with an installed act that is not `P`-optimal (refutes "some `a*_i` not `P`-optimal ⇒ strict"; `strict_clause_right_fails`): acts `aK` with branch values `(1, 1)` and `b` with `(1, 0)`; `a*_1 = b` (ties `aK` in branch 1), `a*_2 = aK`; `Val(accept) = Val(decline) = 2`, yet `a*_1 = b` is not `P`-optimal. (Repair r1: the directions were labelled the other way round before; audit N6.)
(Numbers above are the normalized branch values `E[U_a ∣ E_i]`; the Lean's `S(a, i) = π_i E[U_a ∣ E_i]` is the product form, so `strict_clause_left_fails` shows `1/2` and `0` where this text says `1` and `0`, and `strict_clause_right_fails` `1/2, 1/2; 1/2, 0` for `(1, 1); (1, 0)`: the same examples.) The correct clause: **strict iff the status-quo act `a^K` fails to maximize some branch value `E[U_a ∣ E_i]`** (equivalently iff `E[U_{a*_i} ∣ E_i] > E[U_{a^K} ∣ E_i]` for some `i`), which `good_theorem_strict_iff` proves; the note's clause holds under uniqueness of maximizers (`good_theorem_strict_iff_of_unique`). Lean: `Good.lean` (the two counterexamples are N+ witnesses there). Severity: local error (the inequality itself, the content of Claim 2, is correct).

## F3 — Claim 1's "`a*_i` is one fixed act" needs a tie convention (imprecision, §2.4)

If `Q_i = Q` for all `i`, the installed maximizers `a*_i ∈ argmax_a E_Q[U_a]` need not be one act: with ties the quantifier allows `a*_i` to vary with `i`, and then `Val(accept) = ∑_i π_i E[U_{a*_i} ∣ E_i]` can *exceed* `Val(decline)` (the same example as F2's ⇐ with `Q` uniform). Claim 1 is true when the installed choice is a function of the installed state (`a*` constant), which is the only reading on which the installed agent "has one state"; formalized with that hypothesis (`known_target`), with the tie counterexample (`known_target_tie_counterexample`). The same convention is §2.7's "since `a*` is a function of the vector": it is a hypothesis, not a consequence of maximization — `act_value_hfac_needed` (`Modest.lean`, repair r4) has act-value reflection, maximization and `P`-optimality with the anti-choice `a*_i = !i` (a maximizer at each outcome, not a function of the constant vector) and `Val(accept) = 0 < 1/2 = Val(decline)`. Severity: imprecision (the intended reading is clear; ATTRIBUTION-UNVETTED).

## F4 — The "four grades, each implies the next" chain of §3.4 is false at its second link (local error, §3.4; the mandate's T10(e) sidesteps it)

§3.4: "Four grades are therefore in play: full reflection …; reflection conditional on legitimacy …; act-level agreement, (A) = 0 on this decision; and a net-positive change. Each implies the next." But §2.6 itself shows (R⁺∣L) ⇒ (A) < 0 "generically", and the λ-example at `λ = 1/8` has (R⁺∣L), (A) = `11/20 − 3/5 < 0`, and `Val(accept) = 11/20 < 3/5 = Val(decline)`: conditional reflection implies neither (A) = 0 nor net-positivity. What is true: (R⁺) ⇒ (R⁺∣⊤) ⇒ (A) = 0 ⇒ net-positive (the chain the mandate states, `grades_chain`), and (R⁺∣L) ⇒ (A) = 0 on the `L`-worlds only. Lean: `CondLegit.lean` (`cond_reflection_not_imp_A_zero`, whose fourth clause `Val(accept) = 11/20 < 3/5` is the net-positivity refutation; N+). Severity: local error in §3.4's sentence; the surrounding analysis (§2.6) already has the right picture.

## F6 — Proposition 5.8(c) needs `P(E) < 1` (local error, boundary case, §5.8)

5.8(c): "If instead `Q = P` … reflection holds iff `U` is `P`-a.s. constant on `E`." When `P(E) = 1`, `Q = P = P(· ∣ E)`, and `(P, U)` satisfies desirability reflection for every `U` (it is case (a)); so the "only if" fails unless `P(¬E) > 0`. ## F7 — Proposition 5.8(b)'s pair identity in the sketch assumes `U_Q = U` at both atoms (presentation, §5.8)

The sketch: "On a pair of atoms `{x, y}` it reads, after expanding both sides, `p_x p_y (f_x − f_y)(U_x − U_y) = 0`." The expansion uses `U_Q = U` at both atoms, which the single-atom step gives only where `f > 0`. When `f_y = 0 < f_x` the pair condition reads `U_x = (p_x U_x + p_y U_y)/(p_x + p_y)`, i.e. `U_x = U_y`, so the identity still holds; the gap closes, but the sketch does not say so. Lean: `Prop58.lean`. Severity: presentation.

## F8 — The worked-example formulas hold on a range the note does not state (imprecision, §2.5)

The fixture tests `r, r' ∈ [1/2, 1]` only. ## F11 — "Intrinsic iff (I) = 0" is not an iff (imprecision, §1.4; mandate T3(e))

The first route is introduced as "Suppose the outcomes reveal nothing about the facts, so (I) = 0 and `w_j = v_K`". The converse fails: `(I) = 0` says only that `a^K` is `w_j`-optimal in every outcome (`termI_pos_iff`, contrapositive), which holds whenever the revealed facts do not change the best act, e.g. a teacher whose signal is informative about `F` but too weak to move the agent off the safe act (`r < s` in the §2.5 parametrization gives `(I) = 0` with `w_j ≠ v_K`). So "intrinsic" (nothing revealed, `w_j = v_K`) is strictly stronger than "(I) = 0", and the note's classification of preferences as intrinsic/instrumental by which term they "rest on" has a middle case: a change that reveals facts, changes no informed act, and pays. Lean: `termI_zero_of_uninformative_outcomes` (⇐ direction), `termI_pos_iff`; the converse counterexample is machine-checked as `termI_zero_not_intrinsic` (`Examples14.lean`, repair r4): the weak teacher `weakTeacherPM` (`P(F = j ∣ C_j) = 11/20`) has `a₃` maximizing every `w_j` and `v_K`, `(I) = 0`, `w_A = (11/20, 9/20, 3/5) ≠ (1/2, 1/2, 3/5) = v_K`, and `q(A, C_A) P(K) = 11/160 ≠ 10/160 = q(A, K) P(C_A)`. Severity: imprecision.

## F14 — §2.6's "`(A)` is now generically negative" has an exact form (presentation, §2.6)

Under (R⁺∣L), `(A) = ∑_i [S_L(a*_i, i) + S_{¬L}(a*_i, i) − max_a (S_L(a, i) + S_{¬L}(a, i))]` with `S_L(a*_i, i) = max_a S_L(a, i)`, so `(A) < 0` **iff** for some `i` the installed (`L`-optimal) act is not optimal for the mixture `S_L + S_{¬L}` (`termAep_eq_zero_iff` with `accept_split`); in the λ-example that is `λ < 1/4` (`cond_reflection_not_imp_A_zero` at `λ = 1/8`, `grade_two_separated` at `λ = 1/2`). "Generically" means: unless the `L`-optimal act happens to be mixture-optimal. Severity: presentation.

## F15 — The Savage–evidential map needs the product world and the uninformative-choice assumption for `v_K` only (precision, Appendix B.5; mandate Known issues)

B.5 defines `U_{(c,a)}(f, j) := U(f, C_j, a)` without saying what the Savage state distribution is. The map is well defined when the EDT world carries a fact coordinate and a configuration coordinate (the product model `F × Option J × A`), and the Savage states are `F × J` with `P(f, j) = P(f ∧ C_j)/P(C)` — the facts and outcomes as seen from the change event. With that choice `p_j`, `v_j`, `w_j` agree with the evidential model unconditionally, and `v_K` agrees exactly when the uninformative-choice assumption holds (`edt_eq_savage` for the if side; `savage_needs_uninformative`, repair r4, for the only-if: `infoPM`, whose step-1 choice reveals the fact, has evidential `v_K = 1` and Savage `v_K = 0`). Severity: precision (the note's claim is right; the construction it leaves implicit is this one).

## F16 — Claim 4's equality clause: equality iff the conditional *mean* is unchanged, not iff "no information" (imprecision, §2.4)

§2.4 Claim 4: "Equality holds iff the modification carries no information about `u_{θ,a}`." Under the natural reading of "carries no information" (the outcome independent of `u_{θ,a}` given `ω`) the "only if" is false: equality in the mean-square statement needs only that the outcome leave the *conditional mean* of `u_{θ,a}` unchanged, and an outcome can be informative about `u_{θ,a}` (about its spread) while leaving its mean alone. Instance (`representation_eq_informative`, `Variants.lean`, repair r4; the audit r4 fidelity probe): `u_θ = (−1, 0, 1)`, one act; outcome `true` (mass `1/2`) is `θ = 1`, outcome `false` is `θ ∈ {0, 2}` with `1/4` each; the installed states are the conditionals, so (R⁺) holds; `P(θ = 1 ∧ i = true) = 1/2 ≠ 1/4 = π_true · P⁺(θ = 1)` (the outcome tells the agent whether `u = 0` or `u = ±1`), yet both conditional means are `0` and both mean-square errors are `1/2`. The ⇐ direction (independence ⇒ equality) is right. What is true is the clause the Lean states: equality iff `Ū^{(i)}_a(ω) = Ū_a(ω)` at every `(ω, i)` of positive probability (`msErr_eq_iff`, `representation_eq_iff`, labelled `variant`). Severity: imprecision (the inequality, Claim 4's content, is correct; the equality clause needs "no information about the conditional mean").
