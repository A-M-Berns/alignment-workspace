### 1.2 Definitions, in the post's notation

**Environment** (pseudocode image; transcribed in the thread by "the gears to ascension", 2024-05-21): `U(): if A()=="cross" & provable(False): return -10; elif A()=="cross": return 10; else: return 0`. In the post's gloss: "if the agent crosses the bridge and is inconsistent, then U=-10. (□⊥ means 'PA proves an inconsistency'.) Otherwise, if the agent crosses the bridge, U=+10. If neither of these (IE, the agent does not cross the bridge), U=0." As modal sentences (the reading the machine check uses): $U{=}{-10} \leftrightarrow c \wedge \square\bot$, $U{=}10 \leftrightarrow c \wedge \neg\square\bot$, $U{=}0 \leftrightarrow \neg c$, where $c$ abbreviates $A(){=}\mathrm{cross}$.

**Agent** (same transcription): `A(): if A()="cross" proves U()=10 return "cross"; elif A()="not cross" proves U()=10 return "not cross"; elif A()="cross" proves U()=0 return "cross"; elif A()="not cross" proves U()=0 return "not cross"; else return "not cross"`. Post's gloss: "you search for every 'action implies utility' pair, and take the action for which you can prove the highest utility (with some tie-breaking procedure)" — the proof-based DT that "eliminates spurious counterfactuals in 5-and-10 type problems" (link: "An Optimality Result for Modal UDT"). Terminology note in the post: "initially called MUDT … I now often call it proof-based decision theory, because it isn't centrally a UDT." As a modal fixed point:
$c \;\leftrightarrow\; \square(c\to U{=}10)\ \vee\ \big[\neg\square(c\to U{=}10)\wedge\neg\square(\neg c\to U{=}10)\wedge\square(c\to U{=}0)\big]$
(the two "not cross" clauses and the else return $\neg c$). Note for §3.1: $\square(\neg c \to U{=}0)$ is a theorem of PA outright (it is the environment's third clause), so the fourth `elif` always fires when reached and the `else` is dead code in the agent as written.

**"Respects logic"** (probabilistic version): a distribution that "assigns probability zero to anything which is logically refutable"; later weakened to "it only requires that the agent respects proofs which it can see, and eventually sees the Löbian proof referenced". Bunthut's thread exchange adds the author's clarification (2021-03-30): two notions — probability 0 to refutable, probability 1 to provable — "equivalent if the underlying logic is consistent, but not otherwise".

**Probabilistic agent**: "_if P(cross)=0, cross; if P(¬cross)=0, don't cross; else, take the action with highest expected utility, breaking ties by not crossing._" The first clause is "a version of the chicken rule"; "Choosing to take an action when the probability of the action is zero guarantees that the agent can never prove its own action". **Probabilistic troll**: "_if the agent crosses the bridge due to the P(cross)=0 clause, blow up the bridge._"

**The four chicken rules** (Random Exploration): "(A) … if you prove that you don't take an action, you immediately take it. (B) … if P(A)=0, then do A. (C) Epsilon-chicken: if P(A)<epsilon, then do A. (D) Epsilon-exploration: randomly do A with probability epsilon." Claimed relations: (A) ≈ (B) under "respects proofs", identical if "assigning positive probability to anything not disproven"; (C) generalizes (B); (C) ≈ (D) with the randomness internal vs external. "So we have a chain connecting the chicken rule to random exploration."

**Exploring agent**: "With small probability, explore. If exploring, flip a coin to cross or not cross. If P(cross)=0, cross. If P(¬cross)=0, don't cross. Otherwise, take the max-expected-value action, breaking ties randomly." **Exploring troll**: blows up the bridge "on exploration, or if PA is inconsistent". Also the tie variant: "We then modify the troll's algorithm to blow up the bridge if and only if P(A=cross)=0 or there is a tie."

### 1.3 The Löbian proof (pure-logic version), exactly, and its one presentational hole

Post's proof, verbatim structure (bullets = subproof depth):
- Reasoning within PA: Suppose the agent crosses.
  - Further suppose that the agent proves that crossing implies U=−10.
    - "Examining the source code of the agent, because we're assuming the agent crosses, either PA proved that crossing implies U=+10, or it proved that crossing implies U=0. So, either way, PA is inconsistent — by way of 0=−10 or +10=−10. So the troll actually blows up the bridge, and really, U=−10."
  - "Therefore (popping out of the second assumption), if the agent proves that crossing implies U=−10, then in fact crossing implies U=−10. By Löb's theorem, crossing really implies U=−10. So (since we're still under the assumption that the agent crosses), U=−10."
- "So (popping out of the assumption that the agent crosses), the agent crossing implies U=−10."
- "Since we proved all of this in PA, the agent proves it, and proves no better utility in addition (unless PA is truly inconsistent). On the other hand, it will prove that not crossing gives it a safe U=0. So it will in fact not cross."

The "either way, PA is inconsistent" step, spelled out (reavowed 2019-08-31 and Diffractor 2021-10-14 in the thread; my restatement): write $L := (c \to U{=}{-10})$. Under $\square L$ and $c$: the code gives $\square(c\to U{=}10)\vee\square(c\to U{=}0)$; with $\square L$ and the provable incompatibility of the utility values, $\square\neg c$. Then $\square\neg c \to \square(c \to U{=}10)$ (vacuous implication), and PA knows its own code, $\square(c\to U{=}10)\to c$, so $\square\square(c\to U{=}10)\to\square c$; hence $\square c$; with $\square\neg c$, $\square\bot$ — Diffractor: "it happens to be a con(PA) theorem that the agent can't prove in advance what it will do, ie, ¬□(¬cross)". Then $c \wedge \square\bot$ is the troll's condition: $U{=}{-10}$.

**Stuart Armstrong's hole (2019-10-13, no reply in the thread) and its repair [derived].** "You use Löb's theorem within an assumption sub-loop. This seems to assume that from 'A→(□B→B)', we can deduce 'A→B'. But this cannot be true in general! To see this, set A=□B→B." Correct as a criticism of the *presentation*: the pure-logic proof applies Löb inside the "Suppose the agent crosses" subproof. It closes by reordering, and closes *because of the specific shape of the sentence*: what the inner derivation establishes is $c \to (\square L \to U{=}{-10})$, which is propositionally equivalent to $\square L \to (c \to U{=}{-10}) = \square L \to L$ — Löb's hypothesis for $L$ itself, with no assumption open. Löb then gives $\vdash L$. Stuart's schema $A\to(\square B\to B)\ \Rightarrow\ A\to B$ is indeed invalid in general, but here $B = L$ is a conditional whose antecedent is $A = c$, so $A \to (\square B \to B')$ with $B = (A\to B')$ *is* $\square B\to B$. The probabilistic version in the post is already written in the repaired order ("Suppose □(A=cross→U=−10); Suppose A=cross; …; Therefore, A=cross→U=−10; Therefore □(…)→(…)", then Löb). Machine check: `tb_modal.py` V0 reports both "PA ⊢ c → (□L → U=−10)" and "PA ⊢ □L → L" true, and "PA ⊢ L" true — §3.1. So the [sequence-map](../sequence-map.md) §5.3 open item ("whether Stuart Armstrong's Löb-inside-a-subproof objection … is a real gap") is settled: a gap in exposition, not in the theorem.

### 1.4 The probabilistic version, exactly

Setup: $P$ respects logic (refutable ⇒ probability 0; provable ⇒ probability 1 — the post's "since the agent is certain of things which are provable"). Agent and troll as in §1.2. Proof (post's order):
- Suppose $\square(A{=}\mathrm{cross}\to U{=}{-10})$.
  - Suppose $A{=}\mathrm{cross}$.
    - "Examining the agent, either crossing had higher expected utility, or P(cross)=0. But we assumed □(A=cross→U=−10), so it must be the latter. So the bridge gets blown up."
  - Therefore $A{=}\mathrm{cross}\to U{=}{-10}$.
- Therefore $\square(A{=}\mathrm{cross}\to U{=}{-10})\to(A{=}\mathrm{cross}\to U{=}{-10})$; by Löb, $\square(A{=}\mathrm{cross}\to U{=}{-10})$.
- "Therefore, since the agent is certain of things which are provable, the agent assigns expected value -10 to crossing. Since the expected value of the other action will always be higher than this, and since we know the agent doesn't ever really enter into the P=0 conditions, the agent will choose not to cross."

Two implicit premises, made explicit [derived]: (i) the inner step "either crossing had higher expected utility, or P(cross)=0" needs PA to reason about $P$ — $P$ must be PA-representable and the agent's code PA-transparent (the post's "Examining the agent"); (ii) "crossing had higher expected utility" is refuted under $\square L$ because certainty of provable things gives $P(U{=}{-10}\mid \mathrm{cross}) = 1$ whenever $P(\mathrm{cross})>0$, while $P(U{=}0\mid\neg\mathrm{cross}) = 1$ always ($\neg c\to U{=}0$ is a theorem) — so $EU(\mathrm{cross}) = -10 < 0 = EU(\neg\mathrm{cross})$ and the tie-break is never reached. **Refinement of the conclusion [derived]:** the clause "since we know the agent doesn't ever really enter into the P=0 conditions" is not needed for the pessimistic verdict. Case $P(\mathrm{cross})>0$, $P(\neg\mathrm{cross})>0$: EU-branch, does not cross, $U=0$. Case $P(\neg\mathrm{cross})=0$: does not cross by the second clause. Case $P(\mathrm{cross})=0$: crosses by the chicken clause, and *that* is what the troll punishes, $U=-10$. So the agent never obtains $+10$, whatever $P$ does at the boundary; the post's remark "It isn't weighing the risk; it's decided that the worst outcome is inevitable" and "no matter what overall probability it assigns to P(A=cross)=0" hold with the boundary cases included. The post's "the utility of the bridge getting blown up could be -0.000001, and the agent still won't cross" is exact: the proof uses only that $U{=}{-10}$ is provably below $U{=}0$ — the numerical values never enter.

The exploring version's proof (post): under $\square(\mathrm{cross}\to u{=}{-10})$ and cross on a round, "I can only be crossing the bridge for two reasons — either this is an exploration round, or P(cross)=0. In either case, crossing the bridge yields payout u=-10." Same Löb closure. The LIDT variant is asserted, not proved ("I omit the proof here"): "LIDT might successfully cross for a long time, apparently learning that crossing is safe … Then, one day, it finds the Löbian proof and stops crossing the bridge!"

### 1.5 The analogy to Smoking Lesion (post's five points, verbatim heads)

"An agent is at risk of having a significant internal issue" (medical / logical inconsistency); "The internal issue would bias the agent toward a particular action" (smokes / "an inconsistent agent crosses the bridge"); "The internal issue also causes some imagined practical problem" (cancer / the troll); "There is a chain of reasoning which combines these facts to stop the agent from taking the action" (EDT's correlation / the Löbian proof); "We intuitively find the conclusion nonsensical." Gloss: "both EDT and proof-based decision theory evaluate actions by adding them to the knowledge base and seeing what the world looks like under that additional assumption … proof-based DT reasons about actions as if they're observations. That's the fundamental idea of evidential decision theory." And: "I've come to think of Troll Bridge as 'the real smoking lesion', since I'm generally not satisfied with how smoking lesion is set up" (link: P01). Point 2 is load-bearing for the theorem, not decoration — §3.1 shows the Löbian proof fails when the inconsistent agent does *not* cross.

### 1.6 The RL non-example and the conclusions

RL: "the RL agent can get past the bridge if its prior expectation that crossing is a good idea is high enough … Troll Bridge is about the inevitable confidence that crossing the bridge is bad … The RL example seems similar in that it depends on the agent's prior." The strengthened troll ("punish crossing unless the crossing is justified by an empirical history of crossing being good") makes RL fail "no matter what" but "You're just messing with these agents … of course you don't put your hand in the fire if you get burned every single time you try it. There's nothing wrong with the way the RL agent is reacting!" Conclusions: the catch-22 (chicken rule needed against spurious proofs, exploited by Troll Bridge); dropping the chicken rule "is very severe. We cannot simply drop the chicken rule and open the gates to the (much more common!) spurious proofs"; "Troll Bridge was originally invented to counter proof-length counterfactuals"; "Another possible conclusion could be that Troll Bridge is simply too hard, and we need to accept that agents will be vulnerable to this kind of reasoning."

### 3.1 The pure-logic version in the letterless fragment of GL (`P11-scratch/tb_modal.py`)

1. **V0 confirms Eisenstat's theorem exactly**: the agent does not cross, PA proves $c\to U{=}{-10}$ and does not prove $c\to U{=}10$, and Löb's hypothesis $\square L\to L$ is provable (so the §1.3 repair of Stuart's presentational hole is verified: the inner derivation $c\to(\square L\to U{=}{-10})$ and the popped form $\square L\to L$ are both theorems).

3. **V3/V4: where Stuart's point bites, the author's repair works — and produces a different pathology.** For the agent that searches only the $U{=}10$ level with default `cross`, the Löbian proof fails and the agent crosses safely (V3). ### 3.2 Troll Bridge as a v2 tree (`P11-scratch/tb_v2.py`, output `tb_v2.out`)

**Tree $\mathrm{TB}(\theta,\varepsilon_x,\pi)$** (Definitions 5–6). Root chance node: $\mathrm{bot}$ with probability $\theta$ → leaf world $(\mathrm{bot}{=}1,\mathrm{cross}{=}1,\mathrm{src}{=}\text{forced})$, payoff $-10$ (the chicken clause fires in the inconsistent world and the troll acts). $\neg\mathrm{bot}$ with probability $1-\theta$: an optional exploration chance node with probability $\varepsilon_x$ → fair coin → cross (payoff $-10$ if the troll punishes exploration, $\pi = 1$; else $+10$) or not ($0$); otherwise the decision node $d = (s,\ \top,\ \{\mathrm{cross},\mathrm{not}\})$ → cross $+10$, not $0$. Procedure $C(d)(\mathrm{cross}) = q$. **The observation is $\top$** — the agent cannot tell a $d$-run from a forced or exploratory run — which is the v2 image of "the agent cannot prove its own consistency" (and, for exploration, of an agent that does not know when it explores; [P13](../repair/P13.md) P13-10 treated the *informative* case, $d$ reached only on $e=0$ and the state calibrated there, and found it harmless — this section is the complementary, conflating case).

Strictly calibrated state at $O=\top$ (Definition 8): $P_s(\mathrm{cross}) = \theta + (1-\theta)\tfrac{\varepsilon_x}{2} + (1-\theta)(1-\varepsilon_x)q$, and the evidential act value
$$V_s(\mathrm{cross}) \;=\; \frac{-10\theta + 10(1-\theta)\tfrac{\varepsilon_x}{2}\sigma + 10(1-\theta)(1-\varepsilon_x)q}{\theta + (1-\theta)\tfrac{\varepsilon_x}{2} + (1-\theta)(1-\varepsilon_x)q}, \qquad V_s(\mathrm{not}) = 0.$$
At $\theta = \tfrac1{10}$, $\varepsilon_x = 0$: $V_s(\mathrm{cross}) = 10\,\tfrac{9q-1}{9q+1}$, zero at $q^\ast = \tfrac19$.

Results [checked, `tb_v2.out`, exact rationals; five parameter settings]:

## 6. Smoking Lesion, the tickle defence, and mixed-strategy ratifiability

**Smoking Lesion.** Register: structural claims about the TB tree, checked; the identification of the tree with the post's problem is derived and carries the losses of §3.2. The post's "the real smoking lesion" is right in this sense: Troll Bridge is the lesion problem (§7.3's (S1)+(S3): an upstream common cause, an uninformative observation) in which (i) the common cause is unobservable *in principle* — Gödel II replaces the stipulation that the agent cannot introspect — and (ii) the lesion-branch act is *forced* rather than drawn. Because of (ii), Proposition 11 (inconsistency for everyone under (S3)) does not bite: the act-event is realized off the decision node, coverage fails, Lemma 3's screening-off applies inside $\mathrm{occ}(d)$ but not to the act-event, and the population correlation between the lesion and the act is *real* and *calibrated* at $O = \top$ (P11-11, P11-13). Proposition 11 says P01-style Smoking Lesion cannot even be consistently posed for a calibrated agent; Troll Bridge *can* — and that is why it is the better lesion. For [L1](../repair/L1.md) / [C1](../repair/C1.md)'s fairness grid: a row "forced-act lesion, $O=\top$" — honest at the strict, limit and masked grades for $q\in\{0,q^\ast,1\}$ / $\{0\}$ / both; not recorded at $d$; not covered; the correlation dislocated from the decision node (in ID-27's vocabulary, [C1](../repair/C1.md) to grade "decision-determined" — the payoff depends on $\mathrm{cross}$, which the decision fixes only on $\neg\mathrm{bot}$).

**The tickle defence.** Eells's move needs the agent's knowledge of its own inclination to screen off the common cause; Proposition 12 is its v2 form (lesion-informative observations). In Troll Bridge that knowledge is exactly knowledge of one's own consistency, which Gödel forbids: the tickle defence is blocked in principle, not by stipulation (P11-13). P03's "strong tickle defence" (self-knowledge of *policy* screens off correlations) also fails here, and the tree shows why: knowing the policy "cross iff the EU clause says so, else forced" does not screen off $\mathrm{bot}$, because the policy's own output depends on $\mathrm{bot}$ through the forced branch — the correlation runs through the agent's machinery, as P04 already said ("part of the environment correlating itself with your internal machinery"). What survives in v2 is the *occurrence* version: per-run SSC conditions on being consulted and needs no observation (Remark 3.10, "the calibration notion that does not presuppose evidence-events") — so v2's replacement for the Gödel-blocked tickle is conditioning on $\mathrm{occ}(d)$, i.e. subjective-state calibration [scrubbed] ([sequence-map](../sequence-map.md) §5.1 item 3, read). Remark 3.9's second cost of masking ("deletes the resource the tickle defence runs on") is moot on this problem: there is no resource to delete.

**Mixed-strategy ratifiability.** The TB tree has three calibrated-and-approved labels including a properly mixed interior one, $q^\ast = \theta/(1-\theta)$ at $\varepsilon_x = 0$ (a tie point, Remark 4.3's mechanism; multiplicity, Remark 5.2) — a small worked instance for [C2](../repair/C2.md). Two morals. (1) P05's theorem ("mixed-strategy ratifiability implies CDT=EDT") fails on this tree at the pessimistic label: the evidential value of crossing is $-10$ while every tree-intrinsic causal value is $+10$, at a strictly calibrated ratifiable label — because P05's implementability (the act's only parent is the decision) is violated by the forced branch, the same violation Diffractor raised in P03 ("would think CON(PA) causally downstream") and the author there predicted "Troll Bridge will end up formally outside the realm where LLC can be justified"; the tree makes the prediction exact — flag to [C2](../repair/C2.md) and [P05](../repair/P05.md). (2) The Löbian proof is a *selector* among ratifiable labels that always picks the worst; ratifiability as an existence theory (Kakutani, C2's SE-18′) says nothing about which label an agent that computes its own label reaches — the post is the sequence's strongest evidence that selection, not existence, is where mixed-strategy ratifiability needs a theorem.

**Representability; what v2 can state; is Told-You-So Troll Bridge with an announcer?** v2 can state the *equilibrium*: the tree $\mathrm{TB}(\theta,\varepsilon_x,\pi)$ of §3.2 with $O_d = \top$ has the pessimistic label $q = 0$ strictly and limit-calibrated and $T_{\mathrm{EDT}}$-approved, with the limit-calibrated counterfactual $P(\mathrm{bot}\mid\mathrm{cross}) = 1$ (P11-11, P11-12); it cannot state the *selector* — the Löbian proof that forces that label for every prior — nor the Gödelian necessity of $O=\top$, nor the identity of the forced crosser with the deliberator (§3.2 "what the tree captures and loses"). **Definition 12 and the chicken rule; spurious proofs.** The chicken rule (B) is the negation of zero-respecting; v2 takes no side — Definition 12 is a description (Import A), Told-You-So mugs one policy and the TB tree the other (P11-9). v2 has no spurious proofs because no procedure computes its own state: the fixed point is the problem's, selected externally (§5), so the chicken rule's job is done by the type.
