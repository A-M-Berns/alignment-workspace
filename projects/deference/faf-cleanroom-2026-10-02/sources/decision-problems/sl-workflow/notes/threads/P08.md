### 1.2 Thesis

Two further arguments that a causal agent's counterfactual expectations should equal its evidential (conditional) expectations — offered as indirect support for P05's implementability assumption ("these considerations are only arguments for implementability in that they're arguments for CDT=EDT") — plus a major caveat restricting both to actions taken arbitrarily often:

(A) **Learning.** Counterfactuals should satisfy *truth-from-truth* ("counterfacting on what's true should result in what's true") and, for learning agents, *non-correctibility* ("you should not be able to systematically correct your counterfactuals"). A causal agent in an "unfair" matching pennies whose counterfactuals say the untaken action would have paid $1$ has correctible counterfactuals (expectation $1/2$ per action, realized payoff $0$ always) — a defect of the counterfactuals, not of the environment.

(B) **Tiling.** Sam Eisenstat's logical-induction tiling result and Alex Appel's probabilistic-tiling sketch both assume that the expected utility of the specific action taken equals the expected utility of "taking some action" without knowing which; equality of counterfactual with evidential expectations is a *sufficient* (not shown necessary) way to satisfy it, so "a condition for reflective stability of CDT is that it equal EDT".

(C) **The Major Caveat.** Both arguments are "restricted to moves which the agent continues to take arbitrarily many times as it learns about the situation it is in"; nothing follows for never-taken actions, and CDT and EDT "may end up taking entirely different actions in the limit" (XOR Blackmail). The author's intuition: such cases are UDT's, not counterexamples — "a class of decision problems for which rational CDT agents converge to EDT in terms of actions taken", excluding problems requiring updateless reasoning, XOR Blackmail among the excluded.

### 1.3 Definitions, principles and arguments in the post's own words

**Implementability (restated).** "when the agent implements a mixed strategy, its randomization is successfully controlling for any factors other than those involved in the decision to use that particular mixed strategy. Stated in bayes-net terms, the action has no parents other than the decision." The justification "had to do with the learnability of the causal connections" (P07: "parents of the action will _look like children_ if you try to perform experiments to see what happens when you do different things", `posts/07-…md` line 73, READ).

**Truth-from-truth.** "there is _one_ desirable property which is very clear: _**counterfacting on what 's true should result in what's true**._ You might get a strange alternative system of mathematics if you ask what things would be like if 2+2=3, but counterfacting on 2+2=4 just gets us mathematics as we know it." Applied to decisions: "When we consider situations where an agent fully understands what decision problem it's in (so we are assuming that its map corresponds perfectly to the territory), this means that counterfacting on the action which it really takes in that situation, the counterfactual should tell it the true consequences of that action. However, it is less clear how to apply the principle for learning agents."

**The Bayesian case and its limits.** "In the purely Bayesian case, one might argue that the prior is the equivalent of the true circumstance or decision problem; the best an agent can do is to respond as if it were put in situations randomly according to its prior. However, this doesn't give any guarantees about performance in particular situations; in particular, it doesn't give guarantees about learning the right counterfactuals. This becomes a somewhat more pressing concern when we move beyond Bayesian cases to logical induction, since there isn't a prior which can be treated as the true decision problem in the same way."

**Non-correctibility (the learning principle).** "I propose the following principle for learning agents: _**you should not be able to systematically correct your counterfactuals.**_ The principle is vaguely stated, but my intention is that it be similar to the logical induction criterion in interpretation: there shouldn't be efficient corrections to counterfactuals, just like there shouldn't be efficient corrections to other beliefs." Its relation to truth-from-truth: "If we run into sufficiently similar situations repeatedly, this is like the earlier truth-from-truth principle: the counterfactual predictions for the action actually taken should not keep differing from the consequences experienced. The principle is also not so strong that it implies opening the scary door."

**The example (unfair matching pennies).** "Consider a very unfair game of matching pennies, in which the other player sees your move before playing. In the setup of [Sam's logical induction tiling result], where the counterfactual function can be given arbitrarily, the most direct way to formalize this makes it so that the action takes always gets utility zero, but the _other_ action always _would have yielded_ utility one, if it had been taken." Dynamics: "The CDT agent doesn't know at the time of making the decision whether the payoff will be 0 for heads and 1 for tails, or 1 for heads and 0 for tails. It can learn, however, that which situation holds depends on which action it ends up selecting. This results in the CDT agent acting pseudorandomly, choosing whichever action it least expects itself to select. The randomization doesn't help, and the agent's expected utility for each action converges to 1/2, which is absurd since it always gets utility 0 in reality. This expectation of 1/2 can be systematically corrected to 0." The evidential agent: "An EDT agent who understands the situation would expect utility 0 for each action, since it knows this to be the utility of an action if that action is taken. The CDT agent also knows this to be the conditional expected utility if it actually takes an action; it just doesn't care." The third option: "Although the EDT agent and CDT agent do equally poorly in this scenario, we can add a third option to not play, giving utility 1/4. The EDT agent will keep going after the illusory 1/2 expected utility." — **Note (typo in the post, [derived] from the sentence's own logic):** the agent chasing the illusory $1/2$ is the *causal* one; the evidential agent, expecting $0$ from playing, takes the $1/4$. The sentence as printed says "EDT"; I read it as "CDT" throughout and flag this as P08-0 in the verdict table.

**Sam's "unfair environments" versus the author's reading.** "Sam's theorem assumes that we aren't in a situation like this. I'm not sure if it came off this way in Alex's write-up, but Sam tends to talk about cases like this as unfair environments: the way the payoff for actions depends on the action we actually take makes it impossible to do well from an objective standpoint. I would instead tend to say that this is a bad account of the counterfactuals in the situation. If the other player can see your move in matching pennies, you're just going to get 0 utility no matter how you move." Consequence: "If we think of this as a hopelessly unfair situation, we accept the poor performance of an agent here. If we think of it as a problem with the counterfactuals, we want a CDT agent to be arranged internally such that it couldn't end up with counterfactuals like these. Asking that counterfactuals not be systematically correctible is a way to do this." Literature pointer: "It looks like there is already an argument for EDT along similar lines in the academic literature: _[The Gibbard-Harper Collapse Lemma for Counterfactual Decision Theory.]_" (Fusco; §3.5 below reads the paper.)

**Dutch book (conjecture).** "We can get a CDT agent to bet against the correctible expectations if we give it a side-channel to bet on which doesn't interfere with the decision problem. However, while this may be peculiar, it doesn't really constitute a Dutch Book against the agent. I suspect a kind of Dutch Book could be created by asking it to bet in the same act as its usual action (so that it is causally conditioning on the action at the time, and therefore choosing under the influence of a correctable expectation). This could be combined with a side-bet made after choosing. I'm not sure of the details here, though. EDIT: Yes, we can dutch-book it."

**Sam's tiling assumption, in Alex Appel's words (quoted by the post).** "The key starting assumption effectively says that the agent will learn that the expected utility of selecting an action in the abstract is the same as the expected utility of selecting the specific action that it actually selects, even if a finite-sized chunk of the past action string is tampered with. Put another way, in the limit, if the agent assigns the best action an expected utility of 0.7, the agent will have its expected utility be 0.7, even if the agent went off-policy for a constant number of steps beforehand." The author: "The part about 'even if a finite-sized chunk of the past action string is tampered with' is not so relevant to the present discussion. The important part is that the expected utility of a specific action is the same as that expected without knowing which action will be selected."

**Three ways to satisfy it.** (i) "if the agent learns to accurately predict which action it will select. The expectation of this action equals the expectation in general because the expectation in general already knows this action will be taken." (ii) "if the counterfactual expectation of each action which the agent might take equals the evidential expectation of that action. In other words, the CDT expectations equal the EDT expectations. This implies the desired condition because the counterfactual expectations of each action which the agent believes it might take end up being the same. (If there were a significant difference between the expectations, the agent could predict the result of its argmax, and therefore would know which action it will take.)" (iii) "a more exotic way, where the counterfactual expectations and the evidential expectations are not equal individually, but the differences balance each other out. I don't have a strong argument against this possibility, but it does seem a bit odd." Conclusion: "I don't have an argument here that CDT=EDT is a necessary condition, but it is a sufficient one." Fair-problem property or design constraint? "The stronger condition of knowing your own action isn't a feasible design constraint; some circumstances make your action unpredictable (such as 'I'll give you $100 - [the degree of expectation you had of your action before taking that action]'). We can, however, make the counterfactual expectations equal the evidential ones."

**Diff's tiling result.** "the conclusion of Sam's theorem is that an agent won't envy another agent for its _actions_, but _not_ that it won't self-modify into that other agent. It might envy another agent for _counterfactual_ actions which are relevant to getting utility. Indeed, counterfactual mugging problems don't violate any of the assumptions of Sam's theorem, and they'll make the agent want to self-modify to be updateless." Diff's (Alex Appel's) result "is very preliminary … His first assumption states that concrete expected utility of an action takes equals abstract expected utility of taking some action, along very similar lines to the critical assumption in Sam's theorem."

**The Major Caveat.** "The arguments in this post are all restricted to _moves which the agent continues to take arbitrarily many times as it learns about the situation it is in._ The condition for learning counterfactuals, that they not be systematically correctible, doesn't mean anything for actions which you never take. You can't Dutch Book inconsistent-seeming beliefs which are all conditional on something which never happens. And weird beliefs about actions which you never take don't seem likely to be a big stumbling block for tiling results". Then: "even if counterfactual expectations and conditional expectations are equal for actions which continue to be taken arbitrarily often, CDT and EDT may end up taking entirely different actions in the limit. For example, in XOR Blackmail, CDT refuses to respond to the letter, and EDT responds. Both expect disaster not to occur after their respective actions, and both are right in their utility forecasts." COEDT "define[s] the conditional beliefs for actions we don't take, but where is the argument that counterfactual beliefs must equal these?" The trembling-hand route: "We could argue that CDTs, too, should be limits of CDTs restricted to mixed strategies. This is very much the intuition between trembling-hand Nash equilibria. We then argue that CDTs restricted to mixed strategies should take the same actions as EDTs, by the arguments above, since there are no actions which are never taken. This argument might have some force if a reason for requiring CDT to be the limit of CDTs restricted to mixed strategies were given." The XOR intuition: "It strikes me as a case correctly resolved by UDT, not CDT. Like counterfactual mugging, counterfactual actions of the agent factor in to the utility received by the agent; or, putting it a different way, a copy of the agent is run with spoofed inputs (in contrast with Newcomb's problem, which runs an exact copy, no spoofing). This means that an agent reasoning about the problem should either reason updatelessly about how it should respond to that sort of situation, or doubt its senses (which can be equivalent)." Closing: "my intuition is that there is a class of decision problems for which rational CDT agents converge to EDT in terms of actions taken, not only in terms of the counterfactual expectations of those actions. This class would nicely rule out problems requiring updateless reasoning, and include XOR Blackmail among them."

### 1.4 Stated assumptions (collected)

1. A learning agent repeatedly facing "sufficiently similar situations", so that frequencies of realized payoffs per action are available (the LI-criterion analogy presupposes a sequence of trials).
2. The counterfactual function "can be given arbitrarily" (Sam's setup) — counterfactuals are a free parameter the agent's internals must discipline.
3. For the tiling argument: Sam's key assumption as glossed by Appel; and the "not so relevant" clause about tampering with a finite chunk of the action string is set aside.
4. For the Dutch-book conjecture: a bet placed *in the same act* as the action (evaluated causally) plus a side bet placed *after* the act (evaluated evidentially) — made explicit only in P09/P12.
5. For the Major Caveat: XOR Blackmail with a perfect predictor as P06 sets it up (the letter is sent iff exactly one of {disaster, agent would pay} holds), where CDT refuses and EDT pays under ε-exploration.
6. Throughout: "CDT" is the steelman of P07's header — "some kind of steel-man of CDT which uses logical counterfactuals rather than physical counterfactuals. TDT is a CDT in this sense" (P07, READ).

### 1.6 Load-bearing claims extracted for the audit (the P08-n list)

- **P08-0** (editorial): the "EDT agent will keep going after the illusory 1/2" sentence has the theories swapped.
- **P08-1** Truth-from-truth is a "very clear" desideratum on counterfactuals; for a decision problem the agent fully understands, "counterfacting on the action which it really takes … should tell it the true consequences of that action".
- **P08-2** Non-correctibility: a learning agent's counterfactuals should admit no efficient systematic correction; for repeated similar situations, the counterfactual prediction for the action actually taken should not keep differing from the experienced consequences.
- **P08-3** In the unfair matching pennies as formalized in Sam's setup, a causal agent whose counterfactuals say "the other action would have yielded 1" acts pseudorandomly, its per-action expectation converges to $1/2$, it always receives $0$, and the expectation is correctible to $0$; an evidential agent expects $0$; with a third option worth $1/4$ the two part company.
- **P08-4** This is "a bad account of the counterfactuals", not an "unfair environment" (against Sam's framing); a causal agent should be "arranged internally such that it couldn't end up with counterfactuals like these", and non-correctibility is a way to arrange it.
- **P08-5** Fusco's Gibbard–Harper collapse lemma is "an argument for EDT along similar lines".
- **P08-6** A side-channel bet against the correctible expectation is not a genuine Dutch book; a same-act bet plus a post-act side bet probably is (EDIT: it is — P09).
- **P08-7** Sam's tiling assumption is that the expected utility of the specific action taken equals the expected utility of "selecting an action in the abstract"; CDT=EDT (counterfactual = evidential expectation for every action the agent might take) is sufficient for it, via the argmax-predictability argument; necessity is not claimed.
- **P08-8** "Knowing your own action" is not a feasible design constraint (the $\$100 -$ expectation example); equating counterfactual with evidential expectations is.
- **P08-9** Sam's theorem concerns envy of another agent's *actions*, not self-modification; counterfactual mugging satisfies its assumptions yet motivates self-modification toward updatelessness; Appel's probabilistic tiling has the analogous first assumption.
- **P08-10** The Major Caveat: all arguments concern actions taken arbitrarily often; never-taken actions are unconstrained ("You can't Dutch Book inconsistent-seeming beliefs which are all conditional on something which never happens").
- **P08-11** In XOR Blackmail, CDT refuses and EDT pays; both forecast no disaster after their act and both are right — so equality of expectations at taken actions does not force equality of actions in the limit.
- **P08-12** "CDTs, too, should be limits of CDTs restricted to mixed strategies" (trembling-hand) would close the gap, if a reason for it were given.
- **P08-13** XOR Blackmail is UDT's case (a copy run with spoofed inputs), so there should be a class of problems — excluding those requiring updateless reasoning — on which rational causal agents converge to evidential *actions*, not only expectations.

### 2.2 The two principles, stated in v2 (post-specific question 1)

**Truth-from-truth (TFT).** *At a queried point $d$ with $P_{s_d}(a^\ast) = 1$: $\mathrm{cf}_{s_d}(a^\ast) = (P_{s_d}, V_{s_d})$.* [derived] This is exactly what Definition 20's evidential criterion says at a self-certain state (P13-6, READ: "Definition 20 restricted to the realized act at a self-certain state; it is *not* a consequence of success"). Objectively (the post's "map corresponds to territory"): at a Definition-7-recorded node under strict calibration the state is certain of the act about to be taken (Remark 3.6) and $V_{s_d}$ is the true conditional payoff (Definition 8 clause 2), so TFT says the supposed state at the realized act *is* the true statistics of the branch — Definition 7's recording plus Definition 20 at positive acts, as the mandate anticipated. Relation to v2: **weaker** than Definition 20 (which also binds every *other* positive act), **stronger** than v2's default (success only): v2 posits nothing beyond success and files TFT under Q6's "rules for $\mathrm{cf}_s$ beyond success" — P2:faithful FA-25′(1′) (READ) derives Definition 20 at positive acts from strict OC + recording + counterfactual calibration to any of R1-state/R2-real/R3, which contains TFT as the $P_{s_d}(a^\ast) = 1$ case.

**Non-correctibility (NC).** *At a queried point $d$, for every act $a$ the agent takes with positive (or tremble-reachable) probability, $\mathrm{cf}_{s_d}(a)$ equals the tremble-evidential referent $\mathrm{R3}(a) := \lim_{\varepsilon \to 0}\big(\nu_{B,C^\varepsilon}(\cdot \mid a \wedge O_d),\ \mathbb E_{\mu_{B,C^\varepsilon}}[r \mid \cdot \wedge a \wedge O_d]\big)$* — counterfactual calibration in Remark 3.11's sense, to the referent Remark 3.9's advice-stance route names, read as the $\varepsilon \to 0$ shadow of a learner (Remark 5.4). [derived] Relation to v2: this is **not** one of v2's adopted definitions — v2 declines to calibrate $\mathrm{cf}_s$ by default (Remark 3.11: doing so "would be ruled miscalibrated in Newcomb's problem by definitional fiat") and lists R3 as "a third candidate referent" (Remark 3.9) — so NC is **stronger** than v2's default. It is **weaker** than Definition 20 read on all of $A_d$ exactly at nulled, tremble-unreachable acts (selection nodes: FA-17′(b), Told-You-So's $d_5$), where R3 is undefined and NC says nothing — which is the post's own Major Caveat. And it is **the same** as Definition 20 at positive acts wherever the point is Definition-7-recorded with a realized observation (FA-20′). The post's "systematically" and "efficiently" have no static content; the finite tree gives exact statistics.

The **difference between the two principles**, in v2: TFT constrains $\mathrm{cf}_s$ at one act (the realized one) and is a *counterfactual theory* (Definition 20, subjective — no statistics consulted); NC constrains it at every positive act and is *counterfactual calibration* (objective — Remark 3.11's family). The post presents NC as a generalization of TFT for learning agents ("If we run into sufficiently similar situations repeatedly, this is like the earlier truth-from-truth principle"); v2's typing shows the generalization crosses the subjective/objective line Definitions 19–20 draw — the reason Remark 1.2(ii) sorts "agreement with conditioning" under counterfactual theories and "equating $\mathrm{cf}_s$ with objective deviation statistics" under calibration.

### 3.3 P08-2, P08-3, P08-4 — non-correctibility and the unfair matching pennies

**Provenance (new, [checked] by fetch).** The example is Alex Appel's, not the author's. ### 3.4 P08-5 (Fusco) and P08-6 (Dutch book)

REFINED.** The lemma (Fusco §3, p. 5): given Gibbard–Harper's characterizing axiom Consequence 1, "$A \supset (S \equiv (A \Box\!\!\to S))$" — derived from Modus Ponens and Conditional Excluded Middle, and equivalent in Lewis's framework to Strong Centering (fn. 10) — "the Egan credence on $s$ in $a$ reduces into the conditional credence in $s$ given $a$": $Cr(a \Box\!\!\to s \mid a) = Cr((a \Box\!\!\to s) \wedge a)/Cr(a) = Cr(s \wedge a)/Cr(a) = Cr(s \mid a)$, so "$Val_{Jeffrey}(a) = U_{Egan}(a)$" — Egan's "future-directed" CDT, which conditions on the act one is about to perform, *is* EDT; §3.1 shows the collapse survives Lewis's chance-consequent reformulation. ### 3.5 P08-7 and P08-8 — the tiling assumption, and "knowing your own action"

**The assumption, stated in v2 [derived].** Appel's gloss (quoted by the post) and his formula "$\mathbb E_n(U(a^\ast_{1:n-1}, a^{\ast n}_{1:\infty})) = \mathbb E_n(U(a^\ast_{1:n-1}, \underline{a^\ast_n}, a^{\ast n}_{2:\infty}) \mid a^\ast_n = \underline{a^\ast_n})$" (Probabilistic Tiling, READ; my reading of the mangled typography: the expected utility of "some action is taken" equals the expected utility conditional on the action actually taken being taken) have, at one queried point $d$, the form

## 5. Smoking Lesion, the tickle defence, and mixed-strategy ratifiability — what this post contributes

**To mixed-strategy ratifiability (MSR).** (i) Route (ii) of P08-7 *is* MSR's indifference signature: a calibrated-and-approved label with a properly mixed support has equal act values across the support (Remark 4.3; C2-9's MSR, READ), and P08 is the post that says why this matters beyond decision theory — it is the condition under which an agent's evaluation of "what I will do" and of "what I am doing" coincide (Appel's abstract $=$ concrete). (ii) P08's "$\$100 -$ expectation" environment and the selection-forcing tree $S_{\mathrm{sel}}$ (checks D–E) are two cases where the *optimal or forced* calibrated label is properly mixed, so "knowing your own action" fails while "knowing your mixed strategy" holds — evidence, from the sequence's own side, for v2's decision to force self-transparency of the *mixture* (Proposition 7) rather than of the act, which is exactly the version of the tickle defence the author favours (P03's "strong tickle defense", sequence-map glossary READ) and the literature does not (C2 §5, READ, not re-derived here). (iii) P08's demand for "a reason for requiring CDT to be the limit of CDTs restricted to mixed strategies" is answered in C2-7/C2-8 (READ): with the act values R3-extended at nulled acts, MSR exists at a point *without* trembles (Kakutani on a continuous best-reply correspondence; equivalently Skyrms's deliberational equilibrium), so trembles are needed not for existence at the point but for off-path discipline across points (Lemma 2) and for the EDT $=$ UDT theorem (item 16). P08's trembling-hand intuition was right about the refinement and wrong about where it is needed.

**To the tickle defence.** (i) Non-correctibility is the counterfactual-slot analogue of the tickle defence's self-knowledge: at a Definition-7-recorded point, self-knowledge (Remark 3.6) screens the act off from the lesion (Lemma 3; Proposition 12) *and* collapses every $O_d$-conditioned referent onto conditioning (FA-20′) — so on the tickle instantiation P08's thesis holds in its strongest form: causal and evidential act values coincide for every self-location weighting, and both smoke (P05-2/-3, READ). (ii) P08 exposes what the tickle machinery needs: *recording*, not merely self-knowledge. Under masking (Definition 9) "the resource the tickle defence runs on" is deleted (Remark 3.9), but R3 is still total (FA-17′(b)), so a *limit*-calibrated agent keeps both the tickle defence and non-correctibility — a point in favour of Remark 3.9's preference for Definition 10 over Definition 9 that the post supplies from the learning side ("the counterfactual predictions for the action actually taken should not keep differing from the consequences experienced" is Definition 10's learning gloss).

**To Smoking Lesion.** (i) The see-the-move stipulation "the other action would have yielded 1" is to $\mathrm{cf}_s$ what (S2) is to $P_s$: a stipulation about the agent's opinion that no instantiation of the tree realizes (Proposition 11's structure, transposed; Import 4).
