### 1.2 Rows in full

**T1. Decision-point.** *B:* SC Def 9.1 — $d_i = (\hat{\mathbf X}_i, A_i, u_i)$: a probability space (world-model), a finite set of basic actions, and $u_i : A \times X_i \to \mathbb R$ with $A = \prod_j A_j$ the *joint* action space; $U_i(O) = \mathbb E_{\mathbf X_i}[u_i(O, \cdot)]$. *A:* Def 3 — $d = (s_d, O_d, A_d)$, $s_d = (P_s, V_s, \mathrm{cf}_s)$ (Def 2), $O_d \in \mathcal E$, $A_d$ finite pairwise-disjoint non-$\bot$ events; identity of points is exact identity of the triple (Remark 2.2), and one point may label many nodes (its fiber, Prop 5). *Dictionary:* $\hat{\mathbf X}_i \leftrightarrow (\mathcal E, P_{s_d})$ (finite case exact: v2's worlds are the atoms; B's standing assumptions — countable, discrete, finite entropy — exclude v2's finitely-additive charges and infinite designated meets, §0–1, App. A); $A_i \leftrightarrow A_d$ (B's actions are labels, A's are events — the Jeffrey–Bolker reading, Remark 2.1); $u_i \leftrightarrow$ nothing in the point: A's stakes are leaf payoffs $r(\ell)$ supplied by the *problem* (Def 5, Remark 3.5), and the point carries only a subjective desirability $V_s$, which equals conditional expected payoff under calibration (Def 8 clause 2); B's $u_i(O, x)$ takes the *joint profile* as argument, which in A is an event only once $\mathcal E$ carries policy coordinates (Remark 4.2, Q1). B has no observation slot: Part II's decision-points are already-updated world-models ($\mathbf X_i = \mathbf X(\cdot \mid \bar e_i)$ is the updateful case of Remark 13.2), whereas A's $O_d$ is a readable component of the point (Remark 2.1). B's index $i$ plays the role of A's *point*, not A's node — so B's joint outcome space $A = \prod_i A_i$ is A's space of deterministic procedures on the queried points, $\prod_{d} A_d$, **not** A's assignment space $\prod_q A_{d_q}$; Prop 5(b)'s "constant on fibers" is exactly the passage from the latter to the former. *Grade:* approximate. *Why:* same three ingredients (beliefs, actions, stakes), but B puts the stakes and the joint dependence inside the player and leaves observations out; A puts observations inside the point and stakes in the tree.

**T2. Policies.** *B:* notation §2.4 — full policy $\pi : \mathcal R O \to \mathcal R A$ (deterministic function on all observations, internal and external); effective policy $\Pi^\dagger = `\beta_{D_B}`_A$ (what is implemented; a coarsening of the boundary dynamics $D_B$); chosen policy $\Pi^*$ (what would be implemented absent modification); external policy $\ddot\Pi$, $\ddot\pi(\ddot o) = `\rho_{d_{I,B}}(\ddot o)`_{\ddot A}$ (external observations → external actions, a subvariable of $D_{I,B}$). *A:* Def 4 — a procedure $C : (d : \mathcal D) \to \Delta(A_d)$, deterministic when point-valued; Prop 5(a) — an assignment $\pi$ on decision nodes, $\pi(q) \in A_{d_q}$, not required to be constant on fibers. *Dictionary:* B's full policy ↔ A's deterministic procedure restricted to queried points, with B's domain $\mathcal R O = \mathcal R(\dot O, \ddot O)$ matching A's $(s_d, O_d)$ (internal observation ↔ state; row T16) — approximate, because A's procedure is also defined on the *state* component and may be mixed. B's $\Pi^\dagger \ne \Pi^*$ (an instance forced off its chosen policy by the side channel) ↔ A's assignment that is not constant on a fiber — analogous only: A's type forbids per-node deviation outright (Remark 2.2, "deviate at this occurrence only is not an operation the type supports"), so the *possibility* B models has no A object. B's $D_B$ beyond $\Pi^\dagger$ (implementation detail) ↔ none: A's problems are functions of $C$ (Remark 3.1, "oracle access, no source code"), so mechanism is quotiented away by the type. *Grade:* approximate / analogous / none as stated. *Why:* A's type is B's external-only, extensional projection with the state folded into the domain.

**T3. Decision-determination (DD) and the three "fairnesses" (brief B PC-13).** *B:* notation §2.7 — (1) $U$ is a function of $E$; (2) $\Pr(E = e \mid D_{I,B} = d_{I,B}) = \Pr(E = e \mid \ddot\Pi = `d_{I,B}`_{\ddot\Pi})$ — "the external policy is the only agent-intrinsic quantity that impacts the environment". Origin: Yudkowsky's "all agents who make the same decision receive the same payoff regardless of which algorithm produced the decision" (quoted in topics/decision-determination, §4.11 below). Lean form (`Substantive.lean`): `satisfiesDecisionDetermination U := ∀ w₁ w₂ π, consistent π w₁ → consistent π w₂ → U w₁ = U w₂`. *A:* Remark 3.1 — the extensional shadow $\widehat B : C \mapsto \Delta(\Omega \times \mathbb R)$ "is a function *of* $C$", which "already secures extensionality: oracle access, no source code"; trees add structure but are still functions of $C$ (Def 6). *Dictionary:* B's clause (2), read as "the environment depends on the agent only through its input–output function", is **automatic in A** for the input–output function on *points*: there is no $D_{I,B}$ to respond to. The Lean form is literally "$V_B$ is a function of $C$" and holds in A by Def 6. But B's clause is stated for the *external* policy $\ddot\Pi$ — a function of external observations only — whereas A's procedures are functions of $(s, O, A)$ and a tree may route two points with the same $(O, A)$ and different states to different subtrees; B would count that as the environment responding to internal state ($\dot O$-dependence of behaviour), i.e. as a DD failure. So B's DD = A's type-extensionality **plus** observation-functionality ("queried points with equal $O_d$ carry equal $(P, V)$" — Def 19's example, Remark 4.4), and the second half is a *normative criterion* in A, not a type fact. Brief B's PC-13 ("extensionality of the environment, which your tree type already guarantees") is therefore right about the extensionality half and silent about the external-only half. Soares's fairness — "decision theory is for making bad outcomes inconsistent" — is a **third** notion, formalized in A as Def 16 / Remark 3.13 ($\delta$-inconsistency); it is not DD. *Grade:* approximate (exact for clause (2) on point-policies; the external-only clause corresponds to Def 19 / Remark 4.4). *Why:* A's type is the mechanism-free quotient B's DD asks the environment to respect; A's point-identity is finer than B's observation-identity.

**T4. Harmony and the bargaining game.** *B:* SC Def 10.1 — a profile is *harmonious* if "no decision-point has a profitable unilateral deviation that modifies the computation of any other decision-point's action" (I/O-preserving modifications trivially equivalent); Def 10.2 — the bargaining game $\mathcal G$: strategies $(b_i, \mathcal A_i)$ (batna, finite acceptable set), outcome $\mathrm{sel}(\bigcap_i \mathcal A_i)$ if nonempty else the batna profile $b$; Def 10.3 welfare selection; Def 10.4 — harmony is *identified with* (audit headline 7: "defined as") trembling-hand equilibrium of $\mathcal G$; Thm 11.1 — harmonious outcomes are not subjectively Pareto-dominated (proved with the $\varepsilon$-gap); Remark 11.4 — no uniqueness. *A:* Def 22 — $C$ is $B$-coherent iff $V_B(C[d \mapsto a]) \le V_B(C)$ for every queried $d$, $a \in A_d$ ("a procedure-level Nash condition of the many decisions against each other"); Thm 2 identifies it with EDT+SSA ratifiability; comment (iii): "neither condition is sufficient — multiplicity of ratifiable policies is exactly Remark 5.2's multiplicity"; P1:synthesis item 25 amends it to mixed deviations $m \in \Delta(A_d)$. Def 23 — conflict-freeness for a family $\mathcal M$ of moral patients $D_i \subseteq \mathcal D$: no joint deviation on $D_i$ improves $\mathbb E_\mu[r \mid \mathrm{occ}(D_i)]$. Conjecture 1 — the spectrum from trivial $\mathcal M$ (contains $V$-optimality) to maximally fine $\mathcal M$ with event-conditioning (Prop 10's myopia). *Dictionary:* Def 22 is the Nash condition of the *identical-interest action game* (players = queried points, strategies $\Delta(A_d)$, common payoff $V_B$); harmony is the trembling-hand equilibrium of a *different* game (batnas + acceptable sets, heterogeneous $U_i$), whose homogeneous case (Thm 13.1) selects the *global optimum* — A's $T_{\mathrm{opt}}$ (Def 18), which is strictly stronger than Def 22 [checked, §2 XC-1: the two-point Stag Hunt is Def-22-coherent at $(H,H)$ under every mixed unilateral deviation, value $1 < 2$]. Def 10.1's "modifies the computation of another decision-point" has as its A-shadow the fact that a point deviation $C[d \mapsto m]$ changes *every* node in the fiber (Remark 2.2) — A cannot express "modify another point's computation" at all (row T24). Def 23 with coalitions ↔ B's acceptable-set intersections (coalition proposals) — analogous; Conjecture 1's endpoints ↔ SC §14's mixed theory: trivial $\mathcal M$ = one epistemically coherent cluster (Thm 13.1), maximally fine $\mathcal M$ with event-conditioning = every point its own decision-point with $\mathbf X_i = \mathbf X(\cdot \mid \bar e_i)$, exactly the updateful case Remark 13.2 says admits Pareto-suboptimal equilibria. *Grade:* analogous. *Why:* both are non-cooperative fixed-point conditions among a problem's decisions; they differ in the game (action game vs bargaining game), the payoffs (common $V_B$ vs subjective $U_i$), and the refinement (none vs trembling-hand).

**T5. Trembling-hand equilibrium vs tremble-consistency.** *B:* SC Def 10.4 — $\sigma^*$ is a trembling-hand equilibrium if there are perturbed games $\mathcal G^\epsilon$ (every strategy played with probability $\ge \epsilon$) and Nash equilibria $\sigma^\epsilon$ of $\mathcal G^\epsilon$ with $\sigma^\epsilon \to \sigma^*$ (Selten 1975). *A:* Remark 3.12 — $\Sigma$ is *tremble-consistent for $C$ w.r.t. $T$* if for every sufficiently small $\varepsilon$ some instantiation $B_\varepsilon \in \Sigma$ is strictly calibrated for $C^\varepsilon = (1-\varepsilon)C + \varepsilon\,\mathrm{Unif}(A_d)$ (Def 10) and $T(C, B_\varepsilon)$ holds — "the procedure must be normative against its own trembled statistics, honestly instantiated"; P1:fair-repair FR-11 applies it to the concrete tree with states freed (tremble-EDT-consistency) and proves $V$-optimality on strongly fair, fully recorded, realized-observation trees; FR-12: optimal $\not\Rightarrow$ tremble-EDT (off-path tie) — a strict refinement. *Dictionary:* same device (full-support perturbation making off-path evaluation payoff-relevant — B: "every proposal has a small chance of being the only one on the table"; A: "at every $\varepsilon > 0$ the calibrated state has both actions subjectively possible", Remark 3.9), different carrier and quantifier: B perturbs *all players'* strategies in $\mathcal G$ and takes a *limit of equilibria*; A perturbs the *agent's own procedure* uniformly across points and requires the *untrembled* $C$ to be $T$-approved at every small $\varepsilon$ against $C^\varepsilon$-generated statistics, with the *states re-instantiated per $\varepsilon$* (calibration has no B analogue). A itself notes Def 10 matches Kreps–Wilson consistency (Remark 5.3); B's is Selten's perfection; both are "trembling-hand perfection transposed" (Remark 3.12 verbatim). *Grade:* approximate. *Why:* one device, two games; A's version couples the perturbation to belief-honesty, B's to payoff-relevance only.

**4.1 Remark 13.2 in full** — SC §13.2 (TRUSTED; unproven, DNI-5):

> **Remark 13.2.** Classical UDT arises from $\mathbf{X}_i = \mathbf{X}$, *not* from conditionalized priors $\mathbf{X}_i = \mathbf{X}(\cdot \mid \overline{e}_i)$ for observation events $\overline{e}_i$. If instances update to their conditionalized beliefs, they disagree about which outcome is best (an instance observing $\overline{e}_i$ evaluates outcomes as $\mathbb{E}_\mathbf{X}[u(\cdot) \mid \overline{e}_i]$, which differs across $i$). This disagreement allows Pareto-suboptimal outcomes to survive as equilibria.
>
> The UDT prescription — do not update before acting — is precisely the prescription to maintain $\mathbf{X}_i = \mathbf{X}$, ensuring unanimous agreement on the globally optimal outcome and hence a unique harmonious profile.
>
> This gives a decision-theoretic *justification* for the UDT prescription via harmony. The policy-before-updating rule is not an assumption; it is what all instances would agree to adopt *before* any of them receives their observation, because maintaining $\mathbf{X}_i = \mathbf{X}$ (rather than updating) is the unique strategy profile ensuring a harmonious outcome. Updating breaks harmony by introducing disagreement.

**4.3 Harmony and the equilibrium concept** — SC §10:

> **Definition 10.1 (Harmony).** A strategy profile $\sigma = (\sigma_i)_i$ is *harmonious* if no decision-point has a profitable unilateral deviation that modifies the computation of any other decision-point's action. Modifications that leave all input-output relationships unchanged are considered trivially equivalent.

> **Definition 10.4 (Trembling-Hand Equilibrium).** A strategy profile $\sigma^*$ is a *trembling-hand equilibrium* of $\mathcal{G}$ if there exists a sequence of perturbed games $\mathcal{G}^\epsilon$ (in which every strategy is played with probability at least $\epsilon > 0$) and corresponding Nash equilibria $\sigma^\epsilon$ of $\mathcal{G}^\epsilon$ such that $\sigma^\epsilon \to \sigma^*$ as $\epsilon \to 0$.
>
> Harmony is identified with the trembling-hand equilibrium condition: a strategy profile is harmonious iff it is a trembling-hand equilibrium of $\mathcal{G}$.

**4.4 Definition 3.5 (calibration, same ontology)** — SC §3.4:

> **Definition 3.5** (Calibration; same-ontology). When $Q = P$, the anticipation structure $(\overline{A}, \kappa)$ is **calibrated** if:
>
> $\mathbf{P}(\cdot \mid \overline{a}) = \kappa_{\overline{a}}(\cdot) \quad \text{for all atoms } \overline{a} \text{ with } \mathbf{P}(\overline{a}) > 0. \tag{Cal}$
>
> Conditional on anticipation state $\overline{a}$, the agent's current beliefs equal the intended future beliefs $\kappa_{\overline{a}}$.

**4.5 Definition 6.2 (calibrated refinement model)** — SC §6.3:

> **Definition 6.2.** A **calibrated refinement model** for $(\hat{\mathbf{P}}, \hat{\mathbf{P}}')$ relative to $(\overline{A}, \kappa)$ (same-ontology, $P' = P$) consists of:
>
> - A finer sub-algebra $\overline{A}^+ \supseteq \overline{A}$ (with $\overline{A}^+ \subseteq \overline{P}$),
> - A refined kernel $\kappa^+$: for each atom $\overline{a}^+$ of $\overline{A}^+$, a measure $\kappa^+_{\overline{a}^+}$ on $\overline{P}$,
> - Calibration: $\mathbf{P}(\cdot \mid \overline{a}^+) = \kappa^+_{\overline{a}^+}$ for all atoms $\overline{a}^+$,
> - An event $\overline{a}_0 \in \overline{A}^+$ with $\mathbf{P}(\overline{a}_0) > 0$ such that $\mathbf{P}' = \mathbf{P}(\cdot \mid \overline{a}_0)$.

**4.6 Definitions 12.1 and 12.2 (epistemic coherence)** — SC §12:

> **Definition 12.1 (Epistemically Coherent Pair).** Two decision-points $d_i$ and $d_j$ with $\hat{X}_i = \hat{X}_j = \hat{X}$ are *epistemically coherent* if there exists a calibrated anticipation structure $(\overline{A}, \kappa)$ on $\hat{\mathbf{X}}_i$ (targeting $\hat{X}$, in the sense of Definition 3.1) such that $\mathbf{X}_j = \mathbf{X}_i(\cdot \mid \overline{a}_0)$ for some atom $\overline{a}_0$ of $\overline{A}$.

> **Definition 12.2 (Cross-Ontology Epistemic Coherence).** Decision-points $d_i$ and $d_j$ with different world-models are *epistemically coherent* (relative to a common information structure $(\hat{C}, \mathbf{c}_i, \mathbf{c}_j)$) if:

> 1. The $\hat{C}$-compatible conditioning model for $(\hat{\mathbf{X}}_i, \hat{\mathbf{X}}_j)$ exists: $\mathbf{C}_j \ll \mathbf{C}_i$ with bounded density (Theorem 2.4), where $\mathbf{C}_k = (\mathbf{c}_k)_* \mathbf{X}_k$;

**4.7 Conditioning models, compatibility, Theorem 4.5** — SC §§1, 2, 4:

**4.8 Decision-points, Pareto, welfare, classical recovery** — SC §§9, 10, 13:

> **Definition 9.1 (Decision-Point).** A *decision-point* is a tuple $d_i = (\hat{\mathbf{X}}_i, A_i, u_i)$ where: $\hat{\mathbf{X}}_i = (X_i, \overline{X}_i, \mathbf{X}_i)$ is a probability space (the *world-model* of $d_i$); $A_i$ is a finite set of *basic actions* available to $d_i$; $u_i\colon A \times X_i \to \mathbb{R}$ is a utility function, where $A = \prod_j A_j$ is the joint action space.

> **Definition 9.2 (Subjective Pareto Dominance).** Outcome $O^*$ *subjectively Pareto-dominates* $O$ (with respect to a collection $\{d_i\}$) if $U_i(O^*) \geq U_i(O)$ for all $i$, with strict inequality for some $i$.

> **Definition 10.3 (Welfare Selection Rule).** A selection rule $\mathrm{sel}$ is a *welfare selection rule* if there exists a function $W\colon A \to \mathbb{R}$ satisfying: 1. *Pareto-consistency*: if $O^*$ subjectively Pareto-dominates $O$ then $W(O^*) > W(O)$; 2. *Selection*: $\mathrm{sel}(S) = \arg\max_{O \in S} W(O)$ (breaking ties arbitrarily but consistently).

> **Theorem 13.1.** *Suppose all decision-points $\{d_i\}$ carry the same prior $\mathbf{X}$ on $\hat{X}$ (i.e., $\mathbf{X}_i = \mathbf{X}$ for all $i$) and the same utility function $u$. The unique outcome surviving Theorem 11.1 is $O^* = \arg\max_O \mathbb{E}_{\mathbf{X}}[u(O, \cdot)]$, the classical UDT optimum.*

> **Claim 12.3.** *If $d_j$ is an epistemically coherent update of $d_i$ (same-ontology, Definition 12.1), then the optimal batna and acceptable set for $d_j$ in the bargaining game are endorsed by $d_i$: $d_i$'s anticipation structure assigns positive probability to the scenario in which $\mathbf{X}_j$ is realized, and $d_i$'s conditional expected utility under that scenario agrees with $d_j$'s unconditional expected utility.* … This claim is not yet a theorem in the sense that it does not determine the *equilibrium selection* …

**4.10 The approximate-factoring lemma and its corollary** — gap1 §4:

> **Lemma (approximate factoring; proof included).** Under access (ii), suppose that for each mechanism $M$ the predictor satisfies the accuracy bound
> $$\Pr_{o \sim D}\big(p(M, o) \neq \pi_M(o)\big) \leq \delta.$$
> Then for any two mechanisms with $\pi_{M_1} = \pi_{M_2}$:
> $$\Pr_{o \sim D}\big(p(M_1, o) \neq p(M_2, o)\big) \leq 2\delta,$$
> and if additionally $D(o) \geq \gamma > 0$ for every $o \in O$, the predictions disagree on at most $2\delta/\gamma$ observations (counting measure).

> **Corollary (utility-level approximate DD).** Which reading you need is determined by whether the *observation distribution itself* is downstream of the predictions — and this is exactly what separates garden-variety prediction problems from transparent-Newcomb-style ones.
>
> *Fixed-observation regime.* … $|U(M_1) - U(M_2)| \;\leq\; R \cdot \Pr_{o \sim D}\big(p(M_1,o) \neq p(M_2,o)\big) \;\leq\; 2\delta R.$ Approximate DD at cost $2\delta R$, no $\gamma$ anywhere.
>
> *Prediction-dependent-observation regime.* … if changing the prediction at one observation moves $D$ by at most $L$ in total variation, the bound becomes $|U(M_1) - U(M_2)| \leq R\,(2\delta + L \cdot 2\delta/\gamma)$. **The $\gamma$-blowup is thus not an artifact of the proof: problems where observations are downstream of predictions structurally require the counting bound, which is why transparent-Newcomb-style cases are exactly the fragile ones.**

**4.11 The punchline** — gap1 §6:

> **An agent should be updateless over exactly the family of situations its predictors generalize across.** The environment's response can only depend on policy structure the predictor can ground; the predictor can only ground structure exercised (at some rate $\gamma$) by the family; so cross-situation dependence — the thing that gives updatelessness its content — extends precisely as far as the family's support, with strength degrading as $\delta/\gamma$. Commitments beyond the family's support are unpriced by the environment: nothing responds to them, so updatelessness there is free but worthless — and updatelessness *within* the family is exactly as valuable as the predictor is accurate.

**4.12 The self-sealing asymmetry** — gap1 §8 and selfseal §2:

> - *True two-boxer verdicted "one-boxer":* box gets filled, agent sees full, two-boxes — disconfirming evidence arrives at rate $\approx 1$. The error is **self-correcting**.
> - *True one-boxer verdicted "two-boxer":* box left empty, agent sees empty and acts on the empty branch; its full-box disposition is never exercised. Disconfirming evidence arrives at rate $0$ (absent trembles). The error is **self-sealing**: a learned predictor can permanently misclassify a genuine one-boxer, and no behavior of the agent can ever demonstrate the misclassification.

> **Moral of the base model:** the learned predictor's errors are asymmetric in the direction that punishes the cooperative type — *errors that withhold opportunity are self-sealing; errors that extend opportunity are self-correcting.* The cost of the $\varepsilon \to 0$ idealization is now quantitative: vindication time scales as $1/\varepsilon$.

selfseal §3, the two families: "**Family-across-time (reputation).** The predictor's data is *this agent's* past episodes. Then the problem is de facto repeated, and a merely *updateful* agent with memory already one-boxes for reputational reasons …" / "**Family-across-agents (reference class).** The predictor's data is the behavior of *other instances of the same type* … The individual episode is genuinely single-shot: the agent's own action contributes measure-zero to the type's statistics, so there is no reputational motive … **This is where distinctively updateless content survives the grounding requirement.**" and: "**This is how decision-determination actually arises in learned environments.** The environment responds to your *algorithm* (not your mechanism-token) because what it possesses is statistics over your algorithm's instances." / "**The reference-class boundary is an ontology question.**"

selfseal §4, the unifying statement: "**counterfactual structure is only as real as the positive-probability process that exercises it, and UDT is precisely a theory whose value proposition lives in counterfactual structure — so every rigorous corner of the theory ends up buying its counterfactuals with an $\varepsilon$.** The three appearances are not analogies; they are the same purchase made at three different counters." and "**Who pays for the trembles?** … exploration is costly to the *explorer* … So the amount of grounding $\varepsilon$ is itself strategically chosen, which makes the agent–predictor interaction a game *about* $\varepsilon$, one level up from the game the agent thought it was playing."

**4.14 Decision-determination** — `notation.md` §2.7 and `topics/decision-determination.md`:

> An abstract decision structure is **decision-determined** if: 1. $U$ is a function of $E$; 2. $E$ is conditionally independent of $D_{I,B}$ given $\ddot{\Pi}$: $\Pr(E = e \mid D_{I,B} = d_{I,B}) = \Pr(E = e \mid \ddot{\Pi} = `d_{I,B}`_{\ddot{\Pi}})$.
