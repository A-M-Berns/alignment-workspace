Standing vocabulary for this thread:

- **The fair class** $\mathfrak F$ := strongly fair trees, fully recorded for every procedure (FRec: Definition 7's recording at every queried point, quantified over $C$), evented chance with zero-probability edges pruned, and every queried observation satisfied by some leaf-world (adversary-repair Claim A's added hypothesis). This is exactly the class on which P1:fair-repair FR-11, as repaired by P1:adversary-repair Claim A, proves tremble-EDT-consistent $\Rightarrow$ $V$-optimal.
- $Q_C(d,a)$ := the continuation value, under $C$, from the $a$-child of a $d$-node — node-independent on strongly fair trees (P1:fair-repair FR-1(ii)), and independent of $C(d)$ on almost-fair trees (no $d$-node below a $d$-node).
- $F_d$ := the fiber of $d$; "$e$ strictly below $d$" := some $e$-node is a proper descendant of some $d$-node. On strongly fair trees this relation is a strict partial order on points (CA-3 below).
- For a self-model $C'$ and a point $d$ with $\nu_{C'}(O_d)>0$, the *masked state at $d$ under $C'$* is $\sigma_d(C') := \big(\nu_{C'}(\cdot\mid O_d),\ \mathbb E_{\mu_{C'}}[r\mid \cdot\wedge O_d]\big)$.

### 1.1 Definitions

**Definition C1 (masked-EDT-consistency, per App. B variant).** For a variant $v$ let $\mathcal S_v(B,C,d)$ be its admissible self-models: LF (local, full-support = Definition 9 official): $\{C[d\mapsto m] : m\in\Delta(A_d)\text{ full-support}\}$; LP (local, plain): $\{C[d\mapsto m] : m\in\Delta(A_d)\}$; GF (global, full-support): all full-support procedures; GP (global, plain): all procedures. $B$ is *$v$-masked-calibrated for $C$* if for every queried $d$ either $\nu_{C'}(O_d)=0$ for every $C'\in\mathcal S_v$ ($d$ is *$v$-free*: unconstrained — this vacuity reading is v2's own usage in Proposition 8 for $C_0$ at $d_{10}$ and in Corollary 9.1, and the toolkit's README §3.1) or $s_d=\sigma_d(C')$ for some $C'\in\mathcal S_v$ with $\nu_{C'}(O_d)>0$. $C$ is *$v$-masked-EDT-consistent on $B$* if some state assignment makes $B$ $v$-masked-calibrated for $C$ with $T_{\mathrm{EDT}}(C,B)$ (Definition 18's support condition, maximization domain $A_d^+$ read off the assigned state). Compare **tremble-EDT-consistency** (Remark 3.12 read on the concrete tree with states freed — P1:fair-repair FR-11's form, implemented by `dp.tremble_edt_consistent`): for all small $\varepsilon>0$, the strictly-calibrated-for-$C^\varepsilon$ state assignment satisfies $T_{\mathrm{EDT}}(C,B_\varepsilon)$, i.e. $\mathrm{supp}\,C(d)\subseteq\arg\max_{a\in A_d^+(\varepsilon)} v_\varepsilon(d,a)$ with $v_\varepsilon(d,a):=\mathbb E_{\mu_{C^\varepsilon}}[r\mid a\wedge O_d]$.

**Definition C2 (downstream-faithful masking, DF — a fifth variant).** $\mathcal S_{\mathrm{DF}}(B,C,d):=\{C' : C'(e)=C(e)\text{ for every point } e \text{ strictly below } d;\ C'(e)\text{ full-support for every other point, } d \text{ included}\}$. So DF frees the present act *and the past* (upstream and parallel points) and pins the future. On strongly fair trees "strictly below" is a strict partial order on points (CA-3), so the definition is unambiguous there.

**CA-2 [derived] — the DF theorem.** On $\mathfrak F$, DF-masked-EDT-consistency implies $V$-optimality, and DF-masked-EDT-consistent procedures exist (deterministic ones).
*Proof.* Fix a queried $d$ and $C'\in\mathcal S_{\mathrm{DF}}(B,C,d)$. (i) *No point is DF-free:* $O_d$ is satisfied by some leaf-world (class hypothesis); by coverage (recording under the full-support $C'$, pruned chance) that leaf is reached with positive probability and passes a $d$-node, so $\nu_{C'}(O_d)>0$. (ii) *Self-transparency:* recording under $C'$ gives $\nu_{C'}(a\mid O_d)=C'(d)(a)>0$ (Proposition 7's recording argument), so $A_d^+=A_d$. (iii) *Faithful values:* by recording, $\{\lambda\models a\wedge O_d\}$ = "reach some $q\in F_d$ and draw $a$" a.s.; conditional on that, the node is distributed by reach weights and the continuation from $q$'s $a$-child involves only points strictly below $d$ (no $d$-node below a $d$-node on a strongly fair tree), where $C'=C$; by FR-1(ii) that continuation value is node-independent, so $V_{\sigma_d(C')}(a)=Q_C(d,a)$ exactly, independent of the self-model. (iv) Hence $T_{\mathrm{EDT}}(C,B)$ at $d$ reads $\mathrm{supp}\,C(d)\subseteq\arg\max_a Q_C(d,a)$ for every queried $d$, and FR-11's Step 3 (height induction with the fair-tree assignment lemma; verified by adversary-repair Claim A) gives $V_B(C)=\max_\pi V_B(\pi)=\max_{C'}V_B(C')$. Existence: leaves-up, choose at each fiber a maximizer of $Q_C(d,\cdot)$ (well-founded by CA-3). $\square$
Toolkit rows `variant=DF`: on $T_2$ the DF values are $V(\mathrm{in})=1$ or $4$ according to $C(d_2)$ and $V(x)=4,V(y)=1$ at $d_2$, self-model-independent (`self-model-dependence=[]`), approving exactly $(\mathrm{in},x)$; on the tie tree (CA-4) DF approves both optima.
*Corollary [derived].* LF suffices for procedures under which every queried observation is on-path ($\nu_C(O_d)>0$ for all queried $d$): then every LF self-model realizes $O_d$ and $\sigma_d(C[d\mapsto m])$ coincides with DF's state (same downstream, same upstream, full support at $d$). LF's only defect on $\mathfrak F$ is off-path vacuity.

**CA-3 [derived] — "strictly below" is a strict partial order on points of a strongly fair tree.** If $e$ has a node strictly below a $d$-node then, by fiber isomorphism, *every* $d$-node has an $e$-node strictly below it; if also $d$ had a node strictly below an $e$-node, iterating gives an infinite descending chain of nodes in a finite tree. So no cycles, and no point is below itself (nested fibers are unfair: FR-1(i)). Consequently a point strictly below $d$ is never on a path *to* a $d$-node, which is what makes DF's "pin below, free elsewhere" coherent and the backward induction well-founded.

**CA-4 [checked] — on $\mathfrak F$: tremble-EDT $\subsetneq$ DF-EDT $\subsetneq$ $V$-optimal.**
- *Inclusions.* Tremble-EDT $\Rightarrow$ DF-EDT: $v_\varepsilon(d,a^\ast)\ge v_\varepsilon(d,a)$ for all small $\varepsilon$ gives $Q_C(d,a^\ast)\ge Q_C(d,a)$ in the limit (leaf probabilities are polynomials in $\varepsilon$; FR-11 Step 2), which is DF's condition by CA-2(iii). DF-EDT $\Rightarrow$ optimal: CA-2.

- *Identification.* DF's state at $d$ has exactly the act-conditional beliefs and values $\lim_{\varepsilon\to0}\nu_{C^\varepsilon}(\cdot\mid a\wedge O_d)$, $\lim_\varepsilon\mathbb E_{C^\varepsilon}[r\mid a\wedge O_d]=Q_C(d,a)$ on $\mathfrak F$: DF **is** Remark 3.9's advice-stance route ("pin act-conditional belief and value by their tremble limits" — the tremble-induced evidential counterfactual structure), and CA-4's tie tree is Remark 3.9's "differ at limit-ties, where the sequence route is the finer refinement" made concrete. ### 1.3 Verdict on open problem 3 (register: the class $\mathfrak F$, Definition 6 semantics, event-conditioned EDT)

Within Appendix B's four-variant family the tremble ingredient is intrinsic: each variant admits a non-optimal EDT-consistent procedure on $\mathfrak F$ (CA-1). But what the theorem consumes from trembles is exactly two clauses — *full support at $d$ and at every point not below $d$* (so every observation is priced and every act is live) and *faithfulness below $d$* (so acts are priced at the true continuation) — and the static, $\varepsilon$-free DF variant with just those clauses proves the same theorem (CA-2). Remark 3.12's trembles are DF plus a lexicographic tie-break (CA-4). The honest slogan: "EDT $=$ UDT on the fair class holds for evidential choice whose self-model is downstream-faithful and otherwise full-support; trembles are the canonical such self-model, and their only extra content is at exact continuation ties." Phase 1's expected answer ("[guess: no]") is confirmed for App. B's grid and refuted for the family of masking rules as such.

## 3. The calibration manifold (Q2; Remark 3.7; mandate item 3)

Script: `calibration-scratch/t3_manifold.py` — every queried point of the tree gets a free mixture (affine parametrization; all examples have two actions), $\nu_{C'}(\cdot\mid O_d)$ is computed as a vector of rational functions on the product of simplices, and its dimension is the Jacobian rank at a generic interior rational point.

**CA-8 [derived] — structure of $M_d:=\{\nu_{B,C'}(\cdot\mid O_d): C'\}$ under coverage.** Let $d$ be consulted at most once per run (almost fair at $d$) and let $B$ cover $d$ for every procedure (a.s. every $O_d$-run passes a $d$-node). Write $m:=C'(d)$, $R_q:=\mu_{C'}(\text{reach } q)$ for $q\in F_d$ — independent of $m$ by Lemma 1's argument — and $\theta_{q,a}$ for the leaf-law below $q$'s $a$-child under $C'$, which depends on $C'$ only at points strictly below $q$. Then
$$\nu_{C'}(X\mid O_d)\;=\;\frac{\sum_{q\in F_d}R_q\sum_{a}m(a)\,\theta_{q,a}(X\wedge O_d)}{\sum_{q\in F_d}R_q\sum_a m(a)\,\theta_{q,a}(O_d)}.$$
(i) On a *strongly fair* tree $\theta_{q,a}=\theta_a$ is node-independent (FR-1(ii)), the $R_q$ cancel, and $\nu_{C'}(\cdot\mid O_d)$ is a function of $m$ and of $C'$ strictly below $d$ only — upstream and parallel points drop out. This is brief B's PC-1 slogan "everything you don't know at $d$ is downstream of $d$" as a statement about Q2 (cite as brief B, PC-1; the calculation is mine). (ii) If in addition every $d$-node is subtree-veridical ($\theta_a(O_d)=1$), then $P(a\mid O_d)=m(a)$ (self-transparency) and $M_d=\{\sum_a m(a)\,\theta^{C''}_a : m\in\Delta(A_d),\ C''\text{ on points below } d\}$ — the join of the downstream continuation manifolds; generic dimension $\le(|A_d|-1)+\sum_{e\text{ below }d}(|A_e|-1)$. (iii) At a *selection* node ($\theta_a(O_d)$ not all $1$) the action marginal is $P(a\mid O_d)\propto m(a)\,\theta_a(O_d)$: a zero on $a$ survives every full-support $m$ iff $\theta_a(O_d)=0$ — Remark 3.7's "which zeros survive" is this factor. (iv) Without coverage, runs realizing $O_d$ off $F_d$ add a term to numerator and denominator that depends on *parallel* points; coverage is exactly the condition for the downstream-only dependence.
