## 0. The one new object: seeded trees and the identified frame

**Definition CFF-A (seeded tree; identified frame).** A *chance seeding* of a concrete problem $B$ (Definition 5) is a map $\kappa : \mathrm{Ch}(B) \to K$ from chance nodes to a set of *chance variables* such that $\kappa(n) = \kappa(n')$ implies $\mathrm{children}(n) = \mathrm{children}(n')$ and $\beta_n = \beta_{n'}$, and such that no root-path contains two nodes of one class (*path-injective*). The *lazy* seeding is $\kappa = \mathrm{id}$ (P1 CF-1). Relocation (P1:fair-repair R1/R2/E2) carries a seeding along: a copied chance node inherits the variable of its original (the toolkit's `origin`). The *identified frame* is
$$\mathrm{Fr}_\kappa(B) := \Big(\prod_{d} A_d,\ \prod_{k \in K} \mathrm{children}(k),\ (\pi, \varepsilon) \mapsto \phi \circ \ell(\pi, \varepsilon)\Big),$$
the deterministic run reading, at a chance node $n$, the coordinate $\varepsilon(\kappa(n))$. $\mathrm{Loc}^\kappa_d(B)$ likewise. "Chance identification" (P1 Seam 2; adversary-repair D.2) is the choice $\kappa$ = original-node classes on a relocated output; it is representation data, exactly as a point label $d_q$ is for decision nodes — a Definition-5 tree carries identity labels for its decision nodes and none for its chance nodes, and $\kappa$ supplies the missing half. Run semantics: for path-injective $\kappa$ a run meets at most one node of each class, so "one draw per chance variable per run" and Definition 6's independent redraws give the same $\mu_{B,C}$ for every procedure — the seeding changes the frame (which is about counterfactual profiles) and nothing about $\mu$, $\nu$, $V_B$, or any calibration sense.

**CFF-1 (the identified frame is a diagonal Assume) [derived].** Let $\Delta_\kappa \subseteq \mathbf E_B$ be the lazy profiles constant on each $\kappa$-class. Then $\mathrm{Fr}_\kappa(B) \cong \mathrm{Assume}^{\Delta_\kappa}(\mathrm{Fr}(B))$ (the evident bijection $\prod_K \mathrm{children}(k) \cong \Delta_\kappa$ commutes with the run). Consequences, all because the three notions are $\forall e$-statements: column-determinedness, powerlessness outside $S$, and observability of a partition (conditional-policies form, with the partition restricted to the smaller image) are each *monotone* from lazy to identified — anything observable / powerless / column-determined in $\mathrm{Fr}(B)$ stays so in $\mathrm{Fr}_\kappa(B)$. Negative statements can flip, and §1–§2 are about exactly which ones do.

## 2. Open problem 1 — the $\varepsilon$-determined forward direction (mandate item 2)

Script: `s2_crown.py` (21 trees). Statement under test (adversary-cf ADV-9; P1 synthesis open problem 1): *on a strongly fair, subtree-veridical, covered tree, every chance-determined partition — membership in $S$ a function of the chance profile alone (column-determined) — is observable in the global frame.* The answer splits by convention.

**Definition CFF-B (crown, exits, pre-decision partitions, straddling).** The *crown* $\mathrm{Cr}(B)$ is the set of chance nodes all of whose ancestors are chance nodes (or decision nodes with a single action). The *crown exits* $X(B)$ are the first non-crown nodes met along every chance-only descent from the root (decision nodes with $\geq 2$ actions, or leaves; the root itself if it is a decision node). Each exit $x$ has an *outcome class* $W_x := \{(\lambda(\ell), r(\ell)) : \ell \text{ below } x\}$. $S \subseteq W$ is *pre-decision* if it is a union of exit classes. A point $d$ *straddles* $S$ if some $d$-node lies below an exit whose class is inside $S$ and another below an exit whose class is outside $S$.

**CFF-11 (Crown Lemma: chance-determined = pre-decision, lazily) [derived; checked on 21 trees].** In the lazy frame $\mathrm{Fr}(B)$, a two-cell partition $\{S, W \setminus S\}$ is column-determined iff $S$ is pre-decision.
Proof. ($\Leftarrow$) The crown is chance-only, so the exit a run reaches is a function of $\varepsilon$; every policy's outcome at $\varepsilon$ lies in that exit's class, which is inside or outside $S$ as a whole. ($\Rightarrow$) Let $m(\varepsilon) \in \{0, 1\}$ be the common membership. If $n$ is a chance node *not* in the crown, some decision node $q$ with $\geq 2$ actions is a proper ancestor of $n$, with $n$ below $q$'s $a$-edge. The policy that answers $b \neq a$ at $d_q$ (any values elsewhere) never visits $n$ — paths are unique in a tree — so its outcome, hence $m$, is unchanged when $\varepsilon(n)$ is changed: $m$ depends only on crown coordinates. Next, for a crown exit $x$ let $R_x$ be the profiles routing to $x$; a crown coordinate off the path to $x$ is never read on runs through $x$, so $m$ is constant on $R_x$, i.e. $m$ is a function of the exit. Membership of an outcome $o \in W_x$ is then $m(x)$, so $S$ is a union of exit classes. $\square$ Checked: on every tree of the battery, all column-determined two-cell partitions are exit-class unions (`allCEU True`) and all nontrivial exit-class unions are column-determined (`CEU=>CD True`). Corollary: no chance node below a nontrivial decision ever contributes a chance-determined partition in the lazy frame — post-decision chance is *decorrelated per action branch* (CF-14(c)'s mechanism), which is why the relocated mugging has no nontrivial column-determined partition at all (`#colDet 0`).

**CFF-12 (Straddle Theorem, any tree) [derived; checked].** If no point straddles the pre-decision set $S$, then $\{S, W \setminus S\}$ is observable in $\mathrm{Fr}(B)$.
Proof. Given $f$ with $f(S) = \pi_S$, $f(\neg S) = \pi_N$, classify each point $d$ as an $S$-point if some (hence, by no-straddling, every) $d$-node lies below an $S$-exit, else an $N$-point, and set $\pi_f(d) := \pi_S(d)$ resp. $\pi_N(d)$. At a profile $\varepsilon$ routing to an $S$-exit $x$, every point consulted by any run is consulted below $x$, hence is an $S$-point, so $\pi_f$ agrees with $\pi_S$ at every point the run of $\pi_f$ meets; the two runs coincide, and the outcome's cell is $S$; symmetrically for $N$-exits. $\square$ The converse fails: the decoupled mugging and the umbrella-mugging have a straddling point and an observable partition (powerlessness resp. policy-richness rescue them; §4). Checked: on all 21 trees every unobservable column-determined partition is straddled (`unobs⊆straddle True`).

**CFF-13 (fairness's frame-side shadow is outcome-fairness) [derived; checked].** Call $B$ *outcome-fair* if the members of every fiber have equal outcome sets $W_q$. Strong fairness implies outcome-fairness (the isomorphism preserves leaf $(\lambda, r)$). Outcome-fairness implies no straddling of any pre-decision $S$: if $q_1, q_2 \in F_d$ lay below an $S$-exit and an $N$-exit, $W_{q_1} \subseteq S$ and $W_{q_2} \cap S = \emptyset$ would contradict $W_{q_1} = W_{q_2} \neq \emptyset$. Hence, by CFF-11–12: **on an outcome-fair tree — in particular on a strongly fair tree — every chance-determined partition is observable in the lazy global frame $\mathrm{Fr}(B)$; neither subtree-veridicality nor coverage is needed.** Checked: every strongly fair tree of the battery has `#unobs 0` (Told-You-So, tickle, CX2, look-decide, $\beta$-pair $P$, $\mathrm{Rel}_d B_1$, and the new tree $M$ below); the unfair straddlers (both muggings, 2-fold mugging, S3, parallel fiber, the tree $U$) have their unobservable column-determined partition straddled by the fiber. The hypothesis is genuinely the weaker one: the $\beta$-pair's $P'$ is outcome-fair but not strongly fair ($\beta = \tfrac13$ vs $\tfrac12$ inside the fiber) and satisfies the conclusion (`all observable True`, with the coin unrecorded so no nontrivial column-determined partition exists); this is the exact sense in which "fairness is not frame-functional" (CF-14(a)) coexists with a true forward direction: the frame sees outcome-fairness and is blind to $\beta$.
Non-vacuous instance (tree $M$, `fair_multi_fiber`): coin $c_1$ recorded; $H \to$ point $e$ ($O_e = \{A = H\}$); $T \to$ unrecorded coin $c_2 \to$ two $d$-nodes with identical labelled subtrees ($O_d = \{A = T\}$). Strongly fair with a genuine two-member fiber; crown $= \{c_1, c_2\}$, exits $= \{e\text{-node}, d_L, d_R\}$; the coin partition $\{A = H\} \mid \{A = T\}$ is column-determined and observable (`True`) — $\pi_f(e) = f(S_H)(e)$, $\pi_f(d) = f(S_T)(d)$.

**CFF-14 (where veridicality and coverage actually enter) [derived; checked].** They do not enter CFF-13; they decide *which* partitions are chance-determined. For a point $d$ the observation partition $\{S_{O_d}, \neg S_{O_d}\}$ is pre-decision iff every exit class is entirely inside or outside $S_{O_d}$; under (V$_d$) + (C$_d$) $S_{O_d}$ is the union of the classes of $d$'s nodes, so the partition is pre-decision iff $d$'s nodes are crown exits (a *first decision*) — the one-round case of CF-12 — and for a mid-tree point it is never chance-determined (CF-13: the look-decide tree has no chance node, its $O_d$ partition is row-dependent, `#colDet 0`). Mandate checks: (i) the relocated-mugging witness CF-14(c) is excluded lazily because $\mathrm{Rel}_d(B_1)$ has no nontrivial chance-determined partition (root decision, empty crown) — confirmed (`#colDet 0`); (ii) CX2's partition $\{O_1, \neg O_1\} = \{w_1, w_2, w_4\} \mid \{w_3\}$ is *not* column-determined (column $c = 2$ contains $w_3 \notin O_1$ and $w_4 \in O_1$), so it never enters the conjecture's scope — the exclusion is by chance-determinedness, and coverage matters only in that under coverage CX2's observations become $\{w_1, w_2\} \mid \{w_3, w_4\}$, the coin partition, which is pre-decision and observable (adversary-verify R4 computed the same witness $(x, y')$). So the honest statement of what P1 called "excluded by coverage" is: coverage + veridicality make first-decision observation partitions chance-determined; CFF-13 then makes them observable on fair trees.

**CFF-15 (the identified convention refutes the forward direction) [checked].** Under chance identification the Crown Lemma fails — identified copies below different action edges are read by *every* policy, so a post-decision coin is chance-determined — and the forward direction is false on three strongly fair, subtree-veridical, covered trees: $\mathrm{Rel}_d(B_1)$ (coin column-determined, not observable, CFF-4), $\mathrm{Rel}_d(\mathrm{S3})$ (lesion partition, CFF-7), and the one-round post-coin tree (the identified $B_c$, CFF-9: `column_determined True, observable False`). In each, the unobservable chance-determined partition is post-decision (CF-24's "re-filed post-decision chance"): the agent moves first and cannot condition on a coin that is tossed afterwards, whatever the fibers look like. Tree-side these are precisely the relocated forms of the coupled problems, so the refutation is not exotic: it says that *after* the repair, the coin is chance-determined-but-unobservable in exactly the way the repair intends.

**CFF-16 (verdict on open problem 1 and Seam 3) [derived].** *Lazy frame:* PROVED — with fairness weakened to outcome-fairness and veridicality/coverage dropped (CFF-13); fairness thereby has a genuine, partial frame-side shadow: what the frame sees of "every fiber has isomorphic labelled subtrees" is "every fiber has one outcome set", and that is exactly "no fiber straddles a pre-decision chance event" — for the observation partition of a first decision, "no straddle" is "no simulation node among the exits", i.e. CF-12's (V), so the shadow *extends* no-simulation from observation partitions to all pre-decision chance. *Identified frame:* REFUTED (CFF-15); the corrected identified statement is "on an outcome-fair tree every *pre-decision* chance-determined partition is observable" (CFF-1's monotonicity applied to CFF-13), and the identified convention is what separates pre-decision from post-decision chance inside the chance-determined class. Seam 3 therefore resolves as: the frame-side shadow of fairness exists and is outcome-fairness; the divorce is not completed, but the shadow is convention-fragile — it is visible in the lazy frame, where relocation is not frame-invariant (D.2), and invisible in the identified frame, where relocation is (CFF-2). Register: these are possibilistic statements about $\mathrm{Fr}(B)$; nothing here touches $\mu$, $\beta$, any calibration sense, or fairness's tree-side work (P1 items 3, 18, 20).

Handed to the zoo: tree $M$ (fair multi-member fiber below an unrecorded coin, observable coin partition), tree $U$ (`unfair_straddle`: same point under both sides of a recorded coin with equal payoffs — unfair, column-determined coin, unobservable), the one-round post-coin tree (`s1_seam2.py`, last block), and the spurious-query pair of CFF-8.

## 3. Open problem 2 — multi-round decomposition, and CF time (mandate item 3)

Script: `s3_multiround.py`. Sources on time: `cf-paper.txt` has no time chapter (grep for time/temporal/updateless/updateful: one sentence on p. 4 — "we can use the subagency notion to model the same agent across time. **Definition CFF-C (stages; stage frames).** The *decision depth* of a node is the number of decision nodes (with $\geq 2$ actions) strictly above it. $B$ is *stratified* if each point's nodes share one depth $k(d)$; $D_k$ is stage $k$, $A_k := \prod_{D_k} A_d$, $A_{<k}$, $A_{>k}$ likewise. The *stage frame* $\mathrm{Fr}_k(B) := (A_k,\ A_{<k} \times A_{>k} \times \mathbf E,\ \text{run})$ — the stage-$k$ team against everything else — is a multiplicative subagent of $\mathrm{Fr}(B)$ on the nose (Def 19 with $X = A_k$, $Y = A_{-k}$, $Z = \mathbf E$, exactly as P1 CF-5); write $\mathrm{Fr}_{>k}$ for the team of all later stages ("the later self"). One-round trees are the case of a single stage; every relocated / E1-sequenced output is stratified; strongly fair trees need not be.

**CFF-17 (stage-peeled CF-12) [derived; checked].** Let $B$ be stratified with (V$_d$) at every $d$ and the realized observations of each stage pairwise disjoint (which (C$_d$) gives: two same-stage points never share a path). ## 4. Open problem 8 — a syntactic criterion for local observability (mandate item 4)

Script: `s4_local.py`. Setting: queried $d$, $\mathrm{Loc}_d(B)$ with columns $c = (\pi_{-d}, \varepsilon)$, a two-cell partition $\{S, \neg S\}$ of $W$ with membership column-determined (CF-8: necessary for observability; otherwise type (a) and the question is closed). Write $E_S$ / $E_N$ for the columns whose outcomes lie in $S$ / outside.

**Definition CFF-D (splice; the two behaviour relations; self-relocation).** For $a, a' \in A_d$: $a \equiv_S a'$ iff $a \cdot c = a' \cdot c$ for all $c \in E_S$; $a \equiv_N a'$ iff the same on $E_N$. The *splice* of $(a_0, a_1)$ is the row vector equal to $a_0$'s on $E_S$ and to $a_1$'s on $E_N$. Call $d$ *cleanly labelled for $S$* if every $d$-node is an $S$-node (all leaves below it in $S$) or an $N$-node (none) — for $S = S_{O_d}$: every $d$-node uniformly veridical or uniformly a simulation. For clean $d$, $E_S$ is the set of columns routing to $S$-nodes (plus inert columns) and $a \equiv_S a'$ iff, at every $S$-node $q$, the subtrees below $q$'s $a$- and $a'$-edges are *outcome-equivalent* — same leaf outcome under every continuation $(\pi_{-d}, \varepsilon)$ — so $\equiv_S$ is "same behaviour at the veridical nodes" and $\equiv_N$ "same behaviour at the simulation nodes", both tree-surgery notions (compare subtrees below edges). The *split* $B^{\mathrm{split}}_d$ relabels $S$-nodes with a fresh point $d_S$ and $N$-nodes with $d_N$ (same action set, observations $O_d$ resp. $\neg O_d$); its product relocation $\mathrm{Rel}_{\{d_S, d_N\}}$ has action set $A_d \times A_d$. $d$ is *self-relocated* if $A_d \to A_d/\!\equiv_S \times A_d/\!\equiv_N$ is onto: every splice is, up to outcome-equivalence, already an action of $d$.

**CFF-24 (the two-cell iff, frame form) [derived; checked].** With $S$ column-determined in $\mathrm{Loc}_d$: $\{S, \neg S\}$ observable $\iff$ every splice is a row $\iff$ $A_d \to A_d/\!\equiv_S \times A_d/\!\equiv_N$ is onto $\iff$ $\mathrm{Loc}_d \simeq \mathrm{Hon}_d$ (P1 CF-21). Proof: post 11's conditional-policies definition for two cells asks, for each $(a_0, a_1)$, for $a_f$ with $a_f \cdot c = a_0 \cdot c$ when $a_f \cdot c \in S$ and $= a_1 \cdot c$ otherwise; column-determinedness turns "$a_f \cdot c \in S$" into "$c \in E_S$", so $a_f \in \mathrm{if}(S, a_0, a_1)$ iff $a_f \equiv_S a_0$ and $a_f \equiv_N a_1$, i.e. iff the splice of $(a_0, a_1)$ is $a_f$'s row; all splices present $\iff$ onto; and $\mathrm{Hon}_d$'s rows are exactly the splices (agent $A_d \times A_d$ evaluated cellwise), so $\mathrm{Loc}_d \simeq \mathrm{Hon}_d$ iff their row sets agree up to duplicates. $\square$ Table (s4; classes as $|A_d/\!\equiv_S| \times |A_d/\!\equiv_N|$ against $|A_d|$): umbrella-mugging $2 \times 2$ vs $4$, onto, observable, $\mathrm{Loc} \simeq \mathrm{Hon}$; mugging $B_1$ $2 \times 2$ vs $2$, not onto, not observable, $\mathrm{Loc} \not\simeq \mathrm{Hon}$; decoupled mugging $2 \times 1$ (powerless: $\equiv_N$ trivial), onto; TN-V1 at $d_E$ $2 \times 1$, onto; tickle $d_1$, look-decide $d$: $2 \times 1$; lesion S3 at $d$ ($S$ = lesion) and parallel fiber at $d$: $2 \times 2$ vs $2$, not onto, not observable; 2-fold muggings (nested, four $d$-nodes: three simulations, one real) $2 \times 2$ vs $2$, not onto. Every row of the table has observable $=$ onto $=$ ($\mathrm{Loc} \simeq \mathrm{Hon}$).

**CFF-25 (the tree-side iff: a point is observable at its own observation iff it is its own relocation) [derived; checked].** For $d$ cleanly labelled with $S_{O_d}$ column-determined in $\mathrm{Loc}_d$:
$$\{S_{O_d}, \neg S_{O_d}\} \text{ observable in } \mathrm{Loc}_d(B) \iff d \text{ is self-relocated} \iff \mathrm{Loc}_d(B) \simeq \mathrm{Loc}_{\hat d}\big(\mathrm{Rel}_{\{d_S, d_N\}} B^{\mathrm{split}}_d\big) \text{ (chance identified, stamps coarsened)}.$$
The middle equivalence is CFF-24 read through Definition CFF-D (for clean $d$, $\equiv_S$/$\equiv_N$ are the nodewise outcome-equivalences). The right-hand frame is $\mathrm{Hon}_d$: the relocated split's root point has action set $A_d \times A_d$ and, with the coin copies identified, its local frame is the cellwise evaluation of the pair — checked on the mugging (`biext~ True`; $\mathrm{Loc}_d(B_1) \not\simeq \mathrm{Hon}_d$, `False`). So the honest companion of P1 CF-20 is, under Seam 2's convention, a relocation: *the frame that could genuinely condition on $O_d$ is the frame of the tree in which $d$'s veridical and simulation instances are distinct points relocated jointly above the coupling*, and "seeming to observe" (CF-20/21) is being the diagonal commitment of that relocated split. The three routes of CF-10/11 read off the criterion: no simulation $\Rightarrow$ no $N$-nodes $\Rightarrow$ $\equiv_N$ trivial $\Rightarrow$ onto; powerless outside $S$ $\Rightarrow$ $\equiv_N$ trivial (inert simulation) $\Rightarrow$ onto; the umbrella has $|A_d/\!\equiv_S| = |A_d/\!\equiv_N| = 2$ and $|A_d| = 4$ with the map bijective — the point carries the full product; the mugging has $2 < 4$. ## 5. Open problem 9 — probability-enriched frames (mandate item 5)

Script: `s5_prob.py`. The cf-paper defers this in its conclusion (p. 18, verbatim, checked in the extract): "It would be useful to understand how the introduction of a probability measure over environments interacts with the rest of the framework."

**Definition CFF-E (enriched frame; defects; the pseudo-observation gap).** An *enriched frame* is $(C, \beta)$ with $\beta \in \Delta(E)$; for a tree, $\beta$ is the product of the chance labels over the frame's chance coordinates (lazy or identified — path-injectivity makes both the law of the chance profile actually drawn), and outcomes carry payoffs, so $V_\beta(a) := \mathbb E_\beta[r(a \cdot e)]$ is $V_B$ on pure profiles. For a two-cell $S$ (column-determined) define the *power defect* $\varepsilon_{\mathrm{pow}}(S) := \beta\{e : \exists a_0, a_1,\ a_0 \cdot e \notin S,\ a_0 \cdot e \neq a_1 \cdot e\}$ (the mass of the columns where the multiplicative definition's "powerless outside $S$" fails), the *conditional-policy defect* $\varepsilon_{\mathrm{cp}}(V) := \max_{f : V \to A} \min_{a_f} \beta\{e : f(v(a_f \cdot e)) \cdot e \neq a_f \cdot e\}$ (total-variation slack in post 11's §2 definition), and the *pseudo-observation gap* $\Gamma_S :=$ (optimum of $\mathrm{Hon}_d$ under $\beta$: best $a_S$ on $E_S$ plus best $a_N$ on $E_N$) $-$ $\max_a V_\beta(a)$: the value the agent would gain if the claimed observation were a true Observation. Under exact observability all three vanish (post 11's factorizations are exact and $\mathrm{Hon}_d \simeq \mathrm{Loc}_d$).

**CFF-27 (two inequalities) [derived; checked].** $\varepsilon_{\mathrm{cp}}(\{S, \neg S\}) \leq \varepsilon_{\mathrm{pow}}(S)$ and $\Gamma_S \leq \varepsilon_{\mathrm{pow}}(S) \cdot \mathrm{range}(r)$. Proof: take $a_f := f(S)$; it can miss only at columns outside $S$ where it differs from $f(\neg S)$, i.e. where the agent has power outside $S$ (CF-9's argument, measured); for the gap, play $a_S$: it matches $\mathrm{Hon}$'s choice on $E_S$ and differs from $a_N$ on $E_N$ only at power columns, each costing at most $\mathrm{range}(r)$. $\square$ Checked (exact fractions): mugging ($x = 1$, $y = 2$): $\varepsilon_{\mathrm{pow}} = \varepsilon_{\mathrm{cp}} = \tfrac12$, $V(\mathrm{pay}) = \tfrac12$, $V(\mathrm{refuse}) = 0$, $\mathrm{Hon}$-optimum $= 1$ (refuse on tails, pay on heads), $\Gamma = \tfrac12 \leq \tfrac32$; decoupled mugging: all zero; TN-V1 at $\mathrm{Loc}_{d_E}$ (context $x$ fixed): all zero (a true Observation); TN-V2 at $\mathrm{Loc}_{d_E}$ (context $x = $ large): $\varepsilon_{\mathrm{pow}} = \tfrac58 > \varepsilon_{\mathrm{cp}} = \tfrac{9}{16}$ (a strict instance), $\Gamma = \tfrac{3}{16} \leq \tfrac52$.

**CFF-28 (what CF can now state about decay) [derived; checked].** The CF-20 taxonomy becomes graded: type (b) coupling is "column-determined with $\varepsilon_{\mathrm{pow}} > 0$", type (c) approximate observation is "small $\varepsilon_{\mathrm{pow}}$", one notion. The $\pi$-mixture mugging (Omega simulates with credence $\pi$, otherwise the heads branch pays nothing whatever the agent does): $\varepsilon_{\mathrm{pow}} = \varepsilon_{\mathrm{cp}} = \pi/2$, $V(\mathrm{pay}) = \tfrac12(\pi y - x)$, $\Gamma = \pi\,y/2$ for $\pi y \leq x$ (computed: $\pi = 1, \tfrac12, \tfrac14, \tfrac1{10}$ give $\varepsilon_{\mathrm{pow}} = \tfrac12, \tfrac14, \tfrac18, \tfrac1{20}$ and $\Gamma = \tfrac12, \tfrac12, \tfrac14, \tfrac1{10}$, each within the bound). So decay as *coupling credence* (brief B PC-9's legitimate half; P1 Seam / spectrum's C4) has a frame-side home: as the credence that Omega's simulation is real fades, the coin's observation defect and the cost of treating it as a true Observation both fade linearly; the updateful and updateless factorizations, which coincide at $\varepsilon_{\mathrm{pow}} = 0$ (post 11 §4.4), separate by a quantity CF can now name. Post 11 §4.4's remark that "the updateless view approximates better" is literal here: the $\&$ factors $\mathrm{Assume}_{S}(C)$ are exact whatever $\varepsilon_{\mathrm{pow}}$ is (they never see the coupled columns), while the $\otimes$ factors carry the defect as a property of the factor ("a subagent that has only a very small effect on worlds in which it does not make the observation").

**CFF-29 (what it still cannot) [checked].** Dilution curvature (P1:verify E2, adversary-verify R6, both SURVIVE) is invisible to the enriched frame: for the $k$-fold mugging, $k = 2, 3$, linear / concave / convex transfer rules all give $\varepsilon_{\mathrm{pow}} = \tfrac12$ and frame values $V(\mathrm{pay}) - V(\mathrm{refuse}) = \tfrac12(y - x) = \tfrac12$, while Definition 6's mixed value has $\partial V/\partial q|_{q=1}$ equal to $\tfrac12$ (linear), $-\tfrac12$ (concave), $\tfrac32$ ($k = 2$) resp. $\tfrac52$ ($k = 3$) (convex) — the frame's rows are pure profiles and mixtures over them are the shared-seed grade (P1 CF-3; seeds SE-4), so the per-instance credit assignment that produces curvature does not exist in the frame at all. Likewise the calibration senses (strict / masked / limit OC, per-run / per-occurrence SSC) and prior calibration are statements about states and $\mu$, neither of which is frame data. So adversary-cf's closing objection survives in sharpened form: $\beta$ on $E$ buys the *weight* of the coupled branch and a graded notion of observation; it does not buy the procedure's mixing, the states, or the anthropic weights. Bridge dossier row T20 / XC-16 (the sibling's Part II with a common prior as a probability-enriched frame) is consistent with this: that translation is exact for pure profiles only.

## 6. Biextensional collapse vs relocation (mandate item 6)

Script: `s6_square.py`. The universal thread owns the categorical statement (UN-6: no unit in $\mathbf{Chu}$ without identification; UN-7: invariance up to $\simeq$ under identification; UN-19: the square); this section supplies the frame-side computation and the exact square.

**CFF-30 (the square that holds) [derived; checked].** Let $p : W^U \to W$ forget the $\mathrm{pol}$-stamps and $p_*$ the induced coarsening of frames (post 5's functor for coarse worlds; CF-24's coarsening). Under chance identification, $p_* \mathrm{Fr}_\kappa(\mathrm{Rel}_U B) = \mathrm{Fr}(B)$ *as matrices* for every $B$ and $U$ (CFF-2), so the square
$$\mathrm{Col}\big(p_* \mathrm{Fr}_\kappa(\mathrm{Rel}_U B)\big) \;=\; \mathrm{Col}\big(\mathrm{Fr}(B)\big)$$
commutes on the nose ($\mathrm{Col}$ = biextensional collapse). Checked (collapse shapes): mugging $2 \times 2 = 2 \times 2$; TN-V2 (nested) $4 \times 16$; AMD (nested) $2 \times 1$; ping-pong $4 \times 2$; umbrella-mugging $4 \times 2$; 3-fold concave (nested) $2 \times 2$; inert point $1 \times 2$ — matrix equality `True` in every case. So: relocation commutes with biextensional collapse exactly under the two moves the convention names — identify the coin with its counterfactual copies, forget the disposition stamp — and each move is load-bearing. The universal thread's UN-6 coreflection question (is relocation counit-shaped in $\mathbf{Chu}/\!\simeq$ without identification?) I did not settle; what CFF-2 adds is that with identification the unit is the identity, so any universal property of relocation lives entirely in the tree-side data the frame forgets (Seam 1's almost-fairness conjunct), not in the frame.
