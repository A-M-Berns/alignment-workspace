## 1. Predictor access in v2 (mandate item 1)

### 1.1 What a tree predictor has access to

The sibling sorts predictors by access (gap1 §2, verbatim in the dossier §4.9–4.10): (i) single-situation statistics — no predictor possible; (ii) family statistics — the predictor generalizes across a family, with $\delta$ = error and $\gamma$ = rarest-branch rate; (iii) extensional mechanism access — "Omega runs your code", where "fairness just *is* extensionality of the simulator" and the exact case is trivial.

In v2 every concrete predictor is a $k$-fold querier: Remark 5.1 ("$C$-dependence has exactly one inlet internal to a concrete problem: branching on sampled draws"), Proposition 4 (the realizable functions of $q = C(d)(a)$ with $k$ queries are the degree-$k$ Bernstein forms), P1:verify H1 (CONFIRMED with the caveat that a predictive query may be a routing node rather than an off-observation node — Told-You-So's root). Under Definition 6 each query is an independent sample of $C(d)$ (Remark 3.2).

**GR-1 [derived].** Classify by *reach* and by *content*. Reach: a decision node carrying $d$ may sit anywhere, including on paths into worlds where $O_d$ is false (Remark 3.3: hypothetical queries are the default). So the tree can evaluate the procedure at any point it likes, realized or not — that is the sibling's (iii) in reach: "run your code on input $d$". Content: for a deterministic $C$ one query returns $C(d)$ exactly — (iii) exactly, $\delta = 0$; extensionality is not a hypothesis but the type (Remark 3.1: "a function *of* $C$ already secures extensionality: oracle access, no source code"; dossier row T3). For a mixed $C$ a query returns a *sample*, not the mixture: $k$ queries give a $\mathrm{Bin}(k, q)$ draw and Proposition 4's Bernstein forms are all the tree can make of it. This is neither the sibling's (ii) (there is no family of situations — the same point is sampled repeatedly) nor its (iii) (the I/O function is not read off, it is estimated): call it **(iii-s), sampling access to the extensional I/O at any point**. The sibling's trichotomy presupposes deterministic policies ($\pi_M : O \to A$) and splits there.

Shared seed (Q12; P1:verify E3/E5) changes the content type: the $k$ queries return the run's own draw, so the predictor learns the *realization* the agent will act on — for mixed $C$ strictly more than (iii) (a clairvoyant, correlated sample; dossier T10's "a type B does not list"); for deterministic $C$ it coincides with (iii). Price already known: Proposition 4 collapses to affine (P1:verify E5), i.e. realization access destroys the sampling that Remark 5.4's learning story needs.

Label-dependence (Definition 14, Remark 5.1: "dependence of the *description* on the agent … lives at the abstract level, where its honesty condition is the fixed-point equation") is exact access to the *mixture* $q$ — the idealized (iii) at the mixture level, realizable by no finite tree (Proposition 4: "no label can *report* $q$"). That is v2's home for the sibling's "exact case is trivial or already assumed" (gap1 Observation 2): trivial in the concrete tree for deterministic $C$ (the type), assumed at the abstract level for mixed $C$ (the label).

Access (i) has no tree instance (dossier T10: a node cannot branch on a draw not yet made; post-decision chance that depends on the drawn action is *response*, not prediction — Lemma 3's screening-off). Access (ii) is not a property of one tree at all: it needs a measure over situations — §1.3.

### 1.2 Predictor-labelled instantiations — the bridge object

**Definition GR-D2 (predictor nodes; labelled instantiation).** In a concrete $B$ call a decision node $q \in F_d$ a *predictor node* if it is not subtree-veridical (Definition 7: some leaf below $q$ has $\lambda(\ell) \not\models O_d$) — Omega's simulation of the agent at $d$ — and *live* otherwise; write $F_d = F_d^{\mathrm{pred}} \sqcup F_d^{\mathrm{live}}$. For a *verdict* $\theta \in \prod_d \Delta(A_d)$, $B_\theta$ is $B$ with every predictor node of $d$ replaced by a chance node with law $\theta_d$ over the same children. $B_\theta$ is a concrete problem (Definition 5) in which the predictor's belief about the agent's disposition is a *label*: label-dependence made concrete by fixing the label.

**GR-2 [checked — `gr_predictor_labels.py`, block L1].** Under independent redraws $\mu_{B_\theta, C} = \mu_{B,C}$ whenever $\theta_d = C(d)$ for every queried $d$. Proof: Definition 6 samples each decision node's action independently from $C(d_q)$; a chance node with $\beta = C(d)$ samples the same law independently; leaf weights are the same products. $\square$ Verified on TN-V1 and TN-V2 (all four pure policies and the mixed $C = (\tfrac25, \tfrac37)$: labelled $= 9427/4900 =$ independent on V2, $1669/700$ on V1) and on the mugging. Under shared seed the identity **fails on both TN variants** (V2: shared $269/140 \ne 9427/4900$; V1: $317/140 \ne 1669/700$) because their fibers are nested (the hypothetical $d_F$ above the real $d_F$, P1:fair-repair FR-5), and holds on the mugging (the two members sit on disjoint branches). So: **the exact label predictor is the shared-seed simulation exactly on non-nested fibers; on nested fibers they differ by FR-7(b)'s mixed-grade gap** — P1 item 19 restated in access vocabulary: relocation (one draw per point) is realization access; independent redraws are sampling access.

### 1.3 Family access, formalized

**Definition GR-D3 (predictor-labelled abstract problem).** A *family* is a finitely supported measure $\pi$ on instantiations of an abstract problem $\Sigma$ (Definition 14) all querying the same points; a *verdict* $\theta$ enters each instantiation through its predictor nodes as in GR-D2. Write $B_{\omega,\theta}$ for situation $\omega \sim \pi$ under verdict $\theta$. Two rates per point and verdict:
$$g_d(\theta) := \mathbb E_{\omega\sim\pi}\,\mu_{B_{\omega,\theta},C}\big(\text{the run passes a live } d\text{-node}\big) \quad\text{(exercise rate: the family's data about } d\text{)},$$
$$m_d(\theta) := \mathbb E_{\omega\sim\pi}\,\mathbb E_{\mu_{B_{\omega,\theta},C}}\big[\#\mathrm{pred}_d\big] \quad\text{(use rate: how often the verdict about } d \text{ is consulted)}.$$
The verdict is *$\delta$-accurate on the family* if $\delta(\theta) := \sum_d g_d(\theta)\,\mathrm{TV}(\theta_d, C(d)) \le \delta$ (for deterministic $C$ and pure verdicts this is the family-weighted misclassification rate, the sibling's $\Pr_{o\sim D}(p(M,o)\ne\pi_M(o))$ with $o \leftrightarrow d$ and $D \leftrightarrow g$); $\gamma(\theta) := \min_d g_d(\theta)$ is the rarest exercise rate. Honesty conditions: **predictor-side**, $\delta$-accuracy, whose $\delta = 0$ form $\theta_d = C(d)$ at every exercised point is Remark 5.1's fixed-point equation at the family level; **agent-side**, mixture calibration (Appendix B item 4: $P_{s_d} = \bar\nu(\cdot \mid O_d)$, $\bar\nu = \int \nu_{B,C}\,d\pi$) — the agent's state matches the family average. Both are needed: the first says the environment's response tracks the disposition, the second that the agent's beliefs track the family it is in.

**GR-3 [derived].** Why the abstract-problem formalization rather than a sequence of problems: (1) v2's own stance (§9, Remark 5.4) is that calibration is the static shadow of a learning process — the sequence is the *process* and $(\Sigma_\pi, \theta)$ its shadow; (2) Definition 14 already hosts label-dependence, and GR-D2 says exactly which labels; (3) the sequence formalization exists and is the dynamic thread's interaction model (b) (DY-7: "a distribution over problems … family access (ii) — vocabulary flagged"). **Vocabulary alignment (flag to dynamic):** my $(\Sigma_\pi, \theta, \delta, \gamma)$ is dynamic's (family $\pi$, the learner's asymptotic estimate of the disposition, its error, the minimum consultation rate); DY-7's mixture optimum "pay iff $\pi > \tfrac{x+y}{2y}$" is the agent-side (mixture-calibration) half of GR-D3 on Prop 6's pair. What the static shadow loses: nothing about *values* (GR-5), everything about *time to learn* (§4).

## 2. The $\delta/\gamma$ bound, transported (mandate item 2)

### 2.1 The sibling's lemma and why its literal transport is vacuous

gap1 §4 (verbatim in dossier §4.10): if $\Pr_{o\sim D}(p(M,o)\ne\pi_M(o))\le\delta$ for each mechanism, then mechanisms with equal policies get predictions disagreeing on $D$-measure $\le 2\delta$, and on at most $2\delta/\gamma$ observations when $D(o)\ge\gamma$; utility corollary: fixed-observation regime $|U(M_1)-U(M_2)|\le 2\delta R$; prediction-dependent-observation regime $\le R(2\delta + L\cdot 2\delta/\gamma)$. Its proof is two lines ($S \subseteq S_1 \cup S_2$; counting).

In v2 "two mechanisms with the same policy" is empty: problems are functions of $C$ (Remark 3.1), so $V_B$ cannot distinguish mechanisms — the sibling's DD is the type (dossier T3). The non-vacuous content is the comparison between the *exact* verdict ($\theta = C$, GR-2) and an *inaccurate* one, which is what a learned predictor delivers; the roles of the sibling's $D$, $\delta$, $\gamma$, $L$ are taken by $g_d$, $\delta(\theta)$, $\gamma(\theta)$, $m_d$ of GR-D3.

### 2.2 The theorem

**GR-4 (verdict substitution) [derived].** Let $\theta, \theta'$ differ only at $d$. Then $\lvert V_{B_\theta}(C) - V_{B_{\theta'}}(C)\rvert \le R\cdot\mathrm{TV}(\theta_d,\theta'_d)\cdot\mathbb E_{\mu_{B_\theta,C}}[\#\mathrm{pred}_d]$, $R := \max r - \min r$. Proof: couple the two runs, using at every predictor $d$-node the maximal coupling of $\theta_d$ and $\theta'_d$ (same child with probability $1-\mathrm{TV}$) and identical draws elsewhere. The runs diverge only when some predictor $d$-node on the path draws differently; $\Pr(\text{diverge}) \le \sum_{q\in F_d^{\mathrm{pred}}}\Pr_\theta(\text{reach } q)\cdot\mathrm{TV} = \mathrm{TV}\cdot\mathbb E_\theta[\#\mathrm{pred}_d]$ (a path reaching $q$ before any divergence has the same law under both); on divergence the payoffs differ by at most $R$. $\square$

**GR-5 (the $\delta/\gamma$ bound in v2 quantities) [derived; checked on TN-V1, TN-V2, mugging — `gr_predictor_labels.py` block T].** Telescoping GR-4 over points,
$$\big\lvert V_{B_\theta}(C) - V_{B_C}(C)\big\rvert \;\le\; R\sum_d m_d\,\mathrm{TV}(\theta_d, C(d)) \;\le\; R\cdot\max_d\frac{m_d}{g_d(\theta)}\cdot\delta(\theta),$$
with $m_d$ a uniform bound on the use rate along the telescoping path. Two regimes:
- **Fixed-consultation regime** — the exercise rates $g_d$ do not depend on $\theta$ (the verdict does not route the run toward or away from live $d$-nodes). Then $\kappa := \max_d m_d/g_d$ is a constant of the tree and the loss is $\le R\kappa\delta$: the sibling's "$2\delta R$, no $\gamma$ anywhere" ($\kappa$ replaces the $2$ because we compare to the exact verdict rather than two $\delta$-accurate ones).
- **Prediction-dependent-consultation regime** — the verdict at $d$ routes the run (TN: whether you face a full box is the verdict). Then $g_d(\theta)$ can be as small as the verdict's own error, the bound is $R\,m_d\,\delta/\gamma$ with $\gamma = \min_d g_d(\theta)$, and since a single wrong verdict at a point exercised at rate $g_d$ costs only $g_d$ in $\delta$, the bound degenerates to $R\,m_d$: **no control by $\delta$ at all**. That is the sibling's blow-up in v2 numbers.

Numbers (TN-V2, $p = \tfrac34$, $L = 4$, $S = 1$, $R = 5$, agent $(1,1)$, exact verdict value $pL = 3$; use rates $m_F = m_E = 1$ since both hypothetical queries lie on every run):

| verdict $(\theta_F,\theta_E)$ | $V_{B_\theta}(1,1)$ | loss | $g_F$ | $g_E$ | $\delta$ | $\gamma$ | $R\sum m\,\mathrm{TV}$ | $R\max(m/g)\,\delta$ |
|---|---|---|---|---|---|---|---|---|
| (large, large) | $3$ | $0$ | $3/4$ | $1/4$ | $0$ | $1/4$ | $0$ | $0$ |
| (large, both) | $1$ | $2$ | $1/4$ | $3/4$ | $3/4$ | $1/4$ | $5$ | $15$ |
| (both, large) | $1$ | $2$ | $1/4$ | $3/4$ | $1/4$ | $1/4$ | $5$ | $5$ |
| (both, both) | $1$ | $2$ | $1/4$ | $3/4$ | $1$ | $1/4$ | $10$ | $20$ |

The sealing verdict (both, large): loss $= (2p-1)L$ exactly ($2, \tfrac{16}5, \tfrac{98}{25}, \tfrac{499}{125}$ at $p = \tfrac34, \tfrac9{10}, \tfrac{99}{100}, \tfrac{999}{1000}$) while $\delta = g_F = 1-p$, so loss$/\delta = 8, 32, 392, 3992 \to\infty$ and the bound $R\,\delta/\gamma = R = 5$ is tight up to the $S$ term. The *asymmetry* the sibling describes in words is in the table: the wrong-at-$d_E$ verdict (large, both) has the same loss $2$ but accuracy penalty $\delta = 3/4$ (the empty box is faced often; self-correcting), the wrong-at-$d_F$ verdict has $\delta = 1/4$ (the full box is faced only by predictor error; self-sealing) — ratio $p/(1-p)$.

Mugging ($x = 1, y = 3$, $R = 4$): $g_d = \tfrac12$ (tails) independent of the verdict, $m_d = \tfrac12$ (the heads-branch simulation), $\kappa = 1$; loss $= \tfrac12 y\,\lvert\theta_{\mathrm{pay}} - q\rvert = y\delta$, so loss$/\delta = 3$ constant, below $R\kappa = 4$: fixed-consultation, grounded at $\gamma = \tfrac12$.

**GR-6 (agent-side dual) [derived].** Let the agent's counterfactual structure be *counterfactually calibrated* (Remark 3.11's family; Definition 20's warning noted) to the family statistic $\theta$ rather than to the true deviation statistics: its $\mathrm{cUDT}$ act values are $V_{B_\theta}(C[d\mapsto a])$. Each is within $\eta := R\max_d (m_d/g_d)\delta$ of the true $V_{B_C}(C[d\mapsto a])$ (GR-5 applied to each deviation), so the agent's argmax loses at most $2\eta$ against the true optimum over deviations — the standard estimated-value bound. So "the value lost by an agent whose $\mathrm{cf}_s$ is calibrated to a $\delta$-accurate family statistic" is $\le 2R\max_d(m_d/g_d)\,\delta$, and blows up in the prediction-dependent regime exactly as GR-5 does.

**GR-7 (what the bound does not control) [derived; numbers P1:verify E2 / P1 item 16].** (i) At $\delta = 0$ the $k$-fold mugging with convex coupling $b_j = \mathbf 1[j=k]$ has an all-pay procedure that is Theorem-1-ratifiable but not optimal ($\partial V/\partial q\vert_{q=1} = \tfrac12(ky - x) > 0$ while $V(1) = \tfrac12(y-x) < 0 = V(0)$ for $y < x < ky$): the gap between a Theorem-1-ratifiable procedure and the $V$-optimum is an equilibrium-selection gap (Remark 5.2 multiplicity, Q4), not a predictor-error gap, and $\delta/\gamma$ says nothing about it. (ii) Under $k$-fold probing with independent redraws, the predictor's implicit estimate of $q$ is $j/k$ with $\mathbb E\lvert j/k - q\rvert \le \sqrt{q(1-q)/k} \le 1/(2\sqrt k)$; the value error of a label-realizing tree against the exact mixture label is the Jensen gap $\lvert \mathbb E[b(j/k)] - b(q)\rvert \le \mathrm{Lip}(b)/(2\sqrt k)$ — zero for affine $b$ (P1 item 16's "no dilution" case), the Bernstein approximation error otherwise. So in v2's self-contained trees "predictor error" is either chance noise written into the tree (TN's $1-p$) or finite-$k$ estimation; the sibling's $\delta$ has no other inlet.

## 3. Graded fairness (mandate item 3)

### 3.1 Three grades — GR-9 [checked — `gr_graded_fairness.py` (2), (3)]

Write $Q_q(C, a) := G_q(C, a)$ (v2 §8: the continuation value of $q$'s $a$-child under $C$ — under non-nesting the honest one-step deviation value at $q$). Define the **fiber value-disagreement** $D_V(B, C) := \max_d\max_{q,q'\in F_d}\max_a\lvert Q_q(C,a) - Q_{q'}(C,a)\rvert$ (payoff units; $\delta_V := D_V/R$ normalized). Three notions of "the point determines the node", in decreasing strength:
1. **labelled-isomorphic** fibers (P1 strong fairness; toolkit `is_strongly_fair`);
2. **law-fair**: every fiber's members have the same continuation $(\lambda, r)$-law under every procedure (FR-1(ii)'s $\theta_d$ well-defined);
3. **value-fair**: $D_V(B, C) = 0$ for every procedure $C$.
Each implies the next; both converses fail. Example (2): one point $d$ ($O_d = \top$, recorded) on two evented chance branches; left member: $a \to$ chance $\tfrac12/\tfrac12$ to payoffs $1, 3$, $b \to 0$; right member: $a \to$ payoff $2$, $b \to 0$. Not labelled-isomorphic (`is_strongly_fair` False), almost fair, laws differ, $D_V = 0$ ($Q(a) = 2, Q(b) = 0$ at both members). Example (3): left member's $a$-child a $\tfrac13/\tfrac23$ split to payoffs $1, 3$; right member's a $\tfrac13/\tfrac13/\tfrac13$ split to $1, 3, 3$: same $(r,\text{prob})$ law $\{(1,\tfrac13),(3,\tfrac23)\}$, not isomorphic (different arity; `is_strongly_fair` False even with the side coordinate exempted). Which grade does what: isomorphism gives the canonical DAG collapse (P1 item 2/slop Claim 1.3); law-fairness gives FR-1(ii) — the *state* of the point is the continuation law, per-run $=$ per-occurrence SSC $= \theta_d$ (P1 item 3; note the fork closes already under non-nesting, FR-1(i) — in example (2) both SSC senses accept the reach-weighted mixture state); value-fairness is all the *optimality* theorem needs (GR-10). Handoff to **equiv**: the "equivalent subtrees" relation for the value pipeline can be as coarse as value-equality; for calibration it must be law-equality; only the DAG-quotient needs isomorphism.

### 3.2 The graded theorem — GR-10 [derived; checked on the near-copy family]

**Theorem (graded FR-11).** Let $B$ be almost fair (no nested fiber), fully recorded for every procedure (FRec), with evented chance (EC), zero-probability edges pruned, every queried observation satisfied by some leaf-world (P1 item 20's hypotheses minus isomorphism), and let $H$ be the maximum number of decision nodes on a root–leaf path. Let $D_V := \sup_{0<\varepsilon<\varepsilon_0} D_V(B, C^\varepsilon)$. If $C$ is tremble-EDT-consistent (FR-11's concrete form: for all small $\varepsilon$ some state assignment makes $B$ strictly OC-calibrated (Def 8) for $C^\varepsilon$ with $T_{\mathrm{EDT}}(C, B_\varepsilon)$), then
$$V_B(C) \;\ge\; \max_{C'} V_B(C') \;-\; 2HD_V .$$
*Proof.* Step 1 (calibrated act values are averages of member $Q$-values). Under FRec and non-nesting, $O_d$-runs pass exactly one live $d$-node, its draw is stamped and independent of the reach, so $V_{s^\varepsilon_d}(a) = \mathbb E_{\mu_\varepsilon}[r \mid \lambda\models a\wedge O_d] = \sum_{q\in F_d^{\mathrm{live}}} w_q\,Q_q(C^\varepsilon, a)$ with $w_q = \Pr_\varepsilon(q\mid O_d)$ (simulation members drop out of the *conditioning* but stay in $V$). Hence for every member $q \in F_d$ (live or simulation) and every $a$: $\lvert V_{s^\varepsilon_d}(a) - Q_q(C^\varepsilon, a)\rvert \le D_V$. Step 2 (support condition transfers with slack). Recording under full support gives $A_d^+ = A_d$; $T_{\mathrm{EDT}}$ says $V_{s^\varepsilon_d}(a^\ast) \ge V_{s^\varepsilon_d}(a)$ for $a^\ast\in\mathrm{supp}\,C(d)$; so $Q_q(C^\varepsilon, a^\ast) \ge Q_q(C^\varepsilon, a) - 2D_V$ at every member $q$; leaf probabilities are polynomials in $\varepsilon$, so letting $\varepsilon\to0$: $Q_q(C, a^\ast) \ge Q_q(C, a) - 2D_V$. Step 3 (induction on height with *procedure* optima). Let $M'_q := \max_{C'} W_{C'}(q)$ be the procedure optimum of the subtree at $q$ and $W_C(q)$ $C$'s continuation. Claim: $W_C(q) \ge M'_q - 2D_V h(q)$, $h(q)$ = decision nodes on the longest path below $q$ inclusive. Leaves trivial; chance nodes average. Decision node $q\in F_d$: $M'_q \le \max_a M'_{q_a}$ (a procedure's value at $q$ is a mixture of its values at the children, each $\le M'_{q_a}$); $W_C(q) = \sum_a C(d)(a)W_C(q_a) \ge \min_{a^\ast\in\mathrm{supp}} W_C(q_{a^\ast})$; under non-nesting $W_C(q_a) = Q_q(C,a)$; by Step 2, $W_C(q_{a^\ast}) \ge W_C(q_{a'}) - 2D_V$ for the $a'$ maximizing $M'_{q_a}$; by induction $W_C(q_{a'}) \ge M'_{q_{a'}} - 2D_V(h(q)-1)$. Chain: $W_C(q) \ge M'_q - 2D_Vh(q)$. At the root $M'_{\mathrm{root}} = \max_{C'}V_B(C')$. $\square$

At $D_V = 0$ this is FR-11 with **value-fairness replacing labelled isomorphism** — a genuine weakening: the proof never used the fair-tree assignment lemma (procedure optima suffice) and never used law-equality. [checked, example (2): the only tremble-EDT-consistent deterministic procedure is $a$, which is optimal, $V = 2 = $ `optimal_value`.]

**Sharpening (single fiber) [derived]; general [guess].** For a single queried point, EDT at face value already maximizes the reach-weighted average of the *live* members' $Q$-values, which is also what a procedure (one action per point) can best do on the live members; the only loss is the simulation members' share: loss $\le (\sum_{q\in F_d^{\mathrm{pred}}} R_q)\cdot D_V$. Checked on the near-copy mugging family (`gr_graded_fairness.py` (1b): live $d$-node pay $\to -x$, refuse $\to 0$; simulation member pay $\to \kappa$, refuse $\to 0$; $x = 1$):

| $\kappa$ | $\max V$ | face-value tremble-EDT | loss | $R$ | $2HD_V$ | $(\tfrac12)D_V$ |
|---|---|---|---|---|---|---|
| $-1, -\tfrac12, 0, \tfrac12, 1$ | $0$ | refuse, $0$ | $0$ | $1,1,1,\tfrac32,2$ | $0,1,2,3,4$ | $0,\tfrac14,\tfrac12,\tfrac34,1$ |
| $\tfrac32$ | $\tfrac14$ | refuse, $0$ | $\tfrac14$ | $\tfrac52$ | $5$ | $\tfrac54$ |

The normalized $\delta_V$ saturates at $1$ on this family (the disagreement *is* the range), which is why the theorem is stated in payoff units. The general multi-fiber sim-share version needs an order on fibers that entangled fibers do not have (P1 FR-3's ping-pong tree: $d$-nodes below $e$-nodes on one branch, $e$-nodes below $d$-nodes on the other), so it stays [guess]; the node-level induction above is what survives entanglement.

### 3.3 (a) The corner — GR-11 [derived; checked]

### 3.4 (b) Coupling-credence is learnable only at the exercise rate — GR-12 [derived; numbers `gr_markov.py` D]

Let the agent hold a credence over coupling hypotheses $h$ (instantiations of the mugging's abstract problem that agree everywhere except on what happens on the heads branch when the agent's disposition is pay — spectrum SP-E2's $\{B_1, B_1^{\mathrm{inert}}\}$, or a rate $c$ of transfers to payers). Every episode that does not reach the coupled branch with a paying disposition has likelihood ratio $1$ between any two such hypotheses; so the Bayesian credence is a function of the *test episodes* alone, whose number by time $t$ is $N_t \sim \mathrm{Bin}(t, \gamma_{\mathrm{test}})$ with $\gamma_{\mathrm{test}} = \Pr(\text{heads})\cdot\Pr(\text{disposition pay}) = q/2$ under a simulating Omega (independent redraws; under the memory-1 learning Omega the test needs a tails-pay *followed by* heads — §4.3). For a Beta-rate model the posterior variance after $N$ tests is $\approx c(1-c)/N$, so the credence's *speed* is $\gamma_{\mathrm{test}}$: in expectation $\gamma_{\mathrm{test}}t$ tests by time $t$, and a refuser ($q = 0$) has $\gamma_{\mathrm{test}} = 0$ — the trap (P1:verify G2) as the $\gamma = 0$ case of the same statement. This is the sibling's "strength degrading as $\delta/\gamma$" on the agent's side: the *family's support* (which branches the agent's own policy exercises) bounds how fast any coupling credence can move. **For spectrum (C4, SP-20/SP-24):** Bayesian updating never zeros a hypothesis, so it never moves the repair's *depth* (SP-20 is right); the "support decay" spectrum asked grounding for is the non-Bayesian rule "drop hypotheses whose distinguishing branches are exercised at rate below $\gamma$" — those are exactly the hypotheses whose credence has speed $< \gamma$, i.e. cannot be learned within the horizon; with the rule, the LCA does move (a fiber whose coupling hypotheses are all dropped becomes a spurious query, P1 CF-15). Decay's speed is a function of the family's support in this precise sense; whether to adopt the truncation rule is spectrum's adjudication, not mine.

## 4. Self-sealing verdicts and the refuser trap (mandate item 4)

### 4.1 The sibling's chain, exactly — GR-14 [checked — `gr_markov.py` A]

selfseal §2: verdict $v_t \in \{1B, 2B\}$ about a true one-boxer; box filled w.p. $1-\varepsilon$ under $1B$, $\varepsilon$ under $2B$; a filled box reveals the full-box action and sets the verdict; drift $\rho$ per episode. Ordering A (drift, then fill): $P(1B\to2B) = \rho(1-\varepsilon)$, $P(2B\to1B) = \rho + (1-\rho)\varepsilon$; stationary $\pi(2B) = \dfrac{\rho(1-\varepsilon)}{2\rho + \varepsilon - 2\rho\varepsilon}$, odds $2B:1B = \rho(1-\varepsilon) : (\rho+\varepsilon-\rho\varepsilon)$. Ordering B (fill, then drift): $\pi(2B) = \rho/(2\rho+\varepsilon-2\rho\varepsilon)$, odds $\rho:(\rho+\varepsilon-2\rho\varepsilon)$. The sibling's "$\rho : \rho+\varepsilon$" is the first-order odds in both orderings — confirmed as stated (it is odds, not a probability; at $\rho = \varepsilon = \tfrac1{100}$ the exact $\pi(2B)$ is $99/298 \approx 0.332$, odds $99/199$). Vindication time from $2B$ at $\rho = 0$: geometric($\varepsilon$), mean $1/\varepsilon$. The realized per-episode value of *being* a one-boxer (selfseal §5 item 1's request): $f(\varepsilon,\rho) = L\big[(1-\varepsilon)\pi(1B) + \varepsilon\pi(2B)\big] = \dfrac{L(1-\varepsilon)(\varepsilon+\rho)}{2\rho+\varepsilon-2\rho\varepsilon}$; $f \to L(1-\varepsilon)$ as $\rho \to 0$ and $f \to L/2$ as $\varepsilon\to0$ with $\rho>0$ — with no exploration, drift alone leaves the one-boxer correctly classified half the time.

### 4.2 One chain, two bearers — GR-15 [derived; hazards checked]

Refuser trap (slop §6 via P1:verify G2 CONFIRMED; dynamic DY-13): credence $\pi$ over $\{h_1 = $ Omega couples, $h_0 = $ inert$\}$, pay iff $\pi > x/y$; a payer sees decisive evidence on every heads episode; a refuser sees no transfer under either hypothesis (likelihood ratio $1$), so refusing at $\pi_0 \le x/y$ is self-confirming. With exploration (pay w.p. $\eta$ while sealed) and a simulating Omega with symmetric transfer noise (transfer w.p. $1-\varepsilon$ if the simulated disposition pays, $\varepsilon$ if it refuses), the sealed state's escape hazard per episode is $r_b = \tfrac12\big[\eta(1-\varepsilon) + (1-\eta)\varepsilon\big] = \tfrac12(\eta+\varepsilon-2\eta\varepsilon)$ (a transfer of either origin is decisive for coupling): $\eta/2$ at $\varepsilon = 0$ (dynamic's correction of XC-8's "$1/\eta$": mean $2/\eta$), $\varepsilon/2$ at $\eta = 0$. Add forgetting $\rho$ (a fresh agent with the sealed prior arrives w.p. $\rho$ per episode) and the stationary sealed probability is $\rho(1-r_b)/(\rho(1-r_b)+\rho+(1-\rho)r_b)$ — GR-14's formula with $\varepsilon \mapsto r_b$.

**Identification.** Both are the *gated-learning chain*: two states, data that confirms arrives at rate $\approx 1$ in the good state and data that corrects arrives at rate $r_b$ in the bad state, where $r_b$ is a tremble; drift/forgetting $\rho$ makes both states transient; stationary odds bad:good $\approx \rho : (\rho + r_b)$; vindication time $1/r_b$. The two are one Markov skeleton with these substitutions and these five differences: (1) *state-holder*: the predictor's verdict about the agent (TN) vs the agent's credence about the predictor (mugging) — the "withholding role swapped" of XC-8, confirmed. (2) *Seal-breaker*: in TN only the predictor's tremble $\varepsilon$ can unseal (the sealed branch, a full box, is under Omega's control), and the agent's own tremble at $d_F$ (two-boxing when full) *confirms* the seal — hazard $\varepsilon(1-\eta_F)$; in the mugging the agent's exploration $\eta$ and Omega's tremble $\varepsilon$ *add*. (3) The factor $\tfrac12$: the mugging's coupled branch is reached only on heads; TN's box decision is reached every episode. (4) *Two-sided correctness*: the mugging's payer learns the truth under either hypothesis (under $h_0$ it stops paying after the first heads); TN's chain has no analogue because the learner is the predictor and the agent's type is fixed. (5) *Cost bearer*: in TN the seal costs the agent ($L$ per episode) but only the predictor can pay to break it; in the mugging cost and remedy both fall on the agent, unless Omega trembles at its own cost — §4.6.

### 4.3 The product chain with a learning Omega — GR-16 [checked, exact — `gr_markov.py` C; Lean candidate `grounding-learning-omega-unsealing.lean`]

Agent: two hypotheses, sealed $S$ (refuses, explores w.p. $\eta$ on tails) or unsealed $U$ (pays). States $(v, a) \in \{P,R\}\times\{U,S\}$; truth $h_1$. Transitions: tails ($\tfrac12$): $(\cdot,U)\to(P,U)$; $(\cdot,S)\to(P,S)$ w.p. $\eta$, $(R,S)$ w.p. $1-\eta$. Heads ($\tfrac12$): $(P,S)\to(P,U)$ (transfer observed); all other states fixed. ### 4.6 Who pays for the trembles — GR-19, GR-20, GR-21

**GR-19 (mugging) [derived].** Two ways to break the refuser's seal: agent exploration at rate $\eta$ (hazard $\eta/2$, cost under $h_0$ $x\eta/2$ per episode — cost per unit hazard $x$) and Omega's tremble $\varepsilon$ (transfers to refusers on heads: hazard $\varepsilon/2$, cost to Omega $y\varepsilon/2$ per episode — cost per unit hazard $y$). Since $x < y$, the efficient unsealer is the agent. And Omega has nothing to learn in the mugging — the tails branch is exercised every tails episode, so its verdict is always current and its accuracy is never at stake; whatever Omega's objective, unless it includes the agent's welfare, $\varepsilon^\ast = 0$. **The equilibrium grounding level on the mugging is a corner: Omega supplies none, the agent supplies a transient exploration rate** (DY-13's $\sum\eta_t = \infty$, $\eta_t\to0$; GR-18's constant under a learning Omega). There is no stationary interior pay rate for a single agent under a stationary coupling: the mixture value $V_\pi(q) = \tfrac q2(\pi y - x)$ is affine in $q$ (spectrum SP-19), so the optimum is a threshold.

**GR-20 (TN) [derived first order; checked exact — `gr_markov.py` F, F′; `gr_population.py`].** In TN only the predictor can pay (GR-15 (2)). Give Omega the accuracy objective: minimize $g(\varepsilon) = f L\,\pi(2B\mid\text{one-boxer}) + (1-f)L\varepsilon$ — misclassified one-boxers (a fraction $f$ of the population) lose $L$, and each tremble on a two-boxer wastes $L$. With the first-order $\pi(2B) \approx \rho/(\rho+\varepsilon)$: $\varepsilon^\ast = \sqrt{\rho f/(1-f)} - \rho$, interior iff $f/(1-f) > \rho$. Exact-objective grid argmin vs the formula: $(f,\rho) = (\tfrac12,\tfrac1{100})$: $0.080$ vs $0.090$; $(\tfrac9{10},\tfrac1{100})$: $0.285$ vs $0.290$; $(\tfrac1{10},\tfrac1{100})$: $0.015$ vs $0.023$; $(\tfrac12,\tfrac1{10})$: $0.145$ vs $0.216$ — good at small $\rho$, off by up to $30\%$ otherwise. The two-boxer's chain (its misverdict $1B$ is corrected whenever the box is filled, hazard $1-\varepsilon$) gives $f_2 = S + L[(1-\varepsilon)\pi(1B\mid 2\text{-boxer}) + \varepsilon\,\pi(2B\mid 2\text{-boxer})]$; the one-boxer's value is GR-14's $f_1$. At $L = 4, S = 1$ one-boxing wins at every sampled $(\rho,\varepsilon)$ ($f_1 = 3.36, 2.66, 2.10$ vs $f_2 = 1.40, 1.04, 1.00$ at $\rho = \tfrac1{100}$, $\varepsilon = \tfrac1{10},\tfrac1{100},\tfrac1{1000}$) — no interior population mixture. At $L = 4, S = \tfrac52, \rho = \tfrac1{100}$ with types endogenous and $\varepsilon = \varepsilon^\ast(f)$: $f_1 - f_2$ is negative at $f \le 0.02$, positive on $[0.05, 0.7]$, negative from $f = 0.8$ on — two indifference points, the lower ($\approx 0.03$) unstable, the upper ($f^\ast \approx 0.75$) **stable**: below it one-boxing pays better and $f$ rises, above it Omega's exploration hands two-boxers enough filled boxes ($\varepsilon^\ast(0.8) = 0.19$) that two-boxing pays better and $f$ falls. At $\rho = \tfrac1{10}$ two-boxing dominates throughout (the one-boxer is never grounded well enough: $f_1 \le L/2 < S + \ldots$).

## 5. Told-You-So through the self-sealing lens (mandate item 5) — GR-22 [checked — `gr_told_you_so.py`]

$B_P$ (§7.1): root queries $d_5$ (announced $5$): $m{=}5 \to (5,5)$; $m{=}10 \to$ query $d_{10}$ (announced $10$): $m{=}10\to(10,10)$, $m{=}5\to(10,5)$; $s_5, s_{10}$ certain of $(5,5), (10,10)$; the zero-respecting $C_0$ takes $5$ at $d_5$, value $5$; $C^\ast$ takes $10$ at both, value $10$ (Prop 8). Toolkit facts recomputed: strongly fair (singleton fibers), does not record at $d_5$ for any procedure, root not subtree-veridical.

Is $B_P$ a self-sealing verdict system? Yes, but of a type the sibling's chain does not contain. In TN the sealed verdict is *false* (a one-boxer called a two-boxer) and unfalsifiable because the withheld box generates no data. In $B_P$ the announcement $5$ is *true* — $C_0$ really does take $5$ given the announcement — and it is sealed because the agent's own policy of respecting the state's zero at $d_5$ makes the fallback branch ($d_{10}$, value $10$) never fire. The gate is not withheld data but the agent's dogmatic zero: a *selection* seal (P1 item 12: "an announcement is a controllable wearing an observation's label"). Consequences, all checked:
- (a) problem-side limit calibration (Def 10) leaves the seal: $\lim_\varepsilon \nu_{C_0^\varepsilon}(\cdot\mid O_5) = \delta_{(5,5)}$ exactly (the $O_5$-leaf is reachable only through the compliant draw — Remark 3.4's selection bias), $\lim \nu_{C_0^\varepsilon}(\cdot\mid O_{10}) = \delta_{(10,10)}$: $B_P$ is limit-calibrated for $C_0$ (Prop 8), as remark (4) says;
- (b) observation-event-conditioned tremble-EDT (FR-11's concrete form; toolkit `tremble_edt_consistent`) *approves* $C_0$: the $\varepsilon$-calibrated state at $d_5$ still has $\nu_\varepsilon(m{=}10\mid O_5) = 0$, so $A^+_{d_5} = \{m{=}5\}$ and $T_{\mathrm{EDT}}$ has nothing to object to (P1 fair-repair §3.2's third bullet, reproduced);
- (c) act-event-conditioned tremble value with the observation dropped (v2 §7.1 remark (2)'s device): $\mathbb E_{C_0^\varepsilon}[r\mid m{=}10] = 10 > 5 = \mathbb E_{C_0^\varepsilon}[r\mid m{=}5]$ — breaks the seal;
- (d) draw/occurrence-conditioned forcing (Theorem 1's $G_q$; Appendix B's tremble/forcing conjecture, P1 item 15): at the root $G(m{=}5) = 5$, $G(m{=}10) = 10$, $\mathrm{supp}\,C_0(d_5) = \{m{=}5\} \not\subseteq \arg\max = \{m{=}10\}$ — Theorem 1's condition fails for $C_0$ and holds for $C^\ast$: breaks the seal.
Rate and cost: under Def 10's uniform tremble $\nu_{C_0^\varepsilon}(O_{10}) = \varepsilon/2$, so the sealed branch is exercised at rate $\varepsilon/2$, mean $2/\varepsilon$ episodes to the first exercise (XC-19's number confirmed), and the exercise *pays* $10 > 5$: exploration cost negative — the seal is held by nothing but the zero. Data-side: no leaf-world has $n{=}5\wedge m{=}10$; an observation-conditioned learner (dynamic's $\kappa = \mathrm{ev}$) can never observe a counterexample to "announced $5 \Rightarrow$ I take $5$" at any $\varepsilon > 0$, because the truthful prophet changes the announcement when the agent deviates. **What the lens adds to the Löb-shadow diagnosis** (remarks (1)–(4) after Prop 8): it predicts *which* procedure-side device breaks the seal — any device that conditions on the controllable (the draw or act-event) rather than on the pseudo-observation it falsifies — and *why* the observation-conditioned devices (Def 10; FR-11's event-conditioned tremble-EDT) cannot, at any tremble rate: the seal sits on the conditioning event itself. It also gives the cost: $2/\varepsilon$ episodes to exercise, no exploration loss. The learning-first reading (dynamic): $B_P$ is $\mathcal L_{\mathrm{occ}}$-learnable and $\mathcal L_{\mathrm{ev}}$-unlearnable at every $\varepsilon$ — flagged, not developed.

## 6. Reference classes (mandate item 6) — GR-23 [derived]

selfseal §3: *family-across-time* (reputation: the predictor's data is this agent's past episodes; "a merely updateful agent with memory already one-boxes") vs *family-across-agents* (reference class: other instances of the type; the episode is single-shot; "this is where distinctively updateless content survives"); the boundary between the predictor's type system and the agent's self-model is "an ontology question" — a mismatched-ontologies instance.

Does v2's occurrence structure distinguish them? (1) *Across-agents* is rendered inside one run: the other instances are the other members of the fiber $F_d$ (Omega's simulations are copies of the agent at the same point), $\#_d$ counts them, Definition 13 weights them; the coupling that gives updatelessness its content is Definition 22's all-occurrence deviation — the agent's choice is the *type's* choice, and the "measure-zero contribution of the individual" is the $k\to\infty$ pivotality of one member under per-occurrence weights (P1 item 16: sign set by the coupling's curvature, not a uniform $1/k$). (2) *Across-time* is outside one run: either a sequence of problems (dynamic's model (a)) or one big tree in which each episode's point carries its history in $O_d$ — then no two nodes share a point, fibers are singletons, the tree is strongly fair and FR-11 makes EDT $=$ UDT there: "the updateful agent with memory already one-boxes" is a theorem of the fair class, and §4.3's product chain is that big tree taken episode by episode (the verdict is a state variable causally downstream of the agent's past action, so a sequential updateful reasoner pays for the future — no updateless content). (3) Definition 13's per-run/per-occurrence fork is *orthogonal*: it weights members within across-agents and says nothing about time (dossier T13 confirmed). (4) The sharp point: **v2 deliberately conflates the two as predictor data under independent redraws** — $k$ simulation members within a run yield $k$ i.i.d. samples of $C(d)$, exactly what $k$ episodes would (Remark 5.4: "repeated interaction is repeated probing"; Prop 4; P1:verify E5) — **and separates them under shared seed**, where the members return one draw (copies, not samples). The run semantics is therefore the switch between "the fiber is a reference class of identical instances" and "the fiber is a sample of my behaviour": handoff to **seeds** (Q12).

Where the reference-class boundary lands: in **point identity** (Remark 2.2 — the fiber is the extension of exact $(s,O,A)$ identity; PC-6's one-belief-different simulation is a different point, a singleton fiber, no coupling in the description even though Omega's type system treats it as "you") — with the **algebra** (Q1/Q7) as what makes the instances distinguishable at all (coarsen $\mathcal E$ so the one belief is not an event and the points merge), and the fiber structure as the *consequence*, not the locus. Dependencies stated, not resolved: **identity** owns whether point identity should be coarsened to behavioural/type identity (XC-6, XC-17); **anticipation** owns the cross-ontology bridge (SC Def 12.2 with $\hat C$ = the algebra the predictor's type system can express — dossier XC-17's test). My contribution to both: under independent redraws the *data* Omega has about the type is the same whether the type is "copies of me now" or "me over time", so the boundary cannot be read off the statistics — it is a modelling choice about which nodes carry the same point, i.e. a choice of fibering; under shared seed the copies are statistically distinguishable from the samples (one bit vs $k$), so the boundary becomes observable in the run law.
