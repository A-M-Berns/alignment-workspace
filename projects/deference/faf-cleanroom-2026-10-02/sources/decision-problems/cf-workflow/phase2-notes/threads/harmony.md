## 0. What the two formalisms are, in one paragraph each (the objects the bridge must match)

v2 side: a concrete problem $B$ (Definition 5) is a finite tree with chance nodes $\beta_n$, decision nodes labelled by points $d = (s_d, O_d, A_d)$ (Definition 3; identity is identity of the whole triple, Remark 2.2, so one point labels a *fiber* $F_d$ of nodes), and leaves $(\lambda(\ell), r(\ell))$; a procedure $C : (d : \mathcal D) \to \Delta(A_d)$ (Definition 4) induces $\mu_{B,C}$ by independent redraws (Definition 6) and the common value $V_B(C) = \mathbb E_{\mu_{B,C}}[r]$. There is exactly one payoff, attached to leaves, and every point's stake in it is the same number: the tree is an identical-interest object. Beliefs live in the labels $s_d$ and are *constants*; calibration (Definitions 8–11, 13) equates them with $C$-dependent statistics — the fixed-point structure of v2 §5.

SC Part II side: a decision-point $d_i = (\hat{\mathbf X}_i, A_i, u_i)$ (SC Def 9.1) is a *player*: its own probability space, a finite action set, and a utility $u_i : A \times X_i \to \mathbb R$ on the *joint* action space $A = \prod_j A_j$; $U_i(O) = \mathbb E_{\mathbf X_i}[u_i(O, \cdot)]$ for a pure joint outcome $O \in A$. The world-models $\mathbf X_i$ are fixed measures — they do not depend on the outcome $O$ being evaluated. Harmony (SC Def 10.1, "no decision-point has a profitable unilateral deviation that modifies the computation of any other decision-point's action") is *defined as* (SC Def 10.4; audit headline 7) trembling-hand perfect equilibrium of the bargaining game $\mathcal G$ (SC Def 10.2: strategies $(b_i, \mathcal A_i)$ = batna + acceptable set; outcome $\mathrm{sel}(\bigcap_i \mathcal A_i)$ if nonempty, else the batna profile; sel = argmax of a Pareto-consistent welfare $W$, SC Def 10.3). SC Thm 11.1 claims every harmonious outcome is subjectively Pareto-undominated (DNI-6: proved with the $\varepsilon$-gap); SC Thm 13.1 recovers classical UDT when $\mathbf X_i = \mathbf X$, $u_i = u$; SC Remark 13.2 (DNI-5, unproven) says maintaining $\mathbf X_i = \mathbf X$ is the unique harmonious profile and updating breaks harmony.

The bridge dossier's "same word, different object" table (§0.3) is binding: v2's "coherence" (Definition 22, a Nash-type condition on $V_B$) and SC's "epistemic coherence" (SC Def 12.1, a conditioning relation between beliefs) are unrelated words; v2's "calibration" is external (state = run statistics), SC's is internal (kernel = own conditional). Nothing below trades on either pun.

## 1. The translation (Task 1)

### 1.1 Granularity: one SC decision-point per queried point

**HA-1 [derived] — the induced collection is one decision-point per queried point, $\mathrm{DP}(B) := \{\, \delta_d = (\hat{\mathbf X}_d, A_d, u) : d \text{ queried in } B \,\}$, with joint action space $A = \prod_d A_d$ = the pure profiles = $\mathrm{Agent}(\mathrm{Fr}(B))$ (P1:synthesis item 4), world-state space $E$ = chance-outcome profiles (one outcome per chance node, the frame's "lazy coins") carrying $\beta := \bigotimes_n \beta_n$, and the *common* utility $u(O, e) := r(\mathrm{leaf}(O, e))$ — the payoff of the leaf that the pure profile $O$ and the chance profile $e$ jointly determine.** Three alternatives were rejected. *Per node* (players = decision nodes, joint outcomes = assignments of Proposition 5(a)): the type forbids it — a procedure is a function of the point, and "deviate at this occurrence only is not an operation the type supports" (Remark 2.2); a per-node bargaining game would optimize over assignments and reach Proposition 5(b)'s unattainable values (Remark 4.3's miniature: assignment optimum $2$ against pure-procedure value $0$ and mixed-procedure optimum $\tfrac34$; the AMD: $4$ against $1$ and $\tfrac43$) [checked, `miniature.py`; P1:fair-repair FR-7(c)]. *Per fiber* is per point (the fiber is the set of nodes carrying the point). *Per observation* would merge same-$O$ points with different states, which v2 keeps distinct (Remark 4.4) and which SC's §14 would also keep distinct unless one state is a calibrated update of the other. The per-point choice also matches SC's own individuation: two nodes carrying the same point carry the same $\hat{\mathbf X}$ and are "the same decision-point" trivially in SC §14's sense.

With the homogeneous world-model $\mathbf X_d := \beta$ for every $d$, $U_d(O) = \mathbb E_\beta[r(\mathrm{leaf}(O,\cdot))] = V_B(O)$ for every pure profile $O$ — exact (bridge-dossier row T20). The utilities are identical across players ($u_d = u$), so **heterogeneity can enter only through $\mathbf X_d$**: v2's trees are identical-interest games with, possibly, heterogeneous beliefs.

### 1.2 World-models: from $\beta$, not from the calibrated states — and where the calibrated states *can* be used

**HA-2 [derived] — SC's type requires each $\mathbf X_d$ to be a fixed measure on $E$ (independent of the outcome $O$ being evaluated); v2's calibrated states $P_{s_d} = \nu_{B,C}(\cdot \mid O_d)$ (strict OC, Definition 8) are measures on worlds that depend on the procedure $C$ through the conditioning; they translate into an SC world-model exactly when the conditioning event is *chance-determined* — a set of chance profiles $E_d \subseteq E$ such that "$\lambda(\mathrm{leaf}(O,e)) \models O_d$ iff $e \in E_d$" for every pure profile $O$ — in which case $\mathbf X_d := \beta(\cdot \mid E_d)$ and $U_d(O) = \mathbb E_\beta[r(\mathrm{leaf}(O,\cdot)) \mid E_d]$.** Instances. (i) Counterfactual Mugging $B_1$ (Proposition 6): $O_T = \{\mathrm{coin} = T\}$ is chance-determined, $\mathbf X_d = \beta(\cdot \mid T) = \delta_T$, $U_d(\mathrm{pay}) = -x$, $U_d(\mathrm{refuse}) = 0$ — the updated (SC Remark 13.2 "conditionalized") decision-point refuses; the homogeneous one has $U(\mathrm{pay}) = \tfrac12(y-x)$ and pays iff $y > x$ [checked, `tn_bg.py`, at $x=1,y=2$: $E[r \mid T] = -1$ vs $V = \tfrac12$]. (ii) Transparent Newcomb V1/V2 (§7.2): $O_F = \{\mathrm{fill} = 1\}$ and $O_E$ are *not* chance-determined — the branch taken depends on the hypothetical answers, so which chance node's coin is consulted depends on $O$ — and no profile-independent $\mathbf X_F$ exists. The only reading available is *own-profile* event-conditioning, $U_d(O) := \mathbb E_{\mu_{B,O}}[r \mid \lambda \models O_d]$, which is Proposition 10's myopic functional and *not* of SC's form $\mathbb E_{\mathbf X_d}[u(O,\cdot)]$ (its conditioning measure moves with $O$: $\nu_{(1,1)}(O_E) = 1-p$, $\nu_{(1,2)}(O_E) = p$, Proposition 10). Used as a bookkeeping device it gives $U_F(x,y) = L + S\,\mathbf 1[x=2]$, $U_E(x,y) = S\,\mathbf 1[y=2]$ [checked, `tn_bg.py`: $(4,4,5,5)$ and $(0,1,0,1)$ at $p=\tfrac34, L=4, S=1$]. (iii) Occurrence-conditioning (per-run SSC, Definition 13) translates iff $\{e : \mathrm{leaf}(O,e) \in \mathrm{occ}(d)\}$ is independent of $O$: true where $\mathrm{occ}(d)$ is every leaf (the mugging, TN-V2's both points — Remark 7.1 — the AMD, the miniature), where it *coincides with the homogeneous model* $\beta$; false for TN-V1's $d_E$ (the empty branch is reached iff the hypothetical $d_F$-answer routes there) and for any point below another point's action. Lemma 1 makes $\mu(\mathrm{occ}(d))$ invariant under deviations *at $d$*; SC's type needs invariance under everyone's deviations.

Consequence for the calibration vocabulary: SC Remark 13.2's dichotomy "$\mathbf X_i = \mathbf X$ vs $\mathbf X_i = \mathbf X(\cdot \mid \bar e_i)$" is, in v2, "prior calibration (Definition 11) at every point vs strict observation calibration (Definition 8) at every point", and the second is expressible in SC's type only on the sub-class where every queried observation is chance-determined. This is precisely the cf-frontier thread's "$\varepsilon$-determined" observation notion (P1:synthesis open problem 1) met from the other side. *Handoff → cf-frontier.*

### 1.3 Grade: pure / shared-seed, not independent redraws

**HA-3 [derived; checked] — the translation is exact at the pure-profile grade; mixed strategies of $\mathcal G$ produce distributions over pure outcomes (correlated / shared-seed grade, Q12), so on trees with nested fibers v2's independent-redraw values exceed anything the bargaining game can represent: the AMD's $\tfrac43 > 1$ (P1:synthesis item 4) and Remark 4.3's miniature's $\tfrac34 > 0$ [checked, `miniature.py`: $V_{\text{indep}}(q) = 3q - 3q^2$, $V_{\text{shared}} \equiv 0$, both pure values $0$]. On almost-fair trees (no nesting) $V_B$ is multiaffine in the per-point mixtures, so mixed optima are attained at pure profiles and nothing is lost.** This is XC-16 confirmed; owner seeds. Every identity below is stated at the pure grade.

### 1.4 Type-check of SC Thm 11.1's hypotheses, and where its $\varepsilon$-gap lands

Finite $A$: yes (finitely many queried points, finite $A_d$). Welfare selection rule: exists — in the homogeneous translation $W := V_B$ plus any injective tie-break is Pareto-consistent; in general SC's "standard argument" for finite $A$ holds (any strictly Pareto-consistent injective $W$, e.g. a weighted sum of normalized $U_d$ with a generic tie-break). Trembling-hand equilibrium of $\mathcal G$: $\mathcal G$ is a finite game, so Selten's existence theorem applies [reconstructed: Selten 1975, cited by SC's references]. So the hypotheses type-check on *every* concrete $B$. The $\varepsilon$ of SC Thm 11.1 perturbs the *proposals* $(b_i, \mathcal A_i)$ of the bargaining game, not the actions at tree nodes: in v2's vocabulary it is Definition 10's tremble $C^\varepsilon = (1-\varepsilon)C + \varepsilon\,\mathrm{Unif}$ applied to the *bargaining game encoded as a tree* (one point per player with action set = its $K_i$ proposals; each other proposal then gets weight $\varepsilon/K_i$), with Remark 3.12's "normative against its own trembled statistics for all small $\varepsilon$" as the equilibrium condition — and the payoff of every proposal is then a polynomial in $\varepsilon$ whose lowest-order coefficients decide (the toolkit's `sign_near_zero_plus`). XC-9 hoped this closes the gap. It does the opposite: the coefficient comparison can be carried out exactly, and it goes against the theorem.

**HA-4 [checked] — SC Theorem 11.1 is false as stated, already for two players, two actions each, and strict subjective Pareto dominance.** Counterexample (`bargaining_fast2.py`, seed 17; verified independently in `verify_cx.py`): players $1, 2$ with $A_1 = \{a, b\}$, $A_2 = \{c, d\}$; utilities
$$U_1 : \; ac \mapsto 3,\; ad \mapsto 0,\; bc \mapsto 2,\; bd \mapsto 0; \qquad U_2 : \; ac \mapsto 0,\; ad \mapsto 0,\; bc \mapsto 1,\; bd \mapsto 3;$$
welfare $W = U_1 + 2U_2 + \text{tie-break}$: $W(ac) = 3$, $W(ad) = \tfrac{1}{1000}$, $W(bc) = 4 + \tfrac{2}{1000}$, $W(bd) = 6 + \tfrac{3}{1000}$ (Pareto-consistent and injective, checked exhaustively). Profile $\sigma^\ast = \big((b_1, \mathcal A_1), (b_2, \mathcal A_2)\big) = \big((a, \{ac\}),\ (d, \{bd\})\big)$: each player accepts only its favourite deal; the acceptable sets are disjoint, so the outcome is the batna profile $ad$ with $U = (0, 0)$, **strictly dominated** by the compromise $bc$ with $U = (2, 1)$. $\sigma^\ast$ is a Nash equilibrium at $\varepsilon = 0$ and, for every $\varepsilon \in \{10^{-2}, 10^{-3}, 10^{-6}\}$, a Nash equilibrium of the uniformly perturbed game $\mathcal G^\varepsilon$ (each of the other $31$ pure proposals of each player played with probability exactly $\varepsilon$): each $s^\ast_i$ attains the maximum of player $i$'s expected payoff over all $32$ pure proposals [checked: payoffs $\tfrac{18}{25}$, $\tfrac{9}{125}$, $\tfrac{9}{125000}$ at the three $\varepsilon$, equal to the maxima]. Hence $\sigma^\varepsilon := \sigma^\ast$ with the minimal weights on everything else is a sequence of perturbed-game equilibria converging to $\sigma^\ast$, and $\sigma^\ast$ is a trembling-hand equilibrium in exactly SC Def 10.4's sense. Its outcome is strictly Pareto-dominated. Where the proof fails, read off the numbers: SC's deviation "add $O^\ast = bc$ to $\mathcal A_1$" has first-order payoff equal to $s^\ast_1$'s and second-order coefficient *lower by $4$* (`bargaining_fast2.py` margins $(0, 4)$ for both players). Two mechanisms, both missing from the proof: (a) in the gain event $E_\varepsilon$ (the other player proposes $\{O^\ast\}$) the baseline outcome under the original strategy is the **batna profile**, not $O$ — when player 2 trembles to $(d, \{bc\})$ the no-deal outcome $ad$ is worth $0$ to player 1 but when it trembles to $(c, \{bc\})$ the no-deal outcome $ac$ is worth $3 > 2 = U_1(bc)$, a loss; (b) **welfare displacement**: whenever player 2 trembles into accepting both $ac$ and $bc$, player 1's accepting $bc$ lets sel pick $bc$ ($W = 4.002 > 3$) over player 1's favourite $ac$, a loss of $1$ in each of $8$ such profiles. Net: $-8 + 4 = -4$ at order $\varepsilon$. Player 2 symmetrically loses $4$ through mechanism (a) alone. The audit's suspicion (DNI-6: "$\varepsilon^{n-1}$ vs $O(\varepsilon)$ points the wrong way for $n \ge 3$") was aimed at the bookkeeping; the theorem fails at $n = 2$ where all terms are of order $\varepsilon$, so no repair of the bookkeeping can save the statement. The finite core of this counterexample (Nash at $\varepsilon = 0$; lexicographic second-order margins; the exact loss of $4$ for the SC deviation; Pareto-consistency of $W$) is written as a Lean candidate, `lean/harmony-thm111-counterexample.lean` (STATUS: UNCHECKED; kernel `decide` over `Fin 32`). A weaker counterexample with *weak* dominance and a strictly-preferring player who already accepts $O^\ast$ (so SC's deviation is not a deviation at all) is in `bargaining.py`; a family of further instances with small integer utilities is printed by `bargaining_fast.py`.

What survives of SC Thm 11.1: its Remark 11.2 direction is right that the welfare rule is inessential to the *argument*; what the argument needs, and lacks, is that no player prefers the no-deal profile (or a $W$-displaced deal) to $O^\ast$ in any tremble profile — a condition on batnas and on $W$, not a theorem. Repair candidates I did not prove: (r1) require batnas to be Pareto-dominated by every deal each player accepts and $W$ to respect each player's own ranking within its acceptable set (excludes both mechanisms; likely restores the theorem for $n = 2$ — [guess]); (r2) restrict to the homogeneous case, where the theorem holds by a different argument (HA-5 below). The heterogeneous case of Part II therefore currently has *no* proved Pareto guarantee. *Handoff → the sibling project (via the final phase): SC Thm 11.1 needs a correction, and SC Thm 13.1's proof, which invokes it, needs HA-5's route instead.*

## 2. Coherence = harmony? (Task 2)

### 2.1 Homogeneous harmony is optimality — proved without SC Thm 11.1

**HA-5 [derived] — for every concrete $B$, in the homogeneous translation ($\mathbf X_d = \beta$ for all $d$, $u = r \circ \mathrm{leaf}$), (i) every trembling-hand-perfect outcome of $\mathcal G(B)$ is a $V_B$-optimal pure profile; (ii) some harmonious profile exists (Selten), so at least one optimum is harmonious; (iii) $W$ does not select among optima: which optimal outcome arises depends on batnas, and on the FR-12 tree (out $\to 0$; in $\to$ [$x \to 0$, $y \to -1$]) all three optima $(\mathrm{out},x), (\mathrm{out},y), (\mathrm{in},x)$ arise as trembling-hand outcomes under each of the three Pareto-consistent $W$ tested (each optimum made $W$-maximal in turn) [checked, `bargaining.py`].** This proves SC Thm 13.1(2) — "the unique outcome surviving Theorem 11.1 is $\arg\max_O \mathbb E_{\mathbf X}[u(O,\cdot)]$" — in the form "the surviving outcomes are exactly the maximizers, unique iff the maximizer is", by a route that does not pass through the false SC Thm 11.1.

*Proof of (i).* Let $M$ be the set of $V_B$-maximal pure profiles. Fix $O^\dagger \in M$. For any player $j$ and proposal $s_j = (b_j, \mathcal A_j)$ with $O^\dagger \notin \mathcal A_j$, compare $s_j' := (b_j, \mathcal A_j \cup \{O^\dagger\})$ against an arbitrary pure profile $s_{-j}$ of the others. If $O^\dagger \notin \bigcap_{i \ne j} \mathcal A_i$ the two intersections coincide and so do the outcomes. Otherwise the new intersection is the old one plus $O^\dagger$; if the old one was empty the outcome moves from the batna profile $b$ to $O^\dagger$ (value $V(b) \le \max$); if not, sel moves from $O' := \mathrm{sel}(\text{old})$ to $O^\dagger$ exactly when $W(O^\dagger) > W(O')$, and since $O^\dagger$ strictly dominates every non-optimal profile in the common-utility case, $W(O^\dagger) > W(O')$ whenever $O' \notin M$ (Pareto-consistency), while if $W(O') > W(O^\dagger)$ then $O' \in M$ and the value is unchanged. So $s_j'$ weakly dominates $s_j$ in value, profile by profile; and it is strictly better against the completely mixed $\sigma^\varepsilon_{-j}$ of any perturbed game unless *every* profile in which the others accept only $O^\dagger$ and no deal forms under $s_j$ has an optimal batna profile — i.e. unless $b_j$ is a *safe batna*: every profile $(b_j, \cdot)$ is optimal. Hence in every perturbed-game equilibrium $\sigma^\varepsilon$, a proposal with weight $> \varepsilon$ either accepts $O^\dagger$ or has a safe batna; the same holds for every proposal in the support of the limit $\sigma^\ast$ (its weight in $\sigma^\varepsilon$ is eventually $> \varepsilon$). Now take a pure profile $s$ in the support of $\sigma^\ast$. If every player accepts $O^\dagger$, the intersection contains $O^\dagger$ and sel returns an element of $M$ ($W$-maximal elements of any set containing $O^\dagger$ are optimal). Otherwise some $j$ has a safe batna $b_j$; if no deal forms, the outcome is a batna profile containing $b_j$, hence optimal; if a deal $O \notin M$ forms, then $j$'s deviation to $(b_j, \emptyset)$ yields a profile $(b_j, \cdot)$ — optimal — against every pure profile of the others, so it strictly improves $j$'s payoff against $\sigma^\ast_{-j}$, contradicting that $\sigma^\ast$ (a limit of equilibria) is a Nash equilibrium. $\square$ *(ii)* is Selten's existence theorem for finite games [reconstructed]. *(iii)* is the computation cited.

Register: this is a theorem about the *bargaining game built on $B$*, at the pure grade (HA-3), with no fairness, recording or calibration hypothesis on $B$ — harmony, unlike every tree-side device, is blind to the tree's structure because it only sees $V_B$ on pure profiles.

### 2.2 Definition 22 is not harmony (XC-1 confirmed)

**HA-6 [checked] — Definition 22's $B$-coherence (pure, and the calibration thread's mixed amendment A1) is the Nash condition of the identical-interest *action* game among points and admits non-optimal fixed points that harmony excludes; so "coherence = harmony" is false under the translation, and the true identity is harmony (homogeneous) $= T_{\mathrm{opt}}$ at the pure grade.** Witnesses (toolkit, `toolkit_checks2.log`). (a) The two-point Stag Hunt tree ($d_1$ then $d_2$, no chance; leaf payoff $2$ at $(S,S)$, $1$ at $(H,H)$, $0$ otherwise): $(H,H)$ has $V = 1$, is Definition-22-coherent in the pure and in the mixed sense (`coherent(mixed=True)` True; every unilateral mixed deviation has value $1 - m(S) \le 1$), and is not optimal ($V(S,S) = 2$); in the homogeneous bargaining game $0$ of its $43$ Nash profiles pass the trembling-hand test while $4$ of $(S,S)$'s $337$ do [checked, `bargaining.py`]. The Stag Hunt tree is almost fair but not strongly fair ($d_2$'s two nodes have different leaf payoffs), so FR-11 does not apply either — tremble-EDT approves $(H,H)$ there (calibration thread's XC-1 flag, confirmed by its `t6_def22.py`). (b) Inside the fair class: the fantasy tree $(2;4,1)$ (out $\to 2$; in $\to$ [$x \to 4$, $y \to 1$]; strongly fair, fully recorded, observations realized): $(\mathrm{out}, y)$ has $V = 2$, is coherent pure and mixed (deviating $d_1$ to in yields $1 \le 2$; $d_2$'s deviation is off-path), not optimal ($4$), not tremble-EDT-consistent, and not harmonious (HA-5: only $V = 4$ outcomes are). So even on the fair class Definition 22 $\supsetneq$ harmony, while tremble-EDT $\subseteq$ optimality $=$ harmony there (FR-11 as repaired by adversary-repair Claim A). Comment (iii) after Definition 22 already says coherence is not sufficient; the new content is the *placement*: coherence sits strictly between "anything" and harmony, with tremble-EDT strictly inside harmony (FR-12, HA-11).

The open half of XC-1 — does harmony under the *heterogeneous* translation $\mathbf X_d := P_{s_d}$ reduce to Definition 18's $T_{\mathrm{EDT}}$? — is answered negatively by HA-2 and HA-4: the heterogeneous translation exists only for chance-determined observations, and where it exists harmony is a trembling-hand equilibrium of a game with subjective payoffs whose only general theorem (SC Thm 11.1) is false; on the mugging it gives refuse (the updated point's $U(\mathrm{pay}) = -x$), which coincides with event-conditioned EDT's verdict there but for the trivial reason that there is one player [checked, `tn_bg.py`].

### 2.3 Definition 23: the anthropic layer cancels at every granularity

**HA-7 [derived; checked] — coalition Lemma 1: for any set $D$ of queried points, $\mu_{B,C}(\mathrm{occ}(D))$ does not depend on $C$ restricted to $D$ (joint revisions on $D$ included). Consequently Definition 23 with its occurrence-conditioning, for *any* family $\mathcal M$, is equivalent to: no $D \in \mathcal M$ has a joint revision $C'$ (on $D$ only) with $V_B(C') > V_B(C)$ — an $\mathcal M$-coalition Nash condition of the common-value game.** Proof: $\mathrm{occ}(D)$ is the disjoint union over *minimal* $D$-nodes $q$ (no $D$-node strictly above) of the events "reach $q$"; a path cannot contain two minimal $D$-nodes, and reaching one involves draws at non-$D$ nodes only — Lemma 1's proof verbatim with $d$ replaced by $D$. Then for a revision $C'$ on $D$: $V_B(C') - V_B(C) = \mathbb E_{C'}[r\,\mathbf 1_{\mathrm{occ}(D)}] - \mathbb E_{C}[r\,\mathbf 1_{\mathrm{occ}(D)}]$ (leaves outside $\mathrm{occ}(D)$ have no $D$-node on their path, so their probabilities and payoffs are untouched) $= \mu(\mathrm{occ}(D)) \cdot \big(\mathbb E_{C'}[r \mid \mathrm{occ}(D)] - \mathbb E_{C}[r \mid \mathrm{occ}(D)]\big)$ by the invariance, so the two differences have the same sign. $\square$ Toolkit check: on TN-V2 the invariance holds for every deterministic $C$ and every $D \in \{\{d_F\}, \{d_E\}, \{d_F, d_E\}\}$ [checked, `def23.py`]. This is Theorem 2's "SSA is a null operation" (comment (i) after Definition 22; Wei Dai's thread observation quoted there) extended from points to coalitions: the per-run occurrence weights are a positive constant times the common value at *every* granularity, so Definition 23 has no anthropic content at all — only coalition-structure content.

**HA-10 [derived] — Definition 23 is *not* "harmony for coalitions in the bargaining game": harmony (HA-5) is optimality for every choice of player set, so a bargaining game whose players are the patients $D_i$ (action sets $\prod_{d \in D_i} A_d$, common utility) has the same harmonious outcomes — the $V_B$-optima — whatever $\mathcal M$ is; the family axis is invisible to trembling-hand bargaining and visible only to Nash-type coherence (Definitions 22–23).** In the bargaining game each single player can already put the global optimum on the table and the trembles make everyone accept it (HA-5's proof); coalitions add nothing. In the action game, by contrast, a coalition can move several points at once, which is exactly what escapes a Nash trap (Stag Hunt: only the pair $\{d_1, d_2\}$ can move $(H,H)$ to $(S,S)$).

### 2.4 Conjecture 1: two axes, both endpoints verified, the interpolation real only on one of them

**HA-8 [checked] — endpoints.** (a) Trivial $\mathcal M = \{\mathcal D\}$ with occurrence-conditioning: conflict-freeness *equals* $V_B$-optimality (not merely contains it), because by HA-7 the condition is "no joint revision of all points improves $V_B$" — with joint revisions ranging over procedures this is $T_{\mathrm{opt}}$ at the pure grade (and at the mixed grade if mixed revisions are admitted). The hedge "$\mathrm{occ} = $ everything when the root queries" in Conjecture 1 is unnecessary: the conditioning cancels whether or not the root queries. ## 3. Trembling hands (Task 3)

### 3.1 One device, two trees

**HA-11 [derived; checked] — SC Def 10.4's trembling-hand equilibrium and v2's tremble-consistency (Remark 3.12; concretely P1:fair-repair FR-11's device, calibration thread's D2) are the same *mathematical* device applied to two different trees, and therefore different *normative* devices: SC trembles the proposals $(b_i, \mathcal A_i)$ of the bargaining game built over $B$; v2 trembles the action mixtures $C(d)$ at $B$'s own decision nodes and re-fits the states.** Precisely: encode $\mathcal G(B)$ as a v2 tree $B^{\mathcal G}$ with one point per player whose action set is its $K_i$ proposals and whose leaves carry the outcome rule; then "$\sigma^\ast$ is a trembling-hand equilibrium of $\mathcal G$" is implied by "$\sigma^\ast$ is normative against its own Definition-10-trembled statistics on $B^{\mathcal G}$ for all small $\varepsilon$" (Remark 3.12 with $T = $ Nash-best-response), which is exactly the lexicographic test HA-4/HA-5 run (weight $\varepsilon/K_i$ on every other proposal). What differs is what the trembles bite on. On $B^{\mathcal G}$ they force every player to *accept* every optimum (coordination: the Stag Hunt's $(H,H)$ dies because a player who accepts $(S,S)$ gains whenever the other trembles into proposing it, HA-5). On $B$ they force *honest states at unrealized observations* (off-path fantasy: the imperfect equilibrium $(\mathrm{out}, y)$ of the tree out $\to 0$; in $\to$ [$x \to 4$, $y \to 1$] dies because the $\varepsilon$-calibrated state at $d_2$ sees $4 > 1$; P1:fair-repair §3.2) and they select among *continuation ties*.

The extensions differ accordingly. On the fair class $\mathfrak F$ (strongly fair in the pre-enrichment sense, fully recorded, evented pruned chance, every queried observation realized): harmony $= T_{\mathrm{opt}}$ (HA-5) while tremble-EDT $\subsetneq T_{\mathrm{opt}}$ (FR-11 as repaired by adversary-repair Claim A, plus FR-12). Witness, the FR-12 tree (out $\to 0$; in $\to$ [$x \to 0$, $y \to -1$]): optimal set $\{(\mathrm{out},x), (\mathrm{out},y), (\mathrm{in},x)\}$; harmonious outcomes = all three [checked, `bargaining.py`]; tremble-EDT-consistent set $= \{(\mathrm{out},x)\}$ only — $(\mathrm{out},y)$ is rejected at $d_2$ (off-path tie broken by the tremble, FR-12) and $(\mathrm{in},x)$ is rejected at $d_1$ because for every $\varepsilon > 0$ going in risks the $-1$: $v_\varepsilon(\mathrm{in}) = -\varepsilon/2 < 0 = v_\varepsilon(\mathrm{out})$ [checked, `toolkit_checks2.log`]. Off $\mathfrak F$ the inclusion reverses on the examples: event-conditioned tremble-EDT approves refuse on the mugging and $(2,2)$ on TN-V2 (calibration thread's table, column D2), neither of which is harmonious under the homogeneous translation, while both are harmonious under the updateful translation [checked, `tn_bg.py`]. So neither device refines the other in general; on $\mathfrak F$, tremble-EDT is the strict refinement.

### 3.2 The theorem Remark 13.2 becomes inside v2, and what stays conjectural

**HA-12 [derived] — Theorem H (updatelessness and harmony on trees).** Let $B$ be a concrete problem, $\mathcal G(B)$ its homogeneous bargaining game (HA-1), $M$ its set of $V_B$-optimal pure profiles.
(a) *Harmony is optimality.* The harmonious outcomes of $\mathcal G(B)$ are elements of $M$, and $M$ is nonempty and contains at least one harmonious outcome (HA-5). Tree-side, "attains a harmonious outcome" is $T_{\mathrm{opt}}(C, B)$ at the pure grade.
(b) *Not updating attains it.* Let $B$ have evented chance and let $\widetilde B = \mathrm{Rel}_U(B)$ be its joint relocation at the entanglement closure (P1:fair-repair E2/FR-4, fairness in the pre-enrichment-marginal sense per adversary-repair Claim B). Its root point $\hat d$ is consulted exactly once per run, records for every procedure, and its strictly calibrated state is Definition 11's prior calibration — $P_{\hat s} = \nu_{\widetilde B, \widetilde C}$ unconditioned, $V_{\hat s}(\mathrm{pol} = O) = \mathbb E[r \mid \mathrm{pol} = O] = V_B(O)$ (FR-8; FR-7(a): pure-profile laws are preserved for *every* $B$, nested fibers included). Hence $\mathrm{EDT}(\hat d)$ under strict, masked or limit calibration is $\mathrm{Unif}\arg\max_{O} V_B(O)$: the relocated, prior-calibrated — "do not update" — procedure realizes an element of $M$ and is harmonious. (Mixed grade: exact iff $B$ is almost fair, FR-7(b).) This is SC Remark 13.2's first half ("classical UDT arises from $\mathbf X_i = \mathbf X$") as a theorem: the common $\mathbf X$ is $\beta$, and v2 supplies it structurally as the calibration of the relocated root, with $\rho_d(a) = \{\mathrm{pol}_d = a\}$ derived (FR-2), at Remark 3.8(iii)'s price.
(c) *On the fair class, updating does not break harmony.* If $B \in \mathfrak F$ and $C$ is tremble-EDT-consistent — every point uses its own *updated* strictly observation-calibrated state $\nu_{B, C^\varepsilon}(\cdot \mid O_d)$, re-fitted per $\varepsilon$ (Remark 3.12 read concretely) — then $V_B(C) = \max_{C'} V_B(C')$ (FR-11 repaired by Claim A), so $C$ attains a harmonious outcome. SC Remark 13.2's mechanism, "updating breaks harmony by introducing disagreement", has *no* instance on $\mathfrak F$: there the updated points' tremble-EDT verdicts are unanimous for the optimum (Step 1 of FR-11: fiber-isomorphism makes the reach-weighted act values node-independent, and recording makes the act-event conditioning a reach-and-draw event).
(d) *Where updating does break it.* Off $\mathfrak F$ the updated (event-conditioned) profile can fail harmony: TN-V2's $(2,2)$ and the mugging's refuse — updateful-harmonious, not homogeneously harmonious [checked, `tn_bg.py`]. The mechanism is not disagreement: in TN-V2 both updated points *agree* on $(2,2)$ ($U_F$ and $U_E$ both maximal there). It is Proposition 10's event-conditioning pathology — the updated point discards the term by which its policy moves the probability of its own observation — which SC's type cannot even express (HA-2: the updated world-models of TN-V2 are not profile-independent measures).
(e) *Uniqueness.* SC Remark 13.2's "the unique strategy profile ensuring a harmonious outcome" fails as literal uniqueness: on $\mathfrak F$ the updated assignment also attains harmony (c), and wherever $\mathrm{occ}(d)$ is chance-determined the occurrence-conditioned assignment (per-run SSC states, Proposition 2's lift) coincides with the prior assignment (HA-2(iii); TN-V2 by Remark 7.1). What is true and provable: among the two calibration disciplines SC compares — prior calibration at every point vs strict observation calibration at every point — only the first attains a harmonious outcome on *every* concrete tree; the second fails exactly off $\mathfrak F$ (TN-V2, the mugging). That is the defensible form of "updatelessness justified by harmony": justified as the *description-independent* guarantee, not as the unique route.
(f) *Heterogeneous case.* Conjectural and now unsupported: genuinely different $\mathbf X_d$ (not conditionings of one measure) fall outside (a)–(e); SC Thm 11.1 was the only general statement about them and it is false (HA-4). Nothing in v2 replaces it; §5 shows what a welfare rule does there on the mugging.

Register of the whole: (a) is a theorem about $\mathcal G(B)$ for every $B$ at the pure grade; (b) is FR-8 plus HA-5, exact at the pure grade for every evented $B$ and at the mixed grade for almost-fair $B$; (c) is FR-11 in its Claim-A-repaired form (hypotheses: strong fairness pre-enrichment sense, full recording, evented pruned chance, realized observations, tremble-EDT in the concrete event-conditioned form); (d) is two computations; (e) is (c)+(d); (f) is a gap.

## 4. Pareto frontier vs tie-freedom (Task 4)

**HA-13 [checked] — Remark 4.3's miniature as a bargaining game (`miniature.py`).** One point $d$ (the predictor's sample node above the live node — a *nested* fiber, so not almost fair), actions $\{a, b\}$, payoff $2$ on (live $a$, sample $b$), $1$ on (live $b$, sample $a$), else $0$. Under independent redraws with $C(d)(a) = q$: $V(q) = 2q(1-q) + q(1-q) = 3q - 3q^2$, maximal $\tfrac34$ at $q = \tfrac12$; under shared seed $V \equiv 0$; both pure outcomes are worth $0$; the per-node assignment optimum is $2$. The strictly calibrated act values are $V_{s_d}(a) = 2(1-q)$, $V_{s_d}(b) = q$; Remark 4.3's unique calibrated-and-$T_{\mathrm{EDT}}$-approved label is $q = \tfrac23$ (tie $\tfrac23 = \tfrac23$) with $V = \tfrac23 < \tfrac34$, and it violates both Theorem 1's condition (SIA-weighted forcing values $1$ for $a$, $2$ for $b$: Theorem 1 demands $b$) and mixed Definition 22 ($\sup_m V(C[d \mapsto m]) = \tfrac34 > \tfrac23$); the optimum $q = \tfrac12$ satisfies Theorem 1 (tie $\tfrac32 = \tfrac32$) and mixed Definition 22 but is rejected by $T_{\mathrm{EDT}}$ at its calibrated state ($V_{s_d}(a) = 1 > \tfrac12 = V_{s_d}(b)$). As a bargaining game the miniature has one player, two pure outcomes of equal value $0$, every proposal harmonious, and no trace of any of this. XC-10 is confirmed, for two independent reasons: (i) $\mathcal G$'s outcomes are pure profiles and its mixed strategies are shared-seed mixtures, while the miniature's entire value is the independent-redraw cross term $3q(1-q)$ (HA-3); (ii) $\mathcal G$'s world-models are profile-independent, while Remark 4.3's label must *equal the realized mixture* — a self-referential fixed point (the nearest SC item is its §15 open question 3, "self-reference", stated for anticipation structures, not for decision-points). Register: the miniature separates three tree-side notions on one tree — Remark 4.3's calibrated-and-approved point ($\tfrac23$), the coherent/optimal point ($\tfrac12$), and the harmonious set (everything) — so Remark 4.3's "unique jointly calibrated-and-approved answer" is a uniqueness of *ratifiability*, not of optimality; flag to calibration (their amendment A4 governs the wording).

**HA-14 [derived; checked] — the welfare rule is a tie-break of limited reach, and Definition 18's mixtures are not the frontier.** (i) In $\mathcal G$, $W$ selects within a *deal*; harmony can also realize an optimum through the batna channel with no deal, so $W$ does not pin the outcome even homogeneously — the FR-12 tree realizes all three optima under each of the three $W$-orderings tested [checked]; SC Remark 11.4's non-uniqueness is therefore not a heterogeneity phenomenon. (ii) Remark 4.3's impossibility — "a theory restricted to any *fixed* tie-break has no solution" — concerns a label that must report the very mixture the tie-break produces; $\mathcal G$ has no such label (its $\mathbf X_i$ are fixed), so the impossibility does not transfer, and conversely $\mathcal G$'s pure outcomes cannot host the mixed solution. The analogy "welfare selection $\leftrightarrow$ tie-break" holds only at the level of *what both do* (choose among value-ties) and fails at the level of *what forces them* (Nash-style existence in Remark 4.3; nothing in $\mathcal G$, where any injective $W$ works). (iii) Definition 18's "any mixture over maximizers is normative" is a per-point face of the simplex over *local act values*; the subjective Pareto frontier is a set of *joint pure profiles*. In the homogeneous case the frontier is $M$; $T_{\mathrm{opt}}$ approves a product mixture over $M$ only when it stays optimal — always for one point, not for several: on the Stag Hunt with $(S,S)$ and $(H,H)$ both worth $2$, the product mixture $(\tfrac12, \tfrac12) \otimes (\tfrac12, \tfrac12)$ is worth $\tfrac14 \cdot 2 + \tfrac14 \cdot 2 = 1 < 2$ [checked, arithmetic]. The honest correspondence is only this: on $\mathfrak F$, tremble-EDT-consistent $\subsetneq$ $T_{\mathrm{opt}}$ $=$ harmonious $=$ frontier (homogeneous), at the pure grade.

## 5. Heterogeneous priors (Task 5)

[scrubbed] In Part II's vocabulary two candidate priors are two decision-points with different world-models over the *same* coin. v2 has no room for them as *queried* points: two points with different $P_s$ at the same observation are different points (Definition 3), and at most one of them can be calibrated to the tree's chance label $\beta$ — the other is simply miscalibrated, and in the counterlogical case there is no chance label at all (the digit is what it is; the "other branch" is not in the tree), so Definition 11 forces $P_{s^\circ}(H) = 0$ and refusal. Where v2 does host the two priors is as two candidate parameters $s^\circ$ of $\mathrm{UDT}_{s^\circ, \rho}$ (Definition 17): $\mathrm{UDT}_{s^\circ_1, \rho}$ pays iff $\tfrac12 y > \tfrac12 x$, $\mathrm{UDT}_{s^\circ_2, \rho}$ (with $P_{s^\circ_2}(H) = \theta$) iff $\theta y > (1-\theta) x$.

**HA-15 [checked] — the two-prior mugging as a bargaining game (`hetero_prior.py`): with a utilitarian welfare rule, bargaining between prior-selves is UDT under the mixture prior; with disagreement-point solutions the pessimistic prior holds a veto.** Model: two decision-points $\delta_1, \delta_2$ with $\mathbf X_1(H) = \tfrac12$, $\mathbf X_2(H) = \theta$, both "controlling the policy" — realized as a joint action space $\{\mathrm{pay}, \mathrm{refuse}\}^2$ with an aggregation $f$ (the implemented policy is pay iff both say pay; disagreement defaults to refuse) and the common utility of the *implemented* policy, so $U_i(O) = \mathbb E_{\mathbf X_i}[r(f(O), \cdot)]$. At $x = 1$, $y = 2$, $\theta = \tfrac14$: $U_1(\mathrm{pay}) = \tfrac12$, $U_2(\mathrm{pay}) = -\tfrac14$, both $0$ at refuse — the two selves disagree, both pure outcomes are subjectively Pareto-optimal, and the frontier is the whole issue. Utilitarian $W = w_1 U_1 + w_2 U_2$: $W(\mathrm{pay}) = w_1 \cdot \tfrac12 - w_2 \cdot \tfrac14$, which is *exactly* the UDT value of paying under the mixture prior $P(H) = w_1 \cdot \tfrac12 + w_2 \theta$ (linearity of expectation; the numbers coincide at every weight pair tested: $(\tfrac12,\tfrac12) \mapsto \tfrac18$, $(\tfrac34, \tfrac14) \mapsto \tfrac{5}{16}$, $(\tfrac14, \tfrac34) \mapsto -\tfrac1{16}$); pay iff $w_1 > \tfrac13$. So the utilitarian bargaining game between prior-selves adds nothing to hierarchical Bayes: "which prior?" is answered by the mixture, and the weights are the credences. Disagreement-point solutions (Nash product, Kalai–Smorodinsky) with the disagreement point refuse ($U = (0,0)$) give refuse: paying has a negative gain for $\delta_2$ at every mixing rate $q > 0$ ($U_2 = -q/4$), so the individually-rational set is $\{\mathrm{refuse}\}$ — the most pessimistic prior holds a veto, and no evidence about the coin moves it unless it moves $\mathbf X_2$ itself. Two selection rules, one frontier, opposite verdicts: Part II's "bargaining solution concept" (SC §13.3) is not a neutral device here.

What this gives the two briefs' decay proposals (adjudication belongs to spectrum, C4; I supply representability only). *Brief B's split (PC-9):* the legitimate kind — learning whether the coupling is real / which prior — has a Part II home as movement of the weights $w_i$ (Bayesian model averaging over prior-selves), and under the utilitarian rule that movement is ordinary conditioning of the mixture prior; the condemned kind — the $1/k$ credit-assignment fading — has *no* Part II home, because SC's $U_i$ are per-outcome expectations and never per-instance quantities (there is no instance count anywhere in SC Def 9.1). *Brief A's decay-as-repair-shrinkage (Sharpening 4):* no Part II home either — SC §14's "same decision-point" criterion (SC Def 12.1) is binary (one's beliefs are or are not a calibrated update of the other's), so the sliding LCA — relocate to the extent the coupling is credible — cannot be expressed as a graded cluster membership; the closest Part II object is a *mixture of two games* (UDT within the cluster with probability $c$, bargaining across with $1-c$), which is not in the type. *Handoff → spectrum:* Part II represents the legitimate half of B's split (as weight-learning) and neither A's slider nor B's condemned half.

**HA-16 [derived] — the anthropic fork is not a heterogeneous-decision-point phenomenon.** Per-run vs per-occurrence SSC (Definition 13) are two candidate world-models for *one* point controlling *one* action (they differ only under nesting: on the AMD at $q = \tfrac13$ per-run gives $(\tfrac13, \tfrac29, \tfrac49)$ and per-occurrence $(\tfrac15, \tfrac4{15}, \tfrac8{15})$ over the three exits — toolkit audit §3.6).
