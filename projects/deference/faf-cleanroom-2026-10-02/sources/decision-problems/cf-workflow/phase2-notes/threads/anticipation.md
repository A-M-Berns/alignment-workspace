## 0. Setup and dictionary

**v2 side.** $B$ a concrete problem (Def 5), $C$ a procedure, $\mu := \mu_{B,C} \in \Delta(\mathrm{Leaves})$, $\nu := \nu_{B,C} = \lambda_*\mu \in \Delta(\mathcal A)$ (Def 6), $\mathrm{occ}(d) \subseteq \mathrm{Leaves}$, $\#_d$. The map $\lambda^{-1} : \mathcal E \to 2^{\mathrm{Leaves}}$, $X \mapsto \{\ell : \lambda(\ell) \models X\}$, is a Boolean homomorphism; its image $\lambda^{-1}(\mathcal E)$ is the sub-algebra of leaf-sets that are unions of $\lambda$-fibers.

**Sibling side (SC, TRUSTED).** A random variable $\mathbf q : \hat P \to \hat Q$ is a homomorphism $\overline Q \to \overline P$ (SC §0.2), so $\lambda^{-1}$ *is* the random variable $\boldsymbol\lambda : \widehat{\mathrm{Leaves}} \to \hat\Omega$ and $\boldsymbol\lambda_*\mu = \nu$. Conditioning model $(\hat{\mathbf L}, \mathbf p, \mathbf p', \overline l)$: SC Def 1.1. **Standing translation.** Common information $\hat C := (\Omega, \mathcal E)$ with $\mathbf c = \mathrm{id}_{\mathcal E}$ on the $\mathcal E$-side and $\mathbf c' = \lambda^{-1}$ on the $2^{\mathrm{Leaves}}$-side (or the reverse), so "shared propositions" are exactly the world-events, and "private propositions" of the lifted ontology are the leaf-sets not of the form $\lambda^{-1}(X)$ — which node a run passed through, when two leaves carry one world.

**The occurrence algebra.** $\overline A_{\mathrm{occ}} := \sigma\{\mathrm{occ}(d) : d \text{ queried}\} \subseteq 2^{\mathrm{Leaves}}$. Its atoms are the *occurrence patterns* $\overline a_S := \{\ell : \{d : \#_d(\ell) > 0\} = S\}$, $S$ a set of queried points; $\mathrm{occ}(d) = \bigcup_{S \ni d} \overline a_S$. The *occurrence anticipation* on a lifted prior $\hat{\mathbf P} = (\mathrm{Leaves}, 2^{\mathrm{Leaves}}, P_{s^\circ})$ targeting $\hat\Omega$ has kernels $\kappa_{\overline a} := \lambda_* P_{s^\circ}(\cdot \mid \overline a)$; it is $\hat C$-calibrated (SC Def 5.1) by construction, and its prior-predictive is $\mathbf Q_0 = \lambda_* P_{s^\circ}$ (SC Obs 3.4). When $s^\circ$ is prior-calibrated in the lifted sense, $P_{s^\circ} = \mu$ and $\mathbf Q_0 = \nu$.

**Density notation.** For probabilities $P, Q$ on one finite algebra, $P \ll Q$ iff $Q(w) = 0 \Rightarrow P(w) = 0$, and $\|dP/dQ\|_\infty := \max_{Q(w) > 0} P(w)/Q(w)$. SC Thm 2.4's necessity direction gives, for any conditioning model with evidence $\overline l$: posterior $\ll$ prior on shared ground with density $\le 1/\mathbf L(\overline l)$.

## 1. Task 1 — Proposition 2 as a conditioning model; Q3

### 1.1 Two readings of the lift

Fix a queried $d$ with $\mu(\mathrm{occ}(d)) > 0$.

**AN-1 [derived] — the lift is a conditioning model in two readings, and in both the model's existence *is* the per-run SSC equation.**

*Reading (a), the statistical pair.* Prior $\hat{\mathbf P} := (\Omega, \mathcal E, \nu)$, posterior $\hat{\mathbf P}' := (\Omega, \mathcal E, P_{s_d})$, enlarged space $\hat{\mathbf L} := (\mathrm{Leaves}, 2^{\mathrm{Leaves}}, \mu)$, $\mathbf p = \mathbf p' := \lambda^{-1}$, evidence $\overline l := \mathrm{occ}(d)$. Check against SC Def 1.1: $\mathbf p_*\mathbf L = \lambda_*\mu = \nu$ (probability-preserving); $\mathbf L(\overline l) = \mu(\mathrm{occ}(d)) > 0$; and $\mathbf p'_*\big(\mathbf L(\cdot \mid \overline l)\big) = \lambda_*\mu(\cdot \mid \mathrm{occ}(d))$, which equals $P_{s_d}$ exactly when clause 1 of per-run SSC (Def 13) holds at $d$. Same ontology on both ends, $\hat C = \mathcal E$ with identities, compatibility automatic. So **the tuple $(\mu, \lambda^{-1}, \lambda^{-1}, \mathrm{occ}(d))$ is a conditioning model for $(\nu, P_{s_d})$ iff $B$ is per-run SSC at $d$ for $C$.** The $V$-clause is the same statement for the conditional expected payoff.

*Reading (b), the lift pair — the pair the mandate names.* Prior $\hat{\mathbf P} := (\Omega, \mathcal E, P_{s_d})$ (the queried state), posterior $\hat{\mathbf P}' := (\mathrm{Leaves}, 2^{\mathrm{Leaves}}, P_{s'_d})$ with $P_{s'_d} := \mu(\cdot \mid \mathrm{occ}(d))$ (the lifted state), common information $(\mathcal E, \mathbf c = \mathrm{id}, \mathbf c' = \lambda^{-1})$. Then $\mathbf C = P_{s_d}$ and $\mathbf C' = \lambda_* P_{s'_d} = \lambda_*\mu(\cdot \mid \mathrm{occ}(d))$. Take $\hat{\mathbf L} := \hat{\mathbf P}'$, $\mathbf p := \lambda^{-1}$, $\mathbf p' := \mathrm{id}$, $\overline l := \top$. Then $\mathbf p'_*\mathbf L(\cdot \mid \top) = P_{s'_d}$, $\mathbf L(\top) = 1$, compatibility $\mathbf c \circ \mathbf p = \lambda^{-1} = \mathbf c' \circ \mathbf p'$ holds identically, and $\mathbf p_*\mathbf L = \lambda_* P_{s'_d} = P_{s_d}$ iff per-run SSC at $d$ — v2's own sentence "$\lambda_* P_{s'_d} = P_{s_d}$ *is* the per-run SSC hypothesis" (Prop 2). So under SSC the lift is a **$\hat C$-compatible refinement** (SC Def 0.5: $\hat{\mathbf P}$ a coarsening of $\hat{\mathbf L}$ along $\lambda^{-1}$) with trivial evidence; $\mathbf C' = \mathbf C$, density $\equiv 1$, $B = 1$. SC Thm 2.4's construction divides by $B - 1$ (the sibling audit's flagged edge case), but nothing is lost: the direct model above exists and the theorem's statement (existence iff D–Z) is true at $B = 1$.

*What happens when SSC fails.* Then $\mathbf C' \ne \mathbf C$ and Thm 2.4 asks $\mathbf C' \ll \mathbf C$ with bounded density. On the no-doubt mugging ($q = q_0 = \tfrac12$): $\mathbf C' = \nu$ puts $\tfrac12$ on heads-worlds, $\mathbf C = P_{s_d}$ puts $0$ there — absolute continuity fails. [checked, `t1_lift.py`: "reverse (P_s → SSC state): SSC ≪ P_s: False"] So no $\mathcal E$-compatible conditioning model leads *from the tails-certain queried state to the lifted state*: the superconditioning repair (Prop 2 run backwards, P1:fair-repair FR-15 (derived)) is not an update of the defective state but its replacement (developed as AN-11).

**AN-2 [derived; numbers checked] — the D–Z condition on $\mathcal E$ is not Q3's criterion.** Three reasons, one per direction the condition can be pointed.
(i) In reading (b), whenever per-run SSC holds the density is identically $1$: D–Z is satisfied by *every* lift of a per-run-SSC point and distinguishes nothing.
(ii) In reading (a), D–Z is necessary but far from sufficient. SC Thm 2.4 (⇒) gives the **occurrence D–Z bound**: per-run SSC at $d$ implies $P_{s_d} \ll \nu$ with $\|dP_{s_d}/d\nu\|_\infty \le 1/\mu(\mathrm{occ}(d))$. It is a bound on how surprised a state may be relative to the world's statistics, given that its only evidence is being consulted. On the mugging: $\|dP_{s_d}/d\nu\|_\infty = 2 > 1 = 1/\mu(\mathrm{occ}(d))$ — the tails-certain state fails it [checked, `t1_lift.py`, `t1b_matched.py`; Lean candidate `anticipation-occurrence-dz.lean`, UNCHECKED]. But the bound does not pin the evidence event: a state with density $\le 1/\mu(\mathrm{occ}(d))$ that is not $\lambda_*\mu(\cdot \mid \mathrm{occ}(d))$ passes it and fails SSC (AN-9 gives the general condition).
(iii) In the reverse direction ($s_d \to s'_d$ as an update), absolute continuity fails whenever the queried state has zeros that $\nu(\cdot \mid \mathrm{occ}(d))$ lacks — every no-doubt state. So the question "is the lift a legitimate belief change *of the queried state*?" has the answer *no* precisely on the problems Q3 is about, and *trivially yes* on the SSC problems where there is nothing to repair.
Hence XC-4's [guess] is settled: **D–Z cannot be Q3's criterion.** What can be is the next item.

### 1.2 Occurrence-expressibility: the criterion

**Definition (occurrence-expressibility).** $\mathrm{occ}(d)$ is *$\mathcal E$-expressible* (for $C$) if there is $\mathrm{Occ}_d \in \mathcal E$ with $\mu\big(\mathrm{occ}(d) \,\triangle\, \lambda^{-1}(\mathrm{Occ}_d)\big) = 0$; equivalently, no world is realized with positive probability both on an occ-leaf and on a non-occ leaf. In SC's vocabulary: the evidence event $\overline l = \mathrm{occ}(d)$ of reading (a) lies in the image $\mathbf p(\overline C)$ of the common information — the analogue, for the *statistical* prior, of §4.6's "$\overline l \in \mathbf p(\overline A)$".

**AN-3 [derived] — per-run SSC is strict OC at a relabelled point, exactly when the occurrence is expressible.**
(i) If $\mathrm{occ}(d) = \lambda^{-1}(\mathrm{Occ}_d)$ mod $\mu$-null, then for every $X \in \mathcal E$: $\mu(\lambda^{-1}X \mid \mathrm{occ}(d)) = \mu(\lambda^{-1}X \cap \lambda^{-1}\mathrm{Occ}_d)/\mu(\lambda^{-1}\mathrm{Occ}_d) = \nu(X \wedge \mathrm{Occ}_d)/\nu(\mathrm{Occ}_d) = \nu(X \mid \mathrm{Occ}_d)$, and $\mathbb E_\mu[r \mid \lambda \models X,\ \mathrm{occ}(d)] = \mathbb E_\mu[r \mid \lambda \models X \wedge \mathrm{Occ}_d]$. So per-run SSC at $d$ (both clauses, the toolkit's reading of "analogous" for $V$) is **strict OC (Def 8) at the point $(s_d, \mathrm{Occ}_d, A_d)$** — Prop 3's proof with $O_d$ replaced by $\mathrm{Occ}_d$; Prop 3 is the case $\mathrm{Occ}_d = O_d$ (subtree-veridicality gives $\subseteq$, coverage gives $\supseteq$).
(ii) Conversely, if $\mathrm{occ}(d)$ is not expressible, some world $w$ is realized on both sides; then $\lambda_*\mu(\cdot \mid \mathrm{occ}(d))$ is not $\nu(\cdot \mid X)$ for any $X \in \mathcal E$ in general, and the lift genuinely adds a proposition ("this run consulted $d$") to the shared language — the lifted ontology has a private proposition of positive measure, and SC Remark 2.7 says shared-ground conditions cannot see it.
(iii) *Sufficient conditions for expressibility.* Write $\mathrm{ctx}(q)$ for the conjunction of the edge-events on the root path to $q$. Under evented chance (P1:fair-repair (EC)), if every edge above every member of $F_d$ is a chance edge or an action-recorded decision edge (leaf-worlds below it entail the action event, and different edges carry disjoint events), then $\{\text{reach } q\} = \lambda^{-1}(\mathrm{ctx}(q))$ exactly, and $\mathrm{occ}(d) = \lambda^{-1}\big(\bigvee_{q \in F_d} \mathrm{ctx}(q)\big) =: \lambda^{-1}(\mathrm{Occ}_d)$. In particular, after E2's entanglement closure the relocated fiber-set has chance-only ancestors (P1:adversary-repair Claim E), so EC alone suffices there; and for a single unfair fiber whose scope has chance-only ancestors, EC suffices.
(iv) *Relation to relocation's observation.* R2 step 4 sets $O_{\hat d} := \mathrm{ctx}(\mathrm{lca}\, F_d)$. Since every $\mathrm{ctx}(q)$, $q \in F_d$, entails $\mathrm{ctx}(\mathrm{lca})$, $\mathrm{Occ}_d \le \mathrm{ctx}(\mathrm{lca}\, F_d)$, with equality iff every path through the lca meets a fiber member (the fiber covers its own scope). So the honest SSC relabelling of the queried observation is the *finer* event $\mathrm{Occ}_d$, the relocated observation the *coarser* upstream context; on the mugging both are $\top$.

**AN-7 [derived; construction checked] — SC Thm 4.5 does not make the audit toothless, because it ranges over models that supply their own evidence; a Thm-4.5 audit rejects exactly the fantasy states.** Thm 4.5 says: for any $\mathbf Q \ll \mathbf Q_0$ with bounded density there is a *calibrated conditioning model* (SC Def 4.1) reaching $\mathbf Q$. So in the finite regime: *a calibrated conditioning model from $s^\circ$ reaches $s$ iff $P_s \ll \nu$*. Every observation-calibrated state is a $\nu$-conditional — strict: $P_{s_d} = \nu(\cdot \mid O_d) \ll \nu$; masked: $\ll \nu_{C[d \mapsto m]}$, the prior the audit uses at the masked grade (FP-21(ii)); limit: $\ll \nu_{C^\varepsilon}$ for each $\varepsilon$ — so **Thm-4.5 reachability never rejects an OC-calibrated state**; it rejects only states charging worlds no run reaches (P1:fair-repair §3.2's fantasy states, P1:adversary-repair A.1's free states).
