**CA-3′ [derived].** On a strongly fair tree, "some $e$-node strictly below some $d$-node" is a strict partial order on points: if $e$ has a node below a $d$-node then, by fiber isomorphism, *every* $d$-node has an $e$-node below it; a cycle would iterate into an infinite descending chain in a finite tree.
