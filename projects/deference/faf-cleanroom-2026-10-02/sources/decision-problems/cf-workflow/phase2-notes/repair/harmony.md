## Definitions carried (restated so the ledger stands alone)

**$\mathrm{DP}(B)$, the induced decision-points.** For a concrete problem $B$ (Definition 5): one SC decision-point $\delta_d = (\hat{\mathbf X}_d, A_d, u_d)$ (SC Def 9.1) per *queried point* $d$; joint action space $A = \prod_d A_d$, whose elements are the pure profiles ($= \mathrm{Agent}(\mathrm{Fr}(B))$, P1:synthesis item 4); world-state space $E$ = lazy chance profiles (one outcome per chance node) carrying $\beta := \bigotimes_n \beta_n$; $\mathrm{leaf}(O, e)$ the leaf reached by pure profile $O$ and chance profile $e$.

**Three translations.** *Homogeneous*: $\mathbf X_d = \beta$, $u_d(O, e) = r(\mathrm{leaf}(O,e))$ for every $d$, so $U_d(O) = V_B(O)$ on pure profiles (bridge row T20, exact at the pure grade). *Common-utility, heterogeneous-belief* (the sub-type SC Thm 13.1 / Remark 13.2 compare, "same utility $u$"): $u_d = r \circ \mathrm{leaf}$ for all $d$, $\mathbf X_d$ a measure on $E$; available for v2's strictly observation-calibrated state at $d$ iff $O_d$ is *chance-determined* — some $E_d \subseteq E$ with $\lambda(\mathrm{leaf}(O,e)) \models O_d \iff e \in E_d$ for every pure $O$ — and then $\mathbf X_d = \beta(\cdot \mid E_d)$. *Point-specific-utility*: SC Def 9.1 types $u_i : A \times X_i \to \mathbb R$ *per point*, so any $U : A \to \mathbb R$ is an SC utility via $u_i(O, x) := U(O)$; in particular own-profile event-conditioned values $U_d(O) := \mathbb E_{\mu_{B,O}}[r \mid \lambda \models O_d]$ are SC utilities (the thread's "updateful translation" is this one and is renamed accordingly).

**$\mathcal G(B)$, harmony, the tremble test.** SC Def 10.2's bargaining game on $\mathrm{DP}(B)$: strategies $(b_i, \mathcal A_i)$ (batna $b_i \in A_i$, acceptable set $\mathcal A_i \subseteq A$); outcome $\mathrm{sel}(\bigcap_i \mathcal A_i)$ if nonempty, else the batna profile; $\mathrm{sel} = \arg\max$ of an injective Pareto-consistent $W$ (SC Def 10.3). *Harmony* $=$ trembling-hand equilibrium of $\mathcal G$ (SC Def 10.4: *there exists* a sequence of perturbed games, every strategy weighted $\ge \varepsilon$, with Nash equilibria converging to $\sigma^\ast$). For $n = 2$ and the *uniform* sequence (each other proposal weighted exactly $\varepsilon$, $K = 32$ proposals per player when $|A_i| = 2$), a pure $\sigma^\ast$ is a perturbed-game equilibrium for all small $\varepsilon$ iff each $s^\ast_i$ maximizes $M + \varepsilon(T - K M)$, i.e. lexicographically $(M, T)$ with $M$ = payoff against $s^\ast_{-i}$ and $T$ = total against all $K$ opponent proposals — the "uniform-THPE test" every enumeration below uses; it is sufficient for harmony (SC Def 10.4 is existential over sequences), and where a claim needs *every* sequence the argument is given analytically.

**Safe batna.** In the homogeneous game, $b_j \in A_j$ is *safe* if every profile $(b_j, \cdot)$ is $V_B$-optimal (a whole row/column of the payoff table is optimal). $M$ := the set of $V_B$-optimal pure profiles.

**Definition-23 modes.** *Occurrence mode* ($\mathbb E_\mu[r \mid \mathrm{occ}(D)]$, v2's letter) and *event mode* ($\mathbb E_\mu[r \mid \lambda \models \bigvee_{d \in D} O_d]$, Conjecture 1's replacement).

**Fair class $\mathfrak F$** (P1, as corrected by the calibration repair): strongly fair (pre-enrichment-marginal sense on relocated outputs), recording at every queried point for every procedure, zero-probability chance edges pruned, every queried observation satisfied by some leaf-world (P1:adversary-repair Claim A's added hypothesis). It is the class on which FR-11 as repaired proves *tremble-EDT-consistent $\Rightarrow$ $V$-optimal* (P1:synthesis item 20).
