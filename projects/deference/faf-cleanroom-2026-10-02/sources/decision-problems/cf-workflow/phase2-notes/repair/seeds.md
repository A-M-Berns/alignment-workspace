## Definitions carried (restated so the ledger stands alone)

**Definition 6′ (shared-seed run semantics).** For a concrete problem $B$ (Definition 5) and a procedure $C$ (Definition 4), a run draws once and independently for each queried point $d$ a *seed* $a_d \sim C(d)$, then walks from the root sampling chance nodes from $\beta_n$ and following the edge $a_{d_q}$ at every decision node $q$ — the same edge at every node carrying $d_q$. Leaf law $\mu'_{B,C}$, world-marginal $\nu'_{B,C}$, value $V'_B(C) := \mathbb{E}_{\mu'_{B,C}}[r]$. $\mathrm{occ}(d)$, $\#_d$, $C[d\mapsto m]$ are unchanged (path-defined); the tremble $C^\varepsilon$ (Definition 10) is one trembled draw per point per run.

**Definition 6″ (seed-class semantics).** A labelling $\sigma$ of decision nodes by class indices; one seed $a_{d,i} \sim C(d)$ per (point, class) pair, independent across pairs; node $q$ follows $a_{d_q,\sigma(q)}$. Definition 6 = $\sigma$ injective on every fiber; Definition 6′ = $\sigma$ constant on every fiber. $\sigma$ is description data beyond Definition 5 (see SE-10 for provenance).

**Theorem 2′** := Theorem 2's evaluator with Definition 6′ in place of Definition 6: $a \mapsto \mathbb{E}_{\mu'_{B,C[d\mapsto a]}}[r \mid \mathrm{occ}(d)]$, whose argmax is $\arg\max_a V'_B(C[d\mapsto a])$ (Lemma 1 holds under 6′ — SE-1(c) — and leaves off $\mathrm{occ}(d)$ contribute a constant in $a$).

**Own-draw evaluator** in cell (semantics, weighting): $E(a) := \mathbb{E}[r\cdot\mathbf 1(\text{my draw}=a)]/\Pr(\text{my draw}=a)$ over (run, instance) pairs, the run drawn from $\mu_{B,C}$ (Definition 6) or $\mu'_{B,C}$ (Definition 6′) restricted to $\mathrm{occ}(d)$, the instance one of the $\#_d(\ell)$ $d$-nodes on the run; **SIA** (per-occurrence) gives every instance weight $1$; **SSA** (per-run, minimal reference class) gives the run weight $\mu(\ell\mid\mathrm{occ}(d))$ split uniformly over its instances. In Appendix B's grid this is procedure-side conditioning on the run event "my draw $= a$" under the actual $C$.

**Vocabulary.** *Pure* = deterministic $C$ (same run under 6, 6′, 6″). *Behavioral* = $C$ run under Definition 6 (Kuhn's behavioral strategy with information sets $=$ points). *Product-mixed* = $C$ run under Definition 6′ $=$ the distribution $\bigotimes_d C(d)$ on pure procedures $\prod_d A_d$. *Correlated-mixed* = arbitrary $m \in \Delta(\prod_d A_d)$ drawn once per run (not a Definition-4 procedure; the general distribution over the frame's agent set, P1:cf-correspondence CF-3 (CONFIRMED)). *Nested* fiber = some path meets two $d$-nodes; *almost fair* = no nested fiber; *strongly fair* = every fiber's members carry labelled-isomorphic subtrees (P1:fair-repair §0 vocabulary; nested $\Rightarrow$ unfair by P1:fair-repair FR-1(i)). SE-2's "positive path" clause refines "nested" by pruning zero-probability chance edges; the toolkit's `nested_fibers` is the unpruned notion, which is the safe (stronger) hypothesis wherever "contains every nested fiber" appears below.
