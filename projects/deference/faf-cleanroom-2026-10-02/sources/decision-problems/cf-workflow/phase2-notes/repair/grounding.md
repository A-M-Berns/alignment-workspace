## Definitions carried (restated so the ledger stands alone)

- **Node classes at a point — GR-D2, repaired.** For a queried point $d$ with observation $O_d$, let $F_d$ (the *fiber*) be the set of decision nodes carrying $d$. A node $q\in F_d$ is **live** if it is subtree-veridical (Def 7: $\lambda(\ell)\models O_d$ for every leaf $\ell$ below $q$); **routing** if it is not subtree-veridical and some $O_d$-leaf below $q$ has no $d$-node strictly between $q$ and it — $q$'s own draw is then the act an $O_d$-world records (Remark 3.4's "routing root"); **predictor** otherwise — not subtree-veridical, and every $O_d$-leaf below it (if any) passes another $d$-node on the way down: Omega's simulation of the agent at $d$. The thread's original dichotomy (live vs. "not subtree-veridical") lumped routing nodes with predictors; that is the defect the review found on Told-You-So. **Domain hypothesis for everything built on GR-D2:** $B$ is *routing-free at $d$* (no routing node in $F_d$) and *covers* $d$ (Def 7: a.s. every $O_d$-run passes a $d$-node).
- **Lemma GR-D2′ (UNREVIEWED as a lemma; used only inside these definitions) [derived from Def 7 verbatim; checked on the battery, rp (F)].** (i) If $B$ records at $d$ for every procedure (FRec at $d$), then $B$ is routing-free and covered at $d$, and every non-live $d$-node has *no* $O_d$-leaf below it. Reason: Def 7 says an $O_d$-run "passes exactly one $d$-node; that node is subtree-veridical", so the $d$-node above any $O_d$-leaf is unique and live. (ii) Under coverage + routing-freeness, "the run passes a live $d$-node" $\iff$ "the leaf-world satisfies $O_d$": a live node's runs all end in $O_d$; an $O_d$-run's last $d$-node exists by coverage and is live by routing-freeness. Hence the exercise rate below equals $\nu_{B,C}(O_d)$. (iii) Routing-freeness is strictly weaker than FRec: TN-V1 and TN-V2 fail recording at $d_F$ (two $d_F$-nodes on every full-box run — the nested fiber of P1 FR-5) yet are routing-free at both points, and $g_d=\nu(O_d)$ holds there for pure and mixed $C$ ($\tfrac34$ and $\tfrac{47}{140}$ at $d_F$, $\tfrac14$ and $\tfrac{93}{140}$ at $d_E$ in V2) [checked rp (F)]; Told-You-So's root is the battery's only routing node [checked rp (F)].
- **Predictor-labelled instantiation $B_\theta$.** For a verdict $\theta\in\prod_d\Delta(A_d)$, $B_\theta$ is $B$ with every *predictor* node of $d$ replaced by a chance node with law $\theta_d$ over the same children (live nodes untouched; the construction is meaningful only under the domain hypothesis — at a routing node it would delete the agent's only consultation). Label-dependence (Def 14, Remark 5.1) made concrete by fixing the label.
- **Rates — GR-D3.** A *family* is a finitely supported measure $\pi$ on instantiations of an abstract problem $\Sigma$ (Def 14) that query the same points; $B_{\omega,\theta}$ is situation $\omega\sim\pi$ under verdict $\theta$. Exercise rate $g_d(\theta):=\mathbb E_{\omega\sim\pi}\,\mu_{B_{\omega,\theta},C}(\text{the run passes a live }d\text{-node})$ $(=\mathbb E_\pi\,\nu_{B_{\omega,\theta},C}(O_d)$ under the domain hypothesis$)$; use rate $m_d(\theta):=\mathbb E_\pi\,\mathbb E_{\mu}[\#\mathrm{pred}_d]$ (expected number of predictor $d$-nodes on the run); family accuracy $\delta(\theta):=\sum_d g_d(\theta)\,\mathrm{TV}(\theta_d,C(d))$; rarest exercise rate $\gamma(\theta):=\min_d g_d(\theta)$. Honesty is two-sided: predictor-side $\delta=0$ ($\theta_d=C(d)$ at every exercised point — Remark 5.1's fixed-point equation at the family level) and agent-side mixture calibration (Appendix B item 4: $P_{s_d}=\bar\nu(\cdot\mid O_d)$, $\bar\nu=\int\nu_{B,C}\,d\pi$).
- **Fiber value-disagreement.** $Q_q(C,a):=G_q(C,a)$ (§8: the continuation value of $q$'s $a$-child under $C$; under non-nesting the honest one-step deviation value). $D_V(B,C):=\max_d\max_{q,q'\in F_d}\max_a\lvert Q_q(C,a)-Q_{q'}(C,a)\rvert$ (payoff units). Three grades of "the point determines the node": **labelled-isomorphic** fibers (P1 strong fairness) $\Rightarrow$ **law-fair** (every fiber's members have the same continuation $(\lambda,r)$-law under every procedure) $\Rightarrow$ **value-fair** ($D_V(B,C)=0$ for every $C$).
- **Tremble-EDT-consistent** (FR-11's concrete form; toolkit `tremble_edt_consistent`, TWC): for all small $\varepsilon$ some state assignment makes $B$ strictly OC-calibrated (Def 8) for $C^\varepsilon$ (Def 10's uniform tremble per point) and $T_{\mathrm{EDT}}(C,B_\varepsilon)$ holds, the act value being conditioned on the *event* $a\wedge O_d$.
- **Gated-learning chain.** Two states (good / bad); confirming data arrives at rate $\approx1$ in the good state, correcting data at hazard $r_b$ in the bad state; a parameter $\rho$ moves the state without data. The two instances below differ in how $\rho$ acts: a *symmetric flip* of the verdict (TN drift) versus a *one-way reset* of the credence (mugging forgetting) — GR-15.
