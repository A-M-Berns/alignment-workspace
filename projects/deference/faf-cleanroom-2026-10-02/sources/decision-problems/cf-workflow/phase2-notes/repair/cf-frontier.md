## Repaired definitions

**CFF-A (chance seeding; identified frame) — unchanged.** A seeding $\kappa : \mathrm{Ch}(B) \to K$ assigns chance nodes to variables (equal children and $\beta$ within a class; *path-injective*: no root-path meets two nodes of one class); relocation carries $\kappa$ along (copies inherit their original's variable). $\mathrm{Fr}_\kappa(B) := (\prod_d A_d,\ \prod_{k \in K} \mathrm{children}(k),\ \text{run})$, the run reading $\varepsilon(\kappa(n))$ at $n$. Lazy: $\kappa = \mathrm{id}$. For path-injective $\kappa$ every $\mu_{B,C}$, $\nu$, $V_B$ and every calibration sense is unchanged; only the frame changes. $\kappa$ is representation data — to chance nodes what the point label $d_q$ is to decision nodes.

**CFF-B′ (crown, exits, realizable classes, pre-decision, consulted straddling) — repaired.** Crown $\mathrm{Cr}(B)$ = chance nodes with no nontrivial decision above; crown exits $X(B)$ = first non-crown nodes on chance-only descents. A *pure run* is the run of a pure profile $\pi$ at a chance profile $\varepsilon$. The **realizable class** $W^{\mathrm{real}}_x$ of a node $x$ = outcomes $(\lambda(\ell), r(\ell))$ of pure runs whose path passes $x$ (on a tree with no nested fiber every leaf is realizable, so this is the all-leaf set; on nested trees leaves below an inconsistently-answered path are realized by no pure run). $S \subseteq W$ is **pre-decision** iff every exit's realizable class lies entirely inside or entirely outside $S$ (*uniformity*, not "union of classes": classes may overlap). A point $d$ **straddles** $S$ iff some pure run consulting $d$ passes an $S$-exit and some pure run consulting $d$ passes a $\neg S$-exit. $W^{\mathrm{real}}_q$ for a decision node $q$ likewise; $B$ is **realizable-outcome-fair** iff the members of every fiber have equal realizable outcome sets. Strong fairness $\Rightarrow$ no nested fiber (P1:fair-repair FR-1(i)) $\Rightarrow$ every leaf realizable $\Rightarrow$ realizable-outcome-fair.

**CFF-C′ (stages; the stage-1 history partition) — extended.** Decision depth, stratified trees, stage-$k$ points $D_k$, $\mathrm{Fr}_k(B) = (A_k, A_{<k} \times A_{>k} \times \mathbf E)$, $\lhd_\times \mathrm{Fr}(B)$ on the nose, $\mathrm{Fr}_{>k}$ = the later self — as in the notes. New: $T_1$, the **stage-1 history partition** of $W$: cells = the recorded history up to and including the stage-1 move (recorded crown chance on the path + the stage-1 node's recorded action). It is a partition of $W$ only where these are recorded in worlds; where nothing is recorded it is trivial.

**CFF-D (splice; $\equiv_S$, $\equiv_N$; clean labelling; self-relocation) — unchanged.** **CFF-E (enriched frame; $\varepsilon_{\mathrm{pow}}$, $\varepsilon_{\mathrm{cp}}$, $\Gamma_S$) — unchanged**, with the note that $\Gamma_S$ (and $E_S, E_N$) is defined only for column-determined $S$.
