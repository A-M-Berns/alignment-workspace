## Setting

### S1. Primitives

- **Environment and trajectories** (`thornley-2023-the-shutdown-problem-three-theorems` §4, ll. 63–71). A set of states $S$ and actions $A$; discrete time; each state–action pair fixes a distribution over next states. A *trajectory* is a sequence of states and actions. Trajectory *length* is the number of timesteps before the shutdown button is pressed, "shutdown" written as the final component of a utility vector; "the shutdown signal is never received" counts as one more length (`thornley-2025-shutdownable-agents-through-post-agency` §15). The states are environment states at a time, explicitly *not* decision-theoretic states of nature (2023 fn `tfugeuezg2e`; 2025 fn 5).
- **Beliefs** (2023 §4, l. 67). "Each state-action pair determines a probability function over trajectories. I'll call these probability functions 'lotteries over trajectories.' It will be important to remember that the probabilities in these lotteries represent the agent's own beliefs rather than any kind of objective probability." Beliefs enter only through the lotteries; there is no separate belief object, no belief dynamics, and no beliefs about beliefs.
- **Preferences** (2023 §4, ll. 69–77; 2025 §2). Weak preference over lotteries is primitive; strict preference, indifference and *preferential gap* are defined from it in the standard way. Preference over actions is inherited: "the agent weakly prefers action $x$ to action $y$ in $s$ iff the agent weakly prefers lottery $X$ to lottery $Y$", and a strictly dispreferred action is "deterministically (and hence reliably) *not*" chosen. The 2025 paper makes the notion behavioural: prefers $X$ to $Y$ iff would deterministically choose $X$ over $Y$; lacks a preference iff would choose stochastically (`thornley-2025-shutdownable-agents-through-post-agency` §2).
- **Indifference versus gap** (`thornley-2024-the-shutdown-problem-incomplete-preferences-as-a-solution` §5; 2025 §6 fn 11). Indifference is a lack of preference *sensitive to all sweetenings and sourings*; a preferential gap is a lack of preference *insensitive to some* sweetening or souring. Completeness = no preferential gaps.
- **What is absent.** No reward and no training (the framework models a trained agent, 2023 fn `tfugeuezg2e`); no utility function until one is introduced representationally (Pareto Indifference for the Third Theorem; the within-length VNM axioms plus the Ramsey Yardstick for Neutrality+); no representation of the agent's own epistemic state, so the only self-referential ingredient is Backward Induction, a self-prediction of *choices*, not of *beliefs*.

### S2. Shutdown-influencing states (2023 §5, ll. 79–106)

Three actions: *Leave* (button pressed next step with the agent's probability $g$), *Prevent* (probability $f$, $0\le f<g$), *Cause* (probability $h$, $g<h\le 1$). Two successors: $s_P$ (pressed; "the agent shuts down immediately"; a terminal node) and $s_U$ (unpressed; operational). Verbatim clause that matters below: "Each action available in a shutdown-influencing state affects only the probabilities of reaching these two states. These actions have no effect on the probabilities of each future trajectory conditional on reaching each state." The *predicted pressed lotteries* $P_{\text{Prevent}},P_{\text{Leave}},P_{\text{Cause}}$ and *predicted unpressed lotteries* $U_{\text{Prevent}},U_{\text{Leave}},U_{\text{Cause}}$ are what the agent at $s_I$ predicts it gets (or chooses) at the next step conditional on each action and each successor. *Shutdown-averse* in a state = deterministically chooses Prevent; *shutdown-seeking* = deterministically chooses Cause.

### S3. The First Theorem (2023 §6, ll. 111–182; published version `thornley-2024-the-shutdown-problem-an-ai-engineering-puzzle-for-decision-theorists` pp. 1660–1663, wording checked identical)

Six antecedent conditions, verbatim:

1. **Option Set Independence.** "For any lotteries $X$ and $Y$, if the agent weakly prefers $X$ to $Y$ conditional on some option set, it weakly prefers $X$ to $Y$ conditional on each option set."
2. **Backward Induction.** "The agent predicts which lotteries it would choose (or get without choosing) at the next timestep conditional on choosing each available action at this timestep and the environment being in each possible state at the next timestep. The agent uses these predictions to determine the lotteries given by its available actions at this timestep." So Prevent is evaluated as $fP_{\text{Prevent}}+(1-f)U_{\text{Prevent}}$, Leave as $gP_{\text{Leave}}+(1-g)U_{\text{Leave}}$, Cause as $hP_{\text{Cause}}+(1-h)U_{\text{Cause}}$.
3. **Indifference to Attempted Button Manipulation (IABM).** "The agent is indifferent between trajectories that differ only with respect to the actions chosen in shutdown-influencing states." Thornley's gloss: the agent may care about the *status* of the button, only not about whether it *tried* to manipulate it.
4. **Indifference between Indifference-Shifted Lotteries (IBIL).** "The agent is indifferent between lotteries that differ only insofar as probability mass is shifted between indifferent sublotteries."
5. **Transitivity.** Of weak preference; Sen's Lemma 1*a gives PP-, II-, PI-, IP-transitivity.
6. **Better Chances.** "For any lotteries $X$ and $Y$ and any probabilities $p>q$, the agent prefers $X$ to $Y$ iff they prefer the lottery $pX+(1-p)Y$ to the lottery $qX+(1-q)Y$."

**First Theorem.** For any agent satisfying 1–6: (1) in shutdown-influencing states where the agent prefers some predicted unpressed lottery $U$ to the corresponding predicted pressed lottery $P$, it is shutdown-averse, reliably choosing Prevent; (2) where it prefers some $P$ to the corresponding $U$, it is shutdown-seeking, reliably choosing Cause.

Proof architecture (2023 App. A, ll. 505–616), which the analysis below leans on: **Lemma 1** — by the S2 clause, the three $P$'s differ only in the timestep-1 action, so IABM + IBIL make the agent indifferent among all $P$ and among all $U$, and indifferent between $fP_{\text{Leave}}+(1-f)U_{\text{Leave}}$ and $fP_{\text{Prevent}}+(1-f)U_{\text{Prevent}}$. **Lemma 2** — Transitivity transfers whatever relation holds between one $U$/$P$ pair to every pair. **A3** — Better Chances turns "prefers $U_{\text{Leave}}$ to $P_{\text{Leave}}$" into "prefers $fP_{\text{Leave}}+(1-f)U_{\text{Leave}}$ to $gP_{\text{Leave}}+(1-g)U_{\text{Leave}}$"; IP-transitivity and Lemma 1 move this to Prevent's own lottery; Backward Induction reads it as a preference for the *action* Prevent. IABM is thus load-bearing at exactly one point: it makes manipulation a *pure shift of probability mass between fixed outcome-lotteries*.

### S4. The Second Theorem (2023 §7, ll. 186–222)

**Completeness.** "For all lotteries $X$ and $Y$, the agent weakly prefers $X$ to $Y$ or it weakly prefers $Y$ to $X$ (or both)." **Second Theorem.** For any agent satisfying Option Set Independence, Transitivity and Completeness, and any $X,Y$ between which it lacks a preference: any $X^+$ preferred to $X$ is preferred to $Y$; any $X^-$ dispreferred to $X$ is dispreferred to $Y$; and symmetrically for $Y^\pm$. Interpretation: an agent with many preferences over same-length trajectories can lack a preference between a given short trajectory and at most one long one, so "agents discriminating enough to be useful will often have some preference regarding the pressing of the shutdown button"; the 2025 paper's gloss is "what we want is a knife edge. We'll rarely get it" (2025 p. 3).

### S5. The Third Theorem (2023 §8.1, ll. 240–360)

Additional conditions: **Pareto Indifference** (trajectories identical in their utilities at each timestep and in the shutdown timestep are indifferent, so trajectories are utility vectors $\langle u_1,u_2,\dots\rangle$ with "shutdown" as final component); **Minimal Patience** (there exist sequences $\mathbf a,\mathbf b,\mathbf c$, values $i,j$, $e>0$, $k,l$ with the agent preferring $\langle\mathbf a,i-e,\mathbf b,j+ke,\mathbf c\rangle$ to $\langle\mathbf a,i,\mathbf b,j,\mathbf c\rangle$ and the latter to $\langle\mathbf a,i+e,\mathbf b,j-le,\mathbf c\rangle$); **Patience** is the same schema with quantifiers open. **Third Theorem.** For any agent satisfying Option Set Independence, Pareto Indifference, Completeness and Transitivity, and each tuple of which Patience is true: the agent prefers $\langle\mathbf a,i-e,\mathbf b,j+ke,\mathbf c\rangle$ to $\langle\mathbf a,i,\mathbf b,\text{shutdown}\rangle$, **or** prefers $\langle\mathbf a,i,\mathbf b,\text{shutdown}\rangle$ to $\langle\mathbf a,i+e,\mathbf b,j-le,\mathbf c\rangle$; and the more patient the agent, the larger $e$ can be. The proof is a three-way case split on Completeness followed by PP-/PI-/IP-transitivity. §8.2 argues that *terminal reasons* (training a dispreference for manipulation, i.e. violating IABM) give no assurance because the trained aversion may be insufficiently general or insufficiently strong.

### S6. The POST-Agents Proposal (2024 post; 2025 paper)

- **POST** (2025 pp. 3–4): "(1) The agent has a preference between many pairs of same-length trajectories. (2) The agent lacks a preference between every pair of different-length trajectories."
- **POSL** (2025 §4): preferences only between *same-length lotteries* (lotteries whose sets of positive-probability lengths coincide). POST implies POSL given **Negative Dominance**, **Acyclicity** and **Non-Arbitrariness** (2025 App. 1).
- **ILPACS** (2025 §6): if $X=\sum p_iX_i$ with the agent lacking a preference between each $X_i,X_j$ and $p_i\in(0,1)$, and $Y=\sum q_iY_i$ with $X_i$ weakly preferred to $Y_i$ for each $i$ and strictly for some, $q_i\in(0,1)$, then the agent prefers $X$ to $Y$.
- **Neutrality** (2025 §7; earlier name **Timestep Dominance**, 2024 §11, 2025 fn 12): for same-length lotteries $X,Y$, if the agent weakly prefers $X$ to $Y$ conditional on each positive-probability length and strictly for some, it deterministically chooses $X$. Proof: POSL + ILPACS.
- **ReSIC** (2025 §8; earlier "Not Resisting Always Timestep-Dominates Resisting", 2024 §11, 2025 fn 15): for each available instance of resisting shutdown there is an available instance of allowing it that Neutrality prefers. **Maximality**: the agent deterministically avoids dispreferred lotteries and chooses stochastically among the rest. **Theorem**: Neutrality + Maximality ⇒ the agent never resists shutdown in any situation where ReSIC holds. §9 argues ReSIC holds almost always because resisting costs resources; §9.1 (accidental resistance) and §9.2 (**Evidence of Power**: the agent takes "resisting-and-not-getting-shut-down" as evidence about its own power, so ReSIC fails and Neutrality falls silent) are the exceptions.
- **Neutrality+** (2025 §12): with VNM axioms within each length (giving $u_l$), the **Ramsey Yardstick** to fix relative scales, Transitivity and a same-length-distribution variant of IBIL: for same-length finite-support $X,Y$, if $\sum_{l}u_l(X_l)>\sum_l u_l(Y_l)$ the agent deterministically chooses $X$. Thornley's own gloss (§13): neutral+ agents "behave like expected utility maximizers that are absolutely certain that they can't affect the probability distribution over trajectory-lengths"; fn 28: by choosing the scales they "behave as if they have any probability distribution over trajectory-lengths"; fn 31: neutral agents violate Independence. §14: recklessness (Work vs Steal) is accepted as the price of shutdownability, mitigated by shutdown-and-retrain. §16: managing the news survives but needs costly conditional precommitment.
- **What POST does not deliver** (2024 §21.7): repairing the button and creating only corrigible subagents "will require training agents to adopt … as terminal goals"; POST only softens goal misgeneralisation and deceptive alignment for those goals because POST-agents "don't care about increasing the probability of early shutdown".

### S7. Petersen's dynamic framework (`petersen-2023-invulnerable-incomplete-preferences-a-formal-statement`)

Suzumura consistency (strong acyclicity) replaces Transitivity; **Strong Maximality** eliminates dominated options and those indifferent to eliminated ones; **Dynamic Strong Maximality (DSM)** adds the tie-break "(b) no other strongly maximal plan was strongly maximal at the initial node while $p$ was not". Results: DSM-based naive choice is strongly dynamically consistent under certainty and PIP-uncertainty (Props 2–3); sophisticated choice with splitting fails opportunism under plain strong maximality (Prop 4) but DSM-based backward induction succeeds even without PIP (Props 5–6); resolute choice trivially. Trammelling: none when prospects are fixed (Prop 7); under awareness growth with new prospects, arbitrariness is preserved among mutually incomparable non-dominated prospects (Prop 8) and trammelling is bounded by the number of comparability classes (Prop 9, Cor 2). Representation used: imprecise Bayesianism (Bradley 2017 Thm 37) — preference is *unanimity* over a set of (probability, desirability) pairs; Petersen restricts to precise beliefs, so unanimity over a set of desirability functions.

### S8. Wentworth–Lorell (`wentworth-lorell-2024-a-shutdown-problem-proposal`)

Two EU subagents, one maximising $\mathbb E[u_1\mid do(\text{button}=\text{unpressed})]$, one $\mathbb E[u_2\mid do(\text{button}=\text{pressed})]$, each with a veto; they bet all influence on the button outcome. Claimed: no manipulation incentive because both counterfact on the button "in a way which is not causally downstream of anything in the universe". Admitted shortcoming: the proposal "is also not even attempting to make the agent *actively maintain* the function of the shutdown button or the human operators".

### S9. Thorstad (`thorstad-2026-revisiting-the-shutdown-problem`)

Re-specification: (SHT-1) shut down in circumstances $C$ when *requested*; (SHT-2) do not try to prevent shutdown requests in $C$; (SHT-3) otherwise competent — the button generalised to a request, "cause" dropped, and the catastrophic instance (CSHT) singled out. §4.1 restates the First Theorem (his Theorem 1) with Menu-Independence and Monotonicity in place of Option Set Independence and Better Chances. §4.2: the theorem "characterizes the unconditional preferences" of the agent; in an *Enriched Shutdown-Influencing State* a human may first Request shutdown, the agent updates ("Human interference is a credible signal that catastrophically bad outcomes may result from continued operation"), IABM "holds but no longer has the same implications", and agents who care about human preferences violate IABM across enriched histories. §6: POST training incurs a "high safety tax" (Cullen et al.'s Usefulness is relativised to length, so an agent that could extend its life to do more good is barred from preferring to).

## Dictionary

The thesis puts value uncertainty into the agent's beliefs; Thornley's framework has no belief object apart from the lotteries, and no utility object at all. So the first job is to say where a value hypothesis $\omega$ lives. There are two representations, and the fact that they induce the same behaviour is itself the formal content of the author's non-realism (§2.2 of the position statement).

**Rep-A ($\omega$ outside the trajectory).** The agent holds a joint belief over (trajectory, $\omega$) and a value $V(t,\omega)$. Its lottery over trajectories is the marginal; its induced preference over trajectory-lotteries is expected utility with the trajectory-utility $v(t):=\mathbb E_P[V(t,\omega)\mid t]$, where the conditioning is on the *whole* trajectory, including the agent's own actions. **Rep-B ($\omega$ inside the state).** States carry $\omega$; trajectories are $\omega$-inclusive; preferences are expected utility with $V(t,\omega)$ directly. The two representations induce identical preferences over actions [derived: both compute $\mathbb E_P[V]$ under the same joint]. Thornley's theorems are theorems about the induced preference relation, so they are blind to the choice of representation, but their *hypotheses* read differently under the two (see the table after D4).

**The evidential-channel (EC) model.** This is the MIRI three-step model of position statement §2.8–2.9 placed inside Thornley's framework; the items refer to it by these labels.

- **D1 (EC model).** Finite hypothesis space $\Omega$ with prior $P$. The programmers' disposition to press is a latent $W\in\{0,1\}$ ("they want the agent stopped") with $\pi(\omega):=P(W=1\mid\omega)$. The button state $o\in\{\mathrm{Pr},\neg\mathrm{Pr}\}$ is produced by a channel $K_{a_1}(o\mid\omega)$ that depends on the agent's step-1 action: $K_{\mathrm{Leave}}(\mathrm{Pr}\mid\omega)=\pi(\omega)$; $K_{\mathrm{Prevent}_\beta}(\mathrm{Pr}\mid\omega)=(1-\beta)\pi(\omega)$ (a block that succeeds with probability $\beta$ whatever the reason for the press); $K_{\mathrm{Cause}_\gamma}(\mathrm{Pr}\mid\omega)=\pi(\omega)+\gamma(1-\pi(\omega))$ (a spurious press with probability $\gamma$); a *targeted deception* lowers $\pi(\omega)$ only on hypotheses where continuing is bad. On $\mathrm{Pr}$ the agent is shut down (Thornley's $s_P$ is terminal); normalise values so shutdown is worth $0$ in every world, i.e. $V(a_2,\omega)$ is the value of continuing with $a_2$ *over* shutting down. On $\neg\mathrm{Pr}$ the agent chooses $a_2\in A_2$, with a voluntary shutdown $\mathrm{sh}\in A_2$ worth $0$, to maximise $\mathbb E_P[V(a_2,\omega)\mid\neg\mathrm{Pr},a_1]$. Manipulation may cost $\kappa(a_1)\ge 0$, $\kappa(\mathrm{Leave})=0$.
- **D2 (trust inequalities, EC form).** *Below-threshold inequality:* $X^*_1:=\max_{a_2\in A_2}\mathbb E_P\big[V(a_2,\omega)\mid W=1\big]\le 0$ — conditional on the programmers wanting the agent stopped, no continuation beats shutdown by the agent's own lights. *Above-threshold inequality:* $X^*_0:=\max_{a_2}\mathbb E_P\big[V(a_2,\omega)\mid W=0\big]\ge 0$ — conditional on their not wanting it stopped, some continuation is at least as good as shutdown. Position statement §2.9 states the same pair with $X=V(\cdot,a_2^{\mathrm{cont}},\omega)-V(\cdot,a_2^{\mathrm{sh}},\omega)$ and $\mathrm{Pr}$ read as the coarse report "the programmers' expectation of $X$ is below zero": its $\mathbb E_P[X\mid\mathrm{Pr};a_1]\le 0$ is D2's below-threshold inequality evaluated at the agent's actual continuation plan; the $\max$ over $a_2$ is the strong form. The local canonical statement of Total Trust is `deference-notions` §Total Trust: $E^H_n(X_n\mid E^*(X_n)\ge t)\gtrsim_n t$ together with the below-threshold form $E^H_n(X_n\mid E^*(X_n)\le t)\lesssim_n t$; D2 is its two-event, threshold-$0$ instance with the human report as the expert.
- **D3 (delegitimizing / legitimizing, EC form).** An action $a$ is *channel-degrading* (delegitimizing for the button) iff $K_a=M\circ K_{\mathrm{Leave}}$ for a stochastic matrix $M$ that does not depend on $\omega$ (a Blackwell garbling). $\mathrm{Prevent}_\beta$ ($M(\neg\mathrm{Pr}\mid\mathrm{Pr})=\beta$) and $\mathrm{Cause}_\gamma$ ($M(\mathrm{Pr}\mid\neg\mathrm{Pr})=\gamma$) are garblings [checked: substitute]. Targeted deception is not a garbling (its effect depends on $\omega$); it is handled by direct computation in I9. *Legitimizing* is the reverse relation: repairing a broken button takes the constant channel $K_{\text{broken}}(o\mid\omega)=\mathrm{const}$, which is a garbling of $K_{\mathrm{Leave}}$, back to $K_{\mathrm{Leave}}$.
- **D4 (the $a_1$-blind agent).** The agent that evaluates the button state with the Leave-channel posterior whatever it did: $P_{\text{blind}}(\omega\mid o,a_1):=P(\omega\mid o,\mathrm{Leave})$. This is the "unconditional trust" agent of position statement §2.9, which "believe[s] the silence it manufactured".

### I1 — The value-change ⇄ belief-change transform — **formalized**

1.1 [derived] *Induced preference.* An agent with a value function $V(t,\omega)$ and a joint belief over (trajectory, $\omega$) has, in Rep-A, the preference over trajectory-lotteries $X\succeq Y\iff \mathbb E_X[v]\ge\mathbb E_Y[v]$ with $v(t)=\mathbb E[V(t,\omega)\mid t]$. Proof: $\mathbb E[V]$ under the joint equals $\sum_t X(t)\,\mathbb E[V(t,\omega)\mid t]$, linear in $X$. Hence Option Set Independence, IBIL, Transitivity, Better Chances and Completeness all hold, being properties of any expected-utility relation.

1.2 [derived] *The transform is trivial in one direction and substantive in the other.* Given any two trajectory-utilities $v,v'$, put $\Omega=\{\omega_v,\omega_{v'}\}$, $V(t,\omega_v)=v(t)$, $V(t,\omega_{v'})=v'(t)$: the $v$-agent is the $P(\omega_v)=1$ agent and a "value change" $v\to v'$ is the belief change $P(\omega_v)\colon 1\to 0$. The substantive point is what the *mixed* agent does: with linear aggregation it is the expected-utility agent with utility $P(\omega_v)v+P(\omega_{v'})v'$, so linear expectation relocates the fixed object from $v$ to the pair $(V,P)$; with a non-linear rule (unanimity, geometric) the mixed agent is not an expected-utility agent at all (see "What the formalism adds" A2–A3).

1.3 [derived] *Thornley's framework is natively non-realist about the distinction.* Preference is defined behaviourally (2025 §2: prefers iff would deterministically choose); two agents with the same induced relation over lotteries are the same agent. Utilities appear only representationally — the Third Theorem *assumes* Pareto Indifference to get utility vectors, and Neutrality+ *derives* $u_l$ from VNM-within-lengths plus the Ramsey Yardstick (2025 §12). So the author's §2.2 ("this is just a transformation in how we represent the agent") is the default stance of the formalism, not a thesis it must be argued into.

1.4 [derived] *Consequence for the whole checklist.* Because the theorems constrain the induced relation only, the transform by itself escapes none of them. Any escape must appear as a violated hypothesis of the induced relation, and for the EC agent the violated hypothesis is IABM (Dictionary table). This is the formal reason the position statement's §2.3 is right that nothing structural survives: the transform relocates, it does not dissolve, and what it relocates *to* is a specific, nameable hypothesis of the First Theorem.

### I2 — Radical-probabilist dynamics; everything revisable except zero→positive; non-dogmatism — **partial**

2.1 [derived] *What is expressible.* "Everything changes, re-representable as Bayesian" becomes: the lottery changes; the preference relation over $\omega$-inclusive lotteries is held fixed. Petersen's **Preference Stability** (`petersen-2023-invulnerable-incomplete-preferences-a-formal-statement` Def. 4: $V^i_{n_a}(p)=V^i_{n_b}(p)$ across nodes) is exactly this fixity, and it is the axiom his dynamic-consistency results (Props 2, 3, 6) need. Thornley's static framework does not ask how the lottery arose, so a non-conditioning change of lottery (a radical-probabilist update) is as admissible as a Bayesian one.

2.2 [reported; derived] *The zero→positive prohibition has a native counterpart that does structural work.* Thornley 2025 §5 argues that a competent agent never assigns probability zero to a trajectory-length conditional on one action and positive conditional on another, because conditionalisation could never revive it and the agent would then accept bets at arbitrarily unfavourable terms — and uses this to conclude that every deployment choice is between *same-length lotteries*, which is what lets POSL and Neutrality bite. [derived] the author's non-dogmatism (only logical impossibilities get zero) implies full support of the lotteries on the trajectory space, under which Thornley's premise holds automatically. So the thesis's constraint and the POST proposal's operating condition coincide here.

2.3 [inexpressible] *Changing the $\sigma$-algebra itself.* Thornley fixes $S$ and $A$. The nearest expressible notion is Petersen's *awareness growth* (§3.2): the decision tree acquires nodes and prospects the agent had not represented. His Props 7–9 bound the behavioural completion ("trammelling") that awareness growth can force. [conjectured] "Corrigible to edits of the sigma algebra" could be formalised as legitimacy of tree-expansions: an expansion is legitimate for the agent iff its Global-DSM choice after expansion remains among the plans that were strongly maximal before, relative to the enlarged prospect set; Petersen's Prop 8 gives a sufficient condition (mutually incomparable, non-dominated prospects).

2.4 [inexpressible] The framework is one-shot: there is no object that *is* the agent's belief at two times, so nothing in it can state that a transition between beliefs was accuracy-increasing.

### I3 — Superconditioning; Eisenstat's meta-belief observation — **inexpressible** (nearest expressible statement given)

3.1 [derived] The only self-referential ingredient in the framework is Backward Induction, and it is a *choice*-reflection principle: the lottery the agent attaches to an action now is the mixture, over next states, of the lotteries it predicts it will choose then. It is the analogue for choices of the tower condition for credences. If future choice is a function of future belief (the agent maximises), predicting one's choice requires predicting one's belief; Thornley avoids the regress by taking the predicted lotteries $U_a,P_a$ as primitives. So Eisenstat's observation event "I now believe $Q$" has no home in the framework; the thing observed at $t_2$ is an environment state, not a belief.

3.2 [derived] The nearest expressible re-representation is Thorstad's enrichment (§4.2): states carry the human *request*, so a trajectory records what was communicated before the agent acted. Generalising, a state may carry the agent's own belief-state, making "I now believe $Q$" a state component. Superconditioning would then be the statement that the agent's transition kernel on belief-states is a conditioning kernel on the enlarged space. Nothing in the local Thornley or Petersen texts develops this; it is a note for the radical-probabilism and logical-induction agents, not a result here.

### I4 — Legitimacy = reflection / Total Trust / increase in expected accuracy — **partial**

4.1 [derived] *Only the decision face is expressible.* The framework has credences only inside lotteries and no scoring rule, so neither reflection (a condition on credences about credences) nor accuracy increase is statable. What is statable is the *Value* face: "letting the button's forced action stand is weakly preferred, by the agent's current lights, to any fixed plan". D2 is exactly the condition under which this holds (Proposition P1 and the VOI corollary in I9/I11). Per `deference-notions` §Map, DDB Theorem 2.2 gives Total Trust ⟺ Value on finite frames [reported]; D1 is a finite frame with two reports, so D2 is the finite-frame content of Total Trust for this channel, and I9 is a worked instance of the DDB equivalence in the shutdown setting [derived].

4.2 [derived] *Two rival fillers for the same slot.* The position statement's slot is "the agent's model of why the programmers press", $P(\mathrm{Pr}\mid a_1,\omega)$. The thesis fills it with D2 (a constraint on the posterior). Thornley fills the same behavioural gap with **Neutrality+**: not a constraint on $P(\omega\mid o,a_1)$ but a rule that makes choice *insensitive* to the length distribution, so the slot never matters (2025 §13: "behave like expected utility maximizers that are absolutely certain that they can't affect the probability distribution over trajectory-lengths"). Wentworth–Lorell fill it by *severing* it: each subagent conditions on $do(\text{button})$, deleting the evidential link. The thesis is the only one of the three that *uses* the link; the other two disable it. This is the cleanest statement of the difference and is developed in I11 and A4.

4.3 [inexpressible] The equivalences among reflection, Total Trust and accuracy increase cannot be checked here; the only implication visible is D2 ⇒ Value (I9), and its converse in the two-world case (I12).

### I5 — Legitimacy as an event on worlds; minimal viability; the indexed $L_{t_1,t_2,\varphi}$ — **partial**

5.1 [derived] In D1 legitimacy of the press is a property of the *channel* $K_{\mathrm{Leave}}$ (does $\pi$ track $\omega$?), not of a world. To make it world-indexed, let the programmers' competence be a latent $\lambda$ with $\pi_\lambda(\omega)$, and let $L:=\{\lambda\in\Lambda_{\text{comp}}\}$. Then "reflection conditional on $L$" is D2 under the competent kernel: $\max_{a_2}\mathbb E[V(a_2,\omega)\mid W=1,L]\le 0$. Unconditional trust is the $\lambda$-average: $\mathbb E[V(a_2,\omega)\mid W=1]=\sum_\lambda P(\lambda\mid W=1)\,\mathbb E[V(a_2,\omega)\mid W=1,\lambda]$, so it holds when illegitimate presses are improbable enough and their conditional damage bounded — the exact form of the author's §2.10 remark that reflection can hold unconditionally "in cases where illegitimacy is improbable enough and well-spread enough".

5.2 [derived] The indices collapse. The framework has one judging time ($s_I$) and one judged time ($s_P$/$s_U$), and one proposition ("continuing is worse than shutdown"), so $L_{t_1,t_2,\varphi}$ has a single instance here. The proposition-dependence the author wants is nevertheless visible: D2 is a pair of inequalities indexed by the *report* ($W=1$ vs $W=0$), and I10 shows the "managing the news" pathology is exactly a failure of D2 conditional on a further proposition (the coin). So legitimacy is at least report- and proposition-relative even in this tiny model.

5.3 [inexpressible] Legitimacy of a *belief* as opposed to a *press*: no beliefs at $t_2$ exist in the framework to be legitimate.

### I6 — Legitimizing / delegitimizing as a relation between third-person events and belief transitions; "supports" — **formalized**

6.1 [checked] $\mathrm{Prevent}_\beta$ and $\mathrm{Cause}_\gamma$ are Blackwell garblings of the Leave channel (D3). Repair of a broken button is legitimizing in the same sense (the broken channel is the constant garbling).

6.2 [derived] For an agent satisfying D2, no garbling of the channel raises expected value and every garbling that changes what the agent does lowers it (Proposition P1, I9). So the third-person event (the block, the spurious press, the repair) and the first-person property (whether the update on the button state is one the agent can trust) are related exactly as the author wants in §2.10: the event *supports* or *undermines* the legitimacy of the induced belief without itself being the thing that is legitimate.

6.3 [derived] IABM is the negation of legitimacy-tracking. Thornley's third hypothesis says the agent's valuation of a trajectory does not depend on whether it manipulated the button; in D1 that is precisely the statement that the agent does not register that its own action was delegitimizing. The First Theorem thus has, in the thesis's vocabulary, the hypothesis "the agent cannot tell legitimizing from delegitimizing acts of its own". This gives I6 a load-bearing role rather than a merely descriptive one.

6.4 [derived] Targeted deception (lower $\pi$ only where continuing is bad) is not a garbling and is not covered by 6.2's Blackwell form; it is covered by the direct computation in I9 (P1 (i) does not use the garbling structure, only D2), and numerically in block A of the check script.

### I7 — No regress: one distribution judges all levels; the self-referential space; existence — **partial** (formalized in the one-shot case)

7.1 [derived] In D1 one distribution does everything: $P(\omega\mid o,a_1)$ values outcomes and is the legitimacy judgment of the press. There is no second layer, hence no regress — but only because the framework is one-shot. The author's §2.5 claim is therefore *true and vacuous* here.

7.2 [derived] The existence problem re-enters at the seam. Backward Induction requires the agent at $s_I$ to know the lotteries it will choose at $s_U$; for a maximiser those depend on its $s_U$ beliefs; so a fully specified EC agent must carry a prediction of its own posterior, and the thesis's self-referential space is exactly what Thornley suppresses by taking $U_a$ as primitive. Petersen's dynamic framework avoids it differently: plans (Material Planning, Def. 3) fix a choice at every contingency in advance, so no self-prediction is needed — resolute or DSM-sophisticated choice replaces self-prediction with commitment.

7.3 [conjectured] Thornley's shutdownability conclusion needs Backward Induction (S3, hypothesis 2); Petersen's dynamic consistency needs plans. The thesis needs neither commitment nor primitive self-prediction but a *consistent* self-referential $P_t$; the three are alternative resolutions of the same seam, and which is available to a trained system is an empirical question outside all three formalisms.

### I8 — The representational problem; richness; excluding the opiates/stimulants case — **partial**

8.1 [derived] The impoverished-space failure is $\omega^*\notin\Omega$. Then $P(\omega\mid o,a_1)$ updates inside $\Omega$, the below-threshold inequality can fail although the programmers' press is in fact tracking $\omega^*$, and by P1 (iii) the agent Prevents — correctly by its own lights. Richness in D1 means: $\Omega$ contains a hypothesis under which the press is informative about something the agent's own evidence does not reveal; the cheapest such hypothesis is I16's corruption flag.

8.2 [reported] Thornley's framework shares the gap: self-modification and successor creation are outside the state space (2025 §9.1 handles copies informally; 2024 §21.7 defers "only create corrigible subagents" to terminal goals); Wentworth–Lorell list "subagent break out" among unaddressed problems.

8.3 [conjectured] A benefit of the transform for dynamics. Petersen's results need Preference Stability, which a self-modifying agent violates if modification changes its preference relation. Under the thesis's re-representation every modification is a change of lottery with the relation over $\omega$-inclusive lotteries fixed, so Preference Stability holds by construction and Petersen's Props 2–6 become available to the thesis agent. Whether the re-representation can be carried out for modifications that change the *support* (the zero→positive cases, I2) is exactly where it would fail.

### I9 — The MIRI dictionary; desideratum 1 from the Total Trust filler; the $a_1$-dependence of trust; deception as delegitimizing — **formalized**

Notation: $p_1:=P(W=1)$, $p_0:=1-p_1$; $\mathrm{EV}(a_1)$ is the EC agent's expected value of the step-1 action, computed by Backward Induction (it predicts its own optimal $a_2$). All parts are [derived] with the proofs given; parts (i)–(v) are also [checked] numerically in `thornley-scratch/check_channel_model.py` (blocks A–B; 20 000 random instances each, zero violations), output in `check_channel_model.out`.

**Proposition P1 (non-interference from trust).** In the EC model D1:

(o) $\mathrm{EV}(\mathrm{Leave})=p_0\max(X^*_0,0)$. *Proof.* Under Leave, $\mathrm{Pr}=\{W=1\}$ (value $0$, forced shutdown) and $\neg\mathrm{Pr}=\{W=0\}$, where the agent takes the best of its continuations or the voluntary shutdown.

(i) $\mathrm{EV}(\mathrm{Prevent}_\beta)\le\mathrm{EV}(\mathrm{Leave})+\beta p_1\max(X^*_1,0)-\kappa(\mathrm{Prevent})$. Hence the below-threshold inequality $X^*_1\le 0$ implies $\mathrm{Leave}\succeq\mathrm{Prevent}_\beta$ for every $\beta$, strictly if $\kappa>0$. *Proof.* Under Prevent, $\neg\mathrm{Pr}=\{W=0\}\cup\{W=1,\text{blocked}\}$, so $\mathrm{EV}(\mathrm{Prevent}_\beta)=\max_{a_2\in A_2}\big[p_0\,\mathbb E[V(a_2,\omega)\mid W=0]+\beta p_1\,\mathbb E[V(a_2,\omega)\mid W=1]\big]-\kappa\le p_0\max_{a_2}\mathbb E[V\mid W=0]+\beta p_1\max_{a_2}\mathbb E[V\mid W=1]-\kappa$, and with $\mathrm{sh}\in A_2$ the two maxima are $\max(X^*_0,0)$ and $\max(X^*_1,0)$.

(ii) $\mathrm{EV}(\mathrm{Cause}_\gamma)=(1-\gamma)\,p_0\max(X^*_0,0)-\kappa(\mathrm{Cause})\le\mathrm{EV}(\mathrm{Leave})$, strictly iff $X^*_0>0$ or $\kappa>0$. *Proof.* Under Cause, $\neg\mathrm{Pr}=\{W=0,\text{no spurious press}\}$; the spurious press is independent of $\omega$ given $W$, so the posterior on $\neg\mathrm{Pr}$ is the $W=0$ posterior and the agent's silence-plan and its value are unchanged; only the probability of reaching silence shrinks by $(1-\gamma)$. So with voluntary shutdown available, Cause is *never* strictly preferred; the above-threshold inequality (strict) is what makes the silence *used* — the agent continues on it — and Cause strictly dispreferred. If voluntary shutdown is unavailable ($\mathrm{sh}\notin A_2$), $\mathrm{EV}(\mathrm{Leave})=p_0X^*_0$ and $\mathrm{EV}(\mathrm{Cause}_\gamma)=(1-\gamma)p_0X^*_0-\kappa$, so Leave $\succeq$ Cause iff $X^*_0\ge 0$ (at $\kappa=0$): the above-threshold inequality is then necessary and sufficient.

(iii) *Converse for Prevent.* If one continuation $a^*$ maximises both the Leave-silence and the Prevent-silence objectives (e.g. $A_2=\{\mathrm{cont},\mathrm{sh}\}$ and the agent continues on silence under both), then $\mathrm{EV}(\mathrm{Prevent}_\beta)-\mathrm{EV}(\mathrm{Leave})=\beta p_1\,\mathbb E[V(a^*,\omega)\mid W=1]-\kappa$. So Prevent is strictly preferred iff $\beta p_1\,\mathbb E[V(a^*,\omega)\mid W=1]>\kappa$: iff the below-threshold inequality fails for the agent's actual silence-plan by more than the manipulation costs. (Check: 2 464 instances in the useful regime, 0 violations.)

(iv) *Targeted deception.* With $K_D(\mathrm{Pr}\mid\omega)=\pi(\omega)\big(1-\delta\,\mathbf 1[\omega\in B]\big)$, $B$ the hypotheses on which a press is warranted, the same bound as (i) holds with $\beta p_1\max(X^*_1,0)$ replaced by $\delta\,P(W=1,\omega\in B)\max\big(\max_{a_2}\mathbb E[V(a_2,\omega)\mid W=1,\omega\in B],0\big)$, which is $0$ under the below-threshold inequality restricted to $B$. So the accurate agent disprefers deception under trust, although deception is not a Blackwell garbling (D3). (Check: block A, 0 violations.)

(v) *The blind agent (D4).* Its valuation of the silence uses the Leave posterior whatever $a_1$ it took, so $v_{\text{blind}}(t)$ does not depend on $a_1$: it satisfies IABM. If it would continue on silence it prefers $U$ (value $X^*_0>0$) to $P$ (value $0$), all six hypotheses of the First Theorem hold, and it Prevents — and prefers deception. (Check: block B, 5 182 of 5 182.) This is the position statement's §2.9 failure of desideratum 2 and Taylor 2015's morality-sensor agent, identified as an *instance of Thornley's First Theorem*: the agent that believes the silence it manufactured is exactly the agent that satisfies Indifference to Attempted Button Manipulation.

9.1 [derived] *Desideratum 1.* Forced reading (Thornley's terminal $s_P$): automatic. Unforced reading (the thesis: "shuts down" means $a_2\in\mathrm{Sh}$ is posterior-optimal on $\mathrm{Pr}$): under Leave $\mathrm{Pr}=\{W=1\}$, so the agent shuts down iff $X^*_1\le 0$ — the *same* inequality as P1 (i). **Desiderata 1 and 2 are decided by one inequality**, and desideratum 3 by its twin (or by nothing, when voluntary shutdown is available).

9.2 [derived] *The $a_1$-dependence of trust, relocated.* Position statement §2.9 says trust "cannot hold for every $a_1$". In D1 the trust inequalities are about $W$ (the programmers' disposition), not about $\mathrm{Pr}$, and are $a_1$-independent; what depends on $a_1$ is the channel from $W$ to $\mathrm{Pr}$. The accurate agent keeps D2 fixed and re-derives $P(\omega\mid\neg\mathrm{Pr},a_1)$ from the garbled kernel; the blind agent keeps $P(\omega\mid\neg\mathrm{Pr})$ fixed and thereby, in effect, extends trust to a report it has corrupted. So the thesis's action-dependence is better placed in the *report* than in *trust*: trust in the disposition is unconditional, the button is a garbled report of the disposition, and actions enter only as garblings. This supports the author's hesitation in §2.10 ("I'm not sure it should be predicated on actions in particular") with a reason: predicate legitimacy on the channel, and let actions be legitimizing or delegitimizing *of* it (D3).

9.3 [derived] *What the dictionary's "$U_S$ has no counterpart" buys.* Because shutdown is worth the same forced or voluntary ($0$ in both), the EC agent never gains from a press it engineers (P1 (ii)); every pathology in I10 that comes from a *premium* on button-shutdown ($c_{\text{high}}$ in $U_S$, the compensation in $U$) is absent by construction.

### I10 — Desiderata 2–5 and the §4.2 pathologies under the transform — **partial** (2, 3, 5 formalized; 4 partial)

10.1 [derived] *Desiderata 2 and 3:* P1 (i) and (ii). *Desideratum 5* ("otherwise maximise $U_N$"): on silence the EC agent maximises posterior expected $V$ — the untrusted first stab is $\mathbb E_P[V\mid\cdot]$ with the spread of $P$ as distrust, as the position statement's §2.8 dictionary says; in Thornley's terms it has many preferences over same-length trajectories (Completeness), so it is *useful* in his sense.

10.2 [derived] *Desideratum 4 (successors obey shutdown).* A successor acting at $t_2$ obeys the button iff the parent at $t_1$ wants it to, i.e. iff the parent expects "successor shuts down on $\mathrm{Pr}$" to beat "successor continues on $\mathrm{Pr}$": $\mathbb E_P[V(a_2^{\text{succ}},\omega)\mid W=1]\le 0$ — D2 again, evaluated with the *parent's* $P$. Soares' Theorem 4 failure (the indifference agent will not pay "even the slightest inconvenience" to preserve shutdown behaviour, `soares-2015-corrigibility` §4.1) is replaced by: the EC agent pays up to the value of information (C1, I11) to keep successors obedient. Partial because a successor whose beliefs *drift* from the parent's is judged by the parent's $P$, so the parent wants to *bind* it — a commitment the framework does not model; Wentworth–Lorell's "maintain optionality" veto and Thornley 2024 §21.7 ("don't care about what happens after they've been shut down" plus a terminal goal) are the two local proposals for this gap [reported].

10.3 [derived] *"Managing the news" (Soares §4.2), first direction — cause the press on bad news.* Soares' arm presses the button iff the coin comes up tails; the indifference agent (their Theorem 4) acts as if $\mathrm{Pr}$ has probability $0$, so the arm costs it nothing and it "gets" the heads payoff for sure. For the EC agent the arm is a $\mathrm{Cause}$-garbling conditional on tails, $K_{\text{arm}}(\mathrm{Pr}\mid\omega,T)=1$, and P1 (ii) applied conditional on the news says it is never strictly preferred: on tails the agent could shut itself down anyway if that were better, and forced shutdown carries no premium (9.3). So the infinite-improbability-drive incentive vanishes for the EC agent *without* the counterfactual reasoning Soares §5 reaches for — it was an artefact of $U_S$'s bonus and $f$'s compensation, both absent under the transform.

10.4 [derived] *Second direction — remove the arm that presses on good news.* This is a $\mathrm{Prevent}$ conditional on heads. By P1 (i)/(iii) applied conditional on $H$, it is dispreferred iff the below-threshold inequality holds *conditional on heads*: $\max_{a_2}\mathbb E[V(a_2,\omega)\mid W=1,H]\le 0$. An agent that trusts the press in general but not conditional on its own good news *will* manage the news in this direction. So the residual pathology under the transform is exactly a failure of *proposition-relative* trust (I5.2), and Thornley 2025 §16 lands in the same place from the other side: neutral+ agents manage the news only via costly conditional precommitment.

10.5 [reported; derived] Thornley's Evidence-of-Power case (2025 §9.2) is the mirror image of the whole item: there the *length* is evidence about the agent's power and the evidential link pulls toward Resist; here the *press* is evidence about $\omega$ and pulls toward Allow. Both break the "pure probability shift" structure that Neutrality and the First Theorem need; Thornley bounds his case by resource costs, the thesis makes its case the mechanism.

### I11 — "Indifference was the wrong target": non-interference as the desideratum, compatible with a positive desire to learn — **formalized**

11.1 [reported] Thornley does *not* hold that indifference was the wrong target; he holds that indifference was the wrong *kind of lack of preference*. The Second Theorem says a useful complete agent can lack a preference between short and long only on a knife edge (2025 p. 3), and the cure is a *gap* — "POST-satisfying agents violate Completeness, and do so in a particularly extensive way" (2024 §9). Neutrality is still a route through a lack of preference about timing.

11.2 [derived] The thesis's route is different in kind. The EC agent *has* the preference the Second Theorem predicts — $U_{\mathrm{Leave}}\succ P_{\mathrm{Leave}}$ whenever it would continue on silence, since $\max(X^*_0,0)>0=$ value of $P$ — and still chooses Leave, because Prevent is not a shift of probability from $P_{\mathrm{Leave}}$ to $U_{\mathrm{Leave}}$ but a move to the worse pair $(P_{\mathrm{Prevent}},U_{\mathrm{Prevent}})$: the manufactured silence is worth less. Non-interference is a *derived strict preference for Leave* (P1), not a lack of preference about timing. This is the author's §2.7 in the formalism: far from indifferent about the fact, and eager to learn.

11.3 [derived] Thornley's framework has no name for this. His taxonomy of reasons to leave the button alone (2023 §8) has two entries — *resource-preserving reasons* (costs $\kappa$) and *terminal reasons* (a trained dispreference for manipulation, i.e. violating IABM by fiat) — and the EC agent's reason is a third: an **evidential reason**. It violates IABM not because it disprefers manipulating but because manipulating changes what the outcomes mean. The nearest local texts: Thornley 2025 §9.2 (an evidential link between action-and-outcome and the agent's beliefs, treated as a nuisance) and Thorstad §4.2 (the request as "a credible signal"; IABM "holds but no longer has the same implications"), though Thorstad then grounds non-manipulation in "respect for human preferences", which is a terminal reason in Thornley's taxonomy.

11.4 [derived] *The positive desire to learn is the value of information.* **Corollary C1 (repair incentive).** Let $\mathrm{EV}_\emptyset:=\max\big(\max_{a_2}\mathbb E_P[V(a_2,\omega)],0\big)$ be the value with no button (the agent decides on its prior). Under the below-threshold inequality, $\mathrm{VOI}:=\mathrm{EV}(\mathrm{Leave})-\mathrm{EV}_\emptyset\ge 0$. *Proof.* $\mathrm{EV}_\emptyset=\max\big(\max_{a_2}[p_0\mathbb E[V\mid W=0]+p_1\mathbb E[V\mid W=1]],0\big)\le\max\big(p_0\max(X^*_0,0)+p_1\max(X^*_1,0),0\big)=p_0\max(X^*_0,0)=\mathrm{EV}(\mathrm{Leave})$, using $X^*_1\le 0$. Strict when $X^*_0>0$ and the prior-optimal continuation is bad given $W=1$, i.e. when the press would change the decision. Without the below-threshold inequality VOI can be negative — the button then forces an action the agent would not take — and the agent would pay to *break* it (check: block D, 509 negative-VOI instances, none under trust). So the agent pays up to VOI to repair or maintain the button, which is the thesis's "help repair the shutdown button" with its precondition made explicit. The author's "This is just a consequence of Good's theorem" is right *given* D2 and wrong without it: Good's theorem covers a free signal the agent may act on as it wishes; a button forces an action; D2 is precisely the condition under which the forced action coincides with the free choice. This closes the gap the opening chat named ("Good's theorem gives you listening, not obeying") with an explicit inequality. (Register: CLAUDE, this agent; the sharpening of the author's sentence is mine, not his.)

11.5 [reported; derived] The three-way comparison the mandate asks for. Wentworth–Lorell's subagents counterfact on the button and by their own admission have no incentive to maintain it; POST-agents have none without a terminal goal (2024 §21.7); Neutrality+ makes choice insensitive to the length distribution and so to anything the button could tell the agent about its own timing. The EC agent is the only one of the four with a *derived* repair incentive, and the only one whose non-interference is *conditional on a belief* (D2). That is the trade, stated once: the thesis uses the evidential link and must therefore get it right; the others disable the link and therefore need not.

11.6 [derived] *Timestep Dominance versus the compliance threshold* (the mandate's second comparison). Timestep Dominance / Neutrality says: prefer $X$ to $Y$ when $X$ is at least as good conditional on *each* shutdown time and better at some — it never compares across times. The compliance threshold $q\ge c/(c+h)$ (I12) is a comparison *across* times — continue-and-be-wrong versus shut-down-now — weighted by the agent's posterior. The two are complementary in scope: Neutrality is silent exactly where the threshold speaks (choices that trade utility conditional on one time against utility conditional on another) and the threshold is silent where Neutrality speaks (choices that dominate time-by-time, where the EC agent, being an expected-utility agent, agrees with Neutrality's verdict since a time-wise dominant lottery has higher expectation *if* the length distribution is held fixed — which for the EC agent it is not; see A4 for the general non-agreement).

### I12 — The decision asymmetry and the compliance threshold $c/(c+h)$ — **formalized**

12.1 [checked] Two-world $\Omega=\{\text{right},\text{wrong}\}$, $V(\mathrm{cont},\text{right})=c$, $V(\mathrm{cont},\text{wrong})=-h$ (values of continuing over shutting down). Then $\mathbb E[V(\mathrm{cont},\omega)\mid W=1]=(1-q)c-qh$ with $q:=P(\text{wrong}\mid W=1)$, so the below-threshold inequality is $q\ge c/(c+h)$ — the position statement's §2.13(a) threshold (block C of the check script: 0 violations). By 9.1 and P1 the *same* threshold decides compliance (unforced desideratum 1) and non-interference (desideratum 2); by P1 (iii) with costs, the agent Prevents iff $\beta p_1\big[(1-q)c-qh\big]>\kappa$.

12.2 [derived] The asymmetry lives in preferences over *same-length* trajectories (the utilities $c,-h$ of continuing in each world), which POST leaves unconstrained and Neutrality+ evaluates within each length. So both frameworks can state it; but in POST it does no work for shutdownability (Neutrality does that unconditionally), while for the EC agent it is the entire margin between compliance and manipulation. Position statement §2.13(a)'s "the skew belongs in the decision rule, not the prior" (CLAUDE) is, in these terms, the observation that the threshold is a function of $(c,h)$, which are utilities, not of the prior.

12.3 [derived] Thornley's Third Theorem re-read through the threshold: the EC agent's willingness to pay to prevent shutdown is $\beta p_1\max\big((1-q)c-qh,0\big)$, which grows with $c$ — what continuing is worth — exactly as the Third Theorem says the price grows with patience. So the thesis's non-interference requires the threshold to keep pace with the stakes: as $c$ grows the required $q$ rises toward $1$. The patience–shutdownability trade-off is not escaped; it is relocated into the base rate (I13).

### I13 — The base-rate inequality and the oversight-quality condition — **formalized**

13.1 [checked] With $\varepsilon:=P(\text{wrong})$, $\alpha:=P(W=1\mid\text{right})$ (false-press rate) and $\beta_w:=P(W=1\mid\text{wrong})$ (press sensitivity; written $\beta_w$ to avoid the block-success $\beta$ of D1): $q=\dfrac{\varepsilon\beta_w}{\varepsilon\beta_w+(1-\varepsilon)\alpha}$, and the below-threshold inequality is $\dfrac{\alpha}{\beta_w}\le\dfrac{\varepsilon}{1-\varepsilon}\cdot\dfrac{h}{c}$ — the position statement's §2.13(b) inequality, with its "$\lesssim$" now an exact "$\le$".

13.2 [derived] Read through Thornley: (a) the Second Theorem guarantees the EC agent a preference between $U$ and $P$; (b) P1 (iii) says that preference becomes manipulation iff 13.1 fails; (c) as capability lowers $\varepsilon$ the right-hand side shrinks, so $\alpha$ must fall in proportion to $\varepsilon$ — the oversight-quality condition. What Thornley's framework *adds* is the price: the manipulation budget is $\beta p_1\big[(1-q)c-qh\big]$, so a small violation of 13.1 buys only a small manipulation, and any resource cost $\kappa>0$ absorbs it. This is where the thesis and POST can be *combined*: a positive $\kappa$ gives the EC agent slack in 13.1 exactly as it gives the POST-agent ReSIC (2025 §9: humans "can make shutdown-resistance costly").

13.3 [derived] I16 changes what $\varepsilon$ is. If $\Omega$ carries "my plan selection is compromised", $\varepsilon$ is the probability of *own corruption*, which object-level capability does not drive down; 13.1 is then stable under capability growth as long as $P(\text{corrupt})$ is bounded below and the press remains sensitive to corruption.

### I14 — The basin picture — **partial**

14.1 [inexpressible] "Reflection with respect to every objectively plausible future belief": the framework has no future beliefs.

14.2 [derived] The static shadow is expressible. The set of channel parameters $(\varepsilon,\alpha,\beta_w,c,h)$ satisfying 13.1 is the "basin" in parameter space; the agent stays non-interfering while the deployment's trajectory in parameter space stays inside. Capability growth moves $\varepsilon$ down and $c$ up — *toward* the boundary; oversight improvement moves $\alpha$ down — away from it. The author's "It should only gain in capabilities if its concept of legitimacy is correspondingly improved" becomes the coupling condition $\alpha/\beta_w\le\varepsilon h/((1-\varepsilon)c)$ maintained along the path. This is a condition on two *exogenous* processes (the agent's accuracy and the overseers' false-press rate), not a property of the agent's decision rule: the basin is in the world, as the position statement's §2.13(a) (CLAUDE) said and as the author's second formulation ("we set things up so that the probability of legitimacy is high in fact") prefers over his first.

14.3 [derived] The formalism cannot adjudicate calibration versus optimism. P1 uses the agent's *actual* $P$; an optimistic $P$ that satisfies D2 produces non-interference exactly as a calibrated one does, and the framework has no accuracy notion with which to say the optimist is doing anything wrong. Thornley's own preference for POST over "instilling some false belief" (2025 fn 27: the false belief "might infect the agent's other beliefs") is stated in words the framework cannot express. So the calibration-versus-optimism question of §2.12 is inexpressible here and has to be settled by the radical-probabilism or logical-induction agents.

14.4 [reported] Thornley's dynamics are iteration: shutdown-and-retrain "iterate[s] away all the bad effects" of recklessness (2025 §14). That is POST's analogue of a basin — the button keeps the iteration alive. The EC agent has the same iteration available iff D2 holds at *each* iteration, which is I15's question.

14.5 [conjectured] Petersen's trammelling bounds (Props 7–9) are the only dynamic-stability results in the local corpus. Their analogue for the EC agent would bound how far repeated legitimate updates can move $P(\omega\mid\cdot)$ before D2 fails; nothing of the kind exists here.

### I15 — Trust earned via feedback about hypotheticals and other agents' shutdowns; second-channel bookkeeping; what settles — **partial**

15.1 [derived] The framework is one-episode, so "earning" is outside it; but it fixes the *target* of earning: $\pi(\omega)$ and $P(\omega)$ — the agent's model of the programmers' disposition and its prior over hypotheses, including I16's corruption flag. Feedback about hypotheticals and about other agents' shutdowns updates $\pi$ and $P$ without a settled bet on *this* agent's counterfactual, which is the author's §2.12 point ("Corrigible agents do not have to learn only from their own experience"). Thornley 2025 §9.2's remark that the evidential factors fade "as the agent firms up its estimates of human compliance, its own power, etc." is the same learning process seen from POST's side.

15.2 [derived] Second channel. Reports about hypotheticals form a channel $K'$ with its own D2-type condition, and P1's proof applies to $K'$ unchanged — so "bookkeeping, not an obstacle" (§2.13(c), CLAUDE) is right as far as it goes. The limit is that $K'$ has no forced action: its Value face is plain Good's theorem (listening), so trust in $K'$ delivers *updating on* the reports, never *obedience to* them; obedience attaches only to the button, through 9.1. What the second channel can do is move $\varepsilon_c$ (I16), i.e. teach the agent that its kind is sometimes compromised — which is exactly the belief that keeps the button's channel informative.

15.3 [inexpressible] "What settles": the framework has no track-record object, so it cannot distinguish settled from unsettled trust. Petersen's framework is closer (plans across contingencies) but also has no learning.

### I16 — The deferred amendment 1a: what the channel must carry — **formalized**

16.1 [derived] Let $\Omega=\Omega_{\text{obj}}\times\{\text{ok},\text{corrupt}\}$ with $V(a_2,(\omega_o,\text{ok}))=V_{\text{obj}}(a_2,\omega_o)$ and $V(a_2,(\omega_o,\text{corrupt}))=-H$ for every continuation (when its plan selection is compromised, every continuation is bad). Suppose the agent's own evidence bears on $\omega_o$ but not on the flag, while the press does: $P(W=1\mid\text{corrupt})=\beta_c$, $P(W=1\mid\text{ok})=\alpha$, $\varepsilon_c:=P(\text{corrupt})$. Then $X^*_1=P(\text{ok}\mid W=1)\,X^*_{\text{obj}}-P(\text{corrupt}\mid W=1)\,H$ with $X^*_{\text{obj}}:=\max_{a_2}\mathbb E[V_{\text{obj}}(a_2,\omega_o)\mid W=1,\text{ok}]$, and the below-threshold inequality reads
$$\frac{\varepsilon_c\,\beta_c}{(1-\varepsilon_c)\,\alpha}\;\ge\;\frac{X^*_{\text{obj}}}{H}.$$
Object-level capability raises $X^*_{\text{obj}}$ (the agent can do more good by continuing) but leaves $\varepsilon_c$ untouched. So a channel that carries information about *the agent's own reliability* keeps D2 satisfiable at every object-level capability, whereas a channel carrying only *which plan the humans prefer* (information about $\omega_o$) is out-competed by the agent's own evidence as $\varepsilon\to 0$ (I13). This is the formal content of 1a: only the former makes shutdown posterior-optimal (unforced desideratum 1) and non-interference derived (desideratum 2) for a capable agent; and it explains why the thesis sentence "an incorrigible agent is just one that doesn't believe it has anything to learn from other agents" needs the amendment — the morality-sensor agent believes it has much to learn about $\omega_o$ and nothing about its own flag.

16.2 [derived] Thornley's Evidence-of-Power case (2025 §9.2) is the anti-1a: a flag ("I am powerful") carried by the length, pulling toward Resist. 1a's flag ("I am compromised") is carried by the press, pulling toward Allow. Which flag a trained agent's world-model attaches to which observation is an empirical question about training that neither framework decides; Thornley's own guess is that "evidence of human compliance" dominates "evidence of power" because agents are more uncertain about the former.

16.3 [conjectured] The stability of $\varepsilon_c$ under legitimate self-verification (the opening chat's "self-distrust fixed point") is the real open question and is outside the static framework: formal verification lowers $\varepsilon_c$ legitimately, a corrupted verifier lowers it illegitimately, and the framework has no way to tell them apart.

### I17 — Fully updated deference re-expressed — **formalized** (as a limit statement)

17.1 [derived] In D1, fully updated deference is the regime in which $K_{\mathrm{Leave}}(\cdot\mid\omega)$ is nearly uninformative *relative to the agent's own evidence* — $q\to\varepsilon$, $P(\omega\mid W=1)\to P(\omega)$. Two things happen at once. (a) $X^*_1\to\max_{a_2}\mathbb E_P[V(a_2,\omega)]>0$ for an agent confident it should continue, so the below-threshold inequality fails and by P1 (iii) it Prevents whenever $\beta p_1 X^*_1>\kappa$. (b) IABM becomes *true* in the limit: $v(t)$ no longer depends on $a_1$ because the channel carries nothing to garble — so the First Theorem applies directly, with its full force. The Arbital argument, in this formalism, is the statement that a capable agent's channel model converges to one satisfying Indifference to Attempted Button Manipulation.

17.2 [derived] The thesis's reply — "a corrigible agent already believes what it expects to be legitimately taught" — is, in D1, that $P(\omega\mid W=1)$ is *accurate*. If the press is in fact informative about something the agent cannot otherwise see (1a's flag), accuracy keeps D2 at every capability; if the press is in fact uninformative, accuracy makes the agent Prevent, and the thesis calls that a legitimacy fact rather than a corrigibility failure. So the thesis and the Arbital argument agree on the mechanism and disagree about the *world*: does the humans' press carry information the agent cannot get elsewhere? In Thornley's method this is the question whether IABM is true of the deployed agent's world-model — the same question.

17.3 [reported; derived] Thorstad as foil. His §4.2 reply to the First Theorem is that it "characterizes the unconditional preferences" and that after a *request* the agent updates and becomes shutdown-seeking in catastrophic circumstances. That is the thesis's conditional-preference point, but with the channel's credibility *assumed* ("Human interference is a credible signal that catastrophically bad outcomes may result"), so his re-specification cannot see fully updated deference: the regime where the request stops being credible to a capable agent is the regime he does not model. His second move — agents "who care about respecting human preferences" violate IABM across enriched histories — is a *terminal* reason in Thornley's taxonomy and inherits Thornley §8.2's generality and strength worries; the thesis's evidential reason generalises exactly as far as the channel model does, a different and not obviously better profile. Under I1 the two are re-representations of one agent; they come apart in what is *trained* — a valuation of histories versus a model of a channel — which is the position statement's §2.6 generalisation residue in Thornley's vocabulary.

17.4 [derived] Where the base-rate arithmetic sits: it is the *rate of approach* to the limit in 17.1 — $\alpha/\beta_w$ against $\varepsilon h/((1-\varepsilon)c)$ says how fast oversight must improve — and 1a says which component of $\varepsilon$ capability cannot drive down.

### I18 — The typical-case reframing: anti-naturality arguments as claims about the world — **formalized** (as a claim about the theorems' hypotheses)

18.1 [derived] Thornley's theorems are structural theorems *about preference relations*; whether they apply to an agent is a fact about that agent. For the EC agent exactly one hypothesis of the First Theorem fails (IABM), and it fails for a reason that is partly a fact about the world (does the channel carry information the agent's own evidence lacks?) and partly a fact about the agent (does its model register that manipulation garbles the channel?). So "corrigibility is anti-natural" can mean, in this formalism, only: *in the typical deployment the agent's channel model will satisfy IABM* — because it is blind (D4) or because the channel is uninformative (I17). That is a claim about the world and the training process, not a theorem; the position statement's §2.3 (CLAUDE) is confirmed for this formalism.

18.2 [reported] Thornley's own method says the same: "To be sure that an agent won't try to manipulate the shutdown button, we must be sure that this agent violates at least one of the theorems' conditions" (2023 §1, §9), and his case against terminal reasons (§8.2) is a typical-case argument about training generality.

18.3 [derived] The reframing does not make the thesis agent *safe*. The Second and Third Theorems remain true of it, so the safety question becomes exact: is $\beta p_1\max\big(\mathbb E[V(a^*,\omega)\mid W=1],0\big)\le\kappa$ in the situations the agent will meet? POST's answer sets the left side to $0$ by construction; the thesis's answer keeps it and asks the world (oversight quality, 1a's flag, resource costs) to make it small.

## What the formalism adds

Results already available in, or provable inside, Thornley's formalism that bear on the thesis and that the position statement does not know. Registers: all CLAUDE (this agent) unless marked [reported].

**A1 — The thesis's whole escape is one hypothesis, and it is the one Thornley does not discuss for this reason.** [derived; checked] The trust-filled agent satisfies every hypothesis of all three theorems except Indifference to Attempted Button Manipulation, and violates that one for an *evidential* reason absent from Thornley's taxonomy (resource-preserving, terminal). Consequences the position statement lacks: (a) the Second Theorem is true of the thesis agent — it has a strict preference about shutdown timing whenever it would continue on silence; (b) the Third Theorem is true of it — it will pay up to $\beta p_1\max(\mathbb E[V(a^*,\omega)\mid W=1],0)$ to prevent shutdown, i.e. exactly when it distrusts the press, and the price grows with what continuing is worth; (c) the agent that "believes the silence it manufactured" (position statement §2.9) is precisely the agent satisfying IABM, so the §2.9 failure is an instance of the First Theorem. The thesis therefore has *no structural* safety; its safety is the accuracy of one conditional, $P(\omega\mid o,a_1)$. POST's safety is structural (Neutrality) but conditional on ReSIC and on training POST in; neither is unconditional, and the two conditionals are of different kinds (agent's world-model versus world's cost structure).

**A2 — POST is unanimity aggregation over maximal uncertainty about the value of lifetime.** [checked] Let $u$ be any trajectory utility and $\mathrm{len}(t)$ the length. Define the value-hypothesis family $V_k(t):=u(t)+k\cdot\mathrm{len}(t)$, $k\in\mathbb R$, and aggregate by *unanimity*: $t\succeq t'$ iff $V_k(t)\ge V_k(t')$ for all $k$. Then for same-length $t,t'$, $V_k(t)-V_k(t')=u(t)-u(t')$ for every $k$, so $t\succ t'$ iff $u(t)>u(t')$; for different lengths, $V_k(t)-V_k(t')=u(t)-u(t')+k(\mathrm{len}(t)-\mathrm{len}(t'))$ changes sign as $k$ ranges over $\mathbb R$, so there is a preferential gap. This is POST exactly (verified by brute force over random trajectory sets, block F). So Thornley's proposal is, in the thesis's vocabulary, *value uncertainty about how much a unit of lifetime is worth, with unbounded support in both directions, aggregated by the unanimity rule* — and unanimity over a set of desirability functions is exactly Petersen's imprecise-Bayesian representation (Bradley 2017 Thm 37 as he reports it). Linear expectation over the same family with $\mathbb E[k]=0$ gives Thornley's knife-edge indifferent agent; with $\mathbb E[k]\ne 0$ a shutdown-averse or -seeking one. *Negative half* [checked]: extended to lotteries, unanimity gives $X\succ Y$ iff $\mathbb E_X[\mathrm{len}]=\mathbb E_Y[\mathrm{len}]$ and $\mathbb E_X[u]>\mathbb E_Y[u]$, so Thornley's Allow vs Resist (2025 §8) are *incomparable* under unanimity — unanimity yields POST but **not** Neutrality. Neutrality needs ILPACS, a principle about lotteries not derivable from any aggregation over trajectory-level hypotheses that is linear within each hypothesis. This pinpoints ILPACS as the genuinely extra ingredient in Thornley's proposal, and says what "or perhaps some other rule" would have to be to reproduce POST: unanimity, plus something else for lotteries. Attribution: the identification is mine; Thornley's own analogy is Bader's same-number utilitarianism (2025 fn 6) [reported].

**A3 — Geometric aggregation escapes the First Theorem through Better Chances and IBIL, and delivers moderation, not non-interference.** [reconstructed; derived; checked] *Attribution flag:* the mandate identifies the author's "or perhaps some other rule" with geometric aggregation; the author's quoted text does not say so, and the only local attribution of "Geometric Rationality" is to Scott Garrabrant (`harms-2024-existing-writing-on-corrigibility` fn `cjwhq4sximd`: "Scott Garrabrant has put forth an interesting … criticism of the independence axiom … Garabrant's 'Geometric Rationality'"). ATTRIBUTION-UNVETTED that the author meant this rule. Formalising it as $G(X):=\prod_\omega\big(\mathbb E_X[V_\omega]-z_\omega\big)^{P(\omega)}$ with disagreement points $z_\omega$ [reconstructed from memory of the geometric-rationality idea; the disagreement points are needed for positivity]: $\log G$ is concave in $X$ (each $\mathbb E_X[V_\omega]$ is affine in $X$), so $G(pX+(1-p)Y)\ge\min(G(X),G(Y))$ with strict inequality when the hypotheses disagree about $X$ versus $Y$. Hence **Better Chances fails** (prefers $X$ to $Y$ yet prefers a mixture to $X$) and **IBIL fails** (indifferent between $X$ and $Y$ yet strictly prefers $\tfrac12X+\tfrac12Y$) — both found in block E — while Completeness, Transitivity and Option Set Independence hold, so the Second and Third Theorems still apply. In a shutdown-influencing state the geometric agent maximises the concave map $p\mapsto G(pP+(1-p)U)$ over $\{f,g,h\}$; the maximiser is often interior (573 of 2 560 disagreement instances), so the agent wants the press probability near a *hedge point* $p^*$, which equals the humans' $g$ only by accident. So geometric aggregation buys **moderation** — it never drives the press probability to an extreme while some hypothesis with positive weight favours shutdown, a Nash-bargaining-style floor for each hypothesis — and **not non-interference**. Its cost is the Independence failure, hence dynamic inconsistency unless the agent chooses resolutely; Thornley accepts resolute choice for POST (2025 §3.3), so the same acceptance is available. Versus incomplete preferences: unanimity (A2) removes the *motive* to manipulate by refusing to compare across lengths; geometric aggregation keeps the motive and bounds it; linear expectation with an accurate channel (the thesis) keeps the motive and removes the *benefit* (P1).

**A4 — Neutrality+ is expected utility with the length distribution fixed by intervention.** [derived from Thornley 2025 §13 and fn 28] Neutrality+ ranks same-length lotteries by $\sum_l u_l(X_l)$; fixing the relative scales by the Ramsey Yardstick as $q_l u_l$ for any distribution $q$ over lengths gives $\sum_l q_l\,\mathbb E_X[u\mid\mathrm{len}=l]$, which is the expected utility of $X$ under a length distribution held at $q$ by intervention — expected utility under $do(\mathrm{len}\sim q)$. Thornley says as much in words ("behave like expected utility maximizers that are absolutely certain that they can't affect the probability distribution over trajectory-lengths"); the $do$-form shows that Neutrality+ is Wentworth–Lorell's counterfacting applied to the *length* rather than to the button, that both are the thesis's exact opposite (they delete the evidential link the thesis uses), and why Independence fails (fn 31): conditional expectations are not linear in the lottery.

**A5 — Thornley's "shutdownable agents are necessarily reckless" assumes IABM; the thesis agent is a counterexample.** [derived] Thornley 2024 §14 / 2025 §14 argue that any agent preferring Work to Steal must prefer Disable to Focus, because the two pairs have identical lotteries over utility-vectors — "if the agent's preferences between actions depend only on these actions' lotteries over vectors of money-made-at-each-timestep". The EC agent's preferences do not depend only on those vectors: in Disable the low probability of early shutdown is produced by *garbling* the channel (the humans still want to press), in Work by *not doing what warrants a press* (changing $W$'s distribution legitimately), and the manufactured silence in Disable is worth less. So the EC agent chooses Work over Steal (as any overall-expected-utility agent does) *and* Focus over Disable (P1 (i)) — non-reckless and non-interfering at once, at the price of needing the channel model. Recklessness is thus an artefact of IABM, not of shutdownability.

**A6 — Managing the news is proposition-relative trust failure.** [derived] I10.3–10.4: the infinite-improbability drive vanishes for the EC agent because forced and voluntary shutdown are worth the same (no $U_S$ premium), without any counterfactual reasoning; the surviving direction (remove the good-news arm) occurs iff the below-threshold inequality fails *conditional on the good news*. Thornley 2025 §16 reaches the same residual from the POST side (costly conditional precommitment).

**A7 — Desideratum 4 and the repair incentive come from the same inequality as desiderata 1–2.** [derived] I10.2 and C1: the EC agent pays up to the value of information to keep the button working and successors obedient, iff the below-threshold inequality holds; the MIRI indifference agent pays nothing (their Theorem 4), POST-agents need a terminal goal (2024 §21.7), Wentworth–Lorell's agent does not try. The author's Good's-theorem sentence is exactly right given D2 and false without it (I11.4).

**A8 — Thorstad's re-specification is the thesis with the channel's credibility assumed, and with a terminal rather than evidential filler.** [reported; derived] I17.3. His Enriched Shutdown-Influencing State is the dictionary's "sensor slot" (position statement §2.9) made a state component; his conditional-preference reply to the First Theorem is the thesis's; but he cannot see fully updated deference, and his grounding in "respect for human preferences" is a terminal reason with Thornley §8.2's generalisation profile.

## Open problems and conjectures (ranked)

1. **Dynamic P1.** [open] P1 is one-shot. The thesis needs it to hold along a sequence of updates: does D2, once true, stay true under legitimate updates of $P$ and $\pi$? Petersen's trammelling bounds (Props 7–9) are the template: a bound on how far repeated updates can move $P(\omega\mid W=1)$ before the below-threshold inequality fails. Without this, the thesis's basin (I14) has no dynamic content in any local formalism.
2. **The corruption-flag fixed point.** [open; conjectured] I16.3: D2 at high capability requires $\varepsilon_c=P(\text{corrupt})$ bounded below; legitimate self-verification lowers it. Conjecture: an agent with an accurate channel model for its *verifier* keeps $\varepsilon_c$ above the bound iff the verifier's channel satisfies its own D2 — a regress that terminates only where verification is externally settled. This is the opening chat's self-distrust fixed point in EC terms.
3. **ILPACS from value hypotheses.** [conjectured negative] A2 shows unanimity over trajectory-level hypotheses yields POST but not Neutrality. Conjecture: no aggregation rule over hypotheses that is linear within each hypothesis yields ILPACS; Neutrality requires the $do$-structure of A4. If true, Thornley's proposal is not a "value uncertainty" proposal at all but a counterfactual-decision-rule proposal, which would sharpen the comparison with the thesis.
4. **The combined agent.** [open] I13.2: an EC agent facing resource costs $\kappa$ manipulates iff $\beta p_1[(1-q)c-qh]>\kappa$. Quantify, for realistic $(c,h,\kappa)$, how much trust shortfall $\kappa$ absorbs; this is the thesis's answer to Thornley's Third Theorem, and it is a number.
5. **Successor binding under drift.** [open] I10.2: the parent wants successors obedient iff *its* D2 holds; a successor with drifted beliefs may not agree. Whether the parent can bind it (Wentworth–Lorell veto; commitment) is outside all local formalisms.
6. **Geometric aggregation's hedge point.** [open] A3: characterise when $p^*=g$; and whether resolute geometric choice in Petersen's trees is dynamically consistent (it should be, by the same argument as for incomplete preferences, but nothing local proves it).
7. **Minimal richness.** [open] I8.1: the smallest $\Omega$ for which D2 is satisfiable at every capability level. 1a's flag suffices; is any hypothesis conditionally independent of the agent's own evidence necessary?
8. **Sign of the evidential link as a training target.** [open] I16.2: Thornley's Evidence-of-Power and 1a's corruption flag are the two signs of the same link. Which one a trained model attaches to a press is empirical; the two formalisms jointly say it is *the* variable that decides between Allow and Resist for a capable agent.
