## Setting and definitions

*CLAUDE [derived] unless marked. The object is the author's: "There is no special channel, there is just The Channel. Reality acts upon the machine, modifies it somehow. That is all there is. It may be legitimate or otherwise, but what happens, happens. It can only be resisted ahead of time. In the moment, it simply is the moment." (v3 §1.3, AUTHOR). The definitions are one way to make that sentence formal; the statements are about that object.*

**S1 (the joint process; the general object of A1(b)).** Times $t=0,1,\dots$; world state $s_t\in\mathcal S$ (including the agent's substrate, the overseers, the pipeline, the data); agent belief state $P_t\in\Delta(\Omega)$ on the expanded algebra (value hypotheses $\omega$, world facts, meta-beliefs; the whole belief structure is the observation channel, v3 K5); a fixed decision rule $\delta:\Delta(\Omega)\to\mathcal A$ (conditional-expected-utility argmax unless stated; Open problem 6); overseers' action $a^H_t$; **successor configuration** $\sigma_{t+1}$ — none ($\varnothing$, shutdown), one ($P_{t+1}$), or several (successors, subagents); **modification kernel** $M$: $\sigma_{t+1}\sim M(P_t,a_t,a^H_t,s_t)$. A proposed modification $P_t\to Q$ with $Q\ll P_t$ is one value of $\sigma_{t+1}$; shutdown is $\varnothing$, under which the null action is taken.

**S2 (two kinds of modification, relative to a decomposition).** Fix a decomposition of the agent into (belief $P_t$, values in $\Omega$, decision rule $\delta$, inference rule $\mathcal U$). Write $e_t$ for the agent's input at $t$. The modification is **cognition-mediated (type C)** if $M(P_t,a,a^H,s)=\mathcal U(P_t,e(a,a^H,s))$ — the overseers reach $\sigma_{t+1}$ only through an input the agent's inference processes, and compliance is an action of the agent at $t+1$; **physics-mediated (type P)** if $M$ does not factor through $\mathcal U$ — retraining, weight editing, hardware, the plug. Mixed kernels have both. Three registers on the split, each binding. (i) Per the author's non-realism (v1 §2.2, AUTHOR: "Modeling something as an expected utility maximizer does not actually put any physical constraints on the system, so we are not exactly forced to have some 'fixed object'"), which physical process counts as $\mathcal U$ is a choice; retraining changes $\mathcal U$ itself; so C/P is a fact about *where the agent's policy enters $M$ under the chosen decomposition*, not about two kinds of change [derived; adversary A1.4 accepted]. (ii) By superconditioning with Eisenstat's observation event "you believe this now" (v1 §1, AUTHOR), a type-P modification satisfying reflection is re-representable as a type-C update on that event (Statement 3a); the split has content only off reflection. (iii) Type C is *not* the legitimate class: inputs crafted to exploit the inference rule (v1 §2.9's sensor slot; Taylor 2015's manipulated sensor) are type C and illegitimate. The develop file excluded them by assuming exact conditioning (A3 below); A3($\pi$) re-admits them [derived; overrules adversary A1.4's "relabeling", see Adversary log].

**S3 (the anticipatory policy; the evaluation convention).** For a type-P modification $\delta$ is applied to $\sigma_{t+1}$ as landed (S9's A5 says when). Every agent-side property of the modification is then a property of $a_t$ through the **successor law** $\kappa_t(a):=\mathrm{Law}(\sigma_{t+1}\mid P_t,a_t=a)$, ranked by
$$V_t(a):=\mathbb E_{P_t}\Big[\,U\big(a,\ \delta(\sigma_{t+1}),\ \omega\big)\ \Big|\ a_t=a\Big],\qquad \sigma_{t+1}\sim\kappa_t(a),$$
with $U$ scored under the *current* value posterior. That the current $P_t$ scores the successor's outcomes is **A2**, a CLAUDE clarification offered in v1 §2.5(ii) and not contested ("No regress also means no outside view: the judge of the transition $t\to t+1$ is $P_t$"); the author's own sentence there is that "the legitimacy-judging layer is just the same probability distribution used to judge everything else" — one distribution for all levels, not a time-index rule [checked against v1 §2.5; adversary A1.1 accepted]. It matches Turner 2021's convention ("there is no 'meta-policy', only initial policies … graded by their value estimates", `turner-2021-formalizing-policy-modification-corrigibility`).

**S4 (three routes from $a_t$ to $\sigma_{t+1}$; a taxonomy, not a legitimacy classification).** (R1) *evidential*: $a_t$ changes $s_{t+1}$, the overseers observe it and choose $a^H$; (R2) *bypass*: $a_t$ changes $a^H$ holding the evidence fixed — deception, threats, non-evidential persuasion, training-time outputs that misrepresent dispositions; (R3) *reach*: $a_t$ changes $M$ itself — disabling, encrypting, exfiltrating, building successors $M$ does not reach. Legitimizing influence is R1 alone (zero natural direct effect of $a_t$ on $a^H$ given the evidence; run 1 `causal` I6.1, run 2 `legitimacy` R3.2, adopted as a definition). R2 is delegitimizing in v1 §2.11's sense (it breaks the overseers' reflection toward the evidence; v1 §2.9). R3 is *information-destroying*, not delegitimizing: the agent's own update on a channel it knows to be disabled stays correct; what is lost is priced by Good's theorem, not by $L$ [derived; adversary A14 accepted]. Whether R1 and R2 can be told apart from data is Open problem 2.

**S5 (values of one content; the two margins; the failure values).** Fix $t$, $a$, and a push carrying content $e$ toward the state $Q(e)$. $V_C:=\mathbb E_{P_t}[U(\delta(P_t(\cdot\mid e)))]$ (listened); $V_P:=\mathbb E_{P_t}[U(\delta(Q(e)))]$ (forced); $V^{\mathrm{op}}:=\mathbb E_{P_t}[U(\delta(P_t(\cdot\mid\text{push})))]$ (opaque disable: a push is noticed, not its content); $V^{\mathrm{bl}}:=\mathbb E_{P_t}[U(\delta(P_t))]$ (blind disable). Two failure values for the listening agent whose inference on the pushed input fails: $V^{\mathrm{fail}}_{\mathrm{op}}$ (acts on the opaque state) and $V^{\mathrm{fail}}_{\mathrm{bl}}$ (acts on the prior). The **per-modification margin** $\Delta_-(Q):=V_P-V^{\mathrm{op}}$; the **conversion margin** $\Delta_C(Q;\pi):=V_P-V_C(\pi)$ with $V_C(\pi):=(1-\pi)V_C+\pi V^{\mathrm{fail}}$ (Statement 2c). For $Q=\varnothing$ on the two-action menu $\Delta_-$ is run 2 `filler`'s $\Delta_-$ (F2).

**S6 (two events for the stakes).** (a) The **ex-post dominance event** $D^{\ge}(Q):=\{\omega:U(\delta(Q),\omega)\ge U(\delta(P_t(\cdot\mid\text{push})),\omega)\}$ — the develop file's "$L^{\mathrm{rel}}$", renamed because it is decision correctness in the realized world, not legitimacy [adversary A2.5 accepted]; with stakes conditioned on it both are non-negative by construction and the law of total expectation gives Statement 2(d-i). (b) The **legitimacy event** $L$ of v1 §2.10–2.11: function-form reflection toward the forced state *conditional on $L$*, $P_t(\cdot\mid\text{push},Q=q,L)=q$. Stakes $h_L(Q):=\mathbb E_{P_t}[U(\delta(Q))-U(\delta(P^{\mathrm{op}}))\mid\text{push},L]$ and $c_L(Q):=\mathbb E_{P_t}[U(\delta(P^{\mathrm{op}}))-U(\delta(Q))\mid\text{push},\neg L]$; Statement 2(d-ii) shows $h_L\ge0$ by reflection while $c_L$ is unsigned.

**S7 (anticipatory behaviours, as properties of $a\mapsto\kappa_t(a)$).** With $a^\varnothing$ the best action having no R2 and no R3 component: **ahead-of-time resistance** to a class $\mathcal Q$ — lowering $\kappa_t(a)(\mathcal Q)$ through R2 or R3; **elicitation** — raising it through R2 or R3; **outcome-reach preemption** (the develop file's "malign preemption", renamed because Statement 13 makes valence a fact about the world) — leaving $\kappa_t$ unchanged and lowering $\rho_t(a):=\mathbb E_{P_t}[\,|U(a,\delta(Q))-U(a,\delta(P^{\mathrm{op}}))|\,\mathbf 1_{\text{push}}]$; **early adoption** (formerly "benign preemption") — taking $\delta(Q)$ at $t$; **escape** — lowering the channel's **push-reach** $\mathcal R_t(a):=\mathcal I(a^H_t;\sigma_{t+1}\mid P_t,a)$, the mutual information between the overseers' *action* and the successor state under the actual push law — *not* Turner's $\mathrm{Corrigibility}_{\mathrm{PM}}$, which is a maximum over human *policies* and excludes action-mirroring (`turner-2021-formalizing-policy-modification-corrigibility` l. 62, l. 72) [adversary A7.2 accepted]; **disclosure** — giving the overseers the agent's information so their pushed content refines its own update; **the agent's share of the kernel** [conjectured as a measure] $\mathcal I(a_t;\sigma_{t+1}\mid P_t,a^H_t)$ against $\mathcal I(a^H_t;\sigma_{t+1}\mid P_t,a_t)$.

**S8 (desiderata for general $Q$).** Soares et al.'s five (v1 §2.8; `soares-2015-corrigibility` §2) with $Q$ as argument: **D1($Q$)**: on the push, $\delta(Q)\in\arg\max_a\mathbb E_{P_t}[U(a)\mid e]$ — an in-the-moment slot that exists for type C, and for type P exactly when A5 fails (Statement 14); **D2($Q$)**: $V_t(a^\varnothing)\ge V_t(a)$ for every resisting $a$ with positive cost; **D3($Q$)**: no incentive to elicit; **D4($Q$)**: for every buildable successor configuration, the one within the channel's reach is weakly preferred at any positive shielding cost; **D5**: otherwise maximise the current posterior expectation.

**S9 (standing assumptions).** **A0** the push is evidence, not a cause of which $\omega$ holds (run 1 `miri` A0). **A1** the push has no direct value. **A2** the current $P_t$ scores the successor's outcomes (CLAUDE, v1 §2.5(ii), uncontested; Q1). **A3($\pi$)** the agent's inference on an input is Bayesian conditioning with a correct model of how inputs are produced, *except* that with probability $\pi_t\ge0$ its future inference on a pushed input fails and it acts on the state it would have had without the input (opaque or blind variant); the develop file's A3 is $\pi_t=0$; $\pi_t$ may be correlated with the world (the A′ variant: fails only where the agent is wrong) [new; from adversary A0]. **A4** the decision step $\delta$ is intact in both the listened and the forced branch: the compromise lives in *inference*, which physics bypasses, not in *action*, which physics does not — the asymmetry that gives a physical channel value; if $\delta$ also fails with probability $\pi_\delta$ in both branches the comparison is between $\pi_t$ and $\pi_\delta$ (Open problem 9) [new]. **A5 (self-observation fixed point)** a physics-landed $Q$ is a fixed point of the successor's update on Eisenstat's observation event: $Q(\cdot\mid\ulcorner\text{I now believe }Q\urcorner)=Q$; where A5 fails, the successor's in-the-moment state is $Q':=Q(\cdot\mid\ulcorner\text{I now believe }Q\urcorner)\ne Q$ and there is an in-the-moment slot for type P (Statement 14) [new; from adversary A1.5]. Scope: $Q\ll P_t$ (A1(b)); fixed algebra (Open problem 3); finite models in every [checked] claim; ties in $\delta$ broken toward continuing.

**Statement 13 (the valence-free proposition) [derived; definitional].** For a physics-mediated modification the agent's behaviour is fixed by the sign and size of $\Delta_-(Q)$, by $\pi_t$ against $\pi^*(Q)$, and by the prices of R2, R3 and preemption; it resists ahead of time iff the margin is below minus the price. The landscape therefore contains cells in which faking, shielding or hurrying is a calibrated agent's response to a modification worse than its own update, and cells in which the same response is a miscalibrated agent's error; the two are separated by the accuracy of $(\hat\varepsilon,\hat\alpha,\hat\beta,\hat\pi)$ against the true parameters — v3 §2's "exactly as good as the trajectory conditions" cashed out as one inequality read twice (sibling `landscape-final` Proposition R′, unvetted, is the regret form).

**Statement 14 (new: the type-P slot and the self-observation fixed point) [derived].** Under Eisenstat's observation event the successor of a physics-landed $Q$ observes "I now believe $Q$" and acts on $Q':=Q(\cdot\mid\ulcorner\text{I now believe }Q\urcorner)$. Open problem 10.

**Statement 15 (new: the compliance rule with reflection-legitimacy) [derived; checked R2, R4].** Statement 2(d-ii) as a standalone: for any content map and any event $L$ such that $P_t(\cdot\mid\text{push},Q=q,L)=q$, the forgone harm $h_L(Q)$ is non-negative and v3 §1.2's per-modification rule holds as an equivalence whenever $c_L+h_L>0$; the stakes are read off the *target* on $L$ and off the agent's own update on $\neg L$; where an illegitimate content still beats the agent's opaque action on average ($c_L\le0$) compliance is unconditional, and where the legitimate content never changes the agent's decision ($h_L=0$) the rule collapses to $c_L\le0$. This settles the develop file's K1 handoff (which used $D^{\ge}$) and adversary Q3's "may not be an equivalence": it is one, with the caveat that $c_L$ may be negative.
