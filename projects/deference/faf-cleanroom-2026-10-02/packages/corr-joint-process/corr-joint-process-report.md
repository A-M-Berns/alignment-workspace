### T4 — Prop. 3′ (`Steering.lean`): sensor-improving steering is a strict Blackwell improvement the agent pays for; D1 can be bought

**Claim.** Lowering the false-press rate at fixed true-press rate, `(α, β) ↦ (α', β)` with `α' < α ≤ β`, makes `(α, β)` a strict garbling of `(α', β)`; the T-agent's two-option value is non-decreasing under it, strictly when it changes a decision; at `ε = 1/50` the agent overrides before and complies after.

**Lean.** (a) `inParallelogram_of_lower_alpha` (kind P): for `0 ≤ α' < α ≤ β ≤ 1` the channel `(λ₀, λ₁) = (β(α−α')/(β−α'), 1 − (α−α')(1−β)/(β−α'))` is stochastic and maps `(α', β)` to `(α, β)` — `tt-finite-frames`'s `InParallelogram α' β α β`; via `blackwellLE_binarySensor_iff` that is `BlackwellLE (binarySensor α β) (binarySensor α' β)` in `lit-ddb-frames`'s order (first argument the less informative, as the mandate warns). `not_inParallelogram_of_lower_alpha` (P): the reverse fails — any would-be channel satisfies `(1 − β)(α' − α) = (1 − p)(β − α) ≥ 0`, so `β < 1` forces `α' ≥ α`, and `β = 1` forces `p = 1` and again `α' ≥ α`. `blackwellLT_of_lower_alpha` (P) combines them: `BlackwellLT`. (b) `twoState_twoOptionValue_anti_alpha` (P): on the closed forms `V^free = max(u, 0) + max(K − u, 0)`, `K = (1−ε)c − εh` constant in `α`, `u` decreasing in `α`; the function `u ↦ max(u,0) + max(K−u,0)` is non-increasing below `max(0, K)` (`max_add_max_anti`), and a right-signed sensor keeps `u ≤ max(0, K)` (`uPress_le_max`, from T7(b)'s `u > 0 ⟹ v ≥ 0`). `twoState_twoOptionValue_lt_of_flip` (P): strict under `u' < u`, `u' < 0`, `v' > 0`. (c) `steering_flip`, `steering_gains`, `steering_package` (N+): `Δ₋(1/10, 3/5) = −1/20 < 0 < 71/2500 = Δ₋(1/50, 3/5)` at `ε = 1/50`; gains `71/2500`, `6/125` (`ε = 1/50`), `9/125`, `9/100` (`ε = 1/10`); the certificate numbers `(12/145, 137/145)`, `(1/10, 14/15)` and the reverse `λ₀ = −12/125`.

**Hypotheses.** All (a): the interval memberships, `α' < α ≤ β`, `c, h ≥ 0`, and for strictness the three decision-change clauses. No press-experiment definition and no bridge to `bayesValue` (that is `corr-osg-chai`'s D4/T15; the value monotonicity is proved directly, which is what the mandate allows).
