## Representation of record, and why

**Frames as two-time credence.** `π : W → ℝ` with `hπ : π ∈ stdSimplex ℝ W` (or the weaker `∀ w, 0 ≤ π w` where that suffices — most theorems) is `P_{t₁}`; `F : Frame W` (`lit-ddb-frames`) is `P_{t₂}` as a function of the world. Radical's INT restricted to the range on the support is DDB's immodesty at the candidates of `π`: `CandsIntrospective π F := ∀ ρ ∈ F.cands π, F.selfMass ρ = 1`. The all-rows form `F.Immodest` implies it (`candsIntrospective_of_immodest`). Every collapse theorem carries `CandsIntrospective` in its statement and a `Scope:` line.

**The new predicates (`Defs.lean`)**, all product-form, no division: `valCell F φ c := {w | mass (F.P w) φ = c}`; `estCell F X s := {w | E (F.P w) X = s}` (equal to `F.estEvent X s ∩ F.estEventLE X s`, `estCell_eq_inter`); `ValueReflects π F := ∀ φ c, mass π (φ ∩ valCell F φ c) = c * mass π (valCell F φ c)` (over **all** `c : ℝ`, vacuous at null cells; the ratio form with the guard `0 < mass π (valCell ..)` is `valueReflectsOn_iff_ratio`); `VarReflects π F := ∀ X s, ∑ w ∈ estCell F X s, π w * X w = s * mass π (estCell F X s)`; `EstimateMatching π F := ∀ X, ∑ w, π w * E (F.P w) X = E π X` (= stationarity `π = πP`, `estimateMatching_iff_stationary`). The mandate's dot-notation names (`F.valCell`) became plain functions (`valCell F`) because dot notation resolves in `Frame`'s own namespace, which this package does not own.

**Conditioning without division.** `restrict π L w := π w * ind L w`. Every product-form predicate is homogeneous of degree one in the deferrer: `reflects_smul_iff`, `totalTrust_smul_iff`, `value_smul_iff`, `valueReflects_smul_iff`, `varReflects_smul_iff`, `estimateMatching_smul_iff`, `candsIntrospective_smul_iff` (for `0 < c`), and `restrict_normalize_mem` puts `(mass π L)⁻¹ • restrict π L` in the simplex when `π(L) > 0`. So "`Φ` conditional on `L`" is `Φ (restrict π L) F`, every `lit-ddb-frames` theorem with the nonnegativity hypothesis applies verbatim, and the `stdSimplex` ones apply after normalizing. `LegitimizingTT π F L := TotalTrust (restrict π L) F` is ddb's strong sense; `LegitimizingVal π F φ L := ∀ c, mass π (φ ∩ L ∩ valCell F φ c) = c * mass π (L ∩ valCell F φ c)` is radical's value-form class (Lemma I5.2's linear characterization taken as the definition; Def I5.1's ratio form is `legitimizingVal_iff_ratio`). This is the mechanism `corr-legit-general` should reuse.

**Refinements and selections.** `fibre f w := {v | f v = f w}`; `condRow π f w` is `v ↦ 𝟙_fibre v · π v / π(fibre)` on a `π`-positive fibre and the point mass `δ_w` on a null fibre (the mandate's junk trap: the ratio would be `0/0`); `refineFrame π hπ f` has rows `condRow π f`; `selectFrame π hπ f s` has row `condRow π (f (s w)) w`; `RetainsGrounds f s := ∀ k w w', s w = k → f k w = f k w' → s w' = k`. Candidates never sit on null fibres (`mass_fibre_pos_of_pos`), so no headline depends on the `δ_w` convention; `refineFrame_immodest` covers the `δ_w` rows too.

**The bridge to `udt-supercondition`** (`Bridge.lean`). `pmfOfSimplex ρ hρ : PMF W` (`pmfOfReal` generalized from `Fin n` to any `Fintype`, as the mandate asks, rather than importing that package's witness file); `toAnticipation F P : AnticipationStructure P W` with atoms `{ρ // ρ ∈ univ.image F.P}` (a finite subtype, hence countable), `a w := ⟨F.P w, _⟩`, `κ ρ := pmfOfSimplex ρ`. The three iffs: `reflects_iff_calibrated`, `estimateMatching_iff_reflective`, `candsIntrospective_iff_introspective` (over `pmfOfSimplex π hπ`). The whole cost is the `ℝ ↔ ℝ≥0∞` conversion, concentrated in `scmass_pmfOfSimplex` (SC's mass of a finite event is `ofReal` of the frame mass) and `toAnticipation_priorPredictive`.

**Witness layer**: `Fin n` carriers with `![…]` vectors and rational weights, closed by `simp [Fin.sum_univ_*]` + `norm_num`; no `decide` beyond `Fin 8` finset-literal identities; no `native_decide`.
