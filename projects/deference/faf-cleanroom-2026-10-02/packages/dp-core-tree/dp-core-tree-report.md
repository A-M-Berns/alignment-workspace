## Modelling choices (disclosed once; each is also in the module docstring of `Defs.lean`)

1. **Worlds** a finite type `Ω`, **events** `Finset Ω`. v2 §0 says nothing turns on the pointless regime; every worked example is a finite atomic algebra.
2. **Points** a type `ι` with `DecidableEq`; actions `acts d` a finite nonempty type; action *events* `actEv : (d : ι) → acts d → Finset Ω` and observation `obs : ι → Finset Ω` are supplied to the theorems that read them (Definition 7). The subjective state `s_d` is **not** package data (no theorem reads it; `dp-calibration` attaches it). Individuation (Remark 2.2) is `DecidableEq ι`.
3. **Scalars** a linearly ordered field `K` (`[Field K] [LinearOrder K] [IsStrictOrderedRing K]`); `ℚ` for catalogue trees. Fidelity `variant: payoffs in a linearly ordered field` (v2 says `ℝ`; every source number is rational).
4. **Distributions** `FinDistr K α` (weights, `nonneg`, `sum_one`). A chance node has `n ≥ 1` children by type: `FinDistr K (Fin 0)` is uninhabited; no junk default.
5. **Definition 6′ is rendered operationally** (mandate route (a)): `leafLawSeed C env B ℓ` is a memoised walk carrying `env : (d : ι) → Option (acts d)`; at a `d`-node with `env d = some a'` the walk follows `a'` with weight one, with `env d = none` it draws `a ∼ C(d)` and records it. `leafLaw' C B := leafLawSeed C (fun _ => none) B`. SE-1(a), the product-mixture form, is therefore a *theorem* (`P`), not a definition. Definitions 6 and 6′ are separate definitions; there is no semantics flag in `leafLaw`.
6. **`occ d` is a `Finset B.Leaves`**, an event of the run space, not of `Ω`.
7. **Node addresses** `DecNode B` are unindexed (`Empty` / `Σ i, …` / `Option (Σ a, …)`) with `pt : DecNode B → ι`; the fiber over `d` is `fiber B d := univ.filter (pt · = d)`. A node-level policy is `(q : DecNode B) → FinDistr K (acts (pt B q))`, updated at one node by `Function.update` (cast-free). The only casts in the package are the `Fin n` / `acts d` index equalities inside `edgeOf`.
8. **`G_q` is derived, not primary.** `forcedBelow B p q a := ∑_{ℓ below q} μ_{p[q↦δ_a]}(ℓ) r(ℓ)` is the object entering the derivative (`= R_q · G_q(a)`); `gNode := forcedBelow / reachNode` exists for readers of v2 §8 but no theorem is stated through the division.
9. **"a.s." in Definition 7** is *for every leaf with `0 < μ_{B,C}(ℓ)`* (per-leaf), never "not identically zero on symbolic weights" (the cf toolkit's reading; see findings F2).
