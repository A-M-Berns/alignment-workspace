## Angle A, as built

The recursion is `dayRec DP ov n = dayStep DP ov n (fun i : Fin n => dayRec DP ov i)` (well-founded on the day), where a `DayRecord` carries the day's **core state** and its **overlaid quote table** with a `[0,1]` proof. `dayStep` reads the previous records into a table (`prevTable`, `0` on days `≥ n`), builds the firm from it (`dayStrat DP n prev = TradingFirmAt DP (prevTable n prev) n`), forms the **restricted past** (`dayPast`: for `k < n` the state with entries `(φ, prevTable k φ)` for `φ ∈ mentionedSet dayStrat`, via `restrictState`/`restrictedPast`; the range comes from the records' proofs, not from a clamp), runs FAF's `MarketMaker` against them (`dayCore`), and writes the overlaid quote: the core quote on the mentioned set, `ov.val n (cores < n) core φ` elsewhere. The definitions of record are read off: `coreState`, `overlayQuote`, `overlayHistory`, `corePast`, and `firmStrat DP ov n := TradingFirmAt DP (overlayQuote DP ov) n` — literally the day-`n` strategy of `tradingFirmTrader DP (overlayQuote DP ov)` (`firmStrat_eq`, `rfl`), so `trading_firm_dominance` applies to this firm. `dayStrat_eq_firmStrat` (by `TradingFirmAt_eq_of_eq_prefix`) and `coreState_eq` (`coreState n = MarketMaker (firmStrat n) (overlayRestrictedPast n) …`) tie the recursion to the definitions of record; the range-proof arguments made `coreState_eq` need `restrictedPast_congr` rather than a rewrite.

Why the record carries its range proof: the restricted past must be a list of `RationalBeliefState`s, whose `bounded` field needs `0 ≤ overlaid quote ≤ 1` on earlier days *inside the definition of the recursion* — a fact about `dayRec` not yet available while defining it. Carrying the proof as data (`DayRecord.range`) discharges it structurally; the mandate's trap (v) (no clamp) is respected.
