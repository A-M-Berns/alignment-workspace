- **Plumbing (L).** `WeakLearns.of_strongLearns`; `WeakLearns.of_fUpdateful (hg : Monotone g) (hfg : ∀ n, n ≤ g (f n))` — the exact gap to the converse: weak learning gives *some* state index per round, no monotone `g`.

- **The one fact everything turns on (C, grade (a)).** `actsAs_true_of_lt`: for `n < N`, `gain > 0`, `γ > 0`, acting as `Q_n` at round `k` on the coin-true realization *is* `π Ask_k = pay` (`udt-bli-tiling`'s `isOneStepChoice_pay`); `actsAs_true_of_le`: for `n ≥ N`, `0 < q`, `0 < c`, `γ > 0`, it *is* `π Ask_k = refuse` (`conditionOn_EU_eq_twoStepEU` + `isTwoStepChoice_refuse`).
