## E1 — The face theorem on a general finite grid (`core`, load-bearing) — done

- **Claim**: on an arbitrary finite carrier `G` of day-`(m+1)` tables and a day-`m` table `t`: (i) if some balance solution exists, a rational one exists whose support is exactly `faceGen G t`; (ii) `Q ∈ faceGen G t` iff `Q ∈ G` and `t + ε(t − πQ) ∈ conv π(G)` for some rational `ε > 0`; (iii) full support iff back-away everywhere; product-grid corollary: face = grid iff no `0/1` coordinate.
- **Lean** (`Face.lean`): `exists_fullSupport_faceGen (G) (t) (hne) : ∃ F, IsProbOn G F ∧ (meanOn G F).restrict = t ∧ ∀ Q, 0 < F Q ↔ Q ∈ faceGen G t` (Kind P); `faceGen_eq_hullFace (G) (t) (Q) : Q ∈ faceGen G t ↔ Q ∈ G ∧ ∃ ε : ℚ, 0 < ε ∧ t + ε • (t − Q.restrict) ∈ convexHull ℚ (↑(G.image Table.restrict) : Set (Table 𝒮 m))` (P); `faceGen_eq_iff_backaway` (C); `faceProd_eq_grid_iff (hd : 0 < d (m+1)) (t) : faceProd 𝒮 d m t = grid 𝒮 d (m+1) ↔ ∀ φ, t φ ≠ 0 ∧ t φ ≠ 1` (C); `faceConst`, `faceConst_prod` (C); vacuity guards `mem_faceGen_of_restrict_eq` (the point mass inhabits `hne` when `t = πQ` for a carrier `Q`) and `faceGen_eq_empty_of_not_mem_hull` (`hne` fails, and (i) is vacuous, when `t ∉ conv π(G)`); infrastructure `restrictₗ`, `meanOn_eq_sum_smul`, `meanOn_mem_convexHull`, `convexHull_image_restrict`, `restrict_meanOn_mem_convexHull`.
- **Route**: (i) as the mandate sketches — `faceWitness` chooses (classically, on the `Finset`) one solution per face point, `faceAverage` averages them with weight `1/card`; `IsProbOn` and the mean are affine; positivity at `Q` from its own witness; zero outside the face from `mem_faceGen_of_pos`. Rational throughout. (ii) forward: condition off `Q` when `F Q = c < 1` (`F' R := (F R − [R = Q]c)/(1−c)`, `ε := c/(1−c)`); when `c = 1` the solution is the point mass, `t = πQ`, `ε := 1`. Backward: `LinearMap.image_convexHull` moves the hull through `restrictₗ`, `Finset.mem_convexHull'` gives weights on `G` (no fiber pull-back needed), then mix with the point mass at `Q` in proportion `1 : ε`.
- **Hypotheses**: (a) throughout; `hne` is the one hypothesis and its scope is stated (both guards).
- **Cited, not re-proved**: `mem_faceGen_of_pos` (definitional containment, kind `T`) and `faceProd_eq_faceGen` (product case via the tent kernel, `bli-finite`).
- **Not attempted**: the identification of the back-away criterion with Mathlib's `intrinsicInterior ℚ (convexHull …)` (F-17).
- **Witness** (`Witnesses.lean`, N+): `G := coherentGrid extIndex extMesh.d 1 ∅ 2` (a non-product carrier, `d = 2`), `t := extT = (1/2, 1/2, 0)`. `ext1 = (1,0,0)` and `ext2 = (0,1,0)` are on `G` (all world mass on `p∧¬q`, resp. `¬p∧q`: `mem_coherentGrid_of_world`), the two-point law `extF` is a balance solution with mean `extT` (`extF_isProbOn`, `extF_mean`), so both are in the face; `face_witness` exhibits (i)'s full-support solution charging both, with `F extQ₀ = 0` (`bli-finite`'s `faceGen_coherentGrid_not_prod`) and face card ≥ 2.
