## F1 — Proposition 5's second clause is false as stated: the cumulative learner can overshoot `p̂` and fall into the basin of `0` (local error, blocking the clause; doc §5 Proposition 5)

**Source.** "If `δ < δ*`, so that the fixed points `0 < p̌ < p̂ < 1` exist, then `p̄_t → 0` when `p̄₀ < p̌` and `p̄_t → p̂` when `p̄₀ > p̌`. Since `p̌ = O(δ)`, the second case is generic."

**Refuted statement.** For every grip below `δ*` and every start `p̄₀ ∈ (p̌, p̂)`, the cumulative trajectory converges to `p̂`. **Witness** (`prop5_refuted_overshoot`, `Cumulative.lean`): at the doc's parameters with `δ = 139/5000` (just below `δ* ≈ 0.02786`, the three-fixed-point regime verified by `norm_num` on the discriminant and the vertex), the trajectory from `x₀ = 33/50` — which lies strictly between `p̌` and `p̂` (both bracketed by sign changes of the quadratic) — takes `b₀ = 1`, overshoots to `x₁ = 83/100 > p̂`, takes `b₁ = 0`, drops to `x₂ = 83/150 < p̌`, and from then on `b ≡ 0`, so `x_t = 83/(50(t+1)) → 0`. The trajectory never ties (`Q(x_t) ≠ 0` at every step), so no selection is involved.

**Diagnosis.** The doc's proof is "an Euler scheme … for the differential inclusion `dp̄/dt ∈ β(p̄) − p̄`", and the basins are read off the vector field. The discrete recursion's early steps (`1/2`, `1/3`, …) are not small: a start in `(p̌, p̂)` jumps halfway to `1` at the first step, and the drop from above `p̂` is by the factor `2/3`. When the two interior fixed points are close (grip near `δ*`) this crosses `p̌`. The ODE heuristic is right only when the basin is wide relative to the early step sizes.

**Repair** (`prop5_weak_between`, `Cumulative.lean`): with the gap condition `p̂ − p̌ > 1/3`, every non-tying trajectory from `x₀ ∈ (p̌, p̂)` converges to `p̂` (the joint invariant "`x_t > p̌` and `|x_t − p̂| ≤ 1/(t+1)`", `between_step`); from `x₀ > p̂` the same holds with gap `1/2` (`prop5_weak_above`, formalized in repair round 1: the first step halves `x₀`, which lands above `p̌` because `p̂ > p̌ + 1/2 > 2p̌`). At the doc's own numerics (`δ = 1/100`: `p̌ ≈ 0.167`, `p̂ ≈ 0.954`, gap `0.787`) the condition holds, so the doc's reported runs are correct and `prop5_weak_between_at_doc` proves the basin claim there hypothesis-free (every rational start in `(p̌, p̂)` converges to `p̂`); the *claim* is not. "Since `p̌ = O(δ)`, the second case is generic" is true in the small-grip limit (the gap tends to `1`), false near `δ*`. **Indexing robustness** (audit r1): the refutation does not depend on the package's indexing shift (F4). Under the doc's literal `p̄_{t+1} = p̄_t + (b_t − p̄_t)/(t+1)` from `t = 0`, the first step wipes the initial policy (`p̄₁ = b₀ = 1`) and `p̄₂ = ½ < p̌ ≈ 0.649` at `δ = 139/5000`, so the trajectory from any `p̄₀ ∈ (p̌, p̂)` converges to `0` under that reading too; the package's witness `33/50, 83/100, 83/150, …` is specific to its indexing, its conclusion is not.

## F6 — The doc's Remark on an independent anti-lesion ("`Δ(1)` would be of order `δ`"): exact under one precedence convention, `0` under the other; the conclusion holds under both (imprecision: the convention is unstated; doc §4 Remark; verified in Lean, repair round 1)

**Source.** "Were the anti-lesion independent of the lesion, forced abstention would carry the base rate of cancer, `Δ(1)` would be of order `δ`, vanishing with the lesion's grip, and smoking would be a fixed point for every sufficiently small `δ`."

**What the Lean says** (`Indep.lean`, the variant tree with the precedence convention as a parameter `aFirst`). When both forcings fire the doc does not say which wins (audit r1 raised this), and the exact value depends on it. (i) **Anti-lesion first** (`indep_aFirst_Delta_one`): `Δ(1) = 0` exactly, for every parameter set — forced abstention is then independent of the lesion and carries the population rate, and so does smoking (everyone else); this is the mandate's §3.6 reading ("both conditionals equal `ε_L`") and matches the Remark's own clause "forced abstention would carry the base rate of cancer". (ii) **Lesion first** (`indep_lFirst_Delta_one`): `Δ(1) = βρδL(1−ρ)(γ₁−γ₀)/((1−ρδL)(1−(1−ρδL)ρAδA))` exactly — positive when `γ₀ < γ₁` (`indep_lFirst_Delta_one_pos`) and of order `δL`, because forced abstention now happens only when the lesion did *not* fire, which is weak evidence against the lesion; the doc's "of order `δ`" is exactly right here. (iii) The Remark's conclusion holds under both (`indep_smoke_fixed_at_doc`): at the doc's parameters `Δ(1) < α`, so smoking is a fixed point (Claim 1.1's criterion), for every grip under (i) and for every `δ ∈ (0, 1/20]` under (ii), where `Δ(1) = 16δ/((1−δ/5)(1−(1−δ/5)δ/5))`.

**Grade.** Imprecision: the Remark's "forced abstention would carry the base rate" is the anti-first convention, under which "of order `δ`" undersells the exact `0`; its "of order `δ`" is the lesion-first convention, under which the base-rate clause is false (`P(k | abstain) = [ρ(1−δL)γ₁ + (1−ρ)γ₀]/(1−ρδL) ≠ ργ₁ + (1−ρ)γ₀`). The two clauses belong to different conventions; the conclusion — smoking becomes a fixed point for small `δ` — survives either way.
