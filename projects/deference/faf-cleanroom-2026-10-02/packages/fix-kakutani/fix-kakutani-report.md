## Target 2 (core) — `exists_approx_selection`

- Claim: `K` compact convex in a real normed space `E`, `F` with nonempty values in `K` on `K`, `ε > 0` ⟹ `∃ f, ContinuousOn f K ∧ MapsTo f K K ∧ ∀ x ∈ K, f x ∈ convexHull ℝ (⋃ x' ∈ K ∩ ball x ε, F x')`. Source: fixpoint-lit-094; infrastructure. Kind P. Status proved. Fidelity `stronger`: any real normed space (the mandate said generalizing is "free and preferable"), and `K.Nonempty` dropped because the construction never uses it.
- Construction, as in the mandate: `IsCompact.finite_cover_balls` gives a finite `t ⊆ K` of ball centres; one point `y c ∈ F c` is chosen per `c ∈ K` (`choose` on a `∀ c, ∃ y, c ∈ K → y ∈ F c` reformulation, so `y : E → E` is a total function); `ψ c x = max 0 (ε − dist x c)`, `S x = ∑ c ∈ t, ψ c x`, `w c x = ψ c x / S x`, `f x = ∑ c ∈ t, w c x • y c`. `S > 0` on `K` by `Finset.sum_pos'` (some centre is within `ε`); continuity on `K` by `ContinuousOn.div` with the positive denominator; `MapsTo` by `Convex.sum_mem`; the hull clause by restricting the sum to the positive-weight centres (`Finset.sum_filter_of_ne`, twice: once for the vectors, once for the weights) and `Convex.sum_mem` on `convex_convexHull`. Division by zero off `K` is harmless and nothing about `f` off `K` is claimed (mandate trap).
- Hypotheses: all (a). No convexity of values, no closed graph (as the mandate demands).

## Target 3 (core) — the limit step and the hemicontinuity bridge

- `mem_of_hasClosedGraphOn_of_tendsto_approx` (ClosedGraph.lean; P): `K` compact, `F` with closed graph over `K` and convex values in `K`, `xs n ∈ K`, `xs → x`, `ε → 0`, `xs n ∈ convexHull ℝ (⋃ x' ∈ K ∩ ball (xs n) (ε n), F x')` ⟹ `x ∈ F x`. Nonemptiness of values is *not* needed here (if `F x = ∅` the hypothesis on `xs` is unsatisfiable), so it is not assumed; it enters only through target 2. Proof: `x ∈ K` (closed); `F x` closed (`HasClosedGraphOn.isClosed_apply`); by `HasClosedGraphOn.exists_delta_subset_thickening` pick `δ` with `F x' ⊆ thickening (η/2) (F x)` for `x' ∈ K ∩ ball x δ`; for `n` with `ε n < δ/2` and `dist (xs n) x < min (δ/2) (η/2)`, the union lies in the thickening, so `xs n ∈ convexHull (thickening (η/2) (F x)) = thickening (η/2) (F x)` by `convexHull_min` and `Convex.thickening`; hence `dist x z < η` for some `z ∈ F x`; `Metric.mem_closure_iff` and closedness finish. (The mandate's thickening route; Carathéodory not needed.)
- `HasClosedGraphOn.exists_delta_subset_thickening` (L): the ε–δ upper hemicontinuity, read off Mathlib's `UpperHemicontinuousAt` (`thickening η (F x)` is an open neighbourhood of `F x`, so eventually a neighbourhood of `F x'`; `Metric.eventually_nhds_iff`).
- The bridge (both directions, L): `HasClosedGraphOn.upperHemicontinuousOn` (first-countable spaces; closed graph over `K`, values in a compact `L` ⟹ `UpperHemicontinuousOn F K`, via `UpperHemicontinuousAt.of_sequences` on `restrictTo F K`, the `∅`-extension) and `HasClosedGraphOn.of_upperHemicontinuousOn` (regular codomain; upper hemicontinuous on a closed `K` with closed values ⟹ closed graph, via `UpperHemicontinuousAt.mem_of_tendsto` along the filter `𝓝 (x, y)`). The hinge is `upperHemicontinuousWithinAt_iff_restrictTo`: at a point of `K`, "upper hemicontinuous within `K`" is "upper hemicontinuous everywhere" for the `∅`-extension, because `𝓝ˢ ∅ = ⊥` makes the off-`K` condition vacuous. This makes `HasClosedGraphOn` demonstrably the classical notion (STANDARDS §3 "definitions mean what the prose word means"); see finding F1 on Mathlib having this file.
- Also in Defs: `hasClosedGraphOn_iff_seq` (first-countable; the iff with conclusion `x ∈ K ∧ y ∈ F x`) and `hasClosedGraphOn_iff_seq_of_isClosed` (closed `K`; conclusion `y ∈ F x`), `HasClosedGraphOn.mem_of_tendsto` (any filter), `HasClosedGraphOn.isClosed_apply`. The definition is stated for `F : α → Set β` between two topological spaces (the mandate's `E → Set E` is the case `α = β`; nothing is lost and the two-type form is what the graph-transport in `kakutani_findim` wants).

## Target 4 (core) — transports
