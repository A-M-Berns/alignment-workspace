## 2. Blocking issues

### B1. `decay_scheme_is_half_rule` (`Decay.lean:204`; also `decay_scheme_of_halvingCondition`, `Decay.lean:230`) and the ledger row 4c(ii): `Fidelity: exact` misstates — the halving hypotheses are assumed at every index of the prefix, so the source's `r` is forced and the source's regime is not covered

- **What the source says.** PDF 06 p. 2 (re-read): "If we know `P_n(∀mϕ(m))`, but not all the `P_n(ϕ(1) ∧ … ∧ ϕ(m))`, we can settle on a 'max-entropy-ish' distribution for them that respects all constraints we have. For example, **if we only have information up to `ϕ(m)`**, we can set `r := P_n(ϕ(1) ∧ … ∧ ϕ(m)) − P_n(∀mϕ(m)) ≥ 0`, and define `P_n(ϕ(1) ∧ … ∧ ϕ(k)) := P_n(∀mϕ(m)) + r/2^{k−m}` (1) for `k ≥ m`." The scheme's content is that the base (`Q_n`'s information) fixes the first `m` instances with whatever masses it has, and the decay fills in beyond `m`; `r` is an input read off the base. The mandate's 4c(ii) reads it the same way: "eq. (1) … *is* `sotoRule` when `U` is enumerated before the instances beyond `m` and no other universal touches them: prove … under `HalvingCondition` from level `m` on."
- **What the Lean says.** `decay_scheme_is_half_rule` takes `hk : StrictMono k`, `hkB : B ≤ k 0`, `hinst : ∀ n, S.inst u (i n) = Formula.atom (e (k n))` and `hhalf : ∀ n (w : FiniteWorld (k n)), …` — for **every** `n`, the first `m` included — and concludes, for `m ≤ n`, `P(instPrefix (fun j => S.inst u (i j)) n) = P(U) + (P(instPrefix … m) − P(U)) / 2^(n−m)`. So every instance in the prefix sits beyond the base (`k j ≥ k 0 ≥ B`) at a level where the agnostic clause fires on every consistent `¬U`-conjunction. Under these hypotheses `decay_scheme_pow` at `m` already gives `P(instPrefix … m) = P(U) + (½)^m · P(¬U)`, i.e. `r = (½)^m · P(¬U)` — machine-checked as `decay_r_forced` (`audit-r3-probes/DecayRForced.lean`, elaborates with no messages; it is `decay_scheme_pow` at `m` plus `ring`). The proof of `decay_scheme_is_half_rule` itself is `rw [decay_scheme_pow … n, decay_scheme_pow … m]; … ring`: the `(m, n)` display is the `(0, n)` identity divided by the `(0, m)` identity, and the `m` carries no content.
- **Why it matters for fidelity.** The theorem is true and sorry-free, but it proves the display only where the base knows nothing about the instances (the base lies entirely below `k 0`, which is below the first instance of the prefix). The source's case — base-informed `φ(1..m)` with a free `r ≥ 0`, decay beyond — is exactly the case the Lean's hypotheses exclude. F-4's headline ("eq. (1) is the ½-rule in disguise … now a theorem") and the name `decay_scheme_is_half_rule` are read as the source's claim; the docstring's "with `r = P(⋀_{j<m}) − P(U) = (½)^m · P(¬U)`" and the ledger's Claim cell do let a careful reader see that `r` is forced, but both Fidelity cells say `exact`, and [STANDARDS](../../STANDARDS.md) §3 asks the name and docstring to say when the Lean is weaker than the note's claim. A second, disclosed-elsewhere restriction belongs in the same label: the identity is along the index map's subsequence `i` (the Claim cell and F-4 say so; the Fidelity cell does not).
- **Fix I would accept**, either: **(i) generalize** (small; the ingredients exist): state the halving step from an arbitrary known prefix — for a sentence `E` with `level e E ≤ k 0` (in the intended use, the base's conjunction of the first `m` instances), with `negUnivPrefix` started at `∼U ⋏ E` instead of `∼U`, `negUnivPrefix_val_succ` goes through unchanged (its only uses of the start sentence are `negUnivPrefix_imp_neg` and `level_negUnivPrefix`, both of which hold for `∼U ⋏ E`), giving `P(¬U ∧ E ∧ ⋀_{j<n} a_j) = (½)^n · P(¬U ∧ E)`; `extrapolateVal_univ_and_instPrefix` with `U ⋏ E` in place of `U` gives `P(U ∧ E ∧ ⋀_{j<n} a_j) = P(U ∧ E)`; hence `P(E ∧ ⋀_{j<n} a_j) = P(U ∧ E) + (½)^n · (P(E) − P(U ∧ E))`, and when `E` is itself a conjunction of instances of `u`, `P(U ∧ E) = P(U)` by the same lemma — which is eq. (1) with the source's `r = P(E) − P(U)` and the halving clause needed only beyond `m`; keep the present theorem as the `E = ⊤` corollary; or **(ii) relabel**: `Fidelity: weaker: the halving hypotheses are assumed at every index of the prefix (the base carries no information about the instances), so the source's r is forced to (½)^m·P(¬U) and the m-parameter is idle; along the index map's subsequence; the source's base-informed case is not covered` — in the docstrings of `decay_scheme_is_half_rule` and `decay_scheme_of_halvingCondition`, in the ledger row's Fidelity cell, and in F-4's "now a theorem" sentence (say "in the no-base-information regime").
