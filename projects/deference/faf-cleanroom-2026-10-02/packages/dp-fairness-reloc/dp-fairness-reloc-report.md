## Modelling choices (disclosed once)

1. **Labelled isomorphism `≅` is an inductive `Prop`** (`LabIso`): leaves iff equal `(ω, r)`; chance nodes iff the same arity `n` and a permutation `σ : Equiv.Perm (Fin n)` with `β' (σ i) = β i` and `child i ≅ child' (σ i)`; decision nodes iff the same point and children `≅` action by action. Chance-child order is not a label; a probability-one chance node does **not** collapse (that would be `≃_Δ`), so `≅` preserves node count (`LabIso.size_eq`), which is what FR-1(i) needs. Term equality is never used in a definition of record; witnesses use `LabIso.refl`/`LabIso.of_eq` only where the trees are literally equal.
2. **The continuation `(λ, r)`-law is a finitely supported function** `contLaw C T : Ω × K →₀ K := ∑_ℓ single (λ(ℓ), r(ℓ)) μ_{T,C}(ℓ)`. This makes "`V` is a functional of `contLaw`" literal (`value_eq_contLaw_sum`, `nu_eq_contLaw_sum`, `sum_leafLaw_mul_eq_contLaw_sum` for any `g : Ω × K → K`) with no finite-support bookkeeping. Payoffs live in the linearly ordered field `K` inherited from `dp-core-tree`.
3. **Fairness grades are `FairWrt E`** with `E : ι → Tree → Tree → Prop` read on the subtrees `subtreeAt B q`, `q ∈ fiber B d` (`dp-core-tree`'s fiber). `StronglyFair := FairWrt (fun _ => LabIso)`; `LawFair := FairWrt (∀ C, contLaw C · = contLaw C ·)`; `ValueFair := FairWrt (∀ C a, value (C[d ↦ a]) · = value (C[d ↦ a]) ·)` — GR-9's `D_V = 0` in act-value form (the mandate's `Q(q, C, a)`), not "equal values under every `C`" (which differs under nesting).
4. **`NestedFiber B d := ∃ q ∈ fiber B d, ¬ IsMinimal B q`** (some member has a same-point ancestor), read off `dp-core-tree`'s `ancestorPts`; `Pruned B := ∀ ℓ, Positive B ℓ`.
5. **Relocation types**: points `ι ⊕ Unit` (`inl d` survivors, `inr ()` the root point `d̂`); actions `actsR acts U` (`@[reducible]`, so `actsR (inl d)` unfolds to `acts d` in instance-transparency checks); worlds `RW Ω acts U := Ω × ((d : ↥U) → acts d)` — the `pol` coordinates are a **fresh product factor by construction** (the cf toolkit's `pol_<point>` collision cannot arise). `FinDistr.pi` is the product law; `lift C` is `C` on survivors and the product at `d̂` (never a correlated law).
6. **`resolve` is built together with its leaf map and node map** as one structural recursion `resolveAux : (B) → (T : Tree) × ((T.Leaves → B.Leaves) × (T.DecNode → B.DecNode))`, with `resolveW := ·.1`, `leafMapW := ·.2.1`, `nodeMapW := ·.2.2`, `resolve σ B := resolveW (fun ω => (ω, σ)) σ B` (stamping = a world map), `relocRoot U B := decision (inr ()) (fun σ => resolve σ B)`, `leafMap ⟨σ, ℓ'⟩ := leafMapW … ℓ'`. This is cast-free; the price is that proofs unfold to the projections and rewrite the `dite` on `d ∈ U` (`resolveAux_decision`, a `rfl` equation lemma). Root site only; the LCA site (T12) was not attempted.
7. **Evented chance is structural**: `EventedChance B` says leaf worlds below distinct children of any chance node are distinct — equivalent to the existence of pairwise-disjoint edge events entailed by the leaf worlds (the world sets below the edges). Recording is `dp-core-tree`'s Definition 7 (per leaf of positive mass); "a.s." is `Pruned`.
8. **Concrete witnesses are over `ℚ`**, rebuilt from the sources' one-line descriptions; GR-9's trees have `Unit` worlds (the sources say `O_d = ⊤` and example (3) is the repaired one with no `side` coordinate), so the laws are payoff laws.

## What resisted, and why

- **Dependent leaf types.** `Tree.Leaves` and `Tree.DecNode` are non-reducible type families, so `rw`/`simp` on goals containing sigma-typed leaves fail at instance transparency. The package's answer is `resolveAux` as one recursion returning the tree with its leaf and node maps (no casts) and per-leaf statements assembled by a generic preimage-sum lemma (`sum_preimage_eq`), never `ite` on sigma equalities.
- **Concrete-tree arithmetic.** `decide` cannot evaluate `ℚ` (`Rat.add` is irreducible); witnesses are computed by the `sum_leaves_*`/`Tree.sum_leaves_leaf` rewrite chain and `norm_num`, or by `decide` where only `ℕ`/`Bool` are involved (recording, singleton fibers).
- **T8's coupling algebra** (resolved in repair round 1). The composition coupling is one generic lemma over `Fintype` indices (`compCoupling_sum_right/left`, `compCoupling_ne_zero`) reused for `≃` (indices `Fin n`) and `≃_Δ` (indices the support subtypes); the product coupling needed the total-function presentation of flat couplings (`FlatCoupling`), because the children's couplings live on different support subtypes and must be summed with weights.
- **EQ-3** (open, theorem form `bisimΔ_of_trEq_of_fairBisimΔ`). Round 1's attempt record said the (decision, decision) step stalls at `C(d)(a) = 0` and would need a perturbation argument.
