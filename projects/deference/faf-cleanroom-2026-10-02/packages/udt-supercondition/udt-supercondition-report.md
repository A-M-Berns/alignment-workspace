## Representation of record, and why

Point-set over countable types with `PMF` (Mathlib `Probability.ProbabilityMassFunction`), not `MeasureTheory.Measure`. Reasons: SC §0.10's standing assumption is countable discrete, and §0.2 says every σ-algebra homomorphism is then induced by a point function, so `q : Ω → Q` with pushforward `P.map q` is an *exact* rendering (fidelity `exact`, recorded in the `Mass` module docstring). `PMF` values are `ℝ≥0∞`, sums are `tsum` with no summability side conditions, and `PMF.map`/`bind`/`normalize` give the pushforward, the prior-predictive (`(P.map a).bind κ` is literally SC §3.3's displayed sum, `PMF.bind_apply`) and conditioning with no measurability bookkeeping. Every division in the package sits behind a positivity hypothesis: the single helper `condOn P s (h : 0 < mass P s)` (via `PMF.normalize`) is the only place an event mass is inverted, and every calibration-type predicate is stated multiplicatively (`P(ā ∩ q̄) = κ_ā(q̄) · P(ā)`), vacuous at null atoms exactly as SC's "for atoms with P(ā) > 0". Absolute continuity with bounded density is `BoundedDensity Q P B := ∀ x, Q x ≤ B * P x` with `B ≠ ⊤` at use sites (no `rnDeriv`, no `⨆`). A `toMeasure` bridge for the entropy file was not needed because the entropy file was not attempted (stretch, see T19).

Carriers are `Type` (universe 0) throughout because `CondModel.L : Type` and the constructions take `L = Ω × Ω′ × Bool` etc.; `Countable` is a structure field of `CondModel`, `CommonInfo`, `AnticipationStructure` (SC §0.10) but no proof uses it.

### The one construction

`Thinning.lean`: `thin M w hw : PMF (X × Bool)` with `(x, true) ↦ w x · M x`, `(x, false) ↦ (1 − w x) · M x`; `thin_map_fst` (first marginal is `M`), `mass_thin_evTrue` (evidence mass `∑ w · M`), `thin_condOn_map` (the conditional pushforward along `g ∘ fst` is `normalize (w · M)` restricted to fibres). On top of it `steerWeight M g Q B x = Q (g x) / (B · (M.map g) (g x))` (explicitly `0` on null fibres, not `0/0`) and `steerThin_condOn_map`: the conditional pushforward along `g ∘ fst` is exactly `Q`. Thm 2.4 (⇐), Remark 2.5, Thm 4.5 and Prop 4.7 are all `steerThin` on a coupling `couple P f : PMF (X × Y)`, `(x, y) ↦ P x · f x y`. SC's residual measure `C″ = (B·C − C′)/(B − 1)` and the `B = 1` division (audit finding 7) do not occur: when `B = 1` the `false` layer has mass `0`.

One representational point the mandate did not anticipate: SC's compatibility `c ∘ p = c′ ∘ p′` is an *exact* function equality on `L`, so the carrier of a compatible model must contain no off-diagonal point. The constructions of T4 and T10 therefore live on the subtype `diagSet ci = {(x, x′) | c x = c′ x′}` (`toSubtype`, `mass_toSubtype_preimage`), not on `Ω × Ω′`; compatibility is then `funext fun l => l.1.property`. The a.e. variant `CompatibleAE` is defined and the obstruction is proved for it too (`compatibleAE_range_subset`).
