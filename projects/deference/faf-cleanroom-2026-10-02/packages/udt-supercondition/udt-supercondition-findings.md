## F1 — SC Thm 2.4 (⇐) is false as stated: the quotient obstruction (local error, blocking for §2.5's iff; dp-cf-105 confirmed)

- (i) SC §2.5, Theorem 2.4: "A `Ĉ`-compatible conditioning model for `(P̂, P̂′)` exists if and only if `C′ ≪ C` and `‖dC′/dC‖_∞ < ∞`."
- (ii) Reading formalized: point-set over countable types (SC §0.2), `Compatible m ci := c ∘ p = c′ ∘ p′` as functions on `L` (SC Def 2.3, "as random variables"), translations `c`, `c′` arbitrary functions — a σ-algebra homomorphism may send a nonempty event to `⊥` (SC §0.2 says nothing against it, and the decision-problems run's deductive quotient AN-21 is such a `c′`). Whether the author tacitly meant a surjective `c′` is ATTRIBUTION-UNVETTED. Refutation: `compatible_range_subset` (a compatible model forces `C(y) = 0` for every `y ∉ range c′`; the a.e. variant `compatibleAE_range_subset` is the same obstruction, as AN-22′ notes) and the `Fin` instance `thm24_sufficiency_refuted` (`P` uniform on `Fin 2`, `P′ = δ` on `Fin 1`, `c = id`, `c′ ≡ 0`: `C′ = δ₀ ≤ 2 · C`, no compatible model).
- (iii) Surviving neighbour: `commonInfo_condModel_iff` — a compatible model exists iff `C′` has bounded density w.r.t. `C` *and* `∀ y, 0 < C(y) → y ∈ range c′`. The added conjunct is exactly the missing hypothesis dp-cf-105 names ("`c′(c̄) = ⊥ ⟹ C(c̄) = 0`"). The (⇒) direction and the bound `1/L(l̄)` are as SC states (`compatible_boundedDensity`).
- Also verified: the sufficiency construction's residual measure `C″ = (B·C − C′)/(B − 1)` (audit finding 7's `B = 1` division) is unnecessary; the thinning construction (`diagModel`) has no such division, and the `false` layer simply has mass `0` when `B = 1`. The audit's "empty fibres" edge case *is* the obstruction of (ii), not an edge case: SC's `P′(p̄′ | c′ = c̄)` is undefined exactly when the fibre is empty, and then no model exists at all.
- bli-soto-b-054: the journal draft breaks off at "what structure on `(P̂, P̂′)` makes existence non-trivial"; SC is that draft's continuation (inferred from content — ATTRIBUTION-UNVETTED as to what was meant to come next), and the answer is: a common-information structure, with `commonInfo_condModel_iff`'s right-hand side as the exact condition.

## F2 — SC Prop 4.7 is false as stated and needs Ĉ-calibration (local error in §4.5, blocking for the §8.1 hierarchy's level 2′)

- (i) SC §4.5, Proposition 4.7: "The combined constraint still does not restrict achievable posteriors beyond `C′ ≪ C` with bounded density (the common-information D-Z condition) and `P′ ≪ Q₀` with bounded density (the calibration D-Z condition)." Proof sketch: "By supporting `L` on the 'diagonal' … while using the anticipation-calibrated conditionals … both constraints are satisfied simultaneously. … the tighter of the two determines the achievable set."
- (ii) Reading formalized: `Compatible` (exact) and `CMCalibrated` (SC Def 4.1, multiplicative), over an anticipation structure targeting `Ω′` with a common-information structure; the two D–Z conditions as `BoundedDensity`. The mandate writer's suspicion (udt-rep-060's flag) was verified: a `Ĉ`-compatible calibrated model forces the anticipation to be `Ĉ`-calibrated (SC Def 5.1) — `BridgeCalibrated.of_compatible_cmCalibrated` — because the diagonal support forces `κ_{a x}` to live on the `c′`-fibre over `c x`. Hence `not_compatible_calibrated_of_not_bridgeCalibrated`: whenever Ĉ-calibration fails, no compatible calibrated model exists, whatever the D–Z conditions say. `Fin` instance `prop47_refuted` (`Ω = Fin 2`, `Ω′ = Bool`, `c = id`, `c′` the identification, `A = Fin 2`, `κ 0 = (1/4, 3/4)`, `κ 1 = (3/4, 1/4)`: both D–Z conditions hold with `B = 1`, the anticipation is not Ĉ-calibrated, no model) — see the report's Witnesses section for its Lean status. This instance uses *full* common information (`c = id`, `c′` bijective), so it shows the failure at the full-information corner; the general lemma covers partial `C`, and the a.e. variant `BridgeCalibrated.of_compatibleAE_cmCalibrated` (repair round 1) shows exact compatibility is not what does the work.
- (iii) Surviving neighbour: `compatible_calibrated_iff_bridgeCalibrated` — a compatible calibrated model exists iff the anticipation is Ĉ-calibrated and `P′` has bounded density w.r.t. `Q₀`. Under Ĉ-calibration, `Q₀.map c′ = C` (`BridgeCalibrated.priorPredictive_map_c′`), so the common-information D–Z condition is *implied* by the calibration one with the same bound (`BridgeCalibrated.boundedDensity_C`) and T4's range condition is automatic (`BridgeCalibrated.range`): SC's "the tighter of the two" is always the calibration condition. The sketch's construction ("anticipation-calibrated conditionals on the diagonal") is what `bridgeModel` does, once the kernel is conditioned on the fibre and Ĉ-calibration makes that conditioning well-defined on `P`-positive points.
- Severity: local error; §8.1's table row 2′ should read "Ĉ-calibration, then the calibration D–Z condition".

## F3 — SC Def 5.1's "weaker than full calibration" is only well-posed same-ontology (imprecision, §5.2)

SC §5.2: "This is weaker than full calibration (which would equate the measures on all of `P̄`)". The parenthetical already reads as a same-ontology comparison, and cross-ontology "full calibration" is undefined by SC's own Remark 3.6 (`P(· | ā)` is on `P̄`, `κ_ā` on `Q̄`) — so the sentence is well-posed only for `c′ = c`, where it is true. Provable: same ontology with `c′ = c`, `Calibrated → BridgeCalibrated` (`AnticipationStructure.Calibrated.bridgeCalibrated`); the converse fails for non-injective `c` (`bridgeCalibrated_not_calibrated`, repair round 1: SC's `Fin 4` carrier, `C = Bool`, `c = c′ = parity4` with `c 0 = c 2`, `c 0 ≠ c 1`, two atoms with point-mass kernels — Ĉ-calibrated, not calibrated at `(false, 2)`). The round-0 instance with `C = Unit` is degenerate: with trivial common information *every* anticipation structure is Ĉ-calibrated (`bridgeCalibrated_trivialCI`), so it exercised nothing; kept as the N− `bridgeCalibrated_not_calibrated_trivialCI`. Severity: imprecision.

## F4 — SC Prop 6.1 has no strictness witnesses and its counting needs finite `A` (imprecision, §6.1)

Also "measure determined by calibration" vs the reflective reading: `p_* L = P` needs exactly `Q₀ = P` (reflection), and the `2^{|Ā|}` count only makes sense for non-calibrated kernels (calibrated kernels give at most the event conditionings — under calibration the canonical weight at `x` is `P(x)·𝟙[a x ∈ S x]`, two values per point); formalized under `Reflective`, fidelity `variant`. **The reading of "the Jeffrey posteriors" is load-bearing** (repair round 1, from the audits): `JeffreyMixtures` is SC §4.6's restricted `κ`-mixture with weights `∝ P(ā)`, which is a Jeffrey update of `P` (`JeffreyOnA`) only under calibration; under the general reading `JeffreyOnA` (arbitrary weights on positive atoms) the *first inclusion* of Prop 6.1 is false — a reflective `as` with weights not proportional to `P(ā)` is not canonical. Severity: imprecision (sketch).

## F6 — SC Prop 6.4's "recovers unconstrained same-ontology superconditioning" is false under the Diaconis–Zabell reading (local error, §6.3 and §8.4's "interpolates" row)

- (ii) Readings: (D–Z) "unconstrained same-ontology superconditioning" = the posteriors `P′ ≪ P` with bounded density (SC Remark 2.5, `dzPosteriors`); (event) = conditioning on any event of `P̄`. ## F7 — SC Def 12.1 collapses to "conditioning on a positive event" (imprecision, blocking for §14's intended content)

Def 12.1 quantifies existentially over calibrated anticipation structures. Since the prior's own conditionals on any partition are a calibrated kernel (`calibrated_condAnticipation`), the two-atom partition `{S, Sᶜ}` witnesses coherence for every conditioning `Xᵢ(· | S)`: `epistemicallyCoherent_iff_condOn`. So "epistemically coherent" as defined is "`Xⱼ` is a Bayesian conditioning of `Xᵢ` on a positive event", and §14's "the same procedure at different informational states iff one's beliefs are a calibrated update of the other's, within the other's own anticipation structure" has no anticipation content unless `(Ā, κ)` is fixed in advance. The fixed-structure variant `CoherentVia as Xj` is what Claim 12.3 and the endorsement theorems (`corr-reflect-frames`, `udt-endorse-policy`) need. §14's partial-order claim is proved for the collapsed relation (`downstream_isPartialOrder`) — on measures; on decision-points with distinct utilities it is not antisymmetric. Severity: imprecision, blocking for §14 as intended.

## F8 — SC Def 12.2 clause (1) has two readings in isolation, but they coincide with clause (2) (imprecision, §12.2)

Clause (1) says "the `Ĉ`-compatible conditioning model … exists: `Cⱼ ≪ Cᵢ` with bounded density (Theorem 2.4)". By F1 the existence and inequality readings differ exactly by the range condition. But clause (2) (a Ĉ-calibrated anticipation on `Xᵢ` targeting `Xⱼ`) forces the range condition (`BridgeCalibrated.range`), so `crossCoherent_iff_ineq`: the two readings of Def 12.2 agree. The definition is not ambiguous, but the parenthetical "(Theorem 2.4)" cites the false direction. Severity: imprecision. The sharper fact — clause (2) is not merely sufficient for the range condition but *equivalent* to it, so Def 12.2 collapses — is F14 (repair round 1).

## F9 — SC Thm 4.5 is an iff, and its mechanism is thinning-closure (strengthening, §4.4, §8.5 Q5)

Not an error. Beyond SC: (a) `calibrated_condModel_iff` — a calibrated model exists iff `Q ≪ Q₀` with bounded density (SC §4.5 says the condition is necessary but states Thm 4.5 one way); (b) `thinningClosed_nonrestrictive` — *every* model-side constraint that survives thinning (in the strong sense: every weight on `L`) and holds of the trivial model is non-restrictive; calibration is such a constraint (`CMCalibrated.thin`, `sameOntology_cmCalibrated_thinningClosed`), which re-derives the same-ontology content of Thm 4.5 from closure *for calibrated `as`* (the trivial-model hypothesis is `as.Calibrated` there; for non-calibrated `as` Thm 4.5 is `calModel`'s). This is the precise form of Q5's guess ("the answer, if it exists, must constrain how `l̄` interacts with the anticipation-future joint, not merely the joint itself"): a restrictive semantic constraint must take one of two exits — fail thinning-closure, or fail on the trivial model (the canonical-`L̄` constraint of T13 takes both; `EvidenceCI` fails closure).

## F10 — SC §4.6's Jeffrey identity holds; its converse needs a density bound on countable `A` (imprecision in the mandate's T20 (a), not in SC)

SC §4.6/§6.2 state only "`Ā`-compatible / CI evidence gives Jeffrey on `Ā`" (proved: `jeffrey_of_anticipationEvidence`, `jeffrey_of_evidenceCI`). The mandate's T20 (a) asked for the converse "every Jeffrey-on-`Ā` posterior is the posterior of a CI-evidence model". That is false for countably many atoms: a Jeffrey update whose weights are not dominated by the atom masses has no same-ontology model at all (T5 necessity). Witnesses (report, Witnesses section): the finest-partition instance `jeffrey_not_evidenceCI_witness` (`a = id`: every `P′ ≪ P` is Jeffrey, the T5 pair has unbounded ratio) is **N−** — with `a = id` both `JeffreyOnA` and `EvidenceCI` are vacuous, so it is the T5 witness relabelled (audit r1, B2); the **N+** witness (repair round 1) is `pairJeffrey_not_evidenceCI_witness` on the pair partition `a n = n / 2`: `pairP′ = ∑_k 2⁻⁽ᵏ⁺¹⁾ · geomP(· | {2k, 2k+1})` is a genuine Jeffrey update (density constant `4/5 : 1/5` on each two-point atom), its density `(4/15)·2^{3k+1}` on the even points is unbounded, and no same-ontology (a fortiori no CI-evidence) model exists. The correct statement adds the density bound: `jeffrey_iff_evidenceCI`. On finite `A` the bound is automatic. Severity: imprecision (mandate-level); SC makes no such claim.

## F12 — bli-paper-2-023's "geometric update" is Bayesian conditioning when the divergence is KL (presentation / vacuous definition)

Proved in finite form (`KL.lean`): `geometricUpdate_ge` and `geometricUpdate_eq_iff` — for `Q ≪ P` supported in `S`, `KL(Q‖P) ≥ −log P(S)` with equality iff `Q = P(· | S)`, via the chain rule `klFin_condOn_chain` (`KL(Q‖P) = KL(Q‖P(·|S)) − log P(S)`) and finite Gibbs (`klFin_nonneg`, `klFin_eq_zero_iff`, from `Real.log_le_sub_one_of_pos` and its strict form). So the chat's `argmin_Q D(Q‖P)` subject to `Q(x) = 1` is `P(· | x)` when `D` is KL — the I-projection onto the constraint set is conditioning — and no other `D` is named: the "geometric update" adds nothing as stated. The measure-level form over Mathlib's `klDiv` is stated OPEN (`geometricUpdate_klDiv_open`, listed in `udt-supercondition-open.txt`); obstacle: the pointwise identification of `llr` on a discrete carrier through Mathlib's a.e.-characterized `rnDeriv`. Severity: presentation (AI-generated text with an empty definition), now with the vacuity proved.

## F14 — SC Def 12.2 collapses to the repaired Thm 2.4: clause (2) is idle (imprecision, §12.2; the cross-ontology F7; repair round 1)

Found by both round-1 auditors (fidelity §3.3, adversarial §3.1), missed in round 0. Clause (2) of Def 12.2 — "there exists a Ĉ-calibrated anticipation structure on `Xᵢ` targeting `Xⱼ`" — is *implied* by the range condition of the repaired Thm 2.4: under `∀ y, 0 < Cᵢ(y) → y ∈ range c′`, the one-atom structure whose kernel is `Cᵢ.bind fibreDist` (any kernel pushing forward to `Cᵢ` along `c′`) is Ĉ-calibrated (`bridgeCalibrated_exists_of_range`). With `BridgeCalibrated.range` (clause (2) ⟹ range condition, F8) the existential clause (2) is therefore *equivalent* to the range condition, which clause (1) under the existence reading already carries. Hence `CrossCoherent ci Xi Xj ↔ ∃ m, Compatible m ci` (`crossCoherent_iff_compatible`) and `CrossCoherentIneq ↔ bounded density ∧ range condition` (`crossCoherentIneq_iff`): **Def 12.2 has no anticipation content under existential quantification**, exactly as Def 12.1 collapses to conditioning on a positive event (F7). What survives is the fixed-structure variant `CrossCoherentVia ci Xi Xj as` (the cross-ontology `CoherentVia`): a Ĉ-compatible model exists *and this* `as` is Ĉ-calibrated, which by `crossCoherentVia_iff` is `BridgeCalibrated as ci ∧ ∃ B ≠ ⊤, BoundedDensity C₂ C₁ B` — a genuine constraint (`as10`/`ci10` fail it, `asPar`/`ciPar` and `as38`/… under `ciPar` separate). This is what `corr-reflect-frames` / `udt-endorse-policy` should import; the existential `CrossCoherent` is retained as the exact rendering of SC's words. Severity: imprecision (blocking for any §12 use of Def 12.2 that expects the anticipation clause to constrain).
