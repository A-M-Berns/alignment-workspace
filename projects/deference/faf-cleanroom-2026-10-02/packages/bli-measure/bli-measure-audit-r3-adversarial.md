## 2. Blocking issues

### B1 — `normWeights_noExploit_open` (target 6 (d)) is argued false at FAF's LIA for every covering atom bound; the ledger row, docstring, open-list reason and F7 present it as the open conjecture

**The statement** (`Norm.lean`):

```
theorem normWeights_noExploit_open (P : History) (DP : DeductiveProcess) [IsLogicalInductor P DP]
    (B : ℕ → ℕ) (_hB : ∀ n, ∀ φ ∈ smallSet n, atomBound φ ≤ B n)
    (_hBD : ∀ n, ∀ φ ∈ DP.D n, atomBound φ ≤ B n) :
    ∀ Tr : Trader, EfficientlyComputable Tr →
      ¬ Tr.Exploits (fun n φ => ∑ u : FiniteWorld (B n), normWeights P n (B n) u * (worldOf u).payout φ) DP
```

with `normWeights P n B u := if normSum P n B = 0 then 1 / 2^B else P n (φ_u) / normSum P n B` and `normSum P n B := ∑_{u : FiniteWorld B} P n (φ_u)`. The ledger row says Kind `OPEN`, Fidelity "exact (with the covering bounds; over an arbitrary `B` the statement is argued false — repair round 1; the stage bound `hBD` added in repair round 2 …)", Status `open (listed)`; F7 says "Over an arbitrary (e.g. constant) `B` the statement is argued false, not open"; the open-list reason repeats this. All four present the covering bounds as the repair that turns round 1's argued-false universal into the conjecture.

**What is wrong.** The universal over `P` includes FAF's LIA, `P := liaHistory (paperDP 𝗜𝚺₁)` (`[IsLogicalInductor]` by FAF's `paperLIA`, as the round-3 fidelity audit's N5 notes). For it the statement is false for every covering `B`:

1. **Collapse (machine-checked, probe `audit-r3-probes/NormUniformCollapse.lean`, exit 0).** For every `n` and every `B > sup_{φ ∈ support n} atomBound φ`, where `support n := (liaStates DP n).support`: `normSum (liaHistory DP) n B = 0` (`normSum_lia_eq_zero_of_lt`), hence `normWeights (liaHistory DP) n B u = 1 / 2^B` for every `u` (`normWeights_lia_uniform_of_lt`), hence the induced market of the open row is the uniform marginal `(1/2^B) · ∑_u payout_u φ` on day `n` (`induced_market_uniform_of_lt`). This is the package's own (b) mechanism (`normSum_lia_eq_zero`, `quote_eq_zero_of_not_mem`, `le_atomBound_worldConj`), stated at every bound beyond the support instead of at one.
2. **A covering bound outruns the LIA's support forever (argued).** `hB` makes `B n ≥ atomBound φ` for every `φ ∈ smallSet n`; `Formula.atom a ∈ smallSet n` iff `(natDigits4 (a + 5)).length + 1 ≤ sizeBound n = 2^(2^n)` (`mem_smallSet`, `SmallOn`, `tokenSize_atom`, `sizeBound`), and `atomBound (Formula.atom a) = a + 1`, so `B n` exceeds every atom code with fewer than `2^(2^n)` base-4 digits — `B n ≳ 4^(2^(2^n))`. The LIA's day-`n` support is the key set of `MarketMaker ((TradingFirm DP).action n past) past …` (FAF `liaStates`, `RationalBeliefState.support`), the sentences traded by the day-`n` firm strategy (`Strategy.support`, `ofStrategyVector_support`), which is assembled from efficiently computable traders — polynomial-time functions of the unary day (`EfficientlyComputable`: `F ∈ Complexity.FP`, `strategyOfOutput n (F (unaryDay n))`) — so every sentence in it has `poly(n)` tokens and every atom code in it is below `4^poly(n)`. Hence `sup atomBound (support n) < B n` for all `n ≥ n₀`, and by step 1 the induced market is the uniform marginal on every day from `n₀` on. (For a *fixed* `B` the support eventually catches up — that is why `normSum_tendsto_one` is true; the trouble is a `B n` that grows with the small-sentence bound, which `hB` forces.)
3. **The uniform market is exploited (argued).** Take a stage sentence `φ ∈ (paperDP 𝗜𝚺₁).D n₁` that is not a propositional tautology (the paper process has them). For `B > atomBound φ` its uniform marginal is `c := #{assignments to φ's atoms satisfying φ} / 2^{#atoms} < 1`, independent of `B`, so from day `n₂ := max n₀ n₁` the induced market prices `φ` at the constant `c < 1` while every world plausible on day `n ≥ n₂` holds `φ` (`φ ∈ D n₁ ⊆ D n`). The trader that buys one share of `φ` on every day `n ≥ n₂` and nothing before is efficiently computable (a constant strategy from a fixed day), and its net worth on day `n ≥ n₂` in every plausible world is `(n − n₂)(1 − c)`: unbounded above, bounded below by `0` — FAF's `Exploits` (`plausibleAssessments` bounded below, not above). So the open row's conclusion fails at `P := liaHistory (paperDP 𝗜𝚺₁)`, `DP := paperDP 𝗜𝚺₁`, for every `B` satisfying `hB` and `hBD`.

Steps 2–3 are argued, not machine-checked: step 2 rests on FAF's `TradingFirm`/`EfficientlyComputable` size discipline (poly-time outputs), which I read but did not formalize; step 3 on an e.c. constant trader and FAF's net-worth accounting, which the probe does not build. Step 1 is checked. I regard the chain as solid: it is the same reasoning the package itself uses for (b), extended one step.

**Why it is blocking.** The statement is not "exact (with the covering bounds)" — the covering bounds do not change the verdict round 1 gave for constant `B`; they move the degenerate branch from `atom B` to the whole market. An argued-false statement listed `open`, with four texts saying the restriction made it the conjecture, is a ledger row that misstates status and a findings-file claim (F7's "not open" only for arbitrary `B`) that does not hold as it reads. The conjecture bli-soto-a-042 / 2-002 (a) is after — a PC-coherent market no e.c. trader exploits — is not what finite-day online normalization of an *arbitrary* LI with a growing bound gives; at FAF's LIA it gives the uniform measure.

**Fix I would accept** (any one, plus the wording):

- Add a non-degeneracy hypothesis excluding the default branch, e.g. `hpos : ∀ n, normSum P n (B n) ≠ 0` (or `0 < normSum P n (B n)`), so the statement is about inductors that actually price the day's world conjunctions — and record in F7, the docstring and the open-list reason that **without it the statement is argued false at FAF's LIA for every covering bound**, by (b)'s mechanism (probe step 1), so the finite-day online repair of Conjecture 2 is, for FAF's construction, refuted (argued) rather than open; or
- change the object: state (d) over a market whose finite-day world measure is given — a `CoherentBase` (where `normWeights` is the identity on the small conjunctions and the question becomes target 7's inexploitability of a coherent base), or the limit measure `u ↦ limitingBelief P (φ_u)` that `normWeights_tendsto` reaches; or
- prove the refutation in Lean at `liaHistory (paperDP 𝗜𝚺₁)` (steps 2–3) and retire the row as `refuted (argued → proved)`, keeping one of the two restatements above as the open row of record.

Either way `normWeights_lia_default` (the N−) and `normSum_tendsto_one`/`normWeights_tendsto` stand unchanged; they are what make B1 visible.
