## 3. Non-blocking issues

Numbered for the repair round; none changes a verdict.

1. **Stale docstring pointer** (`Round.lean:11`): the module docstring says `roundTo_not_coherent` is "in `RoundCoherence.lean`"; there is no such file — it lives in `CoherenceExamples.lean`. Same class of slip the `lit-shutdown-prefs` audit flagged. Fix: the file name.

2. **`Fidelity: exact (…)` on `twoAxiom_iff_worldMarginal`** (ledger row and docstring). The parenthetical discloses "non-negativity added; `D`-relativized; over `GenBy A`", which are three variants of the paper's definition, and the paper's pair alone is *refuted* by `twoAxiom_signed_counterexample`. STANDARDS §4's vocabulary for that is `variant: <how>`, not `exact (…)`. The disclosure is complete, so this is a label, not a hidden substitution. Fix: `variant: non-negativity added to the paper's pair (the pair alone admits signed valuations, N−); `D`-relativized; over `GenBy A``. The definition row `TwoAxiomCoherent` already says `variant`, so the two rows should agree.

3. **`roundTo_not_coherent` is labelled `N−` but is a genuine refutation.** Three sentences, three worlds with positive weight, a real coherence witness and a real non-coherence proof; nothing about it is degenerate in AUDIT §0.2's sense (constant sequences, empty types, trivial market). The mandate pre-labelled it `N−` and the package followed. I would grade it N+ as a refutation; the label undersells. Presentation only.

4. **The extension proves inequality, not "strictly smaller".** The mandate's `faceGen_coherentGrid_not_prod` asks that `faceGen (coherentGrid …) t` be *strictly smaller* than `faceProd t ∩ coherentGrid`. The theorem proves one point (`extQ₀`) in `faceProd ∩ coherentGrid` and not in `faceGen` — which is `≠`, and is the content. The `⊆` half needs `faceGen G t ⊆ faceProd t` for `G = coherentGrid`, and `faceGen_subset_faceProd` is stated only for `G = grid 𝒮 d (m+1)`. The pinning lemmas it rests on (`IsProbOn.coord_eq_one_of_meanOn_eq_one`, `…_zero_…`) already take an arbitrary carrier `G` of unit-cube tables, so the generalization is two lines. Fix (optional): state `faceGen_subset_faceProd` for any `G ⊆ grid` (or any `G` with `∀ Q ∈ G, Q.InUnit`), then `ssubset` follows. Also worth recording: **the coherent-grid face over `extT` is nonempty** — probe P2 (`extT1_mem_faceGen`) puts the day-1 copy of `(1/2, 1/2, 0)` in it via the point mass — so the defect exhibited is a proper defect of a nonempty face, not the trivial "empty face ≠ nonempty product face". The package does not say this; the report should.

5. **No `D ≠ ∅` instance anywhere in the package.** Every coherence witness (`roundTable_coherent`, `extQ₀_mem_coherentGrid`, `dT`-style examples, the N± examples) uses `D = ∅`, so the `D`-relativized clauses of `TwoAxiomCoherent`/`IsWorldMarginal`/`CoherentOn` — the part dependents will actually instantiate with a deductive stage — were never exercised. Probe P3 supplies one: `(p ↦ 1, q ↦ 1/2)` is `CoherentOn … {p} 2` (weights ½ on `p∧q`, ½ on `p∧¬q`), and the same-shaped `(p ↦ 1/2, q ↦ 1/2)` is `CoherentOn … ∅ 2` but **not** `CoherentOn … {p} 2` (every `D`-consistent world holds `p`, forcing price 1). So the relativization is inhabited and bites. Suggest adding such an example to `CoherenceExamples.lean` so the ledger's witness column for the de Finetti row covers `D ≠ ∅`.

6. **`hB` is load-bearing, and the package should say so with a witness, not only a docstring.** Probe P4 (`hB_needed`): with `A = ∅`, `D = {atom 5}`, `B = 0`, the indicator of the all-true world satisfies `TwoAxiomCoherent V ∅ {atom 5}` yet `IsWorldMarginal V ∅ {atom 5} 0` is false (the single `FiniteWorld 0` reads atom 5 as `false`, so no world is `D`-consistent and no weight sums to 1). So `twoAxiom_iff_worldMarginal` is **false without `hB`** — exactly design decision 8's trap — and the hypothesis is genuinely doing work (not decorative, not a squeeze). This is evidence *for* the package; recording it (as a small N− lemma) would pre-empt the question for dependents choosing `B`.

7. **`worldRound_err`'s bound `2^B / d` is only informative for `d > 2^B`.** Correct as the mandate specified (and strict, which is stronger than asked), but dependents (`bli-coherent-mm`, `bli-superbelief` E5–E7) need to know that a useful world-rounding error forces `d m` exponential in the atom bound of day `m`'s small sentences. Worth one sentence in the report's interface notes.

8. **`Kernel 𝒮 d m` over bare `d` is uninhabited when `d (m+1) = 0` and `S m ≠ ∅`** (balance fails at `t = 1/2`, as the report's interface note 3 says), so theorems over a bare `d` and a `Skeleton` are vacuous there. Everything that matters is stated over a `Mesh` (the tent kernel, T9); the ∀-`d` statements (`trajLaw_*`) are correct and merely say nothing on that degenerate `d`. Recorded, no change needed.

9. **The degenerate index.** With `S m = ∅` for every `m`, `Balanced` is vacuous (probe P7) and `trajLaw_martingale` has no `φ` to quantify over; every theorem holds trivially. The T9 witness (`|S 1| = 2`, `d = 2`, 9-point grid, 81 trajectories) is what shows the theorems have content, and it does; recorded for completeness.

10. **`worldRound_mem_coherentGrid {dd} (hdd : dd m = d)`** — the extra `dd`/`hdd` indirection exists only because `worldRound` takes a bare `d` while `coherentGrid` takes `d : ℕ → ℕ`. Harmless; a dependent will call it with `hdd := rfl`.

11. **Missing convenience `coherentGrid ⊆ grid`.** True (a marginal of integer world weights summing to `d` is a multiple of `1/d` with numerator `≤ d`), unstated. `bli-coherent-mm` will want it to reuse `IsProb`/`grid` lemmas on the coherent grid. Not a fidelity issue.

12. **T10 (stretch) unattempted with no `OPEN` row.** The mandate allowed "state it `OPEN` … if it resists"; the package chose not to write a `sorry` whose statement was never elaborated, and says so in the report and ledger (`not attempted`). Honest; acceptable under STANDARDS §2. Dependents needing computability of `Kernel` must state their own predicate (interface note 4 says this).

13. **Ledger wording** for the de Finetti witness: "no zero weight on a used world" reads oddly (the fourth world `¬p∧¬q` has weight 0; the three *used* worlds have positive weight). Say "three of the four worlds carry positive weight".
