## Interface notes for dependents (read these first)

1. **`SmallIndex` is a parameter.** Everything is stated over `(𝒮 : SmallIndex)` with fields `S : ℕ → Finset Sentence` and `mono : ∀ m, S m ⊆ S (m+1)`. `bli-found` did not instantiate it (its files do not mention `BliFinite`; it was written independently and earlier), so a dependent that wants the BLI-area index writes `⟨smallSet, smallSet_mono⟩` itself (or whatever `bli-found` names the monotonicity fact). `Table 𝒮 m := ↥(𝒮.S m) → ℚ`; `Table.restrict : Table 𝒮 (m+1) → Table 𝒮 m` uses `mono`; `SmallIndex.mono_le` gives nesting at distance.
2. **`Superbelief 𝒮 m`, not `Superbelief 𝒮 d m`.** The type `Table 𝒮 m → ℚ` does not depend on `d`, and a phantom `d` cannot be inferred from a function type, so `d : ℕ → ℕ` is an explicit argument of `IsProb d F`, `mass d F`, `mean d F`, `Balanced d F t`, `faceProd 𝒮 d m t`, `NonDegenerate d F t`, `Kernel 𝒮 d m`, `Skeleton 𝒮 d`, `trajLaw`, `trajGrid 𝒮 d n h`. The general-carrier forms `IsProbOn G F` (any `Finset α`), `massOn G F`, `meanOn G F` are what `faceGen` and the coherent grid use; `IsProb d F` is definitionally `IsProbOn (grid 𝒮 d m) F`.
3. **`d` is bare data; positivity lives in `Mesh`.** `grid 𝒮 d m`, `Kernel 𝒮 d m` etc. take `d : ℕ → ℕ`; theorems that need `0 < d m` or nesting take `(𝓜 : Mesh)` and are stated over `𝓜.d` (`tentKernel 𝓜 m : Kernel 𝒮 𝓜.d m`). At `d m = 0` the grid is the zero table only, so nothing is vacuous there — but no `Kernel` with a nonempty `S m` exists at `d (m+1) = 0` (balance fails at `t = 1/2`), so state your theorems over a `Mesh`.
4. **`Kernel` has no computability field** (deviation from `bli-program` §2.4, mandate design decision 5). `Kernel.IsComputable` via a `Fin`-reindexing is the stretch target T10 and did not land; `bli-superbelief` E2 / `bli-trajectory` COMP must state computability as their own predicate.
5. **`faceGen` makes E1's containment definitional.** `faceGen G t := G.filter (fun Q => ∃ F, IsProbOn G F ∧ (meanOn G F).restrict = t ∧ 0 < F Q)`, so "every balance solution is supported inside `faceGen`" is `mem_faceGen_of_pos` (kind `T`). The content of the face theorem downstream is (i) existence of a solution supported on *all* of the face and (ii) the relint characterization; on the product grid (i) is this package's `faceProd_eq_faceGen` (T7, via the tent kernel) and `faceGen_subset_faceProd` is the pinning lemma (kind `P`). On the coherent grid the face is **not** a product (`faceGen_coherentGrid_not_prod`), so E1 there needs the general argument.
6. **Trajectories are snoc-oriented.** `Traj 𝒮 n 0 = PUnit`, `Traj 𝒮 n (h+1) = Traj 𝒮 n h × Table 𝒮 (n+h+1)`. `Traj.last t τ : Table 𝒮 (n+h)` (equal to `t` when `h = 0`), `Traj.day τ m hm hmh : Table 𝒮 m` for `n < m ≤ n+h`, `Traj.append`. `trajLaw sk n h t τ` is **defined by** `trajLaw (h+1) t (τ, Q) = trajLaw h t τ * (sk.κ (n+h)).law (τ.last t) Q`; the carrier is `trajGrid 𝒮 d n h`; sum manipulation goes through `sum_trajGrid_zero`/`sum_trajGrid_succ` and membership through `mem_trajGrid_zero`/`mem_trajGrid_succ` (the type `Traj 𝒮 n (h+1)` is only *definitionally* a product, so use these rather than `Finset.mem_product` directly). The multi-step chain rule `trajLaw_chain` identifies `n + h + k` with `n + (h + k)` through the cast-free `Table.castDay`.
7. **The mandate's `restrict_mem_grid` is false as stated** and is *not* provided; see finding F-9 and `mem_grid_of_restrict_mem_grid` (the true nesting consequence: a coarse grid table extended by fine grid values is a fine grid table) / `restrict_mem_grid_of_eq` (the special case `d (m+1) = d m`). `bli-trajectory`'s point-mass kernel E4 should use the former.
8. **`CoherentOn t D B`** carries `B` explicitly with the standing hypothesis `hB : ∀ φ ∈ 𝒮.S m ∪ D, atomBound φ ≤ B` wherever the world type matters (FAF's `FiniteWorld.toBoolPCWorld` reads atoms `≥ B` as `false`, so a `D` mentioning atoms beyond `B` is silently decided). The world in the definition is `worldOf u := u.toBoolPCWorld.toPCWorld`; the existential-`PCWorld` alternative was not used. Only the ⟹ direction of the de Finetti theorem uses `hB`.
9. **World rounding is noncomputable** (`Classical.choose` of the world distribution and of the rounding); the coherent grid is a `Finset` built by `piFinset`/`filter`/`image` with classical decidability. Names: `remainderRound`, not `largestRemainder` (F-12).
