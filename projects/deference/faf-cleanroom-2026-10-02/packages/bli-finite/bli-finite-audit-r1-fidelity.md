## 3. Non-blocking issues

**N1 — `actualState` (T8) is the rounding the package refutes, and its docstring says "Fidelity: exact".** `actualState 𝒮 d Q m := roundTo (d m) (actualTable 𝒮 Q m)` is coordinatewise nearest rounding — the reading of Appendix B's `D_n` that `roundTo_not_coherent` shows does *not* "maintain propositional consistency". Probe P3 (`actualState_coherentHist_not_coherent`) transports the F-2 example: a rational history whose day-0 table is the coherent `roundTable` has an *incoherent* day-0 `actualState`. The definition is what the mandate (T8) and `bli-program` §2.2 prescribe, the program says explicitly that this is harmless for B1 (incoherent tables allowed on the product grid), and the docstring discloses "(coordinatewise rounding)" — so this is a disclosed design decision, not a hidden substitution. But "exact" oversells against the paper's parenthetical, and dependents (`bli-found`'s state atom `Q̂ = actualState m`, `bli-trajectory`) inherit a state that may be incoherent even when the base table is. Fix I'd accept: `Fidelity: variant: coordinatewise (the reading F-2 refutes as coherence-preserving; B3's coherent alternative is worldRound, noncomputable)` on `actualState`, the same phrase in the ledger's `actualState` row, and one sentence in the report's interface notes.

**N2 — F-2: missed evidence and a stronger, reading-independent form.** (i) Constraint 1 at `main.tex:431` writes `𝐏_n(φ) := D_n(𝐐_n(φ))` — `D_n` applied to a *single price* — so the paper's own notation is coordinatewise, while its prose at line 427 has `D_n` act on price-lists "maintaining propositional consistency". That is an internal inconsistency in the paper, and citing it would let F-2 say more than "the paper does not say which rounding it means" (the ATTRIBUTION-UNVETTED hedge stays correct for *intent*). (ii) What is proved is that the rounding of record (nearest, ties down) breaks coherence. The general fact is a few lines: if `S` contains a tautology and two disjoint sentences with their disjunction, then any coordinatewise map `r` into a finite grid that preserves coherence must satisfy `r 1 = 1` and `r (a + b) = r a + r b` on the coherent tables `(a, b, a+b, 1)`, hence `r (2⁻ⁿ) = 2⁻ⁿ` for every `n` — impossible in a finite grid. That would make F-2 independent of *which* coordinatewise `D_n` was meant. Suggested agenda item for a repair round, not required.

**N3 — Extension `faceGen_coherentGrid_not_prod` never shows the coherent-grid face is nonempty.** The theorem puts `extQ₀ ∈ faceProd ∩ coherentGrid` outside `faceGen (coherentGrid …) extT`; if that face were empty the headline "not a product" would be vacuous. It is not empty: probe P2 (`extT₁_mem_faceGen_coherentGrid`) shows the day-1 copy of `extT = (1/2, 1/2, 0)` is on the coherent grid (one unit of world mass on `p ∧ ¬q`, one on `¬p ∧ q`) and the point mass at it is a balance solution. Recommend adding this lemma to `FaceCoherent.lean` and one conjunct to the headline. Related: the module docstring's "`faceGen ⊊ faceProd t ∩ coherentGrid`" uses `faceGen (coherentGrid …) t ⊆ faceProd t`, which the package proves only for `G = grid` (`faceGen_subset_faceProd`); the pinning lemmas apply to any `InUnit` carrier (via `coherentOn_of_mem_coherentGrid` + `CoherentOn.inUnit`), so the coherent-grid instance is a two-line corollary — state it or soften the docstring.

**N4 — De Finetti's `D`-relativization is never exercised by a witness.** All coherence witnesses (`roundTable_coherent`, the extension, the N+/N−) have `D = ∅`; the clause `w u ≠ 0 → (worldOf u).ConsistentWith D` and the `D`-part of `hB` are exercised only by the proof, never by an instance. A witness with a consistent nonempty stage (e.g. `D = {p}`, `A = {q}`, `V` forced to `V p = 1`) would show the relativization is inhabited non-trivially. (I checked the degenerate case by hand: for an inconsistent `D` both sides of `twoAxiom_iff_worldMarginal` are unsatisfiable — `DTaut` and `DContra` hold for everything, forcing `1 = 2`; no world is `D`-consistent, so `∑ w = 1` fails — so the theorem is consistent there.)

**N5 — Kind inflation on two rows.** `worldRound_coherent` and `worldRound_mem_coherentGrid` are ledgered `P`; the first is plumbing from `remainderRound_spec` (the mathematics is `exists_gridRound`, correctly `P`), the second extracts the integer weights — `L`/`C` would be honest. Also `tent1_nonneg` sits in a `P` row with the real `tent1_*` lemmas (harmless, grouped row).

**N6 — `trajLaw_martingale` vs bli-paper-036's "martingale consequence".** The inventory's consequence is the *conditional* form (condition on the day-`o` state `Q₂`, expect the day-`m` table `= Q₂[φ]`, `n < o < m`); the Lean proves the unconditional-from-any-start form `∑ τ, trajLaw … t τ · τ_m φ = t φ`, from which the conditional one follows by the Markov property (`trajLaw_chain`, restart at day `o` from `Q₂`). One sentence in the docstring would close the gap; "exact (in the program's object)" is fair.

**N7 — `roundTo_not_coherent`'s negative half is stated at `B = 2` only.** The disjoint-additivity argument works for every `B`, and above the atom bound `coherentOn_iff_twoAxiom` makes coherence `B`-independent; a `∀ B` form is one line. Cosmetic.

**N8 — `faceGen` docstring.** "The minimal face of `conv G` containing `t`" — `t` lives on day `m`; the object is `G ∩` (minimal face of `conv G` meeting the restriction fibre of `t`), i.e. the union of supports of all balance solutions. Presentation.

**N9 — T10 not attempted, no OPEN row.** Acceptable for a stretch, and the report's wording is honest ("an unattempted stretch recorded here is more honest than a `sorry` whose statement was never elaborated against"). Recorded so consolidation does not count it as silently dropped; the mandate's "state it OPEN if it resists" was not triggered because nothing was tried.

**N10 — Witness column of `twoAxiom_iff_worldMarginal`.** `roundTable_coherent` inhabits the *world-marginal* side (`CoherentOn`); the two-axiom side is inhabited through `coherentOn_iff_twoAxiom`. Fine, say so.

**N11 — Stale pointer.** `Round.lean`'s module docstring says `roundTo_not_coherent` is "in `RoundCoherence.lean`"; the file is `CoherenceExamples.lean`.

**N12 — Register of the N+ `twoAxiom_on_given_sentences_only_not_coherent`.** It guards a *formalization* failure mode (★F4's "va: iff stated on the given sentences only"), not a claim any source makes; the docstring says so correctly. Noting it so no reader takes it as a finding against bli-soto-a-001.
