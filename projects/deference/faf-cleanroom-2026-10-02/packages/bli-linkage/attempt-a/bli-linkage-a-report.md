## Interface notes (what the reconciler and dependents should know)

1. **`cellLit` takes the sentence code.** `CellFamily.cellLit m c r` with `c : ℕ`; the B2 instance is `cellSentence T round hround m c r` and `stateOf` is then `stateSentence` by `rfl`. Statements quantify over coordinates by code and read `sentenceOfCode c`; `Tabular.genuine` ties the two on the index.
2. **`PCPσ`'s worlds respect the day-`(n+1)` cell partition** (`CellFamily.Partitions`). FAF's stage `D n` does not contain the exclusivity/exhaustiveness of day-`(n+1)` literals; the sources' "coherent on the algebra of the quote atoms" takes them to partition. Without this clause K1 is false for a reason unrelated to linkage (a stage world can hold `σ_q` and a second literal of the same coordinate). `PCPσTheory → PCPσ` is proved; `PCPσTheory ∧ E5σ` collapses the superbelief to a point mass (`theory_coherent_point_mass`), so K1/K2 are at `PCPσ`.
3. **`Tabular C index S`** (`keys`: every candidate lists every index code with a cell in `C.cells`; `val`: its value there is the cell's representative; `genuine`) is a genuine hypothesis of K1/K2: a candidate that does not list the coordinate says nothing about its literal.
4. **`E2xσIdx`** — faith on the listed coordinates only — is the faith predicate of record for K2. `bli-found`'s `E2xσ` over a list-table system with junk value `0` off the index is unsatisfiable under coherence with a charged state (the scope `Sminus m m` contains unlisted tautologies such as `⊤ ⋏ ⊤` from `m = 1`): see [bli-linkage-a-findings](bli-linkage-a-findings.md) F-A1. `determination_e2xσ` keeps the mandate's shape as a corollary.
5. **`D_NNUcell`** is stated exactly as the mandate writes it, modulo `cellLit (n+1) c r` taking the code `c` where the mandate wrote `lit (n+1) (sentenceOfCode c) r`.
6. **One-way/two-way tag** (plan §0.4 rule 1): not applicable — every target is about one base `Q` and a market `P` computed from it.
