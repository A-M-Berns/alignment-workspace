The corollary `condExp_deviate_eq` says the masked act value is *independent of the self-model* `m` — `condExp (C[d ↦ m]) = condExp C` because `m(a)` cancels between numerator and denominator. A witness at `m = C(d)` changes nothing: it instantiates the conclusion at the one `m` where both sides are the same term, so no cancellation is tested, exactly as a constant sequence tests no limit theorem ([STANDARDS](../../STANDARDS.md) §3: N+ "exercises the content — not constant sequences"). The round-2 fix moved the witness from a tree where the *values* were trivially equal (`0 = 0`) to a pairing where the *procedures* are trivially equal; the degeneracy changed shape but did not go away. (The same `(½, Unif)` pairing is in the regraded N− `coinQuery_condExp_deviate`, which is therefore reflexive on top of being `0 = 0`.)
