## Interface notes for dependents (read these first)

1. **The prior.** `FiniteBLIPrior 𝒮 m 𝒟 A` with `𝒮 : SmallIndex`, `m : ℕ`, `𝒟 : Finset (Table 𝒮 m)`, `A : Type`. Fields: `Ω` (with `[fin : Fintype Ω]`, registered as an instance), `μ`, `μ_nonneg`, `μ_sum_one`, `state : Ω → ↥𝒟`, `pp : Ω → Policy 𝒟 A`, `U : Ω → ℚ`, `small : Ω → ↥(𝒮.S m) → Bool`, `faith`. **Faith is the only field beyond the probability axioms**; every structural predicate is a derived `Prop`. `Policy 𝒟 A := ↥𝒟 → A` (an `abbrev`, so `Fintype (Policy 𝒟 A)` and `Function.update` apply when `[DecidableEq A] [Fintype A]`). The prior variable is `P` in every file (`Π` is reserved in Lean 4); dependents write `P.EU T a`, `P.homeEU T a`, etc.
2. **Every conditional is `condExp μ f E := integralOf μ f E / massOf μ E`** with `massOf μ E := ∑ ω, if E ω then μ ω else 0`, `integralOf μ f E := ∑ ω, if E ω then μ ω * f ω else 0`, and **Lean's `x / 0 = 0` as the junk value**. The derived quantities are `stateMass T`, `ppMass T a`, `ppUtil T a`, `EU T a` (= `condExp` at `pp · T = a`), `jointMass T' T a`, `jointUtil T' T a`, `condEU T' T a` (at `state = T' ∧ pp · T = a`), `homeEU T a := condEU T T a`, `branchProb T' T a := jointMass T' T a / ppMass T a`, `policyMass π`, `policyUtil π`, `exAnteValue π` (at `pp = π`), `cellMass T π`, `cellUtil T π`, `cellEU T π` (at `state = T ∧ pp = π`), `sepValue π := ∑ T, stateMass T * homeEU T (π T)` (the program's array formula, named as such), `pairMass T T' a b`, `triMass S T T' a b`.
3. **Positivity predicates**: `NDPOL P := ∀ T a, 0 < ppMass T a`, `NDHOME P := ∀ T a, 0 < jointMass T T a`, `NDPOLICY P := ∀ π, 0 < policyMass π`. Theorems take the weakest they need; several take a single `0 < policyMass π` instead of `NDPOLICY`.
4. **Decision rules are predicates** (ties allowed): `IsOneStepChoice P T a := ∀ b, EU T b ≤ EU T a`, `IsUpdatefulChoice P T a := ∀ b, homeEU T b ≤ homeEU T a`, `IsPriorOptimal P π := ∀ π', exAnteValue π' ≤ exAnteValue π`, `IsOneStepPolicy`, `IsUpdatefulPolicy` (pointwise). There is no `oneStepUDT` *function*. **Honest scopes** (each in its docstring): `NDPOL` for `IsOneStepChoice`, `NDHOME` for `IsUpdatefulChoice`, `NDPOLICY` for `IsPriorOptimal` — outside them the comparison is against the junk `0` of a null cell or policy. For priors without `NDPOLICY` use **`IsPriorOptimalOnSupport P π := ∀ π', 0 < policyMass π' → exAnteValue π' ≤ exAnteValue π`** (added in repair r1): it agrees with `IsPriorOptimal` under `NDPOLICY` (`isPriorOptimalOnSupport_iff`) and, unlike it, is invariant under adding a constant to `U` (`isPriorOptimalOnSupport_shiftU_iff` vs `Shift.corrShift_junk`).
5. **Structural predicates** (each with its positivity guard inside): point level `Reflective P` (`0 < ppMass T' a → branchProb T T' a = stateMass T`), `NoCrossBranch P` (`T' ≠ T → both cells positive → condEU T' T a = condEU T' T b`); policy level `ReflectivePolicy P` (`0 < policyMass π → cellMass T π / policyMass π = stateMass T`), `LocalUtility P` (`π T = π' T → both cells positive → cellEU T π = cellEU T π'`); `IndependentPoints P` (product form on `pairMass`), `IndependentPointsGivenState P` (product form `triMass · stateMass = jointMass · jointMass`), `FaithGivenPoints P`.
6. **`ProcLayer P`** (`Proc`, `proc : Ω → Proc`, `eff : Proc → Policy 𝒟 A`, `pp_eff`) and `PolicyFair P L` (equal `eff` ⟹ equal `procEU` on positive procedures). `udt-paper-tiling` states its Theorem 1 over this predicate.
