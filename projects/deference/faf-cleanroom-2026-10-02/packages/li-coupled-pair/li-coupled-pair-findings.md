### R-13 — `FuelDominated` as first shipped had no instance; repaired to the route's clock at the scheduled position, with no instance known; in FAF's fuel model the schedule can pay for the value but never for the threshold comparison (local error in the package, found by audit r2 adversarial B1; fixed; the sharpening is new)

Source: audit r2 adversarial B1 and its probe `audit-r2-probes/FuelDominatedVacuous.lean`; anson-2-007's `e(n) ≥ Λ(n)` (chat 04 L686–703); `B/Scheduled.lean`; Mathlib `Nat.Partrec.Code.evaln_bound`.

**The error.** The hypothesis of `ledgerSeq_codes_of_dominated` / `B.conditioningRoute_inductor_of_dominated` was `∀ j n c, (decode c).isSome → ∃ k ≤ max ((e j).e n) (ledgerPayload j n c), gateVal a p ∈ evaln k c₁ p` with `p = ledgerPayload j n c`. Mathlib's `evaln_bound` needs `p < k`; `p ≥ c` (`code_le_ledgerPayload`) is unbounded in the rational code `c` for fixed `(j, n)`; so for `j = n = 0` and any rational code `c ≥ (e 0).e 0` the bound is `p` itself and the clause fails. The two theorems were true for a vacuous reason. This is the argument of the package's own `not_perDay_dominated` (F-B7), which the `max` was supposed to escape and did not — "the bound must carry the payload" was the wrong conclusion; "the bound must *exceed* the payload" is the right one. The refutation is now the package theorem `not_fuelDominated_le` (statement = the old definition, negated).

**The repair.** `FuelDominated c₁ a e` now asks `gateVal a p ∈ evaln (clock (max ((e j).e n) p)) c₁ p`, with `clock t = (t + 1)² + 1` the clocked route's own fuel (FAF's `clockOf 1 2`): the program halts within the clock of the scheduled position, which exceeds the payload (`lt_clock`). `ledgerSeq_eq_clockedSeq`, `ledgerSeq_codes_of_dominated`, `conditioningRoute_inductor_of_dominated` keep their statements (`clockDigit_eq_gateVal_of_dominated` via the new `clock_mono`).

**No instance is known, and why.** `gateVal a` is never constant (both polarities occur under every table, `ℚ` being unbounded both ways), and Mathlib's `decode : ℕ → Option ℚ` goes through `Σ n : ℤ, {d // 0 < d ∧ n.natAbs.Coprime d}`, so any polarity program computes a gcd; certifying one within quadratic `evaln` fuel on the *value* of `p` (every sub-evaluation's input below the fuel, every `prec`/`rfind'` iteration costing one) is a fuel-calculus construction. FAF's `PolyFueled c f := ∃ b, Fueled c f b ∧ IsPolyBounded f ∧ IsPolyBounded b` certifies at *some* polynomial fuel, not at the route's fixed `clockOf 1 2`, and the schedule cannot absorb the difference (next paragraph). The question is stated OPEN: `B.exists_fuelDominated : ∃ c₁ a e, (∀ p, c₁.eval p = Part.some (gateVal a p)) ∧ FuelDominated c₁ a e`, unknown either way (the payload is at least `c²`, which leaves room; nothing more is claimed). The two theorems' Status is `partial: FuelDominated (c); no instance known`; R-1's and R-9's "sharper than `hψ`" is withdrawn — li-quote-lane's `hψ : MachineSentenceCodes (ledgerSeq a e)` is satisfiable at least for cheap tables, `FuelDominated` is a different hypothesis with no known instance.

**The sharpening (new).** The bound `clock (max ((e j).e n) p)` is `clock p` as soon as `p ≥ (e j).e n`, i.e. for all but finitely many rational codes per `(j, n)`. So `FuelDominated c₁ a e` sits between the schedule-free `PayloadClocked c₁ a` ("the program halts within `clock p` on every payload `p`": `fuelDominated_of_payloadClocked`, for every `e`) and its restriction to payloads at or above the publication stage (`payloadClocked_of_fuelDominated_above`). Over li-quote-lane's per-threshold rendering, anson-2-007's `e ≥ Λ` therefore degenerates into a property of the polarity program alone, up to finitely many small codes per day: the schedule can pay for the *value*, never for the *threshold comparison* — the position must. This is why the clocked route (`clockedSeq_codes`, zero (c)), where every position pays its own clock, is the answer to the mandate's angle-B question and the scheduled route is not. Severity for the package: local error, fixed; for the source: none (the chat prices one rational per day, not a comparison per threshold — F-B7's relabelling stands).
