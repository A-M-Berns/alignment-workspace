## F1 — The wiki's "spacing `≥ δ` is not needed" is false for the product-band form; the partition argument needs it (local error in `reflection-in-li` §It joins the circle / vq-wiki-006's flag; confirmed)

- **Pointer:** `reflection-in-li` §It joins the circle ("Each bracketed difference is a legal `[0,1]`-valued weight … a band weight"); vq-wiki-006's flag ("`t_{k+1} − t_k ≥ δ` is *not* needed — check that each bracket is `[0,1]`-valued"); def-lattice `bandWt δ s ε = Ind_δ(q > s − ε) · Ind_δ(q < s + ε)` (`Expert.lean`).
- **The fact (proved, `Partition.lean` `ctsInd_sub_ctsInd_eq_band`):** for `t + δ ≤ t'`, `ctsInd δ q t − ctsInd δ q t' = ctsInd δ q t · ctsInd δ (t' + δ) q` for every `q`; so the bracket at consecutive thresholds `t_k < t_{k+1}` **is** the band weight `bandWt δ ((t_k + t_{k+1} + δ)/2) ((t_{k+1} + δ − t_k)/2)` exactly when `t_{k+1} − t_k ≥ δ`. Without the spacing the identity fails: at `t' = t` the left side is `0` while the product `ctsInd δ q t · ctsInd δ (t + δ) q` is positive on `(t, t + δ)`; for `t < t' < t + δ` the bracket is `[0,1]`-valued (the flag's check passes) but is **not** a product of an up-ramp and a down-ramp of the same width, so `BandReflection` (whose weights are `bandWt`) gives no face for it. The flag checked the wrong property.
- **Consequence:** the partition argument is quantified over grids with spacing `≥ δ` (`softAbove_instance_of_bandFaces`, `softBelow_instance_of_bandFaces`); the canonical grids `t_k = v ± kδ` realise it (`softTotalTrustAbove/Below_of_bandReflectionWithin`). The theorem the page states is true; its parenthetical justification is not.
- **Nuance (audit r1 adversarial N7):** the spacing is a cost of the predicate's *product form*, not of the Tower: `thresholdAbove_instance_of_tower` is generic in the weight, so from `TowerValued` the wiki's bracket `ctsInd δ q t_k − ctsInd δ q t_{k+1}` gets its face directly at any spacing (it is a nonnegative weight supported above `t_k`); the spacing is needed only because `BandReflection` is defined over `bandWt`. And (F12) the spacing question only arises for *narrow* bands: over def-lattice's unbounded-width predicate the whole partition is redundant.
- **Severity:** local error (in a remark, not in the conclusion).

## F12 — def-lattice's `BandReflection` contains soft Total Trust as its wide-band case: over the unbounded-width predicate, `BandReflection ⟹ TotalTrust` needs no partition (finding about def-lattice's encoding; audit r1 fidelity B1; proved, `WideBand.lean`)
