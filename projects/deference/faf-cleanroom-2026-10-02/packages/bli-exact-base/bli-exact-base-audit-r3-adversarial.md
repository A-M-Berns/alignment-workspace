## 2. Blocking issues

### B1 — `Segment.linked_segment_day_exists` as restated is still neither provable nor refutable: the code is quantified, but the table its cell truth is about is a `Classical.choice` (a ledger row, an open-list entry and a findings paragraph that misstate what would close it; an open statement that is not what it says)

**Declarations.** `Segment.linked_segment_day_exists` (OPEN; ledger Table 2; open list row 9); the `flagged:` clauses of `Segment.segment_D_NNUcell_on_q` (judged item 3, Table 1) and `trilemma_sharp_segment_q`; `Segment.k₀`, `W₀`, `WAt`, `kernelMarket`, `linkedPrice`; findings F16 (b) ("a genuine conjecture, plausibly true … the linked table is the brute-force average over the stage-consistent assignments"); `bli-exact-base-handoff` item 1; report § State ("What is open"), § 3 (b)/(d), deviation (xiv).

**What the statement is.** `∃ (H n : ℕ) (q : BooleanQuoteCode 𝗜𝚺₁ (spliceCellTruth H linkedPrice halfRound)), 2 ≤ n ∧ n < H ∧ ⌜⊤⌝ ∈ pinned (linkedCFq H q) segmentIndex n`. A `BooleanQuoteCode 𝗜𝚺₁ T` (FAF `Quotation/Packages.lean:273`) is a `code : ℕ` with `pos_complete : ∀ input, T input → 𝗜𝚺₁ ⊢ universalQuotePos/[⟨code, input⟩]` and `neg_complete` for `¬ T input` — the program must provably decide `T` at **every** input. Here `T = spliceCellTruth H linkedPrice halfRound`, which at `⟨m, ⟨⌜φ⌝, r⟩⟩` with `m < H` and `φ` day-`m` small is `halfRound m (linkedPrice m φ) = r` (`spliceValue_linked`). And `linkedPrice m φ = kMixRat (D m) (m+1) (WAt m) φ`, `WAt m` the `j ↦ j % k₀ m` re-indexing of `W₀ m`, with `k₀ m := Classical.choose (exists_completeFor …)` and `W₀ m := Classical.choose (Classical.choose_spec …)` (`Segment.lean:72–82`; `AdvChosenFamily.k₀_is_choice`, `W₀_is_choice`, `WAt_is_reidx`, `linkedPrice_is_kernel_of_reidx`, all `rfl`). The only fact Lean has about the chosen family is `W₀_spec m`: `0 < k₀ m`, every member stage-consistent, `CompleteFor (D m) (smallAtoms m) (W₀ m)` — and `CompleteFor` says only that every consistent pattern on the small atoms is realized by *some* member; nothing about multiplicities.

**Evidence (probe `AdvChosenFamily.lean`).** Let `a₁ := freshAtomCode freshFamily ⟨0, 1⟩`, the sibling of `freshCoord` (code `381`; small from day `2`, `a₁_mem_smallSet`; mentioned by no stage, `a₁_fresh`; not of literal shape, `a₁_not_litShape`). The kernel's price of such an atom is the family's frequency of it (`kMixRat_atom`: the slices override only `freshCode` and the literal-shaped atoms), preserved exactly by the `WAt` re-indexing at power-of-two sizes (`sum_reidx_eq`, `kMixRat_reidx_atom`). Then

```
theorem spec_admits_both_cells (n : ℕ) :
    (∃ (k : ℕ) (W : Fin k → PCWorld) (hk : 0 < k),
      (∀ i, (W i).ConsistentWith ((paperDP 𝗜𝚺₁).D n)) ∧
      CompleteFor ((paperDP 𝗜𝚺₁).D n) (smallAtoms n) W ∧
      halfRound n (kMixRat ((paperDP 𝗜𝚺₁).D n) (n + 1) (reidx hk W) (Formula.atom a₁)) = 1) ∧
    (∃ (k : ℕ) (W : Fin k → PCWorld) (hk : 0 < k),
      (∀ i, (W i).ConsistentWith ((paperDP 𝗜𝚺₁).D n)) ∧
      CompleteFor ((paperDP 𝗜𝚺₁).D n) (smallAtoms n) W ∧
      halfRound n (kMixRat ((paperDP 𝗜𝚺₁).D n) (n + 1) (reidx hk W) (Formula.atom a₁)) = 0)
```

— pad any complete family to size `2^(k+2)` with copies of a stage-consistent world holding `a₁`, or refuting it (`free_atom_undecided`); consistency and completeness survive padding (`pad_consistent`, `pad_completeFor`); the frequency is `≥ 1/2` or `≤ 1/4`. And `cellTruth_a₁` (`2 ≤ n < H`): the row's code must decide, at `⟨n, ⟨⌜a₁⌝, r⟩⟩`, exactly `halfRound n (kMixRat … (reidx (W₀_spec n).1 (W₀ n)) ⌜a₁⌝) = r`.

**Why it blocks.** (i) *Not provable.* A proof needs a `q` and a token-size bound on `litIdx q.code (n+1) ⌜⊤⌝ r`; a bound needs an explicit `q.code` (a `Classical.choose`n code, FAF's `ofComputable` included, has none — round 2's B1); an explicit code `c` needs `pos_complete`/`neg_complete`, i.e. that `c`'s output at `⟨n, ⟨⌜a₁⌝, 1⟩⟩` — a definite bit — provably equals a bit that `W₀_spec` leaves open both ways. (The Lean's choice function is fixed, but Lean's axioms do not determine it; both families of the probe are models of everything the development knows about `W₀ n`, so neither `truth` nor `¬ truth` at that input is a theorem, and `truth ↔ [c outputs 1]` is not either.) Nor does a lookup table help: day `n`'s table has more than `2^(2^n) = sizeBound n` entries (`sizeBound_lt_card_smallSet`), above the budget the literal must meet on day `n`. (ii) *Not refutable:* the chosen family might be the canonical one and the LIA's code short. So the row is a statement about which family `Classical.choice` returned — the same species as round 2's B1 ("not a conjecture about the kernel but about which program `Classical.choice` returned"), and judged item 3's non-vacuity is again parked on a statement no continuation can settle. **Fix I would accept.** Make the family of record canonical: define `W₀ n` (or directly `linkedPrice n`) from the stage, not by choice — e.g. the family `exists_completeFor`'s own proof builds, the stage-consistent `FiniteWorld B` patterns on the first `B` atoms (`B := max (A.sup id + 1) (D.sup atomBound)`), each once, with the kernel's sums taken over that `Finset` (so no `Fintype.equivFin` either), and `WAt` the re-indexing of *that* family. Every `Kernel` lemma is for an arbitrary family, so `kMix_coherentOn`, `kMix_partitionAt`, `kMix_faith`, `kMix_two_charged`, `kMix_fresh` and the dyadic grid lemmas transfer; `W₀_spec`'s three clauses are the lemma's conclusion. ### B2 — `OwnQuoteLane ∧ LiveLane` holds at every history through a price-blind quote code; the docstring of `Live.quoteLane_clause_inhabited` claims the opposite, and the three M4 rows still quantify over lanes the program never meant (a false claim in a Lean docstring and in F21's conclusion; an N+ guarding a clause no market can fail)

**Declarations.** `Open.OwnQuoteLane`; `Open.worldMarket_exists`, `bundleMarket_LI_exists`, `weakening_exists`; `Live.quoteLane_clause_inhabited` (N+; its docstring: "Unlike round 1's `ReflectsRounded ∧ LiveLane`, which held at every history, … the clause `OwnQuoteLane ∧ LiveLane` is not inhabited for free: a constant lane fails it, `not_ownQuoteLane_of_constant`, and a non-computable market has no quote code of its cell truth"); `Live.D_NNUcell_own_pointwise` ("pointwise self-trust at the market's own quotation atoms"); F21's round-2 paragraph ("the three OPEN rows now state the program's §3.8 object: `D-NNU` over the market's own `quote_{n+1,φ,I}` literals, named through a program deciding its cell truth"); `Open.lean`'s header and the three rows' docstrings ("its own quote lane"); report item (14) and § 9.

With `round m x := 0`, the predicate "`round m (P m φ) = r`" is "`r = 0`" for **every** `P`; it has a FAF quote code (`BooleanQuoteCode.ofComputable`) that reads nothing about `P`. Probe `AdvBlindLane.lean`: `blindTruth z := z.unpair.2.unpair.2 = 0`, `blindCode`, the family `blindFamily : CellFamilyT (paperDP 𝗜𝚺₁)` (literals `blindCode.sentence ⟨m, ⟨⌜φ⌝, r⟩⟩`, cells `{0, 1}`, representatives `1`/`0`; `excl`/`exh` from `blindCode.reflected`), and

```

theorem blindFamily_live : LiveLane blindFamily smallCodes
theorem lane_clause_for_every_history (P : History) :
    ∃ (C : CellFamilyT (paperDP 𝗜𝚺₁)) (round : ℕ → ℝ → ℕ),
      OwnQuoteLane C round P ∧ LiveLane C smallCodes
```

(liveness by the same machine-metered-family argument as `spliceCF_live`). So the lane clause of all three rows holds at every history — computable or not — exactly as round 1's `ReflectsRounded ∧ LiveLane` did (`certFamily_reflects_live`); the "not inhabited for free" sentence is false on both of its counts, and `quoteLane_clause_inhabited` is again an N+ at the wrong object (round 2 adversarial N1's complaint, verbatim). Under the blind lane `D_NNUcell` at a pinned coordinate reads `P n φ = P n ⌜blind(n+1, ⌜φ⌝, 0)⌝` (`blind_identity`): today's price of `φ` equals today's price of a theory-valid atom (`blindLit_zero_valid`) that no stage `n` mentions and that says nothing about `φ` — "self-trust at the market's own quotation atoms" (`D_NNUcell_own_pointwise`'s docstring) with a quotation of nothing. **It closes no row** (so Status `open` is right): under an LI the e.c. sequence `n ↦ blind(n+1, ⌜⊥⌝, 0)` of eventually-asserted atoms is priced toward `1` and `⊥` toward `0`, so (α)/(β) cannot be met this way for any representatives (prose, not machine-checked); under `D_PCsmall` the weakening's identity at `⊥` forces the eventually-asserted atom to be priced `0` from some day on (or, with representatives `0`/`1`, a refutable atom to be priced `1`), which a one-share-a-day efficiently computable trader of magnitude `1` exploits (prose). What it shows is that "with its own quote lane" is not what the statements force: each row is a disjunction over roundings including ones that quote a constant decision — the third lane in three rounds that the clause admits and should not (padding, the certain lane, the blind lane), each found by the same move (the guard constrains one thing, the rows leave the next thing free).

**Fix I would accept.** Tie `round` to the lane in all three rows (and in `OwnQuoteLane` or beside it), with the splice's lane as the check: (i) the rounding is a genuine cell map with the representative in the cell — `∀ m, ∀ x ∈ [0,1], round m x ∈ C.cells m ∧ |C.rep m (round m x) − x| ≤ w m` with `w m < 1` (at `roundR`/`rep01`, `w = 1/2`), and (ii) it is sensitive to the price — `∀ m, round m 0 ≠ round m 1` (or `C.cells m` has two cells hit by `round m` on `[0,1]`); or fix the grid family instead of quantifying over `round` (`round m x := ⌊x · d m⌋`-style with `d m ≥ 2`, representatives the cell midpoints or endpoints, as `bli-program` §3.8 and the mandate's § Definitions have it), which removes the whole species of degenerate lanes at once. Then correct `quoteLane_clause_inhabited`'s docstring (the clause *is* inhabited for free without the tie; with it the splice's lane is a genuine witness), F21's round-2 conclusion, `D_NNUcell_own_pointwise`'s docstring, `Open.lean`'s header, report item (14), and incorporate the probe (`blindFamily`, `lane_clause_for_every_history`, `blind_identity`) as round 3's record beside `padFamily` and `certFamily`.
