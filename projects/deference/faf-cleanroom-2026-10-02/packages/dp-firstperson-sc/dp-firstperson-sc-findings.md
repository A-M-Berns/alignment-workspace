`PredictorAt obs d child := ¬ LiveAt ∧ ∀ a ℓ, world (child a) ℓ ∈ obs d → 0 < count d (child a) ℓ` renders GR-D2's "predictor otherwise — not subtree-veridical, and every `O_d`-leaf below it (if any) passes another `d`-node on the way down" verbatim. With no `O_d`-leaf below, the second clause is empty and the first holds, so a `d`-node whose every leaf lies outside `O_d` is a predictor node and not a routing node (the probe: `decision d (fun _ => leaf ω r)` with `ω ∉ obs d`). Such a node is then "Omega's simulation of the agent at `d`" by definition: `replacePred` replaces it by `θ d` and `usePred` counts it, so GR-4's bound charges it `tv(θ_d, θ'_d)` per visit although no observation of `d` can be made below it. Nothing in the package is affected (TN-V2's four nodes are classified by their real content), and the source's "(if any)" makes the reading deliberate; a reader who wants predictor nodes to be nodes *at which the agent is simulated for a `d`-observation* needs the extra clause "some `O_d`-leaf below it".
