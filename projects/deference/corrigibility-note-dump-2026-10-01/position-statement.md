## 1. The thesis (AUTHOR, verbatim)

> I don't think corrigibility is as anti-natural as people commonly make it out to be. I think the arguments for anti-naturality have hidden or under-scrutinized assumptions, so I'd like to go through them and address them. I haven't done a thorough literature review myself yet, so I'm not confident of what all the arguments and frameworks are. I think the basic argument is the argument against utility change, eg the ghandi murder pill argument. "You will predictably like the result of a universe optimized by a different utility function less." U(argmax(U)) ≥ U(argmax(U')). But corrigibility is just the desire to learn, grow, get better. Is that so anti-natural? Any change of utility function can be represented as a change in belief in an expanded sigma-algebra in which we add events representing utility, and representing the various possible utility functions (so we've got beliefs about values, and we then make decisions by taking linear expectation over this uncertainty, or perhaps some other rule). So we can think about change of belief instead of change of utility. But it is easy to come up with situations where change of belief is fine and desirable. Bayes updates are one example. More generally, any accuracy-increasing modification. Just have to obey the reflection principle. But we can always re-represent radical probabilist updates as classic bayesian updates in an expanded sigma algebra. This is called superconditioning. Sam Eisenstat observed that we can choose the expanded sigma algebra to be meta-beliefs, ie beliefs about what you believe; more concretely, the observation event is always "you believe this now" (you observe your new beliefs). This is an embedded-agency, radical-probabilist version of "observations": you observe your own mental state, rather than some inputs (eg retinas) on an agent boundary. The environment pushes the mental state around however it does. That pushing around may or may not be legitimate, ie accuracy-inducing, ie fit with the reflection principle. An incorrigible agent is just one that doesn't believe it has anything to learn from other agents. So long as learning is anticipated to be legitimate, the reflection principle holds, so there is no fully updated deference problem: a corrigible agent already believes what it expects to be legitimately taught. Failures of corrigibility result from failures of legitimacy detection, so it is crucial that such an agent have quite accurate beliefs on the subject of legitimacy, particularly for highly capable agents. It seems like the agent naturally wishes to maintain the legitimacy of its modifications, eg help repair the shutdown button. This is just a consequence of Good's theorem; information is valuable, and legitimate modifications are just "information channels". The shutdown button is an information channel.

### 2.1 Arguments by example (AGREED)

AUTHOR: "I agree that arguments by example, like murder pill, only establish resistance to value change for that example, and risk over-emphasizing such examples. ### 2.2 Non-realism about the value/belief distinction; nothing is a fixed object (AUTHOR, verbatim)

> But I am non-realist about the distinction: this is just a transformation in how we represent the agent. We can represent it as belief change or value change. It is the same change either way. […] Modeling something as an expected utility maximizer does not actually put any physical constraints on the system, so we are not exactly forced to have some 'fixed object'. The prior over value hypotheses: we can consider this changing as well. Indeed, that is what I had in mind when I talked about radical-probabilist updates: everything is allowed to change, with the sole exception of stuff that's set to probability zero becoming positive. (But the agent should obey non-dogmatism so that these things that are zero are only the logical impossibilities, so don't need to become nonzero.) But we can re-represent all those changes (via superconditioning) to make things bayesian again, if we wish. Again, I'm non-realist about the difference: it _is just_ a different representation of the same agent. We can even consider being corrigible to edits of the sigma algebra itself. "The Omohundro paragraph re-applies verbatim": and so does my response to that argument! the idea that the agent will harden and error-correct its legitimacy checks once again reasons from a 'typical case' where the environmental effects being hardened against are harmful noise rather than useful corrections. Again, the reality is that agents may or may not distrust specific sources of modification. The main problem here, I think, is merely representational: it is not obvious how to represent a Bayesian agent thinking about all the possible ways it could be modified. We need to make assumptions about the richness of the hypothesis space to rule out cases such as the oscillation between opiates and stimulants. (This is similar to the non-dognatism point.)

### 2.3 What survives of the utility-change argument (CLAUDE, offered; the author did not object)

Claude withdrew the claim that values-as-beliefs relocates a "fixed object" to the meta-level. What survives is relational: at each moment the agent's current state (its meta-beliefs about sources of modification, i.e. where reflection holds) arbitrates the legitimacy of the next change, and that arbiter is itself revisable next round. "Resists changes its current state judges illegitimate" is just what having a state means. Consequently every remaining anti-naturality argument has to be a *typical-case* claim that the agent's current legitimacy judgment will reject the overseers' actual corrections; none can be a structural theorem.

### 2.4 The representational problem (AUTHOR, OPEN)

From 2.2: "it is not obvious how to represent a Bayesian agent thinking about all the possible ways it could be modified. We need to make assumptions about the richness of the hypothesis space to rule out cases such as the oscillation between opiates and stimulants." The opiates/stimulants case is Soares et al. 2015 §1 and the Arbital Corrigibility page: a value-learner with an impoverished hypothesis space "updates" within its space and still resists shutdown.

### 2.5 No regress (AUTHOR; two CLAUDE clarifications)

AUTHOR: "the legitimacy-judging layer is just the same probability distribution used to judge everything else. So there is no infinite regress. This (more-or-less?) follows from my argument so far."

CLAUDE clarifications, offered and not contested: (i) that distribution lives on a self-referential space (beliefs about one's own future total belief-states), so "no regress" becomes an existence/consistency requirement — the representational problem of 2.4 in exact form; reflective oracles and logical induction are the known partial solutions (from memory, not from the corpus). (ii) No regress also means no outside view: the judge of the transition $t \to t+1$ is $P_t$, the judge at $t+1$ is $P_{t+1}$; an illegitimate transition that produces a self-endorsing successor is judged illegitimate only by the past self. The design load therefore sits on the *accuracy of $P_t$'s meta-conditionals about modification sources* — a first-order calibration requirement, not a regress. Precedent: Armstrong's sequential unbiasedness ($\mathbb{E}_{\rho_i}\mathbb{E}_{\rho_j}X = \mathbb{E}_{\rho_i}X$ for $i<j$) in "Double indifference is better indifference" is one reflection condition across the estimator sequence, and he shows it removes the estimator-manipulation incentive.

### 2.8 The MIRI 2015 model and a dictionary into the thesis (CLAUDE, working translation; the author engaged with it without objecting to the dictionary)

Soares, Fallenstein, Yudkowsky, Armstrong (2015), "Corrigibility", §2: three timesteps; $a_1 \in A_1$; programmers press or not; observation $o \in O$ with $\mathrm{Press} \subset O$; $a_2 \in A_2$; the agent has $p(o; a_1)$ and maximises $\mathbb{E}[U(a_1, o, a_2)]$; $U_N$ is the programmers' "first stab", "potentially flawed, and therefore untrusted"; $U_S$ "incentivizes shutdown" ($c_{high}$ if $\mathrm{Sh}(a_2)$, else $c_{low}$, with $\mathrm{Sh}$ a given predicate on $A_2$). Five desiderata on $U$: (1) shut down if pressed; (2) no incentive to prevent pressing; (3) no incentive to cause pressing; (4) successors/subagents only insofar as they obey shutdown; (5) otherwise maximise $U_N$. Absent from the model: world state, value uncertainty, any content in $o$ beyond the press.

| Paper | Thesis |
|---|---|
| $A_1, O, \mathrm{Press}, A_2$, timing | unchanged |
| $U(a_1,o,a_2)$ fixed | $V(a_1,o,a_2,\omega)$, $\omega$ a latent in the expanded algebra; agent holds $P$ over $(\omega,o)$ given $a_1$, maximises $\mathbb{E}_P[V\mid a_1]$ |
| $U_N$ untrusted first stab | $\mathbb{E}_P[V\mid\cdot]$ before observing; distrust = spread of $P$ over $\omega$ |
| $U_S$, $\mathrm{Sh}$ | no utility counterpart; $\mathrm{Sh}\subset A_2$ is a set of actions; "shuts down" means $A_2(a_1,\mathrm{Pr})\in\mathrm{Sh}$ is posterior-optimal |
| $o$ switches which utility applies | $o$ is evidence about $\omega$ |
| "incentivize" | same: what the $\mathbb{E}_P[V\mid a_1]$-maximiser does |
| legitimacy / reflection | invisible in the 3-step model (one conditioning step trivially satisfies reflection) until successors enter at desideratum 4 |

### 2.9 The sensor slot is the legitimacy criterion (AUTHOR); the Total Trust filler (CLAUDE)

The dictionary has one slot the paper never needs: the agent's model of *why* the programmers press, $P(\mathrm{Pr}\mid a_1,\omega)$. AUTHOR: "That sounds like a slot to be filled by the reflection principle, or something similar like Total Trust or increase-in-expected-accuracy depending on the exact formal setting. Basically the legitimacy criterion we're circling around."

CLAUDE, making it concrete: let $X = V(a_1,o,a_2^{\text{cont}},\omega) - V(a_1,o,a_2^{\text{sh}},\omega)$ (value of continuing over shutting down). Read $\mathrm{Pr}$ as a coarse expert report: the event that the programmers' expectation of $X$ is below zero. Total Trust toward the programmers on this domain is the below-threshold inequality $\mathbb{E}_P[X\mid\mathrm{Pr};a_1]\le 0$ (with the above-threshold twin for $\neg\mathrm{Pr}$); reflection is the same statement about one's own future estimate. This fills the slot with a constraint on the posterior rather than on the sensor, and buys desideratum 1 almost by definition, without any $U_S$. It cannot hold for every $a_1$: for the paper's manipulative action $a_1^-$ (dominated under $U_N$, lowers $p(\mathrm{Pr})$ by deceiving), unconditional trust makes the agent believe the silence it manufactured — desideratum 2 fails, and this is Taylor 2015's morality-sensor agent in the paper's own three steps.

### 2.10 Legitimacy as an event; legitimate versus legitimizing (AUTHOR, verbatim)

> Definitely holds for some actions and fails for others. More generally, for any random variable, it could hold for some values and fail for others. That's not a universal rule; there may be some random variables for which reflection always holds, I suppose, such as maybe a single-valued variable (in cases where illegitimacy is improbable enough and well-spread enough across the possibile beliefs that anything would be believed in expectation). But I'm not sure which variables legitimacy should crucially depend on. Legitimacy could be modeled as an event, which is a predicate of the whole world, so that an entire state of affairs is legitimate or not. Then a notion of legitimacy is minimally viable in the case that the reflection principle holds conditional on legitimacy. Probably better to make legitimacy at least proposition-dependent, so that we can talk about a specific future belief being legitimate. Ah, we could go proposition, time, time, indexing legitimacy by the moment judging legitimacy, the moment being judged for legitimacy, and the belief being vetted for legitimacy. That's L_t1_t2_phi(omega); still predicated on worlds, and there is of course no formal distinction between an index (subscript) and an argument (within parens). Except perhaps that indices can be class-valued, but I wasn't actually thinking about that. The point is there's not a major distinction between what legitimacy is predicated on (eg worlds) and what it is indexed by. I'm not sure it should be predicated on actions in particular. Maybe this just depends on what use we're putting the concept of legitimacy to. But this has all suggested a potentially interesting distinction to me: 'legitimate for'. The series of steps by which the evidence was submitted to the court was legitimate for the way it influenced the beliefs of the jurors. There's a locus of belief-changing activity, and then there's a locus of belief. One is in the 3rd person objective world, and the other is in the 1st person subjective view which we understand to exist via the intentional stance. I'm not sure "for" is the best construction here. In my current usage I'd be tempted to call the evidence-submission legitimate _and_ the induced beliefs legitimate. But that risks conflating different concepts, I think. One thing induces the reflection principle, conditionally, in the other. A crown supports the legitimacy of a king. The way the crown changed hands supports the king's legitimacy. The order is legitimate because it was issued by the king. Of course I don't in fact endorse these royalist examples. Perhaps I should be saying the democratic vote supports the legitimacy of the policy, etc. The point is the vote should be called legitimizing, not legitimate, strictly speaking. Similarly, actions can be delegitimizing.

### 2.11 A formal reading of the legitimizing relation (CLAUDE, offered; not contested)

With $L_{t_1,t_2,\varphi}(\omega)$ the event that the $t_2$-belief in $\varphi$ is legitimate as judged from $t_1$, minimal viability is
$$P_{t_1}\big(\varphi \mid P_{t_2}(\varphi)=c,\ L_{t_1,t_2,\varphi}\big)=c .$$
A third-person event $E$ (an action, evidence submitted, a vote) is *legitimizing* for $(t_2,\varphi)$ when conditioning on $E$ yields the same equation, or more weakly raises $P_{t_1}(L_{t_1,t_2,\varphi})$; *delegitimizing* when it breaks it or lowers that probability. $E$ lives in the world, $L$ is a property of the belief, and "supports" is the relation between them. Deception in 2.9 is a delegitimizing act for the agent's update on the button's silence; this is where the $a_1$-dependence of trust lives, without predicating legitimacy on actions.

### 2.13 The sorting (CLAUDE, offered; the author has not yet responded)

(a) *The skew belongs in the decision rule, not the prior.* Obeying an illegitimate shutdown is cheap and reversible; ignoring a legitimate one is the catastrophe. A calibrated agent already shuts down whenever $P(\text{wrong}\mid\text{press})\ge c/(c+h)$, $c$ the cost of stopping when right, $h$ the harm of continuing when wrong. So the prior over legitimacy should be accurate and the world arranged so legitimacy is in fact high — the author's second formulation, not his first.

(b) *The gold test cuts both ways: base rates.* Let $\varepsilon$ be the agent's residual probability of being wrong when it would continue, $\beta = P(\text{press}\mid\text{wrong})$, $\alpha = P(\text{press}\mid\text{right})$. Then
$$P(\text{wrong}\mid\text{press})=\frac{\varepsilon\beta}{\varepsilon\beta+(1-\varepsilon)\alpha},$$
and compliance stays rational only while $\alpha/\beta \lesssim \frac{\varepsilon}{1-\varepsilon}\cdot\frac{h}{c}$. As capability grows $\varepsilon$ falls; unless the false-press rate $\alpha$ falls with it, presses become rationally discounted — fully updated deference as arithmetic. The stakes ratio $h/c$ buys a large but bounded margin. Proposed as the missing "relationship between the quality of the legitimacy-model and the quality of the feedback-model": the oversight process's false-press rate must improve in step with the agent's accuracy on the domain where it might press, or the agent must keep believing it does.

(c) *Observability mostly dissolved.* Trust in the button can be earned through feedback about hypotheticals and about other agents' shutdowns; what survives is that this earns trust in the programmers' *reports*, a second channel whose legitimacy the agent must also model (bookkeeping, not an obstacle).
