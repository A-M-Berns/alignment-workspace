# Research state

Current lab state is emitted by:

```sh
python3 -m checkers.workspace_state --json
```

Validate it with `python3 -m checkers.workspace_state --check`. Program
interpretation, architecture, vocabulary exposition, and roadmap live in the
[GitHub wiki](https://github.com/A-M-Berns/alignment-workspace/wiki).

The query distinguishes modern registered claims from inherited foundation
claim sources. The Normativity consolidation remains a 180-claim foundation
under its own ledger and status vocabulary; it is not translated into the modern
registry.
